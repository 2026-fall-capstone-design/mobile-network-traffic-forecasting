# 합성 데모 실험 규약

현재 구현된 `synthetic-hourly-v1` 예제의 동작과 검증 범위입니다.
연구용 Milan-900-10min v1.0은 [공통 실험 규약](research-protocol.md)을 따릅니다.

## 데이터와 예측

| 항목 | 합성 데모의 조건 |
| --- | --- |
| 자료 | 3셀, UTC 2026-01-01 00:00–01-04 23:00, 셀당 96시간 |
| 입력 단위 | 합성 활동량, 정시의 1시간 간격 |
| 평가 | 01-04의 24시간 × 3셀 = 72개 표본 |
| `last-value` | 타깃 1시간 전 실제 관측값 |
| `seasonal-24h` | 타깃 24시간 전 실제 관측값 |
| 예측 | 새 실제 관측을 받아 다음 1시간의 한 시점을 예측 |

`origin_time`은 사용할 입력의 기준 시각, `timestamp`는 정확히 1시간 뒤의 타깃 시각입니다.
모델별 `(cell_id, origin_time, timestamp)`와 정답이 같아야 합니다.
선언한 평가 구간을 셀마다 빠짐없이 포함합니다.

## 데모 지표

| JSON 필드 | 계산 |
| --- | --- |
| `mae` | 전체 표본의 절대오차 평균 |
| `rmse` | 전체 표본의 제곱오차 평균에 제곱근을 적용한 pooled RMSE |
| `macro_rmse` | 셀별 RMSE의 동일 가중 평균 |
| `n_points`, `n_cells` | 평가 표본 수와 셀 수 |

[evaluation 모듈](../src/traffic_forecasting/evaluation/__init__.py)은 이 지표를 소수점 6자리로 저장합니다.
웹의 셀·구간 필터는 차트만 바꾸며 전체 지표를 재계산하지 않습니다.
데모의 RMSE는 연구 기본 비교의 주지표 raw macro MAPE를 대신하지 않습니다.

## 생성과 검증

1. [데이터 안내](../data/README.md)의 합성 예제와 `configs/demo.yaml`을 준비합니다.
2. `demo` 명령이 두 기준 모델의 예측을 생성합니다.
3. `Prediction`의 셀·시각·실제값·예측값으로 데모 지표를 계산합니다.
4. [웹 규약 v1](web-data-contract.md)에 따라 예측·지표·manifest JSON을 내보냅니다.
5. `check-data`와 예제 재현성 검사로 저장된 결과를 대조합니다.

이 경로는 연구용 900셀 집계·스케일러·결측 마스크·MAPE·3시드 평가의 구현이나 완료 증거가 아닙니다.
24시간 전 값은 10분 자료에서 144개 간격 전 값이므로 입력 8개의 연구 기본 조건에도 그대로 들어가지 않습니다.
