# 역할과 진행 기록

담당자 이름은 팀에서 정합니다. 다음은 권장 분담이며 고정 역할이 아닙니다.

| 역할 | 책임 |
|---|---|
| 데이터·기준 모델 | 데이터 준비, 전처리, 단순 기준 모델 |
| 모델 연구 | 군집화·예측 구현, 실험 설정 |
| 평가·연동 | 지표, 공정한 비교, 웹 JSON 생성 |
| 웹·배포 | 정적 화면, 필터·차트, Pages |

진행 기록은 이 폴더, 이슈, PR 중 편한 곳에 남깁니다. 이슈 작성을 강제하지 않습니다.
날짜, 완료 결과, 실행 조건, 결과 위치, 해석·한계, 다음 작업을 포함하면 좋습니다.

권장 마일스톤: 환경·예제 → 기준 모델 → 연구 비교 → 최종 데모·보고서.
