# 2026-10-23 — 공통 실험 기준 v1.2 반영

[개정 PDF v1.2](../standards/milan-900-10min-v1.2.pdf)의 11쪽 전체를 대조해 현재 연구 안내·결과 형식·실험 양식을 갱신했습니다.
현재 규칙은 [공통 실험 규약](../research-protocol.md)에 모으고, 원문과 이전 버전은 [기준 이력](../standards/README.md)에서 연결합니다.

## 기준 변경과 반영 위치

| PDF | 핵심 변경·확인 내용 | 반영 위치 |
| --- | --- | --- |

평가 파일의 기본 행 키는 PDF를 따릅니다. 검증·평가를 한 파일에 합칠 때는 겹치는 셀·시각을 구별하도록 `split`을 키에 추가합니다.
실험 이슈 양식은 새 기준의 필수 항목을 중심으로 정리하고, 과거 시도별 확인사항은 관련 원기록에서 찾도록 연결했습니다.

## 보존 범위

- v1.0 PDF와 2026-10-16의 반영 기록·결정 이력은 당시 기준으로 보존합니다.
- GECOS 643–974번의 세 요약은 기존 수치·조건·진행 상태를 유지하고 v1.2 재평가 결과가 아니라는 안내를 추가합니다.
- 기존 상세 기록·참고 문서와 519개 주제 표, 원본 근거 파일은 보존합니다.
- 합성 데모의 코드·데이터·스키마는 그대로이며, 웹 문서에는 연구 결과 연동에 필요한 조건을 표시합니다.

## 확인 범위

PDF 본문·표를 읽고 렌더된 11쪽을 대조했습니다. 사본의 SHA-256은 제공 파일과 동일합니다.
인덱스의 현지 시각, 후보 수와 셀별 유효 수의 합산, PDF의 작은 지표 예를 산술 대조했습니다.
평가 유효 1,283,738개 등의 데이터 통계는 PDF의 보고값이며 원시 데이터를 다시 계산한 결과가 아닙니다.

669개 Markdown의 구조·748개 표·11,156개 로컬 링크·2,443개 제목 앵커와 실험 이슈 YAML 검사를 통과했습니다.
187개 과거 상세·참고 문서의 본문, 519개 주제 표, 세 GECOS 요약의 안내를 제외한 본문이 보존됐음을 대조했습니다.
아카이브 검사는 1,494개 보존 파일의 바이트와 출처·로컬 링크를 확인했습니다.
이번 변경은 문서 기준의 갱신입니다. 새 모델 실행이나 기존 결과의 v1.2 재평가, 연구용 코드 구현 완료를 뜻하지 않습니다.
