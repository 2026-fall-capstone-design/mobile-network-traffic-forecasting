# 연구 결과 교환 형식

[공통 실험 규약](research-protocol.md)의 Milan-900-10min v1.0 결과를 팀원이 대조하기 위한 형식입니다.
근거는 [기준 PDF 8쪽](standards/milan-900-10min-v1.0.pdf)입니다.
CSV 또는 동등한 테이블을 사용하며, 이 형식은 현재 웹 JSON 스키마 v1과 별개입니다.

## 시드별 예측 테이블

평가 후보 전체 **648,000행을 시드마다 유지하는 방식**을 권장합니다.
그중 `valid_q8=True`인 **647,438행에는 모두 유한한 예측**이 있어야 합니다.
무효 창의 예측을 만들어 유효 표본으로 세지 않습니다.
평가 파일에서 `(model_id, config_id, seed, cell_id, timestamp_utc_ms)`가 행 식별 키입니다.

| 필드 | 의미·조건 |
| --- | --- |
| `model_id`, `config_id` | 모델·확정 설정 식별자. 구조·버전은 실행 명세에 기록 |
| `seed` | 53, 54, 55 |
| `split` | `train`, `validation`, `evaluation` 등 구간 이름 |
| `cell_id` | 원래 셀 ID. 배열 열 번호로 대체하지 않음 |
| `timestamp_utc_ms` | 타깃 구간의 시작 시각, UTC 정수 밀리초 |
| `y_true_raw` | 집계 후 정규화 이전 정답. 결측이면 빈 필드와 마스크로 표시 |
| `y_pred_raw` | 원 척도 예측. 유효 표본에서는 누락·NaN·무한대 금지 |
| `valid_q8` | 입력 8개와 타깃이 모두 유한한 공통 데이터 마스크 |
| `mape_eligible` | `valid_q8=True`이고 `y_true_raw > 0` |

표본 정렬은 원래 셀 ID와 타깃 시각으로 확인합니다.
모델별 예측 실패로 행을 삭제하거나 마스크를 다시 만들지 않습니다.
파일을 합칠 때는 모델·설정·시드·구간을 명시하고 동일 키의 중복을 검사합니다.

## 시드별 요약과 셀별 지표

| 저장할 항목 | 의미 |
| --- | --- |
| MAPE(%)와 MAPE 비율 | 원 척도 셀별 MAPE의 동일 가중 평균과 그 값/100 |
| macro MAE, micro MAE | 셀 동일 가중과 유효 행 동일 가중의 원 척도 MAE |
| 유효 행 수 | `valid_q8=True`인 표본 수 |
| MAPE 양수 타깃 수 | `mape_eligible=True`인 표본 수 |
| MAPE 포함·제외 셀 수 | 양수 타깃이 있는 셀과 없는 셀의 개수 |
| 0 타깃 수 | 유효 표본 중 정답 0의 개수; MAE에는 포함 |
| 셀별 결과 | 셀 ID, 유효 수, 양수 타깃 수, MAE, MAPE와 정의 가능 여부 |

시드 53·54·55의 개별 값과 평균·표본 표준편차(`ddof=1`)를 함께 제공합니다.
같은 시드끼리 기준 모델과의 차이를 계산합니다.
MAPE(%) 차이의 단위는 **퍼센트포인트(%p)**, 상대 개선율의 단위는 **%**입니다.
MAPE가 정의되지 않는 셀이나 전체 결과를 0점으로 채우지 않습니다.

## 실행 명세

| 범주 | 남길 정보 |
| --- | --- |
| 데이터 | 기준 버전, 원시·처리 파일 위치와 해시, 셀 900개와 시각 4,320개의 순서 |
| 전처리 | 집계 규칙, 저장 `lo`·`scale`, 스케일러·마스크 해시 |
| 모델 | 코드 커밋, 모델·가중치 버전, 구조, 사전학습·추가 입력 사용 여부 |
| 선택 | 검증 정규화 macro MAE, 선택 설정·checkpoint·epoch, 동률 처리 |
| 학습 | 손실·학습률·배치·예산·종료 규칙·탐색 횟수·시드 |
| 실행 | 명령·설정, 환경·장치, 실패·재시도·재사용 여부와 실제 실행 수 |
| 결과 | 예측·셀별 지표·요약·로그 위치, 기본 비교 또는 추가 조건 실험 구분 |

파일 형식이 다르면 파일 해시도 다릅니다. 해시와 함께 배열값·ID·시각의 동등성을 확인합니다.
원시 데이터와 큰 실행 결과는 [Git 제외 저장 위치](../data/README.md#저장-위치)에 보관하고 팀 공유 경로를 남깁니다.

## 시간과 메모리

전처리, 모델 준비·학습, 예측, 파일 입출력을 나누어 측정하고 전체 비용도 보고합니다.
같은 장비와 측정 구간을 사용하며, GPU 작업 완료를 동기화한 뒤 시간을 멈춥니다.
첫 실행과 캐시를 사용한 반복 실행을 구분합니다.
GPU 전용 메모리와 시스템 RAM을 따로 기록하고 공유 메모리를 전용 VRAM에 더하지 않습니다.
다른 장비에서 얻은 논문 시간과 직접 속도 우위를 계산하지 않습니다.

## 현재 웹과 연결하기 전

현재 [웹 규약 v1](web-data-contract.md)은 1시간 간격의 완전한 예측열과 MAE/RMSE를 사용합니다.
연구 결과를 억지로 시간 평균하거나 유효하지 않은 행을 채워 이 형식에 넣지 않습니다.
10분 시각·결측 마스크·MAPE 단위·셀 가중·반복 시드를 지원하도록 스키마와 코드가 확장되면
동일 예측 테이블에서 내보내고 원 결과와 다시 대조합니다.
