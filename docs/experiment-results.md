# 연구 결과 교환 형식

[공통 실험 규약](research-protocol.md)의 **Milan-900-10min v1.2** 결과를 팀원이 대조하기 위한 형식입니다.
근거는 [기준 PDF 9쪽](standards/milan-900-10min-v1.2.pdf)입니다.
CSV 또는 동등한 테이블을 사용하며, 이 형식은 현재 웹 JSON 스키마 v1과 별개입니다.

## 실행별 예측 테이블

평가 후보 전체 **1,284,300행을 실행마다 유지하는 방식**을 권장합니다.
그중 `valid_q8=True`인 **1,283,738행에는 모두 유한한 예측**이 있어야 합니다.
무효 창의 예측을 만들어 유효 표본으로 세지 않습니다.
평가 파일에서 `(protocol_id, run_id, cell_id, timestamp_utc_ms)`가 행 식별 키입니다.

| 필드 | 의미·조건 |
| --- | --- |
| `protocol_id` | 데이터·분할·집계 규칙 버전. 이 기준은 `Milan-900-10min-v1.2`로 표기 |
| `run_id` | 모델·설정·시드 또는 앙상블 구성을 유일하게 식별 |
| `model_id`, `config_id` | 모델·확정 설정 식별자. 구조·버전은 실행 명세에 기록 |
| `seed` | 단일 확률적 실행은 53, 54, 55; 앙상블을 단일 시드로 표시하지 않음 |
| `ensemble_id` | 앙상블인 경우 별도 ID. 구성 모델·실행·시드·가중치 목록은 실행 명세에 저장 |
| `split` | `train`, `validation`, `evaluation` 등 구간 이름 |
| `cell_id` | 원래 셀 ID. 배열 열 번호로 대체하지 않음 |
| `timestamp_utc_ms` | 타깃 구간의 시작 시각, UTC 정수 밀리초. 입력 마지막 시각이 아님 |
| `y_true_raw` | 집계 후 정규화 이전 정답. 결측이면 빈 필드와 마스크로 표시 |
| `y_pred_raw` | 원 척도 예측. 유효 표본에서는 누락·NaN·무한대 금지 |
| `valid_q8` | 입력 8개와 타깃이 모두 유한한 공통 데이터 마스크 |
| `mape_eligible` | `valid_q8=True`이고 `y_true_raw > 0` |

표본 정렬은 원래 셀 ID와 타깃 시각으로 확인합니다.
모델별 예측 실패나 작은 양수 정답을 이유로 행·셀을 삭제하거나 마스크를 다시 만들지 않습니다.
원 정답·계수·역변환·채점은 float64로 다루고, 정답은 저장된 원 척도 배열에서 읽습니다.

위 키는 구간별 파일에 적용합니다. **검증·평가를 한 테이블에 합칠 때는 키에 `split`을 추가**합니다.
평가 타깃이 검증의 부분집합이므로 같은 셀·시각이 두 구간에 나타나는 것을 삭제하거나 두 독립 표본으로 합산하지 않습니다.
동일 구간 내 키 중복은 오류로 확인합니다.

## 시드별 요약과 셀별 지표

| 저장할 항목 | 의미 |
| --- | --- |
| raw micro MAPE(%)와 비율 | 우선 보고. 모든 유효 양수 타깃의 상대오차 평균과 그 값 × 100 |
| raw micro MAE | 우선 병기. 모든 유효 표본의 절대오차 평균, 원 활동량 단위 |
| raw macro MAPE(%)와 비율 | 필수 병기. 양수 타깃이 있는 셀별 MAPE의 동일 가중 평균 |
| raw macro MAE | 필수 병기. 셀별 MAE의 동일 가중 평균, 원 활동량 단위 |
| 유효 행 수 | `valid_q8=True`인 표본 수 |
| MAPE 양수 타깃 수 | `mape_eligible=True`인 표본 수; micro MAPE의 분모 |
| MAPE 포함·제외 셀 수 | 양수 타깃이 있는 셀과 없는 셀의 개수 |
| 0 타깃 수 | 유효 표본 중 정답 0의 개수; MAE에는 포함 |
| 셀별 결과 | 셀 ID, 유효 수, 양수 타깃 수, MAE, MAPE와 정의 가능 여부 |

양수 타깃이 없는 셀은 macro MAPE에서 제외하고, 전체에 양수 타깃이 없으면 두 MAPE 모두 미정의입니다.
MAPE가 정의되지 않는 셀이나 전체 결과를 0점으로 채우지 않습니다.
분모에 epsilon을 더하지 않고, 예측을 0 이상으로 자르지 않습니다. 반올림은 모든 계산을 마친 뒤 표시할 때만 합니다.

시드 53·54·55의 개별 값과 **점수 평균·표본 표준편차(`ddof=1`)**를 제공합니다.
예측을 표본별로 평균한 뒤 다시 채점한 **앙상블 점수는 별도 `run_id`와 별도 행**으로 보고합니다.
앙상블 구성·가중치는 검증에서 고정하고, 같은 구성 수·예측 집합의 단순 평균 기준을 함께 제시합니다.
개별 시드 모델 대비 개선과 단순 평균 앙상블 대비 추가 개선을 구분합니다.

같은 조건·같은 시드끼리 기준 모델과의 차이를 계산합니다.
MAPE(%) 차이의 단위는 **퍼센트포인트(%p)**, 상대 개선율의 단위는 **%**입니다.
상대 개선율은 `(기준 오차 - 제안 오차) / 기준 오차 * 100`이며 기준 오차가 0이면 미정의입니다.
데이터·정규화·타깃·마스크·집계가 다른 결과끼리 개선율을 계산하지 않습니다.

## 실행 명세

| 범주 | 남길 정보 |
| --- | --- |
| 식별 | `protocol_id`, `run_id`, 모델·설정·시드 또는 앙상블 ID와 구성 목록 |
| 데이터 | 원시·처리 파일 위치와 해시, 셀 900개·시각 4,320개의 배열 순서와 각각의 해시 |
| 전처리 | 집계 규칙, 전체 30일 scaler fit `[0,4320)`, 저장 `lo`·`scale`·상수 셀 여부, 스케일러·마스크 해시 |
| 타깃 | 학습 `[8,2872)`, 검증 `[2888,4320)`, 평가 `[2893,4320)`, 입력 q8 |
| 평가 해석 | 검증·평가 중복과 전체 30일 통계 사용, `independent_test=false` |
| 정밀도 | 원 배열·계수·역변환·채점 float64, 모델 입력·학습 dtype과 `val_loss` float32 경로 구분 |
| 모델 | 코드 커밋, 모델·가중치 버전, 구조, 추가 입력·사전학습·온라인 갱신 및 적합 범위 |
| 선택 | 각 학습 모델의 유효 검증표본 전체 정규화 MAE, 선택 설정·checkpoint·epoch, 동률 처리, 평가 전 가중치 복원 |
| 학습 | 손실·학습률·배치·예산·종료 규칙·탐색 횟수·시드·초기 가중치 공유 여부 |
| 실행 | 명령·설정, 환경·장치, 실패·재시도·재사용 여부와 실제 실행 수 |
| 결과 | 예측·셀별 지표·요약·로그 위치, 기본 비교 또는 추가 조건 실험 구분 |

파일 형식이 다르면 파일 해시도 다릅니다. 해시와 함께 배열값·ID·시각의 동등성을 확인합니다.
원시 데이터와 큰 실행 결과는 [Git 제외 저장 위치](../data/README.md#저장-위치)에 보관하고 팀 공유 경로를 남깁니다.

## 시간과 메모리

전처리, 모델 준비·학습, 예측, 파일 입출력을 나누어 측정하고 전체 비용도 보고합니다.
같은 장비와 측정 구간을 사용하며, GPU 작업 완료를 동기화한 뒤 시간을 멈춥니다.
첫 실행과 캐시를 사용한 반복 실행을 구분합니다.
GPU 전용 메모리와 시스템 RAM을 따로 기록하고 공유 메모리를 전용 VRAM에 더하지 않습니다.
다른 장비에서 얻은 논문 시간과 직접 속도 우위를 계산하지 않습니다.

## 현재 웹과 연결하기 전

현재 [웹 규약 v1](web-data-contract.md)은 1시간 간격의 완전한 예측열과 MAE/RMSE를 사용합니다.
연구 결과를 억지로 시간 평균하거나 유효하지 않은 행을 채워 이 형식에 넣지 않습니다.
10분 시각·결측 마스크·네 지표·집계 단위·시드와 앙상블·프로토콜 버전을 지원하도록 스키마와 코드가 확장되면
동일 예측 테이블에서 내보내고 원 결과와 다시 대조합니다.
