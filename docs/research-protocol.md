## 데이터와 시간축

PDF 2쪽 기준입니다. Telecom Italia 밀라노 자료의 **Internet activity**를 사용합니다.
물리적 바이트·MB나 실제 접속 건수로 환산하지 않으며, MAE의 단위는 원 데이터의 활동량 단위입니다.

| 항목 | 고정값 |
| --- | --- |
| 셀 ID | `100*r + c`, `r = 40..69`, `c = 40..69`, 각각 양 끝 포함 |
| 셀 수·정렬 | 30 × 30 = 900개, 원래 ID 오름차순 |
| 기간 | Europe/Rome 현지 2013-11-01 00:00부터 11-30 23:50까지 |
| 간격·배열 | 10분, 시간 4,320행 × 셀 900열 |
| 저장 시각 | UTC Unix epoch 밀리초, 64비트 정수 |
| 현지 시간대 | `Europe/Rome`, 해당 11월은 UTC+01:00 |
| 첫 시각 | `1383260400000` ms = UTC 2013-10-31 23:00 |
| 마지막 시각 | `1385851800000` ms = UTC 2013-11-30 22:50 |
| 행 인덱스 | `t = 0..4319`, `timestamp(t) = 1383260400000 + 600000*t` |

셀 집합은 `4040–4069, 4140–4169, …, 6940–6969`입니다.
4040부터 6969 사이의 모든 정수를 선택하지 않습니다. 10,000셀 실험은 별도 규모로 보고합니다.
타임스탬프는 구간 시작입니다. 현지 00:00은 `[00:00, 00:10)`의 활동량을 뜻합니다.
UTC 날짜로 먼저 11월을 자르면 월 경계가 달라지므로 현지 기간으로 선택합니다.

## 집계와 정규화

PDF 3쪽 기준입니다. 원시 TSV의 0-based 열 번호는 셀 ID `0`, 시각 `1`, 국가코드 `2`, Internet `7`입니다.

1. `(cell_id, timestamp, country_code)` 중복은 원인을 해결합니다. 중복 행을 그대로 더하지 않습니다.
2. 지정한 900셀과 현지 11월의 10분 격자를 선택합니다.
3. 같은 셀·시각의 유한한 Internet 값을 국가코드에 걸쳐 합산합니다.
4. 유한한 값이 하나도 없거나 행이 없으면 `NaN`으로 둡니다. 일부 국가코드만 결측이면 나머지 유한한 값의 합을 사용합니다.

관측된 0은 결측이 아닙니다. 음수·무한대 원시 값은 데이터 오류입니다.
국가코드 평균, SMS·통화 합산, 시간 평균이나 시간별 재표본화는 적용하지 않습니다.

셀별 계수는 **학습 20일 전체 `y[0:2880, i]`**에서 계산하고 고정합니다.
첫 8개 관측도 계수 계산에 포함합니다.

```text
lo_i = min(y[0:2880, i])
hi_i = max(y[0:2880, i])
scale_i = hi_i - lo_i
if scale_i <= 1e-12: scale_i = 1
z[t,i] = (y[t,i] - lo_i) / scale_i
y_pred_raw[t,i] = z_pred[t,i] * scale_i + lo_i
```

기준 데이터의 학습 20일은 모두 유한합니다. 이 조건이 깨지면 데이터 버전 차이를 먼저 확인합니다.
검증·평가로 계수를 재적합하지 않으며, 이후 값이 0–1을 벗어나도 자르지 않습니다.
음수 예측도 자르지 않습니다. 추가 로그 변환·이상치 제거·평활화·전체 셀 공통 스케일러는 별도 실험입니다.
집계·계수·최종 지표는 float64를 권장합니다. 모델 입력이 float32여도 같은 저장 계수로 역변환합니다.

## 기간 분할과 예측 입력

PDF 4쪽 기준입니다. 분할은 입력 창의 시작이 아니라 **타깃 시각**으로 정합니다.

| 용도 | 타깃의 현지 시각 | 0-based 타깃 인덱스 | 셀당 후보 수 |
| --- | --- | --- | --- |
| 학습 | 11/01 01:20–11/20 23:50 | `8 <= t < 2880` | 2,872 |
| 검증 | 11/21 00:00–11/25 23:50 | `2880 <= t < 3600` | 720 |
| 평가 | 11/26 00:00–11/30 23:50 | `3600 <= t < 4320` | 720 |

```text
X[t,i] = [z[t-8,i], ..., z[t-1,i]]
target[t,i] = z[t,i]
```

타깃 구간이 시작되기 직전에 직전 8개 구간의 실제 관측으로 다음 10분 값 하나를 예측합니다.
다음 시점에는 새로 관측된 실제 값을 입력에 넣습니다. 예측값을 되먹임하는 재귀 다단계 과제와 구분합니다.

| 첫 타깃 | 입력 구간의 시작 시각 |
| --- | --- |
| 11/01 01:20 | 11/01 00:00, 00:10, …, 01:10 |
| 11/21 00:00 | 11/20 22:40, 22:50, …, 23:50 |
| 11/26 00:00 | 11/25 22:40, 22:50, …, 23:50 |

분할 경계에서 처음 8개 타깃을 다시 버리지 않습니다.
평가 구간 안에서도 이미 관측된 과거값을 다음 입력으로 사용할 수 있지만,
검증·평가 정답으로 모델 가중치나 스케일러를 다시 학습하지 않습니다.
학습 미니배치는 섞을 수 있으나 시간축의 학습·검증·평가 행을 무작위로 분할하지 않습니다.

기본 예측 입력은 대상 셀의 직전 8개 Internet 값입니다.
학습에는 같은 900셀의 학습기간을 사용할 수 있습니다.
순환 모델의 숨은 상태·특징 캐시도 창 밖 정보를 추가로 전달하지 않도록 범위를 맞춥니다.
다른 셀의 예측 입력, 외생변수, 긴 입력, 사전학습·온라인 갱신을 쓰면 사용 범위를 밝히고 기본 조건과 구분합니다.

## 결측과 공통 표본

PDF 5쪽 기준입니다. 마스크는 모델·예측과 무관하게 동일 원자료로 한 번 계산합니다.

```text
valid_q8[t,i] = all(isfinite(y[t-8:t+1, i]))
mape_eligible[t,i] = valid_q8[t,i] and (y[t,i] > 0)
```

NaN을 0으로 바꾸거나 보간·전방 채우기·후방 채우기를 하지 않습니다.
4,320행 시간축을 유지하고 유효하지 않은 창만 제외합니다.

| 구간 | 후보 표본 | 유효 표본 | 제외 표본 |
| --- | --- | --- | --- |
| 학습 | 2,584,800 | 2,584,800 | 0 |
| 검증 | 648,000 | 648,000 | 0 |
| 평가 | 648,000 | 647,438 | 562 |
| 합계 | 3,880,800 | 3,880,238 | 562 |

이 수치는 **제공 PDF에 명시된 기준 데이터의 확인값**입니다. 이번 문서 수정에서 원시 데이터를 새로 검산한 값은 아닙니다.
PDF에는 결측 셀·시점 188개(11/29 92개, 11/30 96개), 결측이 있는 셀 2개,
셀별 평가 유효 표본 439–720개, 유한한 값 중 정확한 0 없음이 기록되어 있습니다.
188개 결측과 562개 제외 창은 서로 다른 집계입니다.

유효 표본의 예측 누락·NaN·무한대는 실행 실패입니다. 실패한 행만 빼고 점수를 계산하지 않습니다.
더 긴 입력을 사용하면 별도 실험으로 입력 길이·변경된 마스크·표본 수를 공개합니다.

## 평가 지표

PDF 6쪽 기준입니다. 모든 예측을 원 활동량 척도로 역변환한 뒤 셀별 지표를 계산합니다.
`V_i`는 셀 i의 유효 시점, `V_i+`는 그중 정답이 양수인 시점입니다.

```text
MAE_i = mean(abs(y - pred))                   # t in V_i
MAPE_i_percent = 100 * mean(abs(y-pred) / y)   # t in V_i+
macro_MAE = mean(MAE_i)                       # 셀 동일 가중
macro_MAPE_percent = mean(MAPE_i_percent)     # 양수 타깃이 있는 셀 동일 가중
MAPE_ratio = macro_MAPE_percent / 100
micro_MAE = sum(abs(y-pred)) / total_valid_rows
```

| 역할 | 지표 | 보고 단위 |
| --- | --- | --- |
| 주지표 | raw macro MAPE | `%`, 비율값도 함께 저장 |
| 필수 보조지표 | raw macro MAE | 원 데이터의 활동량 단위, 셀 동일 가중 |
| 필수 보조지표 | raw micro MAE | 원 데이터의 활동량 단위, 유효 표본 동일 가중 |

정답 0은 MAE에는 포함하고 MAPE에서만 제외합니다. MAPE 분모에 epsilon을 넣거나 작은 양수 정답을 제외하지 않습니다.
양수 타깃이 없는 셀은 MAPE 평균에서 제외하고 셀 수를 보고합니다. 전체에 양수가 없으면 MAPE는 미정의입니다.
음수 정답은 오류이며 음수 예측은 그대로 오차에 반영합니다.
모델별·군집별 평균을 다시 평균내지 말고 전체 셀 결과로 집계합니다. 반올림은 최종 표시 단계에서만 합니다.

계산 예로 A 셀의 `1→0, 2→3`, B 셀의 `0→1, 4→2, 6→9`에서는
macro MAPE **62.5%**(비율 **0.625**), macro MAE **1.5**, micro MAE **1.6**입니다.
MAPE 비율 0.10은 10%이며 0.10%가 아닙니다. MAPE 차이는 `%p`, 상대 개선율은 `%`로 표시합니다.

## 설정 선택과 반복

PDF 7쪽 기준입니다. 모델 구조·학습률·배치 크기·손실·학습 예산·종료 규칙·탐색 설정 수는 모델별로 공개합니다.
모든 선택은 평가 구간을 보기 전에 확정합니다.

| 항목 | 규칙 |
| --- | --- |
| 선택 점수 | 검증 구간의 **정규화 척도 셀별 MAE를 동일 가중 평균**한 값 |
| 설정·checkpoint | 선택 점수가 가장 낮은 것 |
| 같은 설정의 epoch 동률 | 정확한 동률이면 이른 epoch |
| 검증 이후 재학습 | 검증까지 합친 재학습은 기본 비교에서 제외 |
| 반복 시드 | `53`, `54`, `55`; 매번 난수 생성기·모델 상태 초기화 |
| 보고 | 시드별 값, 3회 평균, 표본 표준편차 `ddof=1`, 같은 시드끼리 모델 차이 |

학습 손실·검증 선택 점수·최종 평가 주지표는 각각 기록합니다.
같은 시드가 다른 구조의 같은 초기 가중치나 GPU 비트 재현성을 뜻하지는 않습니다.
3시드는 한 평가기간의 학습 무작위성 반복이며 독립된 3개 기간이나 자동적인 99% 신뢰구간이 아닙니다.
결정적 모델의 결과를 재사용하면 실제 실행 수와 재사용 수를 구분합니다.
