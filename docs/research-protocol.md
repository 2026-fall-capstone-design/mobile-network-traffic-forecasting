## 데이터와 시간축

PDF 3쪽 기준입니다. Telecom Italia 밀라노 자료의 **Internet activity**를 사용합니다.
물리적 바이트·MB나 실제 접속 건수로 환산하지 않으며, MAE의 단위는 원 데이터의 활동량 단위입니다.

| 항목 | 고정값 |
| --- | --- |
| 셀 ID | `100*r + c`, `r = 40..69`, `c = 40..69`, 각각 양 끝 포함 |
| 셀 수·정렬 | 30 × 30 = 900개, 원래 ID 오름차순 |
| 기간 | Europe/Rome 현지 2013-11-01 00:00부터 11-30 23:50까지 |
| 간격·배열 | 10분, 시간 4,320행 × 셀 900열 |
| 저장 시각 | UTC Unix epoch 밀리초, 64비트 정수 |
| 현지 시간대 | `Europe/Rome`, 해당 11월은 UTC+01:00 |
| 첫 시각 | `1383260400000` ms = UTC 2013-10-31 23:00 |
| 마지막 시각 | `1385851800000` ms = UTC 2013-11-30 22:50 |
| 행 인덱스 | `t = 0..4319`, `timestamp(t) = 1383260400000 + 600000*t` |

셀 집합은 `4040–4069, 4140–4169, …, 6940–6969`입니다.
4040부터 6969 사이의 모든 정수를 선택하지 않습니다. 10,000셀 실험은 별도 규모로 보고합니다.
타임스탬프는 구간 시작입니다. 현지 00:00은 `[00:00, 00:10)`의 활동량을 뜻합니다.
UTC 날짜로 먼저 11월을 자르면 월 경계가 달라지므로 현지 기간으로 선택합니다.

## 집계와 정규화

PDF 4쪽 기준입니다. 원시 TSV의 0-based 열 번호는 셀 ID `0`, 시각 `1`, 국가코드 `2`, Internet `7`입니다.

1. `(cell_id, timestamp, country_code)` 중복은 원인을 해결합니다. 중복 행을 그대로 더하지 않습니다.
2. 지정한 900셀과 현지 11월의 10분 격자를 선택합니다.
3. 같은 셀·시각의 유한한 Internet 값을 국가코드에 걸쳐 합산합니다.
4. 유한한 값이 하나도 없거나 행이 없으면 `NaN`으로 둡니다. 일부 국가코드만 결측이면 나머지 유한한 값의 합을 사용합니다.

관측된 0은 결측이 아닙니다. 음수·무한대 원시 값은 데이터 오류입니다.
국가코드 평균, SMS·통화 합산, 시간 평균이나 시간별 재표본화는 적용하지 않습니다.

셀별 계수는 **전체 30일 `y[0:4320, i]`의 유한한 관측**에서 계산하고 고정합니다.
각 셀에 적어도 하나의 유한 관측이 있어야 하며 결측은 통계에서 제외하고 원 배열에는 보존합니다.

```text
lo_i = nanmin(y[0:4320, i])
hi_i = nanmax(y[0:4320, i])
scale_i = hi_i - lo_i
if scale_i <= 1e-12: scale_i = 1
z[t,i] = (y[t,i] - lo_i) / scale_i
y_pred_raw[t,i] = z_pred[t,i] * scale_i + lo_i
```

뒤 10일의 극값도 학습 데이터의 척도에 반영됩니다. 학습기간만의 정보를 사용하는 전처리로 설명하지 않습니다.
현재 30일의 유한 관측은 정규화 후 0–1에 들어가지만, 예측을 이 범위나 0 이상으로 자르지 않습니다.
셀별 `lo`·`scale`·상수 셀 여부를 저장합니다. 학습 20일 스케일러, 추가 로그 변환·이상치 제거·평활화 등은 별도 조건입니다.

저장 원 척도 배열과 계수, 역변환·최종 지표는 **float64**로 다룹니다.
모델 입력·학습은 float32를 사용할 수 있지만, 채점 정답은 저장된 원 척도 배열에서 가져옵니다.
float32로 변환한 정답을 다시 역변환해 채점하지 않습니다.

## 기간 분할과 예측 입력

PDF 5쪽 기준입니다. 분할은 입력 창의 시작이 아니라 **타깃 시각**으로 정합니다.
달력상 20일/10일의 모든 타깃을 사용하는 것이 아니라 제공 코드의 창 경계를 보존합니다.

| 용도 | 타깃의 현지 시각 | 0-based 타깃 인덱스 | 셀당 후보 수 |
| --- | --- | --- | --- |
| 학습 | 11/01 01:20–11/20 22:30 | `8 <= t < 2872` | 2,864 |
| 검증 | 11/21 01:20–11/30 23:50 | `2888 <= t < 4320` | 1,432 |
| 평가 | 11/21 02:10–11/30 23:50 | `2893 <= t < 4320` | 1,427 |

```text
X[t,i] = [z[t-8,i], ..., z[t-1,i]]
target[t,i] = z[t,i]
```

학습 영역 끝의 8개 타깃을 사용하지 않고, 검증은 21일 01:20부터 시작합니다.
평가 시작은 검증보다 5시점(50분) 늦습니다. 경계에서 빠진 타깃을 임의로 복원하지 않습니다.

| 첫 타깃 | 입력 구간의 시작 시각 |
| --- | --- |
| 11/01 01:20 | 11/01 00:00, 00:10, …, 01:10 |
| 11/21 01:20 | 11/21 00:00, 00:10, …, 01:10 |
| 11/21 02:10 | 11/21 00:50, 01:00, …, 02:00 |

타깃 구간이 시작되기 직전에 직전 8개 구간의 실제 관측으로 다음 10분 값 하나를 예측합니다.
다음 시점에는 새로 관측된 실제 값을 입력에 넣습니다. 예측값을 되먹임하는 재귀 다단계 과제와 구분합니다.
학습 미니배치는 섞을 수 있으나 시간축을 무작위로 분할하지 않습니다.

모델 가중치의 경사 업데이트에는 위 학습 타깃을 사용합니다.
정규화에는 전체 30일 통계를, 설정·checkpoint 선택에는 뒤 10일의 검증 정답을 사용합니다.
평가는 검증의 부분집합이므로 독립 시험으로 해석하지 않으며, 검증·평가를 5일씩 나누지 않습니다.
비교 후보·시드·탐색 예산·선택 규칙은 실행 전에 정하고 모든 시도와 선택을 기록합니다.
별도 평가 결과를 본 뒤 유리한 실행만 남기지 않습니다.

기본 예측 입력은 대상 셀의 직전 8개 Internet 값입니다. 학습에는 같은 900셀의 학습기간을 사용할 수 있습니다.
숨은 상태·특징 캐시도 직전 8개 입력 조건에 맞춥니다. 타깃 시점의 실제 값을 입력에 넣지 않습니다.
다른 셀의 예측 입력, 외생변수, 긴 입력, 사전학습·온라인 갱신, 별도 학습형 변환·추가 특징은
사용·적합 범위를 명시하고 기본 조건과 구분합니다.

## 결측과 공통 표본

PDF 6쪽 기준입니다. 마스크는 모델·예측과 무관하게 동일 원자료로 한 번 계산합니다.

```text
valid_q8[t,i] = all(isfinite(y[t-8:t+1, i]))
mape_eligible[t,i] = valid_q8[t,i] and (y[t,i] > 0)
```

NaN을 0으로 바꾸거나 보간·전방 채우기·후방 채우기를 하지 않습니다.
4,320행 시간축을 유지하고 유효하지 않은 창만 제외합니다.

| 구간 | 후보 표본 | 유효 표본 | 제외 표본 |
| --- | --- | --- | --- |
| 학습 | 2,577,600 | 2,577,600 | 0 |
| 검증 | 1,288,800 | 1,288,238 | 562 |
| 평가 | 1,284,300 | 1,283,738 | 562 |

검증과 평가가 겹치므로 세 수를 독립 표본의 총수처럼 더하지 않습니다.
이 수치는 **제공 PDF에 명시된 기준 데이터의 확인값**이며, 이번 문서 수정에서 원시 데이터를 새로 검산한 값은 아닙니다.
PDF에는 결측 셀·시점 188개(11/29 92개, 11/30 96개), 결측이 있는 셀 2개,
유한한 값 중 정확한 0 없음이 기록되어 있습니다. 188개 결측과 562개 제외 창은 서로 다른 집계입니다.

898셀은 검증 1,432개·평가 1,427개가 유효하고, 결측이 있는 두 셀은 각각 검증 1,151개·평가 1,146개가 유효합니다.
검증에서도 셀별 유효 표본 수가 달라 macro와 micro가 같다고 가정할 수 없습니다.
유효 표본의 예측 누락·NaN·무한대는 실행 실패입니다. 실패한 행이나 오차가 큰 셀만 빼고 점수를 계산하지 않습니다.
더 긴 입력을 사용하면 별도 실험으로 입력 길이·변경된 마스크·표본 수를 공개합니다.

## 평가 지표

PDF 7쪽 기준입니다. 예측을 저장 계수로 원 활동량 척도로 역변환하고 **float64**로 채점합니다.
`V_i`는 셀 i의 유효 시점, `V_i+`는 그중 정답이 양수인 시점입니다.

```text
MAE_i = mean(abs(y - pred))                 # t in V_i
MAPE_i_ratio = mean(abs(y-pred) / y)         # t in V_i+
macro_MAE = mean(MAE_i)                     # equal cells
macro_MAPE_ratio = mean(MAPE_i_ratio)       # eligible cells
micro_MAE = sum(abs(y-pred)) / total_valid_rows
micro_MAPE_ratio = sum(abs(y-pred)/y) / total_positive_rows
macro_MAPE_percent = 100 * macro_MAPE_ratio
micro_MAPE_percent = 100 * micro_MAPE_ratio
```

micro MAE의 합은 모든 유효 표본, micro MAPE의 합은 모든 **유효 양수 타깃**을 대상으로 합니다.
양수 타깃이 있는 셀만 macro MAPE에 포함합니다. 임의 그룹의 평균을 다시 평균내지 않습니다.

| 역할 | 지표 | 집계·단위 |
| --- | --- | --- |
| 주지표 | raw micro MAPE | 유효 양수 타깃 동일 가중, `%`와 비율 모두 저장 |
| 우선 병기 | raw micro MAE | 유효 표본 동일 가중, 원 활동량 단위 |
| 필수 병기 | raw macro MAPE | 양수 타깃이 있는 셀 동일 가중, `%`와 비율 모두 저장 |
| 필수 병기 | raw macro MAE | 셀 동일 가중, 원 활동량 단위 |

정답 0은 MAE에 포함하고 MAPE에서만 제외합니다. MAPE 분모에 epsilon을 넣거나 작은 양수 정답을 제외하지 않습니다.
양수 타깃이 없는 셀은 macro MAPE에서 제외하고 셀 수를 보고합니다. 전체에 양수가 없으면 두 MAPE 모두 미정의입니다.
음수 정답은 오류이며 음수 예측은 그대로 오차에 반영합니다. 반올림은 최종 표시 단계에서만 합니다.
제공 코드의 float32 역변환·순차 누적과 작은 수치 차이가 날 수 있으므로 집계 정의 일치와 비트 단위 일치를 구분합니다.

계산 예로 A 셀의 `1→0, 2→3`, B 셀의 `0→1, 4→2, 6→9`에서는
macro·micro MAPE 모두 **62.5%**(비율 **0.625**), macro MAE **1.5**, micro MAE **1.6**입니다.
이 예의 MAPE가 같은 이유는 두 셀의 양수 타깃 수가 같기 때문입니다.
MAPE 비율 0.10은 10%이며 0.10%가 아닙니다. MAPE 차이는 `%p`, 상대 개선율은 `%`로 표시합니다.
상대 개선율은 `(기준 오차 - 제안 오차) / 기준 오차 * 100`이며 기준 오차가 0이면 미정의입니다.

| 항목 | 규칙 |
| --- | --- |
| 선택 점수 | 각 학습 모델에 속한 **유효 검증표본 전체의 정규화 MAE(val_loss)**. 셀별 평균을 다시 평균내지 않음 |
| 설정·checkpoint | 선택 점수가 가장 낮은 것. 평가 전에 선택한 가중치를 명시적으로 복원 |
| 같은 설정의 epoch 동률 | 정확한 동률이면 이른 epoch |
| 검증 이후 재학습 | 검증까지 합친 재학습이나 추가 탐색은 별도 조건으로 기록 |
| 반복 시드 | `53`, `54`, `55`; 매번 난수 생성기·모델·optimizer 상태 초기화 |
| 보고 | 시드별 값, 3회 평균, 표본 표준편차 `ddof=1`, 같은 시드끼리 모델 차이 |

현재 학습의 `val_loss`는 float32 경로이며 최종 보고용 원 척도 float64 오차와 구분합니다.
학습 손실·검증 선택 점수·최종 평가 주지표를 각각 기록하고, 검증과 평가의 중복도 명시합니다.
우수한 시드만 선택하지 않습니다. 추가 시드는 사전에 정해 비교 모델에 같이 적용합니다.
동일 구조끼리는 가능한 경우 같은 시드의 초기 가중치를 공유하고 여부를 기록합니다.
같은 시드가 다른 구조의 같은 초기 가중치나 GPU 비트 재현성을 뜻하지는 않습니다.

**시드별 점수의 평균과 예측평균 앙상블의 점수는 별도 결과입니다.**
앙상블은 별도 `run_id`로 보고하고 구성 모델·시드·가중치를 검증에서 고정합니다.
제안법이 앙상블이면 같은 구성 수·예측 집합의 단순 평균 기준과도 비교합니다.
3시드는 한 평가기간의 학습 무작위성 반복이며 독립된 3개 기간이나 자동적인 99% 신뢰구간이 아닙니다.
결정적 모델의 결과를 재사용하면 실제 실행 수와 재사용 수를 구분합니다.

## 결과 전달과 구현 확인

PDF 9쪽의 [팀 결과 교환 형식](experiment-results.md)에 예측·셀별 지표·시드별 요약·실행 명세를 저장합니다.
모델의 학습과 평가 코드를 연결할 때는 다음 순서로 확인합니다.

1. 900개 ID, 4,320행 시간축, 집계와 전체 30일 스케일러를 대조합니다.
2. 학습 `[8,2872)`·검증 `[2888,4320)`·평가 `[2893,4320)`의 타깃과 입력 창, `valid_q8`를 대조합니다.
3. 평가 후보 1,284,300개와 유효 1,283,738개를 확인하고 모든 유효 타깃의 예측을 보존합니다.
4. 원 척도 float64 역변환·정답·0 처리·분모와 네 지표를 PDF 7쪽 계산 예에 대조합니다.
5. 선택한 가중치·epoch, 검증·평가 중복, 시드와 앙상블 구성, 비용 측정 범위를 기록합니다.
6. 웹 연동을 구현할 때 현재 v1과의 차이를 [지원 범위 표](web-data-contract.md#연구-결과를-연결할-때)에 따라 해소합니다.

PDF 10쪽 NumPy 예제는 원 배열 `(4320, 900)`과 평가 예측 `(1427, 900)`을 사용한 참조 계산입니다.
벡터화·배치 처리로 바꾸어도 셀 ID·타깃 시각·입력 창·마스크·네 지표가 같아야 합니다.
현재 `evaluation.summarize()`와 `check-data`는 합성 데모 규약만 검사하므로 이 기준의 검증을 대신하지 않습니다.
