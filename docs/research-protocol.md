# 공통 실험 규약

## 연구 방향

TabICLv2 직접 예측과 TabICLv2 기반 군집화 + RCTL 예측 중 주력 방향은 미정입니다.
군집화·예측 구현은 교체하되 데이터와 평가 결과 형식을 공통으로 사용합니다.

## 데이터와 시간

- 셀 ID, 관측 시각, 관측값, 원본 단위를 명시합니다.
- 저장 시각은 시간대가 포함된 ISO 8601로 기록합니다. 집계 구간의 시작·끝 의미도 기록합니다.
- 연구 데이터에 맞는 현지 시간대와 서머타임 처리 여부를 문서화합니다.
- 결측과 0은 구분합니다. 시간 누락, 중복, 무한대·NaN은 확인 없이 보정하지 않습니다.
- 활동량 지표를 근거 없이 Mbps 같은 통신 속도 단위로 표시하지 않습니다.

## 분할과 예측

- 시간 순서로 학습·검증·테스트를 분리하고 경계는 설정에 저장합니다.
- 전처리 통계, 특징 선택, 군집화는 허용된 과거 구간에서만 계산합니다.
- 예측 기준 시점과 대상 시점을 구분합니다. 초기 예제는 다음 1시간 예측입니다.
- 롤링 예측 시 실제 관측값이 언제 사용 가능해지는지 명시합니다.
- 모델 선택·튜닝에 테스트 결과를 사용하지 않습니다.
- 비교 모델은 같은 셀·예측 기준 시점·대상 시점으로 평가합니다.

## 지표

MAE는 절대오차 평균, pooled RMSE는 전체 관측값 제곱오차 평균의 제곱근입니다.
macro cell RMSE는 셀별 RMSE를 계산한 뒤 셀마다 같은 가중치로 평균합니다.
두 RMSE는 서로 다르므로 결과 필드와 표에서 구분합니다.
누락 셀·관측값을 조용히 빼지 않고 평가 표본 수와 제외 사유를 기록합니다.

## 실험 기록

각 실행에 `run_id`를 부여하고 다음을 함께 저장합니다.

- 실행 명령, 설정 파일과 해시, 코드 커밋, 작업 트리 변경 여부.
- 데이터 출처·버전·해시, 셀과 분할 구간, 시간 간격·단위.
- 모델 이름·패키지·가중치 버전, 하이퍼파라미터, 시드.
- Python·PyTorch·CUDA 버전, CPU/GPU, 실행 시간.
- 실제값·예측값, 지표·집계 방식, 해석과 제한 사항.

환경이 다르면 같은 커밋에서도 완전히 같은 수치가 보장되는 것은 아닙니다.
성능 비교에 사용한 실행 결과와 환경을 함께 보관합니다.
