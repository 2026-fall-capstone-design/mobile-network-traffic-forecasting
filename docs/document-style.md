# 문서 작성 기준

GitHub에서 제목·표·본문을 일관되게 읽고 현재 규약과 과거 근거를 구분하기 위한 기준입니다.

## 제목과 문단

| 요소 | 작성 방식 |
| --- | --- |
| 문서 제목 | 파일마다 `#` 하나 |
| 주요 구분 | `##`, 문서 전체의 큰 주제만 사용 |
| 같은 주제의 개별 항목 | `###`, 같은 역할은 같은 단계 |
| 항목 안의 세부 설명 | 필요한 경우에만 `####`; 단계를 건너뛰지 않음 |
| 문단 | 한 문단에 한 가지 설명, 문단 사이 빈 줄 하나 |
| 강조 | 핵심 용어·조건에만 굵게 표시; 문단 전체를 크게 보이게 하는 용도로 쓰지 않음 |

제목·목록·표·코드 블록 앞뒤에 빈 줄을 둡니다.
내용을 덧붙일 때는 관련 절에 넣고, 페이지 끝에 별도의 큰 제목을 계속 추가하지 않습니다.
직접 지정한 글자 크기·`<font>`·장식용 HTML 제목 대신 Markdown 제목 단계를 사용합니다.
PR 템플릿처럼 다른 문서 안에 들어가는 조각과 외부 라이선스 원문은 문서 제목 규칙의 예외입니다.

## 표와 탐색

비교 조건·필드 정의·번호별 주제처럼 병렬인 내용에 표를 사용합니다.
헤더는 짧게 쓰고 모든 행의 열 수를 맞춥니다. 셀 안의 수직선은 `\|`로 이스케이프합니다.
긴 과정 설명은 본문으로 옮기고, 안내 페이지에는 찾을 문서와 짧은 용도를 적습니다.
긴 색인은 주요 구분의 목차를 먼저 제공합니다.
링크 문구는 파일의 역할을 설명하고 저장소 안에서는 상대 경로를 사용합니다.

## 기준과 근거

새 연구의 기본 조건은 [공통 실험 규약](research-protocol.md)에 한 번 정의하고 다른 문서에서 연결합니다.
합성 예제·추가 조건 실험·과거 기록은 적용 범위를 표시합니다.
과거 실험의 기간·수치·지표·시드를 현재 기준에 맞추어 소급 수정하지 않습니다.
예전 계획의 ‘진행 중’이나 ‘후속 예정’은 당시 상태임을 표시합니다.

확정 기준, 출처의 보고값, 직접 검산, 미확인 내용을 구분합니다.
MAPE는 `%`와 비율, 차이는 `%p`와 상대 개선 `%`, MAE는 척도와 셀/표본 가중을 명시합니다.
원본 사본·해시·검수 결과 JSON·외부 라이선스는 서식 통일을 위해 다시 쓰지 않습니다.

## 변경 후 확인

1. 제목 순서, 표의 열 수, 코드 블록, 상대 링크·앵커를 확인합니다.
2. GitHub 미리보기에서 대표 문서와 긴 색인의 제목 크기·표·줄바꿈을 확인합니다.
3. 원문과 인용·수치가 그대로인지, 현재 안내와 과거 상태를 혼동하지 않는지 확인합니다.
4. 아카이브를 수정했다면 `scripts/research_archive/check_archive.py`로 근거 바이트와 링크를 검사합니다.
