# 25 · 인접 방법과 다음 연구의 판단 경계

2026-09-25의 [기록25 §3–4](../evidence/0023-0025-pooling/originals/SRC-0021188.md.txt)를 2026-10-09에 대조했다. 이때의 질문은 **조건부 관계·분포·예측 기간을 확장해도 추천을 정하지 못한 상황에서, 이미 알려진 구조를 새 원리로 오인하지 않고 다음 후보를 정할 수 있는가**였다. 세 논문을 검토했지만 새 연구안을 확정하거나 그 알고리즘을 구현·실험한 기록은 아니다. 이번 정리에서도 모델 학습·추론은 0회다. **H018-C01**

앞선 [23·25 조건부 공유 비용](0023-0025-conditional-pooling.md)은 유연한 관계 비용과 유한 표본의 학습 이득을 구분했고, [24·25 recursive 진단](0024-0025-recursive-horizon.md)은 기존 모델의 6시간 뒤 예측에서 global 우위를 확인했다. 이 페이지는 두 결과를 문헌의 성능 수치로 대체하지 않는다.

## 어떤 정보를 써서 무엇을 바꾸는 방법인가

| 지정 논문 | 결정 대상·정보 | 당시 설계와 비교할 지점 |
|---|---|---|
| [Ma v1](https://arxiv.org/pdf/2604.13748v1) | TRAIN에서 적합한 모델의 VAL 예측 손실로 소속·fallback을 선택 | RCTL 성능을 선택에 사용하지 않는 조건과 다름. prototype만 TabICL로 교체했다는 사실로 새 결정 원리를 주장하지 않음 |
| [NeST v2](https://arxiv.org/pdf/2605.16447v2) | 이력 유사도로 지역을 만들고, 지역 미래 예측과 개별 이력을 결합 | 소속 도구를 덧붙이는 것보다 예측기 구조 자체의 변경에 가까움 |
| [Graph Coloring v3](https://arxiv.org/pdf/2509.16959v3) | 학습 중 gradient 관계로 동시에 갱신할 task 집합을 조절 | 하나의 공유 모델을 훈련하는 스케줄. cluster별 독립 RCTL 배포와 다름 |

Ma의 TRAIN 적합/VAL 선택/TEST 평가와 one-step 적합/여러 horizon 할당을 구분한다. fallback은 집단 평균의 VAL 1-step 손실을 비교하며, 개별 cell의 미래 무손해 조건이 아니다. 선택 후 TRAIN+VAL 재적합도 H017의 고정 checkpoint 진단과 다르다. **H018-C02·C03**

NeST는 추론 시 실제 미래 지역값을 미리 관측하는 방법이 아니다. 예측한 지역값이 guidance로 들어간다. 본문과 부록의 affinity·scheduled sampling 설명 차이, SNR 증명의 인쇄된 부등식 문제는 [지정 원문 비교](../references/adjacent-structures.md)에 따로 남겼다. 독립 noise 가정만으로 traffic에서 SNR 이득이 보장된다고 쓰지 않는다. **H018-C04·C05·C06·C07**

Graph Coloring의 충돌 기준은 gradient EMA의 음의 cosine이며 greedy coloring은 최소 색 수의 보장이 아니다. 갱신당 비용과 주기적 refresh의 비용을 구별해야 한다. 도식의 순서와 수식의 차이도 구현으로 확인되지 않았다. RCTL gradient를 사용하면 당시의 ‘RCTL 학습 결과와 독립인 소속 결정’ 조건을 충족하지 않는다. **H018-C08·C09·C10**

NTK 문헌은 당시 검색 발췌와 저자 기관 초록만 읽었다. 이번에도 [기관 초록](https://researchportal.vub.be/en/publications/exploring-task-affinities-through-ntk-alignment-and-early-trainin/)의 범위를 확인했으며 상세 알고리즘 검토 완료로 바꾸지 않았다. 초기 학습 단계의 여러 run 평균이라는 설명을 무학습 초기 kernel의 RCTL 대리성 증거로 취급하지 않는다. **H018-C11**

## 당시 판단과 재검토 조건

기록25는 전체 평균·관측 당시 높은 수준·실제 peak·예측 기간을 바꾸어 유리한 결과만 선택하지 말고, 공유 모델이 반복해서 남기는 손해를 먼저 특정해야 한다고 정리했다. 입력 상태별 손해의 반복성, 실제 위험과의 관계, 단순 보정·계절 예측으로 해결되는지를 확인한 뒤 새 후보를 구체화하자는 판단이다. 이는 당시 미완료 연구의 판단 경계이며 이번 정리에서 새 실험을 실행하라는 지시가 아니다. **H018-C14**

당시 추천안·최종 Word가 미완료였다는 문구는 2026-09-25 시점의 상태다. 뒤의 [642 최종 문서와 미실행 본실험](0642-research-direction.md)과 모순 없이 시점을 구분하되, 그 사이 전체 변경 경로의 통합은 아직 남아 있다. 기록25 전체를 통합 완료로 집계하지 않는다.

후속 설계를 제안할 때는 관련 과거 기록, 기존 실패 조건과 달라지는 입력·정보·결정 대상, 단순 기준, 평균 및 cell/기간 손해, 선택용 자료와 독립 평가 자료를 명시한다. 본 페이지와 논문 비교는 새 방법의 신규성·성능 인증이 아니다.
