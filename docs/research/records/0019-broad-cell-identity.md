# 19: 넓힌 cell 범위에서 ID와 과거 요약의 가치

활동량 범위를 넓힌 32개 cell을 같은 context에 넣고 ID·과거 통계를 추가했다. **이 조건에서 TabICL의 세 추가 입력은 전체 평균을 개선하지 못했다.** Ridge의 과거 요약과 HGB의 ID는 전체 MAE가 조금 줄었으나 cell·날짜별 손해도 있었다. 모든 clustering의 효용이 없다는 결론으로 확대하지 않는다. **H013-C01·H013-C05·H013-C06**

[근거 안내](../evidence/0019-0021/README.md)·[열람 범위](../sources/history-013.md)·[검수](../verification/history-013.md)·[주장별 출처](../verification/history-013-primary-review.json)를 함께 읽는다.

## 질문과 실제 조건

14의 중앙부 16cell 결과를 도시 전체로 확대하지 않기 위해 16에서 정한 기존16+활동량 사분위별 추가16을 그대로 사용했다. 모든 cell의 자료가 context에 함께 있으므로, 한 cell의 context만 다른 cell로 옮긴 교차 이전 실험과 다르다. 새 소속이나 최종 RCTL 성능을 측정한 실험도 아니다. **H013-C01**

| 항목 | 조건·확인 범위 |
|---|---|
| 자료·척도 | 기존 가공 Milan hourly Internet activity, cell별 첫 672시간 평균으로 정규화. bytes/bps 아님 |
| Cell | 고정 32개, 순서는 NPZ와 시작 metadata에 보존. 사후 제외·재추출 없음 |
| Context | target168–671에서 rounded linspace로 64시각. cell별64, pooled2,048행 |
| Query | target672–1007에서 같은 방식으로64시각. cell별64, pooled2,048행. 2013-11-29–12-12 개발 구간 |
| 기본 입력 | 시간 진단의 자기16열: 최근8시간·일/주 lag·24시간 요약·달력 |
| ID | 32열 one-hot을 추가해48열 |
| ID 열 순열 | 같은 one-hot의 열 순서만 변경. 기록된 순열과 seed20260926 보존 |
| 과거 요약 | 첫672시간 raw의 log1p(mean), std(ddof0)/mean, IQR/mean, lag1상관을 추가해20열 |
| TabICL | 계획2.2.0, 기존 regression checkpoint. seed20260925, ensemble1,batch1,CPU,n_jobs1,median. AMP/FA3/offload/자동 다운로드 False |
| Thread | BLAS 계열 환경변수4, torch4, interop2 |
| Ridge | StandardScaler+Ridge(alpha=1) |
| HGB | absolute_error,max_iter100,max_leaf_nodes15,min_samples_leaf20,l2=1,early_stopping=False,seed20260925 |
| 상태 | 시작·4회 Tab 호출·완료·10조건 예측·summary 존재. 작은 fit6회. 추가 RCTL0 |

같은 모델/context를 query 구간 동안 유지하지만 각 query 입력에는 그 시각 직전까지의 실제 관측이 들어간다. **관측 이력을 갱신하는 1시간 앞 예측**이다. query를 약5–6시간 간격으로 골랐다는 사실이 예측 horizon5–6시간을 뜻하지 않는다. 시간 진단의 주별 재적합이나 공간 진단의 cell별504행 적합과도 다르다. **H013-C02**

14일의 query 시각 수는 차례로 5,4,5,4,5,4,5,5,4,5,4,5,4,5개다. 전체 MAE는 32×64행의 동일 가중 평균이며 날짜 평균14개의 단순 평균이 아니다. 모든 날짜·cell 차이와 날짜별 표본 수를 검산 JSON에 남겼다. **H013-C02·H013-C06**

## 평균과 함께 확인할 손해

음수 차이는 앞 조건의 이득이다. cell은64시각 평균, 날짜는 그날 선택된4또는5시각의32cell 평균, cell×날짜는448자리다. 날짜 전체의 모든24시간을 관측한 표가 아니다. cell×날짜와 ID순열−ID 비교는 아카이브 추가 산술이다. **H013-C06**

ID의 미세한 평균 변화나 개선 cell 수만으로 partition의 이득·상한을 주장할 수 없다. ID 열 순열도 같은 정보를 제공하지만 유한한 추정기의 예측은 달라졌다. 순열을 여러 번 새로 뽑아 최적값을 고르는 검토는 수행하지 않았다. **H013-C03·H013-C06**

## 저장 범위와 재사용

최종 NPZ는10예측,actual,cell_ids,context_times,query_times,past_summary_features의15배열이다. partial NPZ의4 Tab 예측과actual/ids/query7개 배열은 최종과 정확히 같다. 파일명 partial은 실행 실패의 증거가 아니다. **H013-C04**

**확장된 실제 모델 입력 X는 두 진단 NPZ에 저장돼 있지 않다.** 앞선 X와 정적 코드,32×4 과거 통계·ID순열로 입력 구성법을 추적한다. 원 H5 지정 구간과 통계·정답·최근 입력을 대조했지만 당시 모델이 소비한 확장 X의 별도 보존 사본을 검증한 것은 아니다. 설치metadata2.2.0과 checkpoint의 현재 바이트는 기존 공식 출처 검수에 연결했다. 실행별 가중치·패키지 해시가 없어 당시 로드 환경 전체의 재현을 주장하지 않는다. **H013-C03·H013-C14**

같은 조건의 재실험 전에는 저장 예측·모든 cell/day 차이·고정 ID/시각을 재사용한다. 새 연구는 다른 자료 범위, 모델 용량, context 구성, 정보 이용 시점 또는 최종 소속 평가 중 무엇을 바꾸는지 명시해야 한다. ID나 요약값의 추가와 최종 RCTL을 여러 모델로 나누는 효과는 별도 질문이다. 당시의 다음 진단은 [큰 오차의 target 표현 의존성](0020-0021-target-parameterization.md)이었다. **H013-C15**
