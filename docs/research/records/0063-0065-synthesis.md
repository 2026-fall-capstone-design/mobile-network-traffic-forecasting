# 63–65: 예측값·잔차·분포 변환을 실제 학습에 연결한 검토

[연구 안내](../README.md) · [과거 시도 색인](../prior-attempts.md) · [출처](../sources/history-062.md) · [검수](../verification/history-062.md) · [후속 66–68](0066-0068-group-risk.md)

63–65번은 Tab의 점수를 소속 결정에 쓰는 안에서, **Tab이 제공한 예측이나 변환을 최종 RCTL의 입력·target에도 연결하는 안**으로 질문을 넓혔다. 실제 학습 문제를 바꾸면 대리 점수와 최종 학습 사이의 차이를 줄일 여지는 있지만, 예측값 추가·잔차 보정·분포 변환 자체는 선행 원리다. 당시에는 새 추천안을 채택하거나 새 모델을 실행하지 않았다. 이 기록은 그 판단을 H055–H061의 일곱 문헌 검수와 연결한다. [원63](../evidence/0063-0065-ecai-interface/originals/SRC-0022008.md.txt) · [원64](../evidence/0063-0065-ecai-interface/originals/SRC-0022015.md.txt) · [원65](../evidence/0063-0065-ecai-interface/originals/SRC-0022016.md.txt) · [C01–C03]

## 세 제안은 무엇을 바꾸는가

| 제안 | 바뀌는 대상 | 이미 확인한 선행과 남는 질문 |
|---|---|---|
| Tab 예측을 RCTL 입력에 추가 | 실제 관측값을 예측하는 RCTL의 입력 열 | ECAI Fig. 3(d)의 global forecast+군집별 예측기와 연결된다. 같은 입력 예산에서 Tab이 더하는 정보·비용을 보여야 한다. |
| 실제값−Tab 예측을 RCTL이 보정 | 관측 target의 잔차 표현과 최종 합성 | Heatload MRRC·KDD 잔차 학습과 연결된다. 잔차가 더 쉽게 학습되는지, 과거 시점에 사용 가능한 기준 예측인지가 별도 질문이다. |
| cell·달력별 분포를 맞춘 뒤 군집화·RCTL | 입력·target의 좌표와 역변환 | copula 군집화, 공유 분포 예측, 조건부 모멘트 정규화는 서로 다른 선행이다. 제거할 변동과 남길 예측 정보를 지정해야 한다. |

이는 Tab의 예측력이 없다는 판단이 아니다. [60번의 4cell 개발 비교](0059-0062-history-grouping.md)에서 global/L2의 Tab MAE 약 0.067327은 Ridge 0.090199, HGB 0.102476보다 낮았다. 그 직접 예측 결과를 새로운 소속의 RCTL 개선으로 바꾸거나, 문헌 검토 때문에 없었던 결과로 처리하지 않는다. 이번 종합에서 이 모델들을 다시 실행하지 않았다. [C04]

## 일곱 문헌에서 가져올 근거와 적용 경계

표는 이미 완료한 개별 검수의 연결이다. 원65의 당시 선택 독해와 이후 아카이브에서 넓힌 검토 범위를 구분한다. 각 링크에는 판본·수식·표·그림·코드 및 남은 공백이 있다. [C05–C11]

| 검수 기록 | 실제 연결 | 그대로 옮길 수 없는 주장 |
|---|---|---|
| [ECAI: H055](0063-0065-ecai-interface.md) | Fig. 3(d)의 예측값 입력. 공개 Type II 코드는 비율 잔차로 군집을 정하고 실제값 target을 학습한다. | 모든 방식이 잔차 target 학습이라는 해석. Ljung–Box를 분산 이질성 검사로 부르는 해석. 누적 sMAPE를 일반 MAE로 바꾸는 해석. |
| [Heatload: H056](0063-0065-heatload-residual.md) | 느린 기준 예측과 빠른 잔차 context를 합성한다. origin 이후 발행 예측을 제외하는 코드 경로를 확인했다. | 비공개 15분 난방 자료의 결과를 통신 cell 성과로 이전. residual만 합산한 summary 시간을 두 단계 총비용으로 사용. |

| [PLOS: H058](0064-0065-plos-copula.md) | 각 시계열 **내부**의 값–lag copula를 다른 시계열과 비교해 군집화한다. | 동시각 cell 간 cross-copula로 해석. 고정 증가 주변 변환의 불변성을 달력·이력마다 다른 변환으로 확대. 군집 일치성을 RCTL 성능 보장으로 이전. |
| [GP-Copula: H059](0064-0065-gp-copula.md) | 경험 주변 CDF→Gaussian 좌표→공유 RNN·저랭크 결합분포→역변환. | 경험 주변 CDF를 전체 이력 조건부의 정확한 CDF로 해석. Jacobian이 포함된 likelihood를 변환 공간 MAE와 동일시. |
| [TACTiS-2: H060](0064-0065-tactis2.md) | 주변분포를 먼저 학습·동결한 뒤 copula를 학습한다. | 무한 표현력·모집단 최적해에 관한 분해 보장을 유한 Tab/RCTL의 정확성으로 이전. 개별 PIT 균등성을 공동 독립으로 확대. |
| [조건부 정규화: H061](0064-0065-conditional-normalization.md) | 조건부 평균·분산을 제거한 뒤 남는 시간 의존을 모델링한다. | 모멘트 표준화를 PIT로 해석. smoother 보간 평가를 미래 예측 평가로 이전. 논문과 공개 패키지의 다른 경로를 같은 실행으로 간주. |

단순 모델 교체가 새로운 원리의 근거가 되지 않는다는 당시 판단은 유지된다. 논문에 성능 손해·인쇄 불일치·구현 공백이 있다고 해서 그 선행 원리 자체가 사라지는 것도 아니다. 반대로 개별 논문에서 개선된 숫자만 가져와 우리 UPC 소속이나 RCTL의 효과를 보장할 수도 없다.

원65에서 **KDD의 보정 강도를 validation으로 정했다고 쓴 부분은 확인 수준을 낮춰야 한다.** H057이 읽은 C.4에는 α를 선택한 데이터 분할이 명시돼 있지 않다. validation 선택과 test 선택 중 어느 쪽도 확정하지 않는다. 원문을 수정하지 않고 후속 검수와 연결했다. Heatload의 잔차 시간 합산, KDD 부록의 학습 가능성 한계, TACTiS-2의 개별 PIT와 공동 의존 구분은 당시에도 기록된 주의점이다. 이번에 처음 발견한 것처럼 소급하지 않는다. [C12]

## 변환이 남기는 학습 문제

**잔차의 부호와 loss.** `r = y−b`를 target으로 두고 최종 예측을 `b+r̂`로 합치면 `|y−(b+r̂)| = |(y−b)−r̂|`다. 이 대수적 일치는 유한 RCTL이 잔차를 더 잘 배운다는 뜻이 아니다. KDD는 반대 부호인 `b−y`를 학습하고 보정값을 빼므로, 부호를 바꾸면 합성식도 함께 바뀌어야 한다. RCTL 내부 residual connection과 외부 target 잔차도 다른 개념이다. [C13]

**전체 이력 H를 조건으로 한 정확한 연속 CDF.** `U=F(Y|H)`는 H에 대해 균등하다. 단일 미래값의 변환 공간 MAE를 최소화하는 조건부 중앙값은 0.5이고, 이를 역변환하면 원래 분포의 중앙값이다. 이 이상적인 설정에서 같은 H만 가진 다음 모델이 새 단일값 정보를 찾아낼 필요는 없다. 실제로 추정한 F에는 오차가 남으므로 보정 문제가 성립할 수 있지만, 그때의 질문은 calibration·추정오차 보정이다. 여러 미래값의 개별 PIT가 균등해도 공동 의존은 남을 수 있다. [C14]

**달력 Z만 조건으로 한 CDF.** `F(Y|Z)`가 Z에 대해 균등하다고 해서 최근 이력을 추가한 H에 대해서도 균등한 것은 아니다. 이후 모델이 배울 정보가 남을 수 있다. 무엇을 제거했는지에 따라 질문이 달라지며, 조건부 평균·분산만 맞추는 H061의 변환에는 정확한 PIT 논리를 그대로 적용할 수 없다. [C15]

**변환 전후의 평가 척도.** 원65의 설명 예에서 정답 100, 두 예측 90/102의 원 오차는 10/2다. 증가 CDF가 각 값을 .48/.50/.90으로 보낸다면 변환 오차는 .02/.40으로 순위가 반대다. 이상적인 중앙값의 역변환 성질과 유한 예측 후보의 MAE 순위 보존은 다른 명제다. H061의 양수 척도 예시에서도 시각·cell마다 다른 척도는 전체 MAE의 가중치를 바꾼다. 따라서 목표 척도에서 역변환 후 손실을 확인해야 한다. 이들은 [결정적 설명 산술](../verification/history-062-logic-check.json)이며 실제 모델 결과가 아니다. [C16]

## 실행·비용과 후속 질문

63–65의 수행 범위는 문헌·정적 구현·논리 검토다. 당시 Tab 65 contexts/38,016 query rows, RCTL 29 fits라는 누적 수치를 인용했으며, 새 호출로 가산하지 않았다. 문헌 검토·다운로드·렌더의 실측 전체 시간은 미기록이다. 외부 논문의 GPU 시간과 정적 연산량을 우리 CPU 실험의 전체 비용으로 환산하지 않는다. [C17]

원66은 이어서 **평균 오차와 일부 cell의 손해를 구분하고, 보호 목적을 실제 최종 학습 loss에 반영할 때 무엇이 달라지는지**를 질문했다. 표현 변경의 성공을 선언한 다음 단계가 아니며, 평균 목표를 버리거나 worst-cell을 최종 목표로 택한 것도 아니다. 이 전환과 저장 예측의 실제 진단은 [66–68 기록](0066-0068-group-risk.md)에 이어진다. [C18]

팀이 비슷한 실험을 제안할 때는 원65의 세 질문을 먼저 적는다. 분리할 변동은 무엇인지, 단순 정규화나 기준 모델 뒤에도 어떤 손해가 남는지, Tab이 그 정보를 더 정확하거나 적은 비용으로 제공하는 근거가 무엇인지다. 여기에 실제 가용 시점·변환 fit 구간·소속 선정과 최종 평가의 분리·평균 및 cell/기간 손해·전체 비용을 연결해야 기존 방법 이름만 바꾼 반복을 피할 수 있다.

이번에는 일곱 문헌의 판단을 통합했으며 기존 독해를 다시 가산하지 않았다. 원 실험의 재현·비공개 데이터·미확인 구현 등 각 문헌의 공백은 그대로 남는다. 66–68의 새 세 논문과 전체 아카이브 정리도 아직 완료되지 않았다.

후속 [78의 task 전이 검토](0076-0079-learning-decisions.md#c19)는 head 재적합을 허용하는 전이 점수와 동일 target의 pooling을 구별했다. 76의 보조 loss, 79의 분산 배치도 다른 결정 단위로 연결하며 기존 기록의 재인용을 새 실험으로 세지 않는다.
