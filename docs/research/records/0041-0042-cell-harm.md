# 41–42 cell별 손해와 사후 선택 진단

[과거 시도 색인](../prior-attempts.md) · [출처·범위](../sources/history-025.md) · [저장 근거](../evidence/0041-0042-cell-harm/README.md) · [검수](../verification/history-025.md)

2026-09-26의 41은 계획, 42는 저장 예측 재집계 코드·결과, 44 §1–2와 §6의 수치 부분은 그 판단이다. **기존 TabICL 소속의 평균 손해가 여러 cell의 지속적인 이득을 가렸다는 근거는 약했고, 사후 최선 선택값을 구현 가능한 clustering 성능으로 삼지 않았다.** 새 후보 채택이나 새로운 RCTL 성능 실험은 아니다. 43과 44 §3–5의 문헌·역할 종합은 별도 검수 대기다. [C01,C12]

## 질문과 실제 수행 범위

[41 계획](../evidence/0041-0042-cell-harm/originals/SRC-0021529.md.txt)은 기존 다섯 K=4 소속의 cell 전체 이득이 앞·뒤 기간에도 남는지, 이미 학습한 경로 중 잘 고르기만 하면 해결되는지 물었다. [42 코드](../evidence/0041-0042-cell-harm/originals/SRC-0022569.py.txt)는 기존 RCTL 8개 조건과 단순 예측 5개 조건을 읽는다. 별도의 42번 Markdown 문서는 이 묶음에서 발견되지 않았으며, 번호를 추가 실험 횟수로 세지 않는다. 완료 result와 시작·종료 marker를 연결했다. 현재 정리에서는 원 연구 코드를 import하거나 실행하지 않았다. [C01,C09]

## 같은 cell·시간·척도에서 비교한다

Milan internet hourly pilot의 cell 순서는 3737, 3745, 3753, 3765, 4537, 4545, 4553, 4565, 5337, 5345, 5353, 5365, 6137, 6145, 6153, 6165이다. 정규화는 각 cell의 원시 index 0–671 평균이며, 실제 Mbps가 아닌 활동량의 정규화 MAE다. design의 scale과 42 입력의 scale을 대조했다. 모든 cell의 관측 수가 같아 전체 7,680개 오차 평균은 cell 평균의 동일 가중 평균과 같다. [C02]

RCTL train target 168–839, validation 840–1007, 이후 개발기간 1008–1487을 구분한다. 이번 평가 재집계는 개발기간의 480시간을 앞 1008–1247과 뒤 1248–1487의 240시간씩 나눈 것이다. validation 168시간과 혼동하지 않는다. 이 480시간은 과거 test 명칭으로 저장되었지만 이미 관찰하여 개발에 사용한 자료다. 34의 저장 validation 예측 21개 checkpoint를 cell membership으로 조립하고, float32 오차 평균이 42가 읽은 여섯 조건의 cell별 validation 값과 정확히 같은지 확인했다. [C02,C07]

주 seed 20260925의 global K=1과 다섯 균형 K=4 조건이 primary 집합이다. 20260926은 TabICL·empirical만 있고 두 번째 global은 없어, 두 seed 모두 같은 primary global과 비교한다. PCC balanced는 원 UPC 전체 재현이 아니다. 단순 global Ridge/HGB의 기존 적합·설정과 실제 X/적합 객체의 보존 공백은 [26–27](0026-0027-observable-states.md), RCTL 구조·학습 설정·선택된 가중치 조건은 [33–35](0033-0035-process-fit-gap.md)에 연결한다. 42에서 설정을 다시 탐색하거나 예측을 clip하지 않았다. [C03,C11]

주 TabICL 소속에서 전체 평균이 좋아진 cell은 4553·4565이지만 두 절반 모두 개선된 cell은 없다. 주 empirical은 3개 cell이 전체 개선이며 두 절반 개선은 3765 하나다. 보조 seed의 두 방법은 전체 개선 cell이 없다. 따라서 작은 표본의 이 결과를 전체 도시, 다른 시간 해상도, 모든 가능한 소속의 불가능성으로 확대하지 않는다. [C04]

HGB는 전체 13개 cell을 개선하지만 두 절반 개선은 3753·4545·5337 세 개다. 전체 앞기간 평균은 +0.002040257로 악화하고 뒤기간은 −0.007354779로 개선한다. Ridge는 전체 6개 cell 개선이나 두 절반 개선은 없다. 전체 평균·cell·기간을 함께 읽어야 한다. 이 단순 모델 결과는 TabICL의 독자적 필요성을 입증하지 않는다. [C05]

[27의 빠른 증가 상태에서 본 empirical 이득](0026-0027-observable-states.md)은 그대로 남는다. 예측 당시 관측 가능한 상태의 손해와 cell 전체의 시간 평균은 서로 다른 질문이다. 42가 전자를 반박하거나 새 상태·cell·threshold를 선택한 기록은 아니다. [C08]

## 사후 최선과 validation 선택의 차이

다음 선택 계산의 후보는 **동일 primary seed의 기존 여섯 경로만**이며 Ridge/HGB·보조 seed를 포함하지 않는다. cell oracle은 cell당 전체 개발 MAE를 미리 보고 최선 경로를 고른 값, sample oracle은 매 시점 실제 정답을 보고 절대오차가 가장 작은 경로로 바꾼 값이다. [C06]

- global MAE: **0.071067767**.
- cell별 사후 oracle: **0.070409939**, global 대비 **0.925635307% 감소**.
- sample별 사후 oracle: **0.036067265**.
- 앞선 validation 손실로 고른 경로의 개발 MAE: **0.077273462**, global 대비 **8.732081404% 증가**.

동률은 global → TabICL → empirical → KNN → PCC → random의 고정 순서에서 먼저 나온 경로를 선택한다. validation에서 global을 선택한 cell은 6개이며, 사후 cell oracle과 선택이 같은 cell은 5개다. 아래 경로와 MAE는 모두 primary seed 20260925이다. [C06,C07]

42의 `numeric_wall_seconds`는 시작점 이후 입력 hash·설정/시작 marker 기록과 저장 배열 계산을 포함한다. RSS 측정, 상한/유한값/입력 hash 재검사, result 기록 등은 그 값이 포착된 뒤 수행되며 종료 marker 시간에 겹친다. 프로세스 시작부터의 별도 wall time은 미기록이다. 코드 변수명이 `peak`이지만 한 번 읽은 `memory_info().rss` 값이므로 전 구간 peak로 보정하지 않는다. 입력 hash 불변은 당시 보고와 현재 보존 바이트 일치를 구분한다. [C09]

원장의 `cell_harm_envelope_42` 값은 0.03152100000079372초로 결과와 같다. 34까지의 지정 합 1,947.664569400002초에 37의 0.0002907999987655785초와 42의 계산 시간을 한 번씩 더하면 1,947.6963812000015초다. 현재 원장에는 후속 기록이 누적되어 있으므로 `used` 전체를 당시 비용으로 가져오지 않았다. RCTL fit 소타이머는 training wall에 포함되고 finish 시간은 numeric과 겹치므로 중복 합산하지 않는다. [C10]

44가 보고한 당시 잔여 35 contexts·24,288 query rows는 초기 80/60,000 상한에서 45/35,712를 뺀 값이다. 과거 예산 서술이며 현재 Goal의 실행 허가가 아니다. 문헌 조사·다운로드·초기 미계측 처리·전체 실패 시도를 합한 총 연구 시간은 이 표로 확정할 수 없다. [C10]

## 당시 판단과 다음 실험 전 확인할 것

당시는 기존 예측을 재선택하거나 routing을 붙이는 경로부터 시작하지 않기로 했다. 평균에 숨은 안정적인 cell 이득의 범위를 좁혔으며 새 소속·손실 가중치·허용 폭·추천안을 확정하지 않았다. 같은 16cell·480시간·저장 조건의 표를 얻기 위한 모델 재실행은 필요 없다. 새 실험은 어떤 정보로 어떤 학습 행동을 바꿀지, 기존 여섯 경로 재선택과 무엇이 다른지, 독립 평가 자료와 cell·기간별 손해를 어떻게 확인할지 먼저 명시해야 한다. [C01,C08]

새 원문 7개 59,195 bytes와 기존 보존 참조 9개를 연결했다. 검산은 현재 저장 배열의 수치 일치이며 모델 적합·추론의 독립 재현이 아니다. 실제 당시 fit/forward 입력 객체와 가중치 팀 접근에 대한 기존 공백은 앞선 기록에 유지했다. 44 원문 전체는 보존했지만 **43과 44 §3–5의 TimeTic·local distillation·역할 종합, §6의 문헌 입수 보고는 아직 이 묶음에서 검수하지 않았다.** 44 전체와 45 이후를 완료 처리하지 않는다. [C11,C12]
