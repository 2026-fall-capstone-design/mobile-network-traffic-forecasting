## 응답과 실제 접근 범위

<a id="c01"></a>**C01.** 새로 읽은 자료는 원83의 검색·열람 응답4그룹이다. JSON2개는 status/value 구조이고 value 전체를696행·260행으로 풀어 읽었으며, TXT2개는454행·364행이다. 합계1774행에54개 응답이 있다. JSON의 fulfilled는 저장된 도구 호출 상태이며 각 원격 문서의 전문 열람 성공을 뜻하지 않는다.

<a id="c02"></a>**C02.** 응답에는 검색 발췌, 지정 행 open, 오류, 원문 미제공 안내와 본문 없는 표제가 섞여 있다. methods/read라는 파일명이나 결과의 총 행 수만으로 전문 독해 또는 요청의 시간 순서를 확정하지 않는다. 원83 scope의6개 검색어도 당시 보고된 검색어 목록으로 남기며 저장되지 않은 모든 검색 입력을 복원했다고 하지 않는다.

<a id="c03"></a>**C03.** 저장 서지는 Hallak·Kem의 Adaptive federated learning framework for predicting EV charging stations occupancy, DOI10.1016/j.ijtst.2025.04.007을 가리킨다. 출판사 결과는22권·2026년6월·282–296쪽과2025 copyright를, HAL 표제는2025-05-22 제출·in press를 담고 있다. 제출일·저작권 연도·권호 연도를 구별한다. 원83의 ResearchGate 업로드2025-05-29는 이4응답에서 직접 재확인하지 못했다.

<a id="c04"></a>**C04.** methods JSON의 ResearchGate open3개에는 웹 원문 L1257–1418, L1476–1719, L383–664가 남아 있다. 요청한 중심 행은 각각1330·1540·420이며 총2428행이라는 헤더는 나머지 내용이 저장됐다는 뜻이 아니다. 다른 read JSON의 ResearchGate open은 총2429행이라는 표제만 있고 본문이 없다.

<a id="c05"></a>**C05.** 원83과 scope는§3.2.1–3.2.3 및 Algorithm3–5를 읽었다고 보고했다. 하지만 현재 보존된4응답에서는 해당 온라인 알고리즘 본문을 찾을 수 없다. §3.1의 global 모델/초기 중심 설명, Algorithm1의 입력 시작과 설정·결과 발췌를 확인한 범위로 한정한다. 과거 열람 보고를 허위로 단정하지도, 현재 알고리즘 전문을 다시 검증했다고 표시하지도 않는다.

<a id="c06"></a>**C06.** ScienceDirect 직접 open 결과는 Internal Error와 총1행 헤더만, HAL PDF open 결과는 Oh noes라는 HTML 표제와 총13행 헤더만 남아 있다. 응답 자체에서403 코드를 읽은 것은 아니며403은 원83/scope의 당시 보고다. HAL PDF 본문·확인 화면13행 전체를 읽었다고 하지 않는다. 지금도 같은 오류가 난다는 주장이나 우회 접근은 수행하지 않았다.

## Fed-PPBC에서 읽을 수 있는 조건과 불일치

<a id="c07"></a>**C07.** 실험 비교 발췌는10회 반복 평균을 보고한다. baseline 설정 절에는 모든 client가 참여하는500 communication round, round당 local1epoch, Adam 학습률10^-3, batch32가 적혀 있다. 이를 확인하지 못한 Fed-PPBC 최종 튜닝값 전체로 확대하지 않는다. Guangzhou·Shenzhen은2021-12-10–31의30개 station으로 학습하고2022-01-01–07의새5개 station에서 평가한다. Paris는 학습에 참여한20개 station의 다음7일을 평가 대상으로 삼는다. §4.7은1-step prediction 비교이므로 이7일을 단일 예측 horizon으로 해석하지 않는다. 서로 다른 일반화 조건을 같은 평가로 합치지 않는다.

<a id="c08"></a>**C08.** 남은 방법 설명은 최근 target/점유율의 패턴을 기준으로 묶는 동기와, local 모델을 평균해 global 모델을 만든 뒤 cluster 중심을 미리 준비하는 offline 단계다. 예측 성능을 감시하고 drift에 대응한다는 개요는 있지만 이것만으로 온라인 갱신의 모든 의사코드·가중치 규칙을 복원할 수 없다. 과거의 필요한 갱신 시점 합집합 비용을 최소화한 실험으로도 바꾸지 않는다.

<a id="c09"></a>**C09.** 발췌는 h=5%, 최근 갱신 sample 수 n=5, m=3의 튜닝 결과를 보고하며 m을 cluster size라고 부르기도 한다. 그러나 변수 표는 m을 drift pattern vector의 길이, k를 cluster 수로 구별한다. 따라서 m=3을 cluster3개라고 옮기지 않는다. 전체 grid search 결과나 구현을 재현한 것은 아니다.

<a id="c10"></a>**C10.** 중심 벡터를 t−m부터 t−1, t까지 열거한 추출 문장은 이를 m차원이라고 설명한다. 양 끝을 포함하면 m+1개라는 인덱스 해석 차이가 있어 그대로 실행 규칙으로 삼기 어렵다. 추출의 기호 손실인지 원문 표기인지 실제 구현 문제인지는 원 PDF·코드를 확인하지 않아 확정하지 않는다.

<a id="c11"></a>**C11.** 저장된 Table2 텍스트에는5개 모델×3개 도시×3개 지표의45개 값이 있다. 도시 순서는 Guangzhou·Shenzhen·Paris, 각 도시의 지표는 RMSE·MAE·MAPE이며 앞의 두 지표는×10^-2, MAPE는%다. 텍스트를 전사해 열을 연결했지만 원 PDF 표 픽셀이나 반복별 실험 출력을 검수한 것은 아니다.

<a id="c12"></a>**C12.** Paris 설명은 Itransform RMSE9.13×10^-2와 LightTS9.33×10^-2를 적지만, Table2 텍스트의 Paris 열은10.13×10^-2와10.07×10^-2다. 문장의9.13·9.33은 표의 Guangzhou 열과 같다. 또한 설명의9.13은 Dlinear9.19보다 작아 Dlinear가 최저라는 같은 문장의 설명과도 맞지 않는다. 열 혼동 가능성을 남기되 저자의 숫자를 임의 수정하지 않는다. 같은 설명은 LSTM11.12를 최대 오차로 부르지만 표의 TSMixer는12.31이다. 이 순위 설명의 불일치도 보존한다.

<a id="c13"></a>**C13.** Guangzhou에서 보고된 Fed-PPBC의 RMSE·MAE·MAPE는8.13·5.87·20.51, AFML은10.18·8.50·42.47이며 앞의 두 값은×10^-2 단위다. (AFML−Fed)/AFML×100으로 계산하면 반올림한20.14%·30.94%·51.71%와 맞는다. 이 산술 일치는 보고된 값 사이의 관계만 확인하며 예측 출력·실험 성능의 재현을 뜻하지 않는다.

<a id="c14"></a>**C14.** Shenzhen의19.69%·26.92%·14.89%, Paris의55.7%·62.6%·51.6%에 필요한 비교군 원값은 이 발췌에 없다. Table3는 제목까지만 남아 있어 역산한 값을 원문 데이터로 채우지 않는다. AFML의 중국 두 도시 결과는 Chen 등2024에서 가져왔으며 Paris는 코드 미제공으로 적용하지 못했다는 저자의 설명도 보존한다.

<a id="c15"></a>**C15.** 원83은 이미 본문·표의 수치와 m 명칭이 일관되지 않아 Fed-PPBC 성능 수치를 후보 판단의 근거로 사용하지 않는다고 썼다. 이번 검토는 그 불일치의 정확한 보존 위치를 연결한 후속이다. 현재 연구의 공동 RCTL 갱신 비용 절감이나 TabICLv2 점수의 효용을 입증한 결과로 전환하지 않는다.

## 주변 후보와 별도 원문 검수

<a id="c16"></a>**C16.** FDA는 서지·요약, 기관 PDF의 첫 쪽 중간까지인 검색 발췌, ResearchGate의 No full-text available 안내, 다른 논문의 인용/관련 목록으로 나타난다. 이 응답의 존재가 식1–8과6쪽 전체의 독해를 증명하지 않는다. 실제 고정 PDF·TXT·이미지 대조는 별도 H106 기록에 연결한다.

<a id="c17"></a>**C17.** LNN 검색에는 제3자 요약, 두 단의 문장이 섞인 Scribd 발췌, DDoS·LDOS 탐지/분류와 다른 관련 문헌이 함께 나온다. 같은 LNN 명칭만으로 ONDM의 링크 부하 회귀와 동일 실험으로 묶지 않는다. ONDM 논문 자체의 조건·지표·표 검수는 H107에 연결하며 탐지 정확도를 RCTL 예측 오차와 비교하지 않는다.

<a id="c18"></a>**C18.** read JSON은22개 검색 결과와 ResearchGate open 표제1개로 구성된다. 환자 matching, 분산 directory, 물리식 조합, 법률 판정, 최적화·fuzzy set·privacy·softmax 등 여러 분야가 섞여 있다. Algorithm3 또는5라는 문구가 잡혔다는 이유로 Fed-PPBC 알고리즘의 본문이나 유효한 비교군을 확보했다고 세지 않는다.

<a id="c19"></a>**C19.** Tracking Time Evolving Data Streams for Short-Term Traffic Forecasting의 저장 발췌는 chunk membership mass로 극단 outlier를 거르고, cluster별 forecaster의 예측을 가중합하며, 최근 창의 outlier density가 임계값을 넘으면 중심과 forecaster를 다시 학습한다고 설명한다. 입력 chunk에 관한 ensemble·재훈련 절의 단서이며 고정 cell partition의 공동 갱신 비용 효과를 확인한 전문 검토는 아니다.

<a id="c20"></a>**C20.** REFOL의 저장 자료는 DOI10.1109/tits.2024.3510913과2025년 IEEE TITS26(2):2777–2792의 서지·요약이다. client 참여 필요성, adaptive online optimization, graph convolution 기반 aggregation을 제안한다는 단서는 있지만 이 응답에는 전체 방법·실험표·비용 수치가 없다. 초록의 효율성 주장을 현재 연구의 비용 절감 근거로 대체하지 않는다.

<a id="c21"></a>**C21.** ACM·Wiley·AutoML survey 발췌와 Polystar webinar는 drift, 재훈련, 에너지/계산 비용이라는 문제를 찾는 동기 자료다. 일반적인 장단점 표와 운영 소개를 특정 cell·기간·모델의 측정 비용으로 옮기지 않는다. 여기서 인용된 개별 연구 전체를 읽었거나 survey 전체를 검수했다는 의미도 아니다.

<a id="c22"></a>**C22.** CESNET-TimeSeries24 검색 발췌는2일·7일 예측에서 RMSE·R²·SMAPE의 차이를 언급한다. 이 짧은 응답만으로 예측 길이를 고정한 재훈련 빈도의 효과를 분리할 수 없다. 원83의 당시 해석과 H105-C10의 별도 원문 검수에서 다룬 조건·지표 설명의 문제로 연결한다.

<a id="c23"></a>**C23.** Eureka의 FDA 페이지는 References라는 표제 아래2025년 항목까지 함께 보여 주므로 이를2020년 논문의 실제 참고문헌 목록으로 그대로 옮기지 않는다. DeepPaper Similar Papers 결과도 When to Retrain이라는 페이지 표제 아래 다른 IoT labeling 연구의 초록을 보여 준다. 표제·본문·관련 자료를 구별하며 Crawled today/last month를 현재의 확인 날짜로 바꾸지 않는다.

## 재검토 조건과 남은 범위

<a id="c24"></a>**C24.** 원83이 보류한 질문은 관측 가능한 변화가 실제 RCTL 갱신 실익을 뜻하는지와 예측 품질을 유지하면서 공동 갱신 범위를 줄일 수 있는지다. 이번 검색 기록은 유사 원리의 존재와 검토 경로를 찾게 하지만 그 연결의 실증 공백을 해소하지 않는다. 다시 설계할 때는 과거와 다른 관측 정보·갱신 결정·품질 조건·비용 비교를 명시해야 한다. 새 연구 코드·모델 실행은0이다.

<a id="c25"></a>**C25.** 새 독해 집계는 응답 TXT2개와 전체 JSON2개다.54응답·47개의 비어 있지 않은 표제 URL, 동일8경로, 기존 원83 자료2개, 파생 표·검수 JSON을 새 논문·새 실험으로 더하지 않는다. 제목·URL·응답 위치·해시·검토 해석을 제공하며 원 응답 파일의 장기 팀 공유 경로는 아직 미확인이다. 현재 외부 URL을 새로 조회한 작업도 아니다.

<a id="c26"></a>**C26.** 원83의 보존 자료 후속6그룹 중 검색·열람4그룹을 읽었고 snapshot25 고유 연혁2그룹은 남는다. 별도로 Fed-PPBC의 미보존 온라인 알고리즘, 수치·차원 표기의 불일치, 당시 오류의 상세 상태와 장기 팀 접근을 미확인으로 추적한다. 원84 이후·이전 미완독·전체 통합·최종 원본 변경과 대표 질문 검수까지 Goal은 계속된다.
