## 어떤 주장을 좁혔는가

[선행연구 비교와 수식 대조](../references/conditional-clustering.md)에 각 논문의 추정 대상, 소속 결정, 재적합 여부, 가정과 읽은 위치를 정리했다.

- Zhang·Wang·Zhu는 개체별 절편을 먼저 추정하고, group quantile loss에 따른 배정과 group 회귀를 번갈아 수행한다. 조건부 분위수 관계로 묶는 발상 자체의 선행이다.
- Yu·Gu·Volgushev는 개체별 파라미터 차이를 그 추정 공분산으로 표준화해 spectral clustering에 넣는다. 개별 추정 결과를 재사용하며 소속마다 회귀를 다시 적합하지 않는다. 이 공분산은 현재 코드의 예측분포 밀도와 다른 양이다.
- Yang·Chen·Li·Li는 상태변수에 따라 변하는 분위수 계수 함수를 추정해 거리와 complete linkage로 묶고, 소속을 고정한 뒤 공동 추정한다. 시간 의존을 허용하는 함수 모형이지만 임의의 모든 다변량 비선형 회귀를 해결한 것으로 확대하지 않는다.
- Sadeghkhani는 실제로 후보 group을 함께 적합한 검증 예측 손실의 감소를 병합 기준으로 삼는다. 현재 graph는 이 공동 적합을 생략하므로 공동 학습 위험도 직접 측정하지 않는다.

따라서 640은 ‘TabICL을 사용한 비선형 관계 clustering’이라는 설명만으로 최종 기여를 채택하지 않았다. 이 결론은 위 방법들과의 제한된 비교다. 모든 관련 연구를 망라한 신규성 조사라는 뜻은 아니다.

## 현재 점수와 실제 구현의 경계

634의 점수는 `w(D−a){0.5−1[Y≤q]}`다. `q`는 두 추정 분포의 혼합 중앙값, `a`는 출처 확률과 예측 밀도로 만든 가중치, `w`는 추정 CDF 차이의 부호다. 실제 query 정답 Y는 마지막 잔차에 쓰인다. [635 코드 65–120, 205–235행](../evidence/0635-0638/originals/SRC-0022528.py.txt)에서 다음 연산을 확인했다.

1. Tab/HGB가 공통으로 유효한 지원 query만 남긴다. 각 출처에서 시간 전반·후반을 나눠 평균한 뒤 두 출처 평균을 같은 비중으로 합하고 음수는 0으로 자른다.
2. 같은 cluster 내부 edge 비용 합을 목적값으로 쓴다. 두 시간 절반 모두 감소하고, 목적지에 지원 이웃이 두 개 이상 있으며, 기존 cluster가 비지 않을 때 이동한다.
3. 최대 3 sweep과 고정 ID 순서를 사용한다. 보장하는 것은 허용된 이동의 목적 감소다. RCTL MAE 감소나 전역 최적 소속의 보장은 아니다.

[638의 정밀도 정정](0638-numeric-precision.md)은 같은 저장 예측에서 유효성을 바로잡았다. 640은 그 결과의 **22개 지원 edge**를 사용한 해석을 다룬다. 지원되지 않은 pair는 미확인 관계다. edge가 없거나 목적값이 낮다는 이유로 cluster 안의 모든 pair가 같은 관계라고 인증할 수 없다. 양의 edge 합은 group 크기와 연결 수의 영향도 받는다.

512와 634의 점수는 정확한 재가중 관계가 있다. 공통 중앙값을 대입한 기존 CQTE 보정항과의 관계도 [수식 대조](../references/conditional-clustering.md)에서 확인했다. 다만 일차 민감도 소거는 참 혼합 중앙값·양의 밀도·올바른 출처 확률 등 조건 아래의 국소 성질이다. 점수는 MAE 단위가 아니며, 잡음 폭·입력 빈도의 영향을 자동 제거한다는 결론은 나오지 않는다. 지원 mask 이후 cell별 평균을 같은 비중으로 합한 평가 분포의 출처 확률과 학습 구간에서 추정한 p가 일치하는지도 이번 기록에서는 입증하지 않았다.

## 비용과 재사용 범위

640은 새 학습 비용을 보고한 기록이 아니다. [635–637](0635-0637-execution-recovery.md)과 [638](0638-numeric-precision.md)에서 검수한 **후보 79pair, 지원 22edge, 완료 14cell·고유 query 3,712행**을 인용한다. 실패·복구를 포함한 635–637의 196.3071837초와 638의 0.7792346초를 합하면 **197.0864183초**다. 이 수치는 그 작은 개발 조건의 준비·계산 비용이다.

일반화한 `E≤Nk`, `Q(N+2E)` 표현은 이웃 수와 edge 수를 제한했을 때의 설계상 연산 수 설명이다. 후보 검색·지원 분류·추정 비용, 잘못 제외한 관계의 대가를 포함한 실측 확장성 결과가 아니다. 모든 선행보다 빠르다거나 전체 도시에서 실행 가능하다고 결론내리지 않는다.

## 후속 판단과 중복 실험 방지

[641 계획 1–31행](../evidence/0640/originals/SRC-0022012.md.txt)은 같은 Tab/HGB 저장 분위수, 22edge, 지원 mask, UPC 초기화·K4와 이동 규칙에서 두 대조를 정했다.

| 대조 | 사용하는 정보 | 결과를 볼 때의 경계 |
|---|---|---|
| 직접 중앙값 거리 | 같은 입력에서 두 저장 중앙값의 절대 차이 | 함수 거리 계열의 단순 대안이다. Yang/Yu 논문 전체 재현은 아님 |
| 정답 없는 plug-in 충돌 | 저장된 `w·p·(1−p)·(F0−F1)` | 추정값과 평가 재가중 때문에 유한 표본에서 실제 Y 점수와 같다고 전제하지 않음 |

두 대조 모두 query Y를 점수에 쓰지 않는 계획이며 RCTL 손실로 소속을 고르지 않는다. 같은 소속이면 이 조건에서 추가 결정 기여가 좁아진다. 다른 소속이면 모두 먼저 보존하고, 실제 효용은 별도로 판단한다. 소속이 다르다는 사실만으로 더 좋은 방법이 되지는 않는다.

팀원이 같은 질문을 다시 다룰 때는 638의 봉인 소속·출력과 641의 후속 검수부터 찾아야 한다. p의 평가 분포 일치, 지원되지 않은 관계, 다른 기간·cohort에서의 효용처럼 아직 확인되지 않은 질문을 명시하고 기존 기록과 달라지는 조건을 남긴다. 640의 비교를 이유로 639의 긍정 결과나 기간·원척도 손해를 삭제하지 않는다.
