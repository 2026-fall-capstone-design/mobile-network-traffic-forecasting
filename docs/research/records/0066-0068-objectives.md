# 66–68 — MMR·MRI·q-FFL의 목표와 재사용 조건

[연구 안내](../README.md) · [저장 위험 진단](0066-0068-group-risk.md) · [MMR](0066-0068-mmr.md) · [MRI](0066-0068-mri.md) · [q-FFL](0066-0068-qffl.md) · [69–71 피크 진단](0069-0071-peak-objective.md)

세 문헌의 본문 검수를 종합하면 **무엇을 보호하는지 먼저 정해야 목적함수를 고를 수 있다.** 큰 절대 손실, 같은 모델 공간에서 피할 수 있었던 손실, 기준 모델 대비 가능한 개선의 비율은 서로 다른 값이다. 세 방법 모두 기존 Tab 소속으로 나눈 RCTL의 보호 성능을 새로 입증한 것은 아니다. 아래는 [H063](../verification/history-063.md)·[H064](../verification/history-064.md)·[H065](../verification/history-065.md)의 검수 범위를 재사용한 통합이며 추가 모델 실험이 아니다. [C41]

| 구분 | 목적의 기준 | 필요한 자료·조건 | Tab-ICL에 옮길 때의 공백 |
|---|---|---|---|
| MMR | 같은 함수집합 F의 집단별 최적 위험 b_g를 빼고 최대 regret 최소화 | 집단별 b_g 추정과 동일한 손실·F; 정리별 독립성·집중·support·최적화 조건 | 유한 local/global RCTL 또는 Tab 점수를 b_g로 간주할 근거 없음. 집단별 기준 적합 비용도 필요 |
| MRI | (기준 위험−현재 위험)/(기준 위험−같은 F의 집단 최적 위험)의 최솟값 최대화 | 사전에 정한 기준 f₀, 모든 집단의 양의 분모, 추정 오차 통제 | 계절 MAE로 나누는 것만으로 MRI가 되지 않음. 작은 분모·비볼록 최적화·시간 분할의 문제 |
| q-FFL | 비음수 client 손실 F_k의 q+1 거듭제곱을 가중 집계 | 손실 척도·client 가중치·q·참여/집계 규칙 | 편차 감소가 모든 client의 손실 감소나 부족 자원 감소를 보장하지 않음 |

q-FFL의 기본 목적은 Σp_k F_k(w)^(q+1)/(q+1)이다. q=0은 지정한 p_k의 평균 손실이다. 원알고리즘 코드의 선택 client 단순 모델 평균과 논문에 쓰인 표본 가중 평균 목적을 동일 구현으로 가정하지 않는다. 유한 q는 정확한 최악 손실 목적과 같지 않으며 q를 키웠다는 사실만으로 모든 손해 없음이나 모든 공정성 기준이 따라오지 않는다. [C42]

MMR에서는 기준 b_g가 모델 매개변수에 대해 상수여도 어느 집단이 최대를 주는지 바꾸므로 최적해에 영향을 줄 수 있다. MRI는 여기에 기준 f₀와 개선 가능 폭의 양의 분모까지 추가된다. 집단 기준을 잘못 추정한 반례와 작은 분모의 오차 증폭은 각각의 기록에 있다. 고정 기준의 평균만 빼는 목적에서는 최적해가 바뀌지 않는다는 사실과 구분한다. [C43–C44]

## 검수 결과가 허용하는 판단

| 확인한 내용 | 허용하는 해석 | 남겨 둔 제한 |
|---|---|---|
| MMR 35쪽의 이론·응용 | 같은 함수집합 기준의 regret를 명시하는 설계 원리 | 별도 supplement·실행판·원배열 미확보. 표기·표/그림의 불일치도 보존 |
| MRI 32쪽과 출판본 | baseline과 개선 가능 폭, 모집단 손해 없음의 조건, 다집단 leximin 구분 | 유한 표본·작은 분모·불완전 최적화의 실제 보장 아님. 증명 중간 식 문제와 실행 근거 공백 |
| 통신 q-FFL 7쪽·표/그림·원알고리즘 코드 | 손실 편차와 개별 손실·부족량을 별도로 봐야 함 | IEEE 최종 본문·통신 구현·원예측·실제 config/seed/scaler/비용 미확인 |

q-FFL 통신 예에서는 q 증가에 따른 CV 감소와 함께 네 client의 손실 및 다섯 연결의 부족량 증가가 관찰된다. 식2와 Table I의 양립 문제, 식5를 그대로 계산하면 상수 100이 되는 문제도 구분해 남겼다. 후보 설명식이 그림에 가까워 보인다는 사실을 저자의 확정 교정으로 쓰지 않는다. 논문 전체나 공정성 연구 전체를 무효라고 선언한 것도 아니다. [C45]

MMR·MRI의 집단은 주어진 비교 단위다. 이 논문들이 Tab 점수로 cluster를 만드는 알고리즘을 제공하거나, 데이터로 고른 cluster와 짧은 시계열에 정리가 자동 적용된다고 쓰면 안 된다. 집단 정의·소속 선택에 사용한 데이터와 최종 예측 평가의 경계부터 따로 지정해야 한다. [C46]

## 기존 저장 결과와 연결

[원67](0066-0068-group-risk.md)은 16cell의 기존 예측을 분석했다. 전체·뒤 기간에는 모든 비global 조건에서 자체 순위의 상위 k 평균(k=1…16)이 global보다 크지만, 앞 기간과 특정 cell에는 개선이 남는다. 각 방법의 자체 상위 k 집합은 같은 cell 집합이 아닐 수 있다. 이 결과는 새로운 MMR/MRI/q-FFL loss로 학습한 성능이 아니다. [C47]

[69–71](0069-0071-peak-objective.md)은 같은 저장 예측에서 실제 target이 높은 순간을 골라 보았을 때의 이득과 전체 손해를 분리한다. cell 보호 목표와 피크 보호 목표를 같은 이름의 ‘공정성’으로 묶지 않는다. 공통 비음수 선형 부족/과잉 비용의 비교도 실제 SLA·capacity나 관측되지 않은 운영 label의 증거로 바꾸지 않는다.

후속 연구를 설계할 때 다음 항목을 먼저 적는다. 이는 새 실행 제안이나 후보 채택이 아니라 기존 이력과의 차이를 확인하는 양식이다. [C48–C50]

1. 보호할 대상: cell·cluster·client·피크 순간 중 무엇이며, 그 집합은 언제 어떤 데이터로 정하는가.
2. 줄일 손해: 정규화/원척도 MAE, 절대 위험, 기준 대비 손해, regret, 상대 개선, 부족 사건/부족량 중 무엇인가.
3. 기준: 같은 F의 집단 최적값과 사전 baseline을 어떻게 추정하며, 그 오차·분모·비용을 어떻게 기록하는가.
4. 허용 행동: 보정·소속 변경·모델 학습·자원 할당 중 무엇을 실제 바꾸는가.
5. 평가: 기존 개발 구간 재사용과 새 시간순 평가를 구분하고 평균·같은 cell 손해·기간별 예외를 함께 남기는가.
6. 실행 근거: 코드 판본·설정·seed·전처리 fit 경계·원배열·재시도 포함 비용을 연결할 수 있는가.

현재까지의 논문 본문 비교는 이 페이지로 통합했다. 각 논문의 실행 근거 공백, 69–71의 기초문헌 본문, 더 뒤의 과거기록과 최종 검색 검수는 여전히 남아 있다. 완성된 문헌 비교표를 전체 연구기록 정리의 완료로 바꾸지 않는다.
