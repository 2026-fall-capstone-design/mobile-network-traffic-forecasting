## 링크 관측에서 OD 흐름을 추정하는 조건

p11 그림 4는 router 4개, 물리 링크 4개, 서로 다른 router 사이의 방향 있는 OD 쌍 12개를 제시하며 75% 감소라고 쓴다. **12개를 4개로 줄이는 동일 개수 기준**이면 감소율은 `(12−4)/12 = 66.666667%`다. OD 12개와 링크 4개를 합한 16개가 기준이라면 75%가 되지만, 이는 분모를 달리 둔 설명 예이고 원문의 명시된 산정식이 아니다. 측정 정보의 크기와 방향별 계수도 같다고 가정하지 않는다. H040-C08.

p12의 관계는 `y≈Rx`다. y는 링크 관측, R은 라우팅 행렬, x는 OD 흐름이며 R의 역행렬이 일반적으로 존재하지 않는다고 설명한다. 이어진 `argmin_x ‖Rx−y‖`는 **관측 링크 잔차**를 줄이는 목적이다. 원문의 참 OD 오차 설명과 동일한 목적함수로 읽지 않는다. 예를 들어 `R=[1,1], y=2`에서 `x=(0,2)`와 `x=(1,1)`은 모두 잔차 0이다. 이는 식의 식별 한계를 보여주는 정적 산술 예이며 저자 전체 방법의 실패 실험이 아니다. 여러 시각 관측이 있으면 maximum likelihood 추정이 된다는 문장은 잡음 분포·식별 조건까지 제시한 증명이 아니다. H040-C09–10.

p13 그림 5는 초기 추정 뒤 추정·기지 제약에 맞추는 조정을 반복한다. ingress/egress 합계가 제약 예다. 확률적 방법을 결합하는 상세는 논문 범위 밖이라고 밝히며, 그림에는 명시적 종료 기준이 없다. 관측 제약을 맞추는 것과 숨은 흐름의 정답을 맞추는 것을 구분한다. H040-C11.

|---|---:|---:|
| Non-AI approach | 29.6% | — |

인쇄값 기준 차이는 **12.6%p**, 상대 감소는 **42.567568%**다. 반올림된 17%만으로 원래 평가의 42%를 정밀 재현했다고 하지 않는다. 비 AI 비교군의 정확한 구현도 특정되지 않는다. 논문은 당시 Abilene를 router 11개·OD 121개·링크 15개로 서술하고, 직접 흐름 관측으로 추정 결과를 평가했다. 이 개수를 물리 cell 수로 옮기지 않는다. H040-C12–13.

p14의 수집량 78% 감소와 p20 요약의 20–75%는 원문 각각의 주장으로 남긴다. 방향별 counter·물리 링크·OD 대각 항목·전송 bytes의 분모가 제시되지 않아 `15/121`을 임의로 적용해 78%를 검증하지 않는다. 17% MAPE가 traffic engineering에 허용 가능하다는 설명도 저자의 판단이며 실제 제어 효용 측정은 제시되지 않는다. H040-C14.

## 표본을 생략한 뒤 복원하는 구조

pp14–16 그림 6–8은 출처 수를 줄이는 §4.1과 달리 출처별 표본을 줄인다. 예시는 두 network element의 A/B·C/D 시계열에서 `A1,A3,B2,B4,C1,C3,D2,D4`를 번갈아 보내는 방식이다. 같은 장치·경로의 상관을 이용하지만 상관이 결정적인 복원 가능성을 보장하는 것은 아니다. 전송량을 줄이거나, 다른 흐름의 빈도를 줄여 특정 흐름의 관측 빈도를 높이는 두 용도를 제안한다. 고정된 공간 cluster 학습이나 RCTL 소속 수정 구현은 아니다. H040-C15·20.

그림 7은 장치 내 수집→표본 제거→전송→복원→품질 평가→제거 규칙 피드백을 그린다. 품질 평가에 참값을 공급하는 경로는 표시되지 않는다. 참값을 언제 추가 관측하고 전송하는지, 그 비용과 제거 규칙을 어떻게 계산하는지는 재사용 시 확인할 사항이다. 그림에 없는 세부를 근거로 전체 구조가 작동 불가능하다고 단정하지 않는다. H040-C16.

복원기는 결측을 잡음으로 다루는 autoencoder다. 그림 8은 주파수 영역 변환, encoder 두 층·bottleneck·decoder 두 층, 시간 영역 복귀를 표시한다. p16 본문은 양 방향에 `inverse Fourier transform`을 쓰지만 그림은 FFT/IFFT 이름을 적지 않아 이 차이를 해소하지 못한다. wavelet 변환도 선택지로 언급된다. 구체적 구현은 미확인이다. 결측 패턴 정보 없이 어떤 제거 전략에도 쓸 수 있다는 설명은 저자 주장이고, 모든 패턴을 평가한 결과는 아니다. H040-C17–18.

| 5% | 4% |

저자는 작은 Abilene 자료라고 설명하며, 약 10% 오차를 허용하면 전송량을 20% 줄일 수 있다는 예를 든다. **20% 생략하면 모든 용도의 정확도가 90%가 된다**는 의미는 아니다. MAPE를 제거한 위치만 집계했는지 전체 위치를 집계했는지, 0값 처리·학습/평가 시간 분할·seed·오차 막대는 명시되지 않는다. 운영 시 필요한 학습·재학습·복원·피드백 전체 지연과 비용도 이 표로 검증되지 않는다. H040-C19–20·33.

## 수집된 이력을 가중치로 압축하는 구조

pp17–19 그림 9–11은 수집한 값을 일시 저장하고 구간으로 나눠 DNN에 학습시킨다. 구간 index의 32개 bit가 입력이고 길이 p인 과거 구간이 출력이다. p18의 예는 `W3 ReLU(W2 ReLU(W1 i+b1)+b2)+b3`인 세 층 구조다. 원문은 index의 bit 표현을 입력 특징으로 설명하면서 식에서는 i로 줄여 쓴다. 가중치 학습과 조회용 hosting, index–기간 대응표가 필요하다. 이미 알려진 이력을 암기·근사 조회하는 것을 미래 예측 또는 무학습 압축으로 집계하지 않는다. 원문의 압축 후 raw data 삭제는 당시 설계 설명이며 이 정리 작업에서 수행한 행동이 아니다. H040-C21–23.

근사 오차를 임의로 작게 할 수 있다는 설명이 **고정된 모델 크기·압축률·학습 비용에서의 보장**은 아니다. 압축률은 원 데이터 크기를 DNN 크기로 나눈 값이며 예시는 16 MB / 4 MB = 4배다. index 표·metadata·수치 정밀도·serving 비용까지 포함한 분모는 아니다. H040-C23–24.

작은 흐름 100개를 100배, 큰 흐름 1개를 10배 압축하는 예에 원문은 전체 91배를 적고 각주에서 흐름들에 걸친 평균이라고 설명한다. 원래 저장 bytes가 흐름마다 같다는 **추가 가정**을 두면 전체 원 크기/압축 크기는 `101/(100/100+1/10)=91.818182`배다. 압축률 숫자의 단순 평균은 `(100×100+10)/101=99.108911`배다. 실제 흐름별 bytes 가중치와 반올림 기준이 없어 91배를 실제 측정 오류로 확정하거나 다른 값으로 교체하지 않는다. H040-C25.

## 비용 예시의 단위와 기간

p17은 출처 백만 개를 1분 간격으로 측정하는 예를 `46Gb/day`, `16Tb/year`로 적는다. 소문자 b의 표기와 실제 청구 단위의 대응은 명확하지 않다. 단순 십진 단위·365일 가정이면 `46×365/1000=16.790`이며, 이를 실제 bytes 단위나 측정된 연간 사용량으로 확정하지 않는다. 같은 단락의 아래 값은 **2021년 저자 비용 예시**로 보존한다. 현재 AWS 요금 견적은 아니다. H040-C29–30.

| 비용 항목 | 원문 표시 |
|---|---:|
| 첫해 저장 | 약 $5000 |
| 5년째 저장 | 약 $25000 |
| 16Tb를 한 번 압축 | 약 $2.50 |
| 압축본 1년 저장 | 약 $150–250 |
| 5년간 절감 주장 | 약 $24000, 96% |

`24000/25000=96%`는 맞지만, 5년째 연간 비용과 5년 누적 비용의 비교 기준은 충분히 설명되지 않는다. 예를 들어 매년 같은 양이 추가되고 첫해 연간 저장비 $5000이 누적분에 비례한다는 **가정**이면 연간 비용은 $5000·10000·15000·20000·25000이고 합은 $75000이다. 이것은 기간 기준을 설명하는 산술 예이지 원 청구서의 정정이 아니다. 월별 적재 시점·요금 조건·압축 학습 장치·시간·hosting·조회·index 표 비용이 없어 $2.50이나 전체 절감 주장을 독립 검증하지 않았다. H040-C31.

15분 값을 하루 평균 하나로 만드는 예의 96배는 `24×60/15=96`으로 확인된다. 같은 크기의 값 하나로 바꾸는 개수 기준이며, 평균화와 DNN 압축의 오차·조회 효용이 같음을 뜻하지 않는다. H040-C32.

## 같은 연구를 반복하기 전에

53·55에서 재사용할 것은 **줄이는 비용의 단위, 실제 이용 가능한 관측, 복원 목표, 단순 비교군과 총비용을 먼저 정하는 질문**이다. Ciena를 읽었다는 이유로 [54의 직접 회귀 확인](0052-0054-partial-observation.md)을 Ciena 구현 실험으로 바꾸거나, 당시 확대하지 않기로 한 판단을 철회하지 않는다. [SRSSS](0053-srsss.md), [Zoom2Net](0053-zoom2net.md), [NETNOMOS](0053-netnomos.md), [TabICL imputation](0053-tabicl-imputation.md)의 입력·선택·복원·비용 단위도 함께 비교할 수 있다. H040-C34–35.
