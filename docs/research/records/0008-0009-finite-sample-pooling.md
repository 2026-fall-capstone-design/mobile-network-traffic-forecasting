# 08·09 — 유한표본 공유 효과와 추가 경로의 기각

2026-09-25의 08 실행 전 계획, 저장 진단, 09 판단을 통합했다. [B2의 RCTL 결과](0004-0007-b2-observed-risk.md) 이후, 조건부 분포가 비슷하다는 것만으로 유한 자료를 합쳐 학습할 이득을 정할 수 있는지 확인한 기록이다. 단순 합성 반례와 기존 출력 분석은 수행됐지만, 새 소속 알고리즘 채택이나 RCTL 개선 검증은 아니다. [원문·실제 읽기 범위](../sources/history-002.md), [보존 근거](../evidence/0008-0009/README.md), [검수](../verification/history-002.md).

## 질문과 실제 수행

08은 학습 자료의 공동 의존성을 바꿔도 각 cell의 조건부 주변분포와 이상적 예측값은 같을 수 있다는 점을 확인한다. 따라서 population risk table과 실제 유한표본 학습 오차를 구분한다. 반례가 성립해도 잔차 상관을 낮추는 소속이 RCTL에 유리하다고 바로 결론내리지 않기로 했다.

실행 근거는 [계획](../evidence/0008-0009/originals/SRC-0020829.md.txt), [과거 코드](../evidence/0008-0009/originals/SRC-0022801.py.txt), [결과 JSON](../evidence/0008-0009/originals/SRC-0023580.json)과 [09 판단](../evidence/0008-0009/originals/SRC-0020830.md.txt)이다. 결과의 계획 SHA-256은 보존 계획과 일치한다. 이는 내용 연결이며, 실행 전 봉인의 독립적인 시각 증명은 아니다. 기록 번호 08·09를 두 번의 RCTL 실험으로 세지 않는다.

## 합성 확인: 같은 주변분포와 다른 표본 의존성

상수 입력을 가진 3cell 각각에 표준정규 관측31개를 둔다. MAE를 최소화하는 표본 중앙값으로 cell별 학습과 전체93개 pooling을 비교했다. seed20260925, 20,000반복이다. 독립 조건은 cell·시점 간 독립이고, 공유 조건은 매 시점 세 cell의 관측이 완전히 같다. 원 코드에서 공유 조건은 독립 배열의 첫 cell을 세 번 복제한다. 같은 표본의 행 순서만 바꾼 비교가 아니다.

평가는 학습 표본과 독립인 표준정규 target에 대한 기대 절대오차다. 예측값 a에 대해 `2φ(a) + a(2Φ(a)−1)`을 사용해 test target을 새로 추출하는 변동을 없앴다. φ와 Φ는 표준정규분포의 밀도와 누적분포 함수다. 아래 오차는 정규화된 교통 MAE와 단위가 다른 합성 분포의 위험이다.

|---|---:|---:|---:|
| population 최적 중앙값0 | 0.7978845608 | 0.7978845608 | 0 |

독립 조건의 paired Monte Carlo 표준오차는 원 JSON에 `0.00009766866118`로 보고됐다. 개별/pooled 초과위험은 각각 `0.01960453761048`/`0.006647268487248`이다. 공유 조건의 pooled 중앙값은 93개 중47번째 값으로, 세 번씩 반복된 원31개 중16번째 중앙값과 정확히 같다. 이 항등식에는 새로운 난수가 필요 없다.

아카이브는 Bayes 위험 `sqrt(2/π)`, 집계값의 차이·초과위험 및 위 순서통계 항등식을 검산했다. **확인한 JSON에는20,000개의 원 난수·중앙값이 없어 MC 평균과 표준오차를 독립 재계산하지 않았다.** 원 코드의 저장문과 관련 이름의 목록에서는 집계 JSON만 확인했다. 전체 폴더의 다른 이름으로 된 표본 파일까지 부재를 확정한 것은 아니다. 현재 정리 작업의 새 Monte Carlo 생성은0이다.

같은 주변 조건부 분포만으로 유한표본 pooling 효과가 정해지지 않는다는 반례로 보존한다. RCTL의 성능·교통망의 인과 효과·새 수학 정리를 증명한 결과로 사용하지 않는다. 독립 조건과 공유 조건의 개별 MAE가 조금 다른 것은 위 집계 방식과 유한 MC 결과이며, population 위험이 달라졌다는 뜻이 아니다.

## 실제 자료: 같은 B2 설계 주간의 잔차·분위수 진단

고정16cell, target672–839의168시간, 이미 저장한129개 midpoint 분위수를 사용했다. 입력·정규화·Tab 설정과 context168–671은 [B2 기록](0004-0007-b2-observed-risk.md)을 따른다. 공통 Ridge 예측과64상태 bin도 기존 값이다. Tab/Ridge/상태 모델을 새로 학습하지 않았고, 이 진단에서 RCTL 출력·loss를 읽지 않았다는 코드 및 결과 표시를 확인했다. 이미 사용한 설계 주간이므로 독립 평가가 아니다.

## 09의 추가 경로 판단과 이후 연결

09는 (1) 잔차 covariance 항을 B2에 추가하는 방향과 (2) Tab 분포의 예측 손실을 관측값으로 보정하는 방향을 검토했지만 채택하지 않았다. 세 일차문헌의 확인 지점과 적용 한계는 [공유 효과·보정 문헌 비교](../references/finite-sample-pooling.md)에 모았다. 동일한 구상 자체의 선행이 있고, 현재 자료·learner에 필요한 추가 정보나 안정적인 이득이 확인되지 않았다는 당시 판단이다. 모든 공분산 방법이나 prediction-powered inference의 일반적 기각은 아니다.

같은 query·같은 예측 손실·같은 가중치와 정규화에서 `Σwᵢ(Lᵢ−Qᵢ) + ΣwᵢQᵢ = ΣwᵢLᵢ`다. 따라서 이런 상쇄만으로 empirical loss에 새로운 정보를 더할 수 없다. 이미 정답이 있는 h=1 과거 자료를 임의로 가려 별도의 unlabeled 이점을 만들지 않기로 했다. 실제 관측 지연·결측 또는 다른 입력 모집단이 존재하는지는 별도 확인 사항이다.

09가 남긴 다음 질문은 현재 중앙부16cell의 전체 Milan 대표성과 UPC peak 요약의 시간 안정성이다. 후속 [10–12 진단](0010-0012-population-upc-stability.md)은 당시 수행한 자료·소속 분석을 저장 결과에 대조해 연결했다. 현재 아카이브 작업의 새 모델 실행으로 세지 않는다. 13 이후의 연결과05 문헌 감사의 남은 범위는 계속 확인한다.

## 비용·재사용·재검토 조건

원 기록의 경과시간은 **0.2492086초**, 새 Tab context/query와 RCTL fit은 모두0이다. 이 시간은 원 코드의 `start` 이후 합성 계산·기존 파일 읽기·실자료 산술을 포함하며, 앞선 import와 최종 JSON 저장 시간은 포함하지 않는다. 계획의30초 상한은 코드에서 assert하지만, 계획의 메모리1GiB는 저장 peak 측정값이나 강제 제한으로 확인되지 않았다. 원문 속 과거 Goal 예산은 현재 실행 지시가 아니다.

동일 주간의 재확인은 보존 JSON과 B2 배열을 사용한다. 같은 합성 조건의 숫자를 다시 만드는 작업을 새 clustering 성과로 세지 않는다. 재검토하려면 다른 기간/자료량에서의 안정성, 같은 정보로 가능한 empirical 기준, 실제 learner의 공유 이득, 실제 존재하는 미관측 입력의 역할을 명시해야 한다. 새 모델 학습과 독립 과학적 재현은 이 아카이브 작업에서 수행하지 않았다.
