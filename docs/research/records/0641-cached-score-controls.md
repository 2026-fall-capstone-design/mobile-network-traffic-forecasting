# 641 — 같은 저장 예측에서 소속 점수만 바꾼 대조

**네 대조(Tab/HGB × 중앙값 거리/plug-in 충돌)는 모두 UPC 소속을 유지했다.** 같은 저장 예측에 실제 query 정답을 반영한 기존 관계 점수를 쓴 638에서는 Tab이 3cell, HGB가 1cell을 이동했다. 이 결과는 한 개발 조건에서 선택한 점수식에 따라 소속이 달라졌다는 근거다. 모든 함수 거리 방법보다 우수하거나 실제 Y 사용이 일반적인 성능 개선을 보장한다는 근거는 아니다.

[640 기여 범위](0640-contribution-boundary.md) → **641 저장 출력 대조** → 642 추천안 계획. [출처](../sources/pilot-004.md) · [검수](../verification/pilot-004.md) · [보존 자료](../evidence/0641/README.md)

## 두 점수와 소속 결과

각 지원 입력에서 다음 값을 계산했다. 같은 mask와 배정 규칙을 적용했지만 두 비용의 단위는 다르므로 목적값 크기를 대조 사이의 성능 순위로 쓰지 않는다.

1. **중앙값 거리:** 두 cell 추정기의 저장 0.5분위수 차이의 절댓값. 정규화 traffic 예측의 거리다.
2. **plug-in 충돌:** 저장 `w × p × (1−p) × (F0−F1)`. `w`는 CDF 차이의 부호이며 확률량으로 만든 비용이다. 이상적인 조건부 기대값에 추정 분포를 대입한 비교이지, 유한 표본에서 관측 정답 점수와 정확히 같은 양이라는 주장이 아니다.

대조 worker는 638 edge 파일의 `mask, p, w, F0, F1`만 읽고 query의 `y`, 출처 `d`, 기존 잔차 `score` 배열을 사용하지 않았다. 중앙값은 637의 저장 예측에서 읽었다. [worker 42–128행](../evidence/0641/originals/SRC-0022557.py.txt)에 해당 계산과 소속 봉인이 있다. 직접 거리 대조는 Yang/Yu 원 알고리즘 전체의 재현이 아니다.

| 추정기·대조 | 앞 32개 목적값 | 뒤 32개 목적값 | 이동·종료 |
|---|---:|---:|---|
| Tab 중앙값 거리 | 0.483176018140 | 0.618303186062 | 이동 없음, UPC 유지 |
| Tab plug-in 충돌 | 0.268550112682 | 0.284239633682 | 이동 없음, UPC 유지 |
| HGB 중앙값 거리 | 0.358392317511 | 0.347410664841 | 이동 없음, UPC 유지 |
| HGB plug-in 충돌 | 0.188983762796 | 0.192554270354 | 이동 없음, UPC 유지 |

모두 초기·최종 목적값이 같고 `no_admissible_move`로 종료했다. 반대로 [638](0638-numeric-precision.md)의 관측 정답 관계 점수는 Tab에서 **3745 → 6153 → 3765**, HGB에서 **3745**를 이동했다. 641은 그 기존 봉인 소속을 읽어 비교했으며 관측 정답 점수를 다시 실행하지 않았다. [소속 봉인](../evidence/0641/originals/SRC-0024473.json)과 [결과](../evidence/0641/originals/SRC-0024478.json)에 두 종류를 구분해 보존했다.

## RCTL 지표는 어떻게 연결했는가

소속을 봉인한 뒤 [linker 전체 36행](../evidence/0641/originals/SRC-0022902.py.txt)은 실제 cell ID, group 구성, seed, 639 protocol hash, 각 예측 파일 hash를 대조했다. 네 대조 × 네 group의 **16개 연결 자리가 같은 UPC 예측 4개**를 반복 참조한다. 16회 새 학습이나 독립 재현이 아니다. 연결 단계는 파일 바이트를 해시했지만 예측 배열을 로드해 MAE를 계산하지 않았다.

최종 예측기는 소속별 RCTL이며 Tab 직접 예측의 MAE가 아니다. 639 조건은 학습 index 168–839, 검증 840–1007, 평가 1008–1487(480시점), steps8·channels9, MAE/Adam·학습률0.001·batch256·최대80epoch·patience10이다. 전체 기간은 개발 자료다. 상위 정규화 생성 과정과 재사용 학습의 thread 차이 등 한계는 [639 조건·출처](0639-rctl-bridge.md)에 남겼다.

아래 수치는 [639 결과를 연결한 JSON](../evidence/0641/originals/SRC-0024476.json)의 재인용이다. 각 cell의 시간 평균 절대오차를 16cell에 동일 가중 평균했다.

| RCTL 소속 | 정규화 전반240 | 정규화 후반240 | 정규화 전체480 | 원척도 전체480 |
|---|---:|---:|---:|---:|
| 네 대조 모두 = UPC | 0.073663 | 0.095851 | 0.084757 | 112.588418 |
| 기존 Tab 관계 점수 | 0.073563 | 0.089228 | 0.081396 | 103.917530 |
| 기존 HGB 관계 점수 | 0.074461 | 0.096335 | 0.085398 | 110.622374 |
| 강한 비교군 HGB_free | 0.071623 | 0.094376 | 0.083000 | 97.497435 |

Tab 관계 점수는 UPC보다 전체 정규화 MAE가 **3.97% 낮다**. HGB_free보다는 전체 1.93% 낮지만 전반은 **2.71% 높고**, 원척도 전체는 **6.58% 높다**. HGB_free 대비 전체 손해 cell 6개(3753, 3765, 4537, 5337, 5345, 6165)도 그대로 남는다. 새 대조가 UPC와 같다는 사실로 이 반례를 해소하지 않는다. 전체 정밀도·절반별 원척도 수치는 [검산 결과의 재인용 지표](../verification/pilot-004-arithmetic.json), 저장 예측에서 MAE를 직접 검산한 근거는 [639 검수](../verification/pilot-002.md)에 있다.

## 당시 판단·재사용·남은 질문

당시는 이 조건에서 점수식의 추가 결정과 기존 RCTL 효용을 연결할 수 있다고 판단하고 642 추천안 문서화로 넘어갔다. 현재 정리는 그 판단을 보존한다. [642 최종 보고서·Word](0642-research-direction.md)는 착수 권고와 미실행 본실험을 구분해 정리했다. 팀의 연구 방향 채택이나 새로운 실험 승인은 별개의 일이다.

같은 cell·query·seed·mask·점수·이동 규칙을 확인하려면 [보존 자료와 검산 명령](../evidence/0641/README.md)을 먼저 사용한다. 새 연구는 새 기간·cohort·seed, 지원 graph, 점수 정의, 비용 대비 효용 중 무엇이 달라지는지 적는다. 기존 대조를 다시 학습해 독립 성과처럼 집계하지 않는다.

이번 결과는 실제 Y 성분만의 보편적 인과 효과, 수학적 신규성, 입력 빈도·잡음 제거, 모든 함수 clustering 대비 우위, 새 도시·기간 일반화를 확정하지 않는다. 대조 간 단위와 추정오차·유한 표본 변동, 희소 graph와 이동 제약도 소속 차이에 영향을 줄 수 있다. 같은 초기 소속에서 이동이 없다는 사실은 그 비용의 전역 최적성도 뜻하지 않는다. before 상태 사본 전체와 상위 원자료 생성 과정은 미검토 범위로 남긴다.
