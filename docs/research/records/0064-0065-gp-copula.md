# 64·65 — GP-Copula의 분포 변환, 공유 예측과 공개 구현의 차이

**경험 CDF로 주변 분포를 Gaussian 좌표로 바꾸고, 여러 시계열이 파라미터를 공유하는 RNN으로 예측한 뒤 역변환하는 연결은 이미 존재한다.** Salinas 등의 *High-dimensional multivariate forecasting with low-rank Gaussian Copula Processes*, NeurIPS 2019가 그 근거다. 경험 CDF를 Tab의 CDF로 교체하고 RCTL을 붙이는 것만으로 새 원리를 주장하기 어렵다는 [64번 계획](../evidence/0063-0065-ecai-interface/originals/SRC-0022015.md.txt)·[65번 검토 §5](../evidence/0063-0065-ecai-interface/originals/SRC-0022016.md.txt)의 판단을 뒷받침한다.

다만 이 논문은 cell 군집화나 TabICL→RCTL 성능을 검증하지 않았다. GP-Copula가 GP-scaling보다 낫다는 결과도 데이터와 지표에 따라 다르다. **Electricity와 Taxi에서는 CRPS·CRPS-sum 모두 GP-scaling의 인쇄 평균이 더 낮다.** 공개 GluonTS 코드는 논문 실행본의 재구현이며, 학습 설정·평가 구간·지표 구현을 구분해서 재사용해야 한다.

이번 검수는 저장된 본문 **11쪽 전체와 3그림·3표**, 공식 보충자료 **12쪽 전체와 3그림·10표**, 고정 커밋의 코드 **12파일 전체·4파일 선택 구간**을 대상으로 했다. 본문의 참고문헌37건과 보충자료24건은 서지를 읽은 범위다. 원 모델·코드는 실행하지 않았다.

## 변환과 예측이 연결되는 방식

계열 i의 관측 z를 `f_i(z)=Φ⁻¹(F̂_i(z))`로 바꾼다. Φ는 표준정규 CDF, F̂는 과거 관측으로 추정한 경험 CDF다. 선형 보간으로 값을 매핑하고 예측 뒤 `F̂_i⁻¹(Φ(y))`로 원척도에 돌아간다. 본문은 m=100을 사용하고, **정상 주변분포를 가정한다**. 선형 추세처럼 가정이 깨질 때 detrending·differencing을 제안한다. 변환만으로 임의의 비정상성이 해결된다는 결과는 아니다. (본문4–5쪽, 보충 B)

각 계열의 RNN 상태는 해당 계열의 이력을 요약하고, RNN 및 출력 투영의 파라미터는 계열 사이에 공유한다. 변환된 관측 벡터의 조건부 결합분포를 Gaussian으로 두며 공분산은 `Σ_t=D_t+V_tV_tᵀ`이다. D는 양의 대각행렬, V는 N×r이고 본문 rank는10이다. 학습은 계열 부분집합 B=20을 사용하며, 전체 계열 예측과 학습 부분집합의 목적을 동일시하지 않는다. (본문3–6쪽)

원척도 밀도에는 Gaussian log likelihood와 `Σ_i log|f′_i(z_i)|`가 함께 들어간다. **본문 식2만 보고 Jacobian이 빠졌다고 판정하지 않는다.** 5쪽의 변수변환 설명과 저장 PNG에서도 확인된다. 이 목적은 변환 공간의 단순 MAE가 아니며, 65번의 “비선형 변환이 유한 후보의 원 단위 MAE 순위를 보존하지 않는다”는 논리와 구분한다.

저랭크 구조의 표현 크기는 O(Nr), Gaussian likelihood 계산은 O(Nr²+r³)이다. 보충 A는 행렬식 보조정리와 Woodbury 식으로 이를 설명한다. 전체 데이터 읽기·CDF 계산·RNN 학습·탐색·모든 예측 표본의 비용까지 이 식 하나로 제한한 것은 아니다. 본문 Table3의 입력/출력 투영 파라미터 비교도 실행시간 측정과 다르다.

이 방법은 [PLOS의 각 시계열 내부 lag copula 거리 군집화](0064-0065-plos-copula.md)와 대상이 다르다. GP-Copula는 시변 결합 예측분포를 학습한다. 또 경험적 주변 CDF를 전체 과거 H에 조건부인 정확한 `F(Y|H)`로 바꾸어 읽지 않는다. 64·65의 정확한 조건부 PIT와 단일 미래값 중앙값 환원 논리는 별도이며, 개별 PIT가 uniform이어도 여러 미래값 사이의 공동 의존은 남을 수 있다.

Traffic는 도로 차선 점유율이며 이동통신 traffic 자료가 아니다. Taxi는 뉴욕 pickup/dropoff 수를 합친 공간 격자 시계열로, 학습은2015년1월·평가는2016년1월을 쓴다. 보충 F는 이상치·공간 범위·0.001 격자·80% 이상 nonzero 조건을 설명한다. 실제 배포 데이터의 전처리를 다시 검증하지는 않았다.

본문은 시간 자료7개·기타 자료5개·Taxi57개 평가 구간을 사용한다. 각 반복에서 첫 평가 구간 이전 자료로 한 번 학습한 모델을 rolling 평가에 재사용하고, 전체 절차를3회 반복한다고 보고한다. 400개 예측 표본과 보충 G의10개 등간격 분위수로 평가한다. **CRPS는 주변 예측, CRPS-sum은 동일 표본의 계열 방향 합을 먼저 구한 뒤 그 합의 분포를 평가한다.** 개별 CRPS를 더한 값으로 바꾸지 않는다.

두 지표에서 각각6개 중4개 자료의 평균은 개선되고2개는 악화된다. MSE·MSE-sum의 승패도 이 표와 같다고 가정하지 않는다. DeepAR/MQCNN 추가 비교는 주변 CRPS이고, DeepGLO/TRMF와의 두 자료 WAPE 비교는 별도 평가다. 모든 자료·지표·seed의 우월성이나 RCTL pooling 효과로 확대하지 않는다.

보충 C의 Electricity rank 실험은5회 mean·95%CI이며, 인쇄 test NLL 평균은 rank32에서 가장 낮다. 높은 rank에서 train loss가 낮아져도 test가 계속 좋아지지는 않는다. 본문 합성 rank2 공분산 실험·상관행렬 그림은 구조의 정성 확인이며 군집 정답이나 통신 cell 성능 검증이 아니다. 보충 J에서100→600 예측 표본의 평균 CRPS 변화는 GP .272→.271, Vec .52→.50으로 보고된다. 전체 곡선의 정확값이나 모든 자료의 단조 개선을 복원하지 않았다.

## 공개 GluonTS 코드를 재사용하기 전에

보충 L은 공개 코드를 **재구현**이라고 명시한다. 링크의 `mv_release`를 2026-10-10 확인해 커밋 [`442bd4f`](https://github.com/mbohlkeschneider/gluon-ts/tree/442bd4ffffa4a0fcf9ae7aa25db9632fbe58a7ea)로 고정했다. 파일별 SHA-256·Git blob SHA와 실제 읽은 줄은 [코드 검수](../evidence/0064-0065-gp-copula/code-audit.json)에 있다. 아래 코드 경로는 정적 확인이며 실행 시 유효 설정 전체를 관측한 결과가 아니다.

| 항목 | 원논문·보충자료 | 고정 공개 코드에서 확인한 것 |
|---|---|---|
| 계열 부분집합 | B=20 | factory의 Hyperparams는 B=2. 학습만 계열을 부분 선택하고 predictor는 전체N을 쓴다. |

| CDF 매핑 | m=100·선형 보간·winsorization·학습 jitter | 시간 구간 분리→전체 차원 CDF 매핑→계열 부분 선택 순서다. 입력 창 길이가m과 다를 때 `_fill`을 호출하며, 이 함수는 남은 과거가 부족하면 반복하고 넘치면 최근m개를 쓴다. 언제나 서로 다른 최근100시점이라고 읽으면 안 된다. |

CDF는 padding과 미관측을 거른 과거로 적합하고, 미래 학습 target에도 그 매핑을 적용한다. `_fill`은 남은 관측이0개면0으로 채운다. 다만 호출 조건은 **필터 전 입력 창 길이**를 사용한다. 입력 길이가 정확히m인데 필터 후 행이 줄면 채우기를 건너뛰고 뒤의 shape assertion과 맞지 않는 경로가 남는다. 이는 정적 조건 대조이며 실제 데이터에서의 발생 여부는 확인하지 않았다.

학습 jitter는 코드상 각 과거 시점의 **차원 방향 표준편차**를 사용한다. 예측은 변환 좌표에서 재귀 표본을 만들고 마지막에 역변환하며, 예측 horizon 안에서 CDF를 새로 적합하는 경로는 확인되지 않았다. 미분항을 loss에서 제거했다는 설명은 매핑의 선형 보간까지 없앴다는 뜻이 아니다.

재구현의 결과도 원결과와 같지 않다. 보충Table9에서 CRPS-sum 평균은 원본 대비3개 자료에서 낮고2개에서 높으며1개는 인쇄값이 같다. Table10의 CRPS는3개에서 낮고3개에서 높다. 여기에는 설정·구간 차이가 함께 있으므로 B=2나 미분항 제거 하나의 인과적 효과로 해석하지 않는다.

데이터 tar·원논문 실행본·전체 benchmark 호출을 검증하지 않았다. 선택 테스트는 빠른 ND<10 점검이며 논문표 재현 검사가 아니다. 해당 테스트가 import하는 심볼/경로 일부는 읽은 파일과 고정 tree에서 확인되지 않았다. requirements도 전체 환경의 완전한 고정본이 아니다. 코드 링크가 있다는 사실을 설치·실행·재현 성공으로 표시하지 않는다.

## 인쇄 불일치와 재현 시 확인할 공백

**표준편차(SD), 표준오차(SE), 95%CI를 서로 바꾸지 않는다.** 본문Table2는3회 mean/std라고 쓰고, 보충Table4·6·7·9·10은3회 mean/standard error라고 쓴다. 특히 본문Table2의 GP-Copula6개 mean/±쌍이 보충Table9 original행에 그대로 나타나지만 명칭은 다르다. 자동으로 √3을 곱하거나 나눠 원표를 수정하지 않았다.

비음수인 n개 결과의 평균을 μ, 표본 표준편차를 s라 하면 `s≤√n·μ`, 따라서 통상적인 `SE=s/√n≤μ`다. 이 정의로 같은3회 결과를 집계했다는 **조건에서만**, 다음 인쇄값은 반올림 범위를 고려해도 맞지 않는다.

| 위치·지표 | 모델·자료 | 인쇄 mean±항 | 적용한 조건 |
|---|---|---|---|
| 본문Table2 CRPS-sum | GP-scaling·Taxi | .183±.395 | SD≤√3·mean |
| 보충Table4 CRPS | GP-scaling·Taxi | .346±.348 | SE≤mean |
| 보충Table6 MSE | GP-Copula·Wiki | 4.0e7±1.6e9 | SE≤mean |
| 보충Table7 MSE-sum | GP-scaling·Taxi | 7.9e6±8.9e6 | SE≤mean |
