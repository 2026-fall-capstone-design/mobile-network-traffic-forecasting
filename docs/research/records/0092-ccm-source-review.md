# CCM v2: 클러스터별 출력층, 공동 학습, 표시값 검수

원81이 참고한 CCM은 **학습 가능한 소속 확률과 클러스터별 선형 출력층을 함께 쓰는 선행연구**다. 클러스터마다 완전한 RCTL 모델을 별도로 학습한 결과로 해석하면 안 된다. 원81의 이 구분은 논문에서 확인되지만, 저장 코드의 실제 동작은 별도 검토가 남아 있다.

## 방법과 구현을 구분해서 읽기

<a id="c05"></a>**C05.** Eq.1은 표준화한 시계열 사이의 제곱 유클리드 거리로 RBF 유사도 `exp(−‖Xi−Xj‖²/(2σ²))`를 정의한다. Appendix A.1의 사용값은 `σ=5`다. 다른 거리나 도메인 지식을 쓰는 방안은 논의하지만, 이 논문의 해당 결과를 DTW 또는 UPC 기반 실험으로 바꿔 부를 수는 없다.

<a id="c06"></a>**C06.** 채널 입력을 MLP 표현으로 변환하고 K개 클러스터 표현과의 정규화된 cosine 점수로 소속 확률을 구한다. Eq.2는 확률이 0∼1이고 합이 1이라고 쓰지만 `Normalize` 연산의 구체적인 구현은 이 식만으로 정해지지 않는다. 근사 Bernoulli 소속 행렬 `M∈R^(C×K)`를 얻는다는 설명도 고정된 서로소 partition을 보장하는 명세와 구분해야 한다.

<a id="c07"></a>**C07.** Eq.3은 소속 행렬로 제한한 cross-attention으로 prototype을 갱신한다. zero-shot에서는 cross-attention을 끄고 학습된 prototype을 고정한다. Appendix B에 따르면 CD 기반 모델은 학습·평가 채널 수가 같아야 하고, CI 기반 모델은 다른 채널 수도 처리할 수 있다. 단변량 적응은 여러 시계열 sample 사이의 군집화로 설명한다.

<a id="c08"></a>**C08.** 학습 목적은 `L = L_F + βL_C`이며 예측 손실과 군집 손실을 결합한다. 따라서 이 방법을 예측 목적과 독립적으로 계산된 군집화라고 기록하지 않는다. 다만 구체적인 역전파 경로와 추가 정규화는 저장 코드 검토에서 확인해야 한다.

<a id="c09"></a>**C09.** 원문 Eq.4는 `−Tr(MᵀSM)+Tr((I−MMᵀ)S)`다. 통상적인 trace와 항등행렬 I로 읽으면 trace 순환성에 의해 `Tr(S)−2Tr(MᵀSM)`로 정리된다. **이는 이번 정리의 수학적 대조 결과**다. S를 고정하면 둘째 항에 M에 관한 독립적인 반발 목적이 추가되지 않으므로, 본문의 “군집 간 분리” 설명을 그대로 구현 보장으로 옮기지 않는다. 구현의 제약·정규화·다른 손실을 확인하기 전에는 코드 오류나 실제 군집 붕괴로 단정하지 않는다.

<a id="c10"></a>**C10.** 클러스터별 출력층은 각각 하나의 선형층이며, 최종 출력은 소속 확률로 각 층의 출력을 가중 평균한다. 선형성 때문에 가중치를 먼저 평균하는 형태와 동등하다고 설명한다. 이는 공유 temporal module과 출력층을 결합하는 구조로, 클러스터마다 독립적인 전체 RCTL 파이프라인을 fit하는 비교와 다르다.

<a id="c11"></a>**C11.** §4.3의 `O(KCd)`는 소속 확률 계산과 prototype cross-attention에 대한 설명이다. Eq.1의 C×C 유사도 구성, 기반 모델 학습, 전처리까지 포함한 전체 실행 비용으로 인용하지 않는다. Appendix A.1의 거리별 복잡도 표 역시 한 쌍의 시계열 거리 계산에 관한 범위다.

## 데이터·설정·재현에 필요한 조건

<a id="c12"></a>**C12.** 장기예측은 ETTh1/2, ETTm1/2, ILI, Exchange, Weather, Electricity, Traffic의 아홉 데이터셋이다. Traffic은 San Francisco 지역의 **862개 도로 센서**, 시간 단위 자료로 설명된다. Milan 셀룰러 트래픽 또는 UPC 자료에 대한 결과는 아니다.

<a id="c14"></a>**C14.** Stock은 1,390개 주식, 2013-11-25∼2023-09-01의 5분 간격 가격으로 설명된다. 개장일 09:30∼16:00 자료를 모으며 조기 폐장일을 제외하고, 주변 시점 보간과 시간 정렬을 수행한다. train/validation/test는 **주식 집합을 7:2:1**로 나누므로 평가 대상 주식은 학습에서 보지 않은 sample이다. 예측 길이 7/24를 날짜 단위로 읽지 않는다. Table 3/9의 Stock `Length=10000`이 어떤 집계 단위인지는 본문만으로 확정하지 않는다.

<a id="c15"></a>**C15.** 저자는 PyTorch, 단일 RTX A6000 48GB, 서로 다른 seed의 5회 평균, RevIN, Adam `(0.9,0.999)`, early stopping을 보고한다. 예측 손실은 장기·Stock에서 MSE, M4에서 SMAPE다. 논문은 기반 모델의 공식 코드와 최적 설정을 사용했다고 쓰지만, 여기서 seed 값·학습률·epoch·전체 선택 절차가 모두 복원된 것은 아니다.

<a id="c16"></a>**C16.** Table 10에서 ETT 네 종류·Exchange·ILI의 K는 2다. Weather는 `[2,5]`, Electricity·Traffic은 `[3,10]`으로 표기한다. β는 ETTh1/ETTm1/ETTh2에서 0.3, ETTm2/Exchange/ILI에서 0.9, 나머지에서 0.5다. MLP 깊이·hidden dimension·기반 모델 깊이도 표에 있으나, 대괄호 값을 각 기반 모델의 단일 K나 검증 데이터 선택 규칙으로 추정하지 않는다.

<a id="c17"></a>**C17.** Eq.5의 MSE·SMAPE·MASE는 합산 첨자 i와 피합산식의 t가 섞여 있고, MASE 분모는 본문에서 예측 길이라고 정의한 H를 사용한다. HTML 수식과 PDF 양쪽에서 이 표기를 확인했다. 기록에는 원문을 보존하고 실제 평가 코드·계절 주기·정규화 구간을 미확인으로 남긴다. 임의로 고친 수식을 이 논문의 구현이라고 제시하지 않는다.

## 표시된 수치로 확인되는 결과

모든 재계산은 **반올림된 표의 십진 표시값**에 대해 `(base−CCM)/base×100`을 사용한다. 실험 재실행, 반올림 전 값 복원, 통계적 유의성 검정은 수행하지 않았다.

<a id="c18"></a>**C18.** Table 4의 9데이터셋×4길이×4모델=144조건을 지표별로 나누면 다음과 같다. 본문 MSE 90.27%·MAE 84.03%는 표시값상 동률을 포함한 비악화 비율과 대응한다. 엄격한 개선 비율로 옮기면 안 된다.

| 지표 | 엄격한 개선 | 동률 | 악화 | 개선만의 비율 | 동률 포함 비악화 |
|---|---:|---:|---:|---:|---:|
| MSE | 126 | 4 | 14 | 87.50% | 130/144 ≈ 90.2778% |
| MAE | 115 | 6 | 23 | 약 79.8611% | 121/144 ≈ 84.0278% |

<a id="c19"></a>**C19.** Table 4의 288개 지표 비교를 동일 가중 평균하면 상대 감소율은 약 **2.442704%**다. DLinear의 MSE/MAE 평균은 약 **5.121453% / 3.043133%**로, 논문의 장기 평균 2.4% 및 DLinear 5.12%/3.04%와 대응한다. 서로 다른 지표의 원시 오차를 합한 평균이 아니다.

<a id="c20"></a>**C20.** 악화 사례도 남긴다. ETTh1 길이96의 TSMixer MSE는 0.361→0.365, ETTm1 길이336의 TimesNet MSE는 0.410→0.412, Traffic 길이720의 DLinear MSE는 0.467→0.471이다. ILI 길이60 DLinear MAE도 1.088→1.096으로 악화한다. 장기 평균의 개선을 개별 조건의 성공으로 대체하지 않는다.

<a id="c21"></a>**C21.** 강조와 표시값의 최저값이 다른 곳도 있다. Table 4 Traffic 길이192 MSE는 TSMixer+CCM **0.340**이 최저인데 PatchTST의 base/+CCM **0.379**에 밑줄이 있다. Table 7 ETTh1→ETTm1 길이720 MAE는 PatchTST+CCM **0.795**가 최저인데 TSMixer+CCM **0.803**에 밑줄이 있다. 표의 값과 강조를 각각 보존한다.

<a id="c23"></a>**C23.** Table 6의 IMP 열은 같은 4모델 동일 가중 상대 감소율로 재계산할 때 19행 중 14행에서 0.01%p 넘게 차이가 난다. 예를 들어 Yearly SMAPE는 인쇄 IMP **7.286%**, 재계산 **5.785473%**다. M4 Avg.까지 포함한 15개 인쇄 IMP의 평균은 **7.214%**로 초록의 7.2%와 대응하지만, 같은 범위의 개별 표시값 60비교 평균은 **6.015670%**다. Avg.를 제외하면 **5.973911%**, Avg.만 쓰면 **6.182706%**다. 저자의 실제 집계 절차나 반올림 전 값을 확인한 것은 아니다. <a id="c27"></a>**C27.** Table 17의 네 데이터셋×네 기반 모델×여섯 cluster ratio는 개선50·동률17·악화29의 96비교다. ratio 0은 K=0이 아니라 모든 채널을 한 군집에 넣는 설정이다. Appendix D.1은 “대부분의 경우”와 한 군집의 성능 저하를 별도로 설명한다.

<a id="c28"></a>**C28.** Table 18은 caption의 길이7·입력14/21/28뿐 아니라 **길이24·입력48/72/96**도 포함한다. 24설정×두 지표는 개선47·동률1이다.
