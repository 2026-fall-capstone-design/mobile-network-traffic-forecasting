# 원85: 자료 공유 비용의 정정과 고정 처리량 배분의 한계

[출처·독해 범위](../sources/history-112.md) · [보존 근거](../evidence/0112-rejection-scope-allocation/README.md) · [검수](../verification/history-112.md)

자료를 빌리면 반드시 학습량이 늘어난다는 판단을 적용 조건에 맞게 좁힌 기록이다. 비용 해석의 정정, 기존 재추출 원리, 고정 손실의 분산식과 실제 학습 성능을 구분한다.

**상태:** 20개 주장·7개 묶음의 작성 후 원문 대조 완료. 새 모델 실행0.

## 당시 질문과 유지할 결과

<a id="c01"></a>**C01.** 원85는 2026-09-26의 기각 범위·자료 배분 재검토다. 원84 중간 보고서를 최종 추천으로 바꾸거나 새 후보의 성능을 검증한 기록이 아니다. 계획·판단·보고서·검증/수집 코드·보조 JSON을 연결하며, 당시 새 모델·수치 pilot 0회라는 보고와 이번 원문 독해·기호 대조를 구분한다.

<a id="c02"></a>**C02.** 원35의 일곱 K4 조건은 16cell·hourly pilot의 저장 checkpoint에서 global보다 train 평균 MAE가 작고 validation 평균은 컸다. 일반화 손해와 일치하지만 원인을 과적합 하나로 확정하지 않았다. 원 UPC의 대규모 cell·10분·K2 조건이나 모든 clustering을 부정한 결과로 확대하지 않는다. 서로 다른 seed·cell·기간의 비교 한계도 기존 기록에서 유지한다.

<a id="c03"></a>**C03.** 원47의 일부 공간 입력 이득, 원62·74·80의 Tab 직접 예측 이득은 유지한다. 공간 입력 열 추가, 학습 sample 행 공유, cell 소속 결정, 출력 압축은 서로 다른 행동이다. 원74의 압축 HGB와 원80의 고정 gradient 진단을 새 최종 RCTL 개선으로 바꾸지 않는다. 원80의 평균 우위에도 Ridge 대비 cell6153의 MSE 반례가 있다는 기존 H088 검수도 함께 읽는다.

## 비용과 선행연구

<a id="c04"></a>**C04.** 한 epoch의 전체 sample–모델 평가 횟수를 N으로 고정하고 매 추출을 모델 하나에 보내면, 외부 sample을 쓴다는 이유만으로 처리 횟수가 KN이 되지는 않는다. 보고서의 10,000개는 설명용 예시다. 비중 추정·후보 검색·배분·batch 구성·모델별 부하·실제 시간은 별도이며, 반복 사용이 새 관측 자료 증가를 뜻하지 않는다.

<a id="c05"></a>**C05.** 원40은 모든 donor sample을 각 RCTL에 추가하는 구현에서 처리량 증가를 지적했다. 원85는 그 사유를 해당 구현에 한정하고 고정 개수 재추출의 가능성을 남겼다. 이는 자료 공유의 신규성·성능 이득을 확보했다는 판단이 아니다. H024에서 별도로 확인한 Tab 열 순서 준비 비용의 정정도 그대로 유지하며, RCTL 표본 수와 Tab 점수 계산 비용을 합치지 않는다.

<a id="c06"></a>**C06.** Bickel 등 ICML2008 §4는 pooled 자료에서 task별 분포에 맞는 재추출을 제시하고 loss 가중을 대안으로 설명한다. PDF3 식1–8은 joint ratio를 출처 posterior/task prior로 표현하고, PDF4–5는 출처 분류와 가중 최종 학습을 연결한다. 일반 loss 항등식과 HIV 분류 응용을 구별하며, 고정 개수 재추출만으로 새로운 원리를 주장하지 않는다.

<a id="c07"></a>**C07.** Katharopoulos·Fleuret ICML2018 §3.1–3.2의 1/(N p_i) 보정은 현재 학습기의 gradient 평균과 선택 분산을 다룬다. PDF4 Algorithm1은 B개 후보의 점수를 계산해 b개를 재추출하고 1/(B g_i)를 사용하며, 추정 이득이 작으면 균등 추출을 유지한다. 후보의 forward 비용도 있으므로 Tab 예측 오차를 그 gradient 중요도나 실제 학습 속도 이득으로 대신하지 않는다. 논문 식24–26의 부록·구현 대조 공백은 기존 H045에 남아 있다.

## 고정 손실의 배분식

<a id="c08"></a>**C08.** 고정 group의 분포 P_g, 양의 혼합비 π_g(합1), Q=Σπ_g P_g, Z=(X,Y)를 둔다. 여기서 r_g(Z)=P(G=g|Z)=π_g dP_g/dQ는 정확한 출처 posterior이며, Bickel 논문의 r_t인 density ratio와 구별한다. 예측 함수·모수·loss ℓ_g와 목표 가중 a_g를 고정한다. 아래 분산식은 관련 제2모멘트가 존재할 때의 group별 식이다.

<a id="c09"></a>**C09.** H_g=1{G=g}(a_g/π_g)ℓ_g(Z), U_g=(a_g/π_g)r_g(Z)ℓ_g(Z)로 두면 E[H_g|Z]=U_g이고 E_Q[U_g]=a_g E_Pg[ℓ_g]다. 마지막 항등식은 참 ratio의 목표 loss 연결이며, 추정 weight로 최적화한 실제 RCTL의 미래 오차 감소를 증명하지 않는다.

<a id="c10"></a>**C10.** 전체분산 공식에서 Var(H_g)=Var(U_g)+E[Var(H_g|Z)]다. 따라서 고정 loss의 출처 지시를 정확한 posterior로 평균하면 분산이 증가하지 않는다. U_g를 모든 group에 계산하는 구현은 보통 같은 sample을 여러 모델에 평가하므로 이 식만으로 단일 모델 평가 비용까지 얻었다고 할 수 없다.

<a id="c11"></a>**C11.** J|Z~p(·|Z)로 한 모델을 뽑고 S_g=1{J=g}a_g r_g ℓ_g/(π_g p_g)로 보정하면 E_J[S_g|Z]=U_g다. r_g>0인 곳에는 p_g>0이 필요하고 r_g=p_g=0인 항은0으로 정의한다. 조건부 분산은 (a_g/π_g)²r_g²ℓ_g²(1/p_g−1)이다. 작은 p_g가 큰 변동을 만들 수 있으며 support 조건만으로 적분 가능한 제2모멘트까지 보장되지는 않는다.

<a id="c12"></a>**C12.** 특히 p=r이면 Q(dz)r_g(z)=π_g P_g(dz)이므로 (Z,J)의 결합분포가 원래 (Z,G)와 같다. 이 모집단의 한 번 추출·고정 함수 조건에서는 자동적인 분산 감소를 얻었다고 할 수 없다. 이는 모든 반복 학습이나 모든 자료 공유가 무의미하다는 결론이 아니다.

<a id="c13"></a>**C13.** 같은 Z와 고정 ℓ_g에 대해 p=r로 J를 E번 조건부 독립 추출하고 기여를 평균하면 Var(평균 S_g)=Var(U_g)+(1/E)E[Var(H_g|Z)]다. 원래 G를 고정해 같은 기여를 반복하는 경우와 다르며 soft 기여의 계산을 근사할 수 있다. E는 양의 정수 반복 수다. 임의 p에서는 뒤 항에 해당 S_g의 조건부 분산을 써야 한다.

## RCTL과 TabICLv2에 남는 조건

<a id="c14"></a>**C14.** 모수가 바뀌는 SGD, 시계열·cell 의존, 추정 r, 고정 group quota는 위 고정 손실·조건부 독립 가정과 다르다. 저장 RCTL Block에는 BatchNorm 두 개와 Dropout이 있어 훈련 batch를 바꾸면 sample의 계산도 달라진다. inference 함수의 loss 항등식을 batch에 의존하는 학습 경로·수렴·최종 MAE 보장으로 바꾸지 않는다.

<a id="c15"></a>**C15.** 다음 Y의 조건부 분포를 잘 예측하는 것과 실제 (X,Y) sample의 group 출처를 잘 추정하는 것은 다른 문제다. joint ratio에는 입력 분포와 prior도 관여한다. 원40의 조건부 ratio 공백을 유지하고, 직접 source 분류·joint ratio·단순 quota/시간대 재추출보다 Tab이 다른 유용한 결정을 만드는지 확인해야 한다.

<a id="c16"></a>**C16.** RCTL gradient로 cell 소속·후보·병합 기준을 바꾸는 것과 소속을 먼저 고정한 뒤 optimizer에서 중요도 추출을 쓰는 것은 다르다. 후자를 자동으로 기존 독립성 위반이라고 하지 않는다. 원76도 실제 target loss를 유지하는 teacher 보조 loss의 연결을 인정했으나, 그것만으로 새 grouping 결정이나 성능 이득을 확보하지 못해 채택하지 않았다. 단일 global에 같은 teacher를 준 대안도 남긴다.

## 증거·독해 범위·재사용

<a id="c17"></a>**C17.** 원 collector는 공개 URL4개를 읽어 파일과 manifest를 쓰고, verifier는 scope 저장·progress 변경·snapshot 복사를 한다. 둘 다 이번에는 정적으로만 읽었다. snapshot27은 자기 manifest를 제외한14파일·188,028bytes이며 현재 보존본의 크기·SHA를 전부 대조했다. verified:true와 old_snapshots_modified:false 같은 원코드 상수는 독립 실행 재현이나 과거 전체 스냅샷 불변의 증거로 승격하지 않는다.

<a id="c18"></a>**C18.** 원85의 verifier는 당시 원장 SHA f3e370…을 검사하고 모델 실행0·예산 유지로 기록했다. 같은 바이트의 기존 budget_after 보존판과 연결했다. 현재 원장 경로의 SHA는 정리 시작 시 보호한 다른 판본17a549…이며 원85 당시 값으로 덮어쓰지 않았다. 원본·보호파일 해시 검사는 현재 바이트 보존의 증거이며 당시 프로세스·환경의 재현은 아니다.

<a id="c19"></a>**C19.** 원85 당시 scope는 Bickel/ICML2018의 지정 절, 2015 논문 초록, 기타 Crossref 메타데이터를 구분한다. 이번에는 핵심9자료432행, 기존 원문9개의441행과 원80 결과의 선택 필드, 논문 두 편의 선택7쪽 텍스트·이미지를 읽었으며 기존 전체 독해로 중복 가산하지 않는다. 원85의 고유 누적연혁·결정색인·Crossref JSON2·공식 HTML2는 아직 미독이다. manifest의 HTTP200은 당시 접근 기록이며 현재 URL 가용성이나 최신 문헌 전수 조사의 증거가 아니다.

<a id="c20"></a>**C20.** 고정 처리량의 자료 배분은 비용 때문에 불가능한 안으로 기각하지 않지만, 이번 형태를 신규 추천안으로 채택하지도 않는다. 기존 재추출과 구별되는 Tab의 유용한 결정·실제 분리 손해를 줄이는 행동·같은 정보와 비용의 비교 근거가 필요하다. 비용 문장을 수정했다는 이유로 같은 후보를 새 이름으로 반복하지 않는다. 원84 중간 Word, 원85 검토, 최종 연구 방향 확정은 서로 다른 완료 상태다.
