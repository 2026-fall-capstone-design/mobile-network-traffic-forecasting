# 원85 후속: 후보 판단의 수정 이력과 문헌의 실제 읽기 범위

> 과거 연구의 조건·결과를 보존한 문서입니다. 새 실험은 [공통 실험 규약](../../research-protocol.md)을 적용하며, 아래 수치는 새 기준의 재평가 결과가 아닙니다.

[출처](../sources/history-113.md) · [검수](../verification/history-113.md) · [보존 근거](../evidence/0113-decision-history-sources/README.md) · [원85 비용·기호식](0112-rejection-scope-allocation.md)

팀원이 과거의 기각 사유와 정정된 결론을 함께 찾도록 결정표20행, 누적연혁36절, 검색 자료의 실제 범위를 연결했다.

**상태:** 20개 주장·7개 묶음의 작성 후 원문 대조 완료. 새 모델 실행0.

## 판본 변경과 판단의 범위

<a id="c01"></a>**C01.** 원85 후속은 snapshot27의 결정색인·누적연혁과 검색 JSON2·공식 출판페이지 HTML2, 고유6자료다. 이는 새로운 실험 여섯 건이 아니다. 결정표20행·긍정 증거5항목·재진입 질문4개를 상세 기록에 연결하며 당시 최종 추천과 최종 Word는 미완료였다는 상태를 유지한다.

<a id="c02"></a>**C02.** snapshot26과 비교하면 결정색인45행 중12–13행만 바뀌었다. 누적연혁은 기존422행에서433행으로 늘었고, 이전 최신 제목을 원85 새 절과 원84의 이전 상태 제목으로 바꿨다. 나머지 구간의 바이트 동일성 비교와 새 판본433행 실제 독해를 각각 확인했다.

<a id="c03"></a>**C03.** 자료 공유의 비용 기각은 모든 외부 sample을 각 모델에 추가하는 구현에 한정됐다. 총 sample–모델 처리 횟수를 고정한 재추출은 가능하지만, score 계산·batch 구성·불균형 부하·실제 시간까지 같다는 뜻은 아니다. 이 정정이 결정표와 연혁 모두에 반영됐으며 새 배분 성능을 확인한 것으로 쓰지 않는다.

<a id="c04"></a>**C04.** p=r인 한 번의 출처 배분과 같은 sample의 반복 배분을 구분한다. 반복식은 고정 loss·정확한 posterior·조건부 독립·관련 모멘트 조건에서 읽어야 한다. 실제 SGD·시간 의존·BatchNorm·추정 비중의 성능 보장은 별도다. 세부 기호식과 일반 p의 조건은 H112에서 확인한다.

<a id="c05"></a>**C05.** cell 소속을 정할 때 RCTL의 학습 정보를 쓰는 것과, 소속을 먼저 고정한 뒤 optimizer의 중요도 추출에 쓰는 것은 다른 단계다. 원85는 후자를 자동으로 독립성 위반으로 기각하지 않았으며 어느 방식도 새로 실행하지 않았다. loss 중요도와 gradient 효율의 차이는 유지한다.

<a id="c06"></a>**C06.** 원60·74·80의 Tab 직접 예측, 원46의 일부 공간 입력, 기존 K4의 일부 기간·피크·cell 이득을 지우지 않는다. 원80의 평균 우위는 모든 cell의 우위가 아니다. H088/H112에 있는 cell6153의 Ridge 대비 MSE 반례와 소속이 동일했다는 관찰을 함께 읽는다. 여기서는 새 예측이나 독립 재현을 수행하지 않았다.

<a id="c07"></a>**C07.** 16cell·hourly·K4의 확인된 손해를 원 UPC의 대규모·10분·K2 또는 모든 clustering의 부정으로 확대하지 않는다. train–validation 차이는 일반화 손해와 일치하지만 원인을 하나로 확정하지 않는다. 직접 예측·sample 행 공유·입력 열 추가·출력 압축의 판단을 분리한다.

## 누적 기록에서 함께 읽어야 할 정정

<a id="c08"></a>**C08.** 누적연혁297행에는 UPC가1~4 cluster를 비교했다는 과거 설명이 남아 있다. 이후 연구에 해당하는276행은 Fig.7의 N=1,2,4,6,8,12로 이를 정정했다. 파일에는 최신 절이 위쪽에 삽입되므로 행 번호가 큰 문장을 최신 결론으로 택하지 않는다. Table II의 대시로 정확한 개선율을 계산하지 않은 제한도 보존한다.

<a id="c09"></a>**C09.** 연혁266행의17열×요청4순서라는 옛 비용 설명을 그대로 현재 계산으로 인용하지 않는다. H024에는 저장된 pinned 순서 생성기를 정적으로 연결해 최대68G를289G 열별 처리로 정정한 근거가 있다. 이는 원85의 RCTL 총 sample 처리량 N 논의와 다른 비용이며, 두 값 모두 실제 wall time이나 학습 횟수로 바꾸지 않는다.

<a id="c10"></a>**C10.** 초기 기록의 RCTL0회와 최종20일 미열람은 당시 상태다. 뒤의 RCTL 완료 절은29fit·1,565epoch와 최종20일 관찰 완료를 보고한다. 관찰한 기간을 새 설계의 독립 test로 되돌리지 않으며, 문단마다 반복된 누적29fit을 합산하지 않는다.

<a id="c11"></a>**C11.** 저장 예측 재분석, 고정 checkpoint의 forward/gradient 진단, 새 학습을 구별한다. 원24의 recursive 추론과 원34의 train/validation 재추론은 새 RCTL fit이 아니며, 원26은 저장 RCTL 예측을 쓰면서 Ridge/HGB 두 fit을 추가했다. 이를 모두 모델 호출0 또는 모두 새 RCTL 실험으로 세지 않는다.

<a id="c12"></a>**C12.** 연혁은 원23 float32 검사 실패 뒤 float64 재개, 원30 interval_seconds의0.6→600초 정정, 원54 실행 전 assert 실패와 수정 후 실행을 구분한다. 문헌 수집·PDF 추출 오류도 모델 성능의 부정 결과와 다르다. 원인·수정·비용을 상세 기록과 함께 찾아야 하며 이 정리에서 원래 코드를 재실행하지 않았다.

## 검색 결과와 논문 전문의 경계

<a id="c13"></a>**C13.** Crossref importance 응답에는8개 item, routing 응답에는3개 item이 저장됐다. total-results 4,842,788과3,686,300은 검색 응답의 메타데이터이지 읽은 논문 수가 아니다. 저장된11개 항목을11편의 방법 검증이나 관련 연구의 전수 목록으로 세지 않는다.

<a id="c14"></a>**C14.** routing 첫 항목은 Boosting Share Routing for Multi-task Learning, DOI10.1145/3442442.3452323와2021-04-19 서지를 담는다. 조회 요청에 abstract가 있어도 저장 응답에는 해당 필드가 없다. PDF 링크와 제목만으로 원85 배분 방식과의 동등성·신규성·예측 효과를 확정하지 않는다.

<a id="c15"></a>**C15.** Zhao·Zhang의 ICML2015 공식 페이지는 PMLR37:1–9 서지, 초록, 인용과 PDF 링크다. 초록은 prox-SMD/prox-SDCA 중요도 추출의 분산·수렴 개선을 주장하지만 수식·증명 전문은 이 HTML에 없다. HTML281행을 읽은 것과9쪽 논문을 완독한 것을 구분한다.

<a id="c16"></a>**C16.** Katharopoulos·Fleuret의 ICML2018 페이지는 PMLR80:2525–2534 서지와 초록을 담는다. gradient norm 상계·분산 감소 추정·적용 시점과 고정시간 결과는 저자의 논문 초록 주장이다. 그 성능 문구를 트래픽 RCTL의 측정값이나 이번 실험으로 쓰지 않는다.

<a id="c17"></a>**C17.** 2018 페이지에 본문 PDF와 보충 PDF 링크가 모두 있지만, 링크를 읽었다는 사실로 H045의 식24–26 부록·코드 대조 공백이 해소되지는 않는다. citation 날짜·학회 개최일·웹페이지 생성 시각도 구분한다. 2018 논문 페이지의2026년 생성 시각을 논문 발표연도로 쓰지 않는다.

<a id="c18"></a>**C18.** 원85 reading_scope는 Bickel과 ICML2018의 지정 절,2015 초록, 기타 검색 메타데이터를 구분했다. source_manifest의 HTTP200과 인증 오류는 당시 접근 이력이다. 이번 저장판 검수는 현재 URL 가용성·최신 문헌 전수 조사·논문 전체 재현을 확인한 것이 아니다.

## 다음 설계에 사용할 조건

<a id="c19"></a>**C19.** 새 제안은 기존 실패 원인을 바꾸는 결정, Tab 값이 바꾸는 선택과 단순 대안, 최종 RCTL에 전달할 정보·target·학습 단위, 관측한 기간과 비용을 밝혀야 한다. 완전한 이론 보장이 없다는 이유만으로 실증 후보를 기각하지 않으며 좋은 Tab 직접 예측만으로 다른 모델의 grouping을 승인하지 않는다. 원문의 과거 Goal·예산·다음 행동은 현재 실행 지시가 아니다.

<a id="c20"></a>**C20.** H112가 남겼던 고유 후속6자료의 본문을 이번에 읽고 연결했다. 이 표현물들의 검수 완료가2015·routing 논문 전문이나 기존 문헌 공백 해소를 의미하지 않는다. 원86 이후와 이전 고유 판본·미독 자료, 전체 실패/비용 통합·장기 팀 접근·최종 원본 변경 및 대표 질문 검수까지 전체 Goal은 계속된다.
