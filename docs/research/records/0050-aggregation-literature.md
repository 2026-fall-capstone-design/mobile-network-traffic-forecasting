# 50 — 합계 예측·다중 출력·대표 예측의 문헌과 채택 판단

2026-09-26의 [원문 50](../evidence/0048-0049-aggregation-recovery/originals/SRC-0021725.md.txt)을 [48–49 저장 진단](0048-0049-aggregation-recovery.md)과 세 논문에 대조한 기록이다. 핵심 판단은 **단순 합계 예측과 고정 비중 배분을 당시 새 추천안으로 채택하지 않았다**는 것이다. 압축을 이용하는 모든 방법을 기각한 것은 아니며, 이번 정리에서도 새 모델 학습·추론·실험은 하지 않았다.

원문 전체 66행의 판단과 세 PDF의 텍스트 35쪽·시각 자료 21쪽을 검토했다. 수치·비용은 H029의 저장 결과 검수를 재사용하고, 여기서는 문헌의 실제 출력·학습 대상, 성능과 비용의 범위, 당시 신규성 판단을 연결한다. [출처와 열람 범위](../sources/history-030.md), [선택 표 수치 검사](../verification/history-030-primary-check.json), [주장별 검수](../verification/history-030-claims.json)를 함께 볼 수 있다.

## 먼저 구분해야 할 연구 질문

| 구조 | 유지하거나 줄이는 것 | clustering이 결정하는 것 | 이 기록에서의 해석 |
|---|---|---|---|
| 학습 표본 공유 | 각 cell의 예측 target을 유지하고 학습 행을 모음 | 같은 함수를 학습할 자료의 범위 | 기존 UPC → RCTL과 가까운 질문 |
| 다중 출력 예측 | 한 모델이 여러 cell의 값을 함께 출력 | 함께 입력하고 출력할 변수의 범위 | 모델 수가 줄어도 개별 출력 수는 유지될 수 있음 |
| 합계 scalar 예측 후 배분 | 그룹마다 합계 한 값만 예측하고 개별 값을 복원 | 같은 비중 규칙으로 압축·복원할 묶음 | 합계 오차 외에 비중 복원 오차가 생김 |
| 대표 시계열 예측 후 조합 | 여러 대표의 예측을 개별 시계열의 예측으로 조합 | 대표와 가중치 | 대표가 반드시 합계는 아니며 직전 비중 배분과도 다름 |

모델 개수, 시계열 개수, scalar 출력 수, 라이브러리 호출 수, 실제 실행 시간은 각각 확인해야 한다. 한 번의 batch 호출에 N개 cell을 넣는 것이 N개의 예측 문제를 K개로 압축했다는 뜻은 아니다. 다중 출력으로 바꾸면 고정 scalar×비중이라는 표현 제약은 제거할 수 있지만, 일반적인 예측 오차까지 없어진다는 보장은 없다. 입력의 cell 순서와 실제 target 대응, 학습 단위와 checkpoint 호환성도 새로 정의해야 한다.

## HiGP: 하위와 상위 출력을 함께 학습하고 맞추는 방법

[Cini·Mandic·Alippi, ICML 2024, PMLR 235:8985–8999](https://proceedings.mlr.press/v235/cini24a.html)의 *Graph-based Time Series Clustering for End-to-End Hierarchical Forecasting*을 확인했다. 저장 PDF `SRC-0061746`의 본문·부록·참고문헌 15쪽을 읽고, 그림·표·관련 수식을 8쪽에서 시각 대조했다.

§2–3.1의 입력은 graph로 연결된 개별 시계열이다. 하위 관측과 상위 집계를 함께 유지하고, 식 4–8에서 시간 인코딩, 같은 계층과 계층 사이의 정보 전달, 각 계층의 readout과 예측 손실을 구성한다. 따라서 전체 합계 하나만 예측해 하위 cell로 나누는 구조가 아니다.

§3.2 식 9–10에서는 Gumbel-softmax와 straight-through gradient를 이용한 hard assignment를 학습하고 graph regularization을 더한다. 일반 설명은 입력 의존 assignment도 허용하지만, 7쪽의 주 실험은 **학습 가능한 고정 hierarchy**로 하위 노드·중간 20개·최상위 1개를 사용한다. 고정 graph pooling도 호환된다는 설명을 함께 남긴다. end-to-end 예측 손실로 배운 소속을 RCTL과 독립적으로 평가한 clustering 결과라고 표현해서는 안 된다.

§3.3 식 12의 `P = I − Qᵀ(QQᵀ)⁻¹Q`는 이미 얻은 전체 계층 예측을 합계 일관성이 있는 공간으로 투영한다. 합계만으로 사라진 개별 정보를 복원하는 보장과 다르다. 본문의 역행렬 비용에서 공간·시간 차수의 표기는 이번 비용 추정에 채택하지 않았다. 식 6의 lift 인덱스도 공식 구현을 확인하지 않고 실행 코드로 임의 보정하지 않았다.

평가 대상은 Metr-LA·PeMS-Bay의 도로 속도, CER-E 에너지, AQI 대기질이다. 부록 B의 입력 길이/예측 길이는 각각 12/12, 12/12, 48/6, 24/3이다. 앞 세 자료는 순차 70%/10%/20% 분할이며 AQI는 인용한 별도 분할을 사용한다. batch 64, 최대 200 epochs·epoch당 최대 300 batches, validation early stopping과 모델별 tuning을 보고한다. 이 설정은 49번의 Milan 활동량·32cell·관측 이력 기반 진단과 다르다.

## ONDM: 모델 수는 줄이고 개별 출력은 유지

[Knapińska 외, ONDM 2023](https://dl.ifip.org/db/conf/ondm/ondm2023/1570874472.pdf)의 *Data Aggregation and Clustering for Traffic Prediction in Backbone Optical Networks*는 저장 PDF `SRC-0061756`의 3쪽 전체를 텍스트와 그림으로 확인했다.

§II의 개별 모델은 각 node pair의 하루·일주일 lag 두 값을 사용한다. 전체 aggregated 모델은 k개 시계열의 **2k개 입력과 k개 출력**을 갖는다. node별 clustering 모델은 유입 또는 유출 시계열을 묶는 다중 출력 회귀이며, 보고된 비교는 유입 grouping이다. 저자는 유출 결과도 유사했다고 설명하지만 별도 저장 출력을 확인한 것은 아니다. node별 28개 모델이라는 계산은 전체 출력이 28개 scalar로 줄었다는 뜻이 아니다.

## HTS-Cluster: 대표 예측을 조합하되 속도와 오차를 따로 평가

[Han 외, arXiv:2205.14104v1, 2022-05-27](https://arxiv.org/abs/2205.14104v1)의 *Efficient Forecasting of Large Scale Hierarchical Time Series via Multilevel Clustering*는 저장 PDF `SRC-0061751`의 17쪽을 읽고 주요 표·수식·그림 10쪽을 시각 대조했다. 일반적 신규성 확정이나 전체 후속 문헌 조사를 수행한 것은 아니다.

§2–3은 주어진 hierarchy의 하위 시계열을 Soft-DTW **divergence**로 비교하고, 그 cluster 중심들의 분포를 Wasserstein 방식으로 비교해 상위 군집을 구성한다. 보정되지 않은 Soft-DTW와 divergence를 같은 것으로 취급하지 않는다. 식 5는 두 계층 목적함수, 식 6과 Algorithm 1은 여러 계층의 bottom-up 절차다. 임의의 통신 cell partition을 단순 합계로 만든 49번과 설정부터 다르다.

Proposition 3.1과 부록 A의 대상은 clustering 목적함수 감소다. 부록은 할당과 중심 갱신이 각 목적값을 최소화하는 단계에 근거한다. 이를 미래 예측 MAE 감소 정리나 근사 gradient 구현의 자동 보장으로 옮길 수 없다. 전체 증명 및 알고리즘 구현의 정합성을 인증하지 않았으며, 독해 범위와 정리의 보장 범위를 구분했다.

§3.4 식 7은 같은 계층의 여러 대표 시계열 예측을 개별 시계열과의 거리 가중치로 조합한다. 양의 거리 `d_j`와 `m > 1`에서는 가중치가 `d_j^(−2/(m−1))`에 비례한다. 이는 직전 관측의 트래픽 비중이나 그룹 합계 분배와 다르다. 예를 들어 m=2, 거리 1·2·4이면 가중치 16/21·4/21·1/21이며 합이 1이다. 이는 고정 수의 정확한 대수 확인으로, 새 실험이 아니다. 거리 0의 처리는 이 식의 표기만으로 정하지 않았고 공식 코드도 확인하지 않았다. 계층 일관성은 별도의 사후 reconciliation으로 맞출 수 있다고 설명한다.

Table 3에서는 상위 계층의 이득과 최하위 계층의 손해가 함께 나타난다. 아래는 최하위 결과이며 낮은 MASE가 좋다.

## 49번 진단과 당시 미채택 판단의 연결

[H029](0048-0049-aggregation-recovery.md)는 같은 32cell·336시간 개발 구간에서 미래 실제 합계를 주어도 고정 비중 복원 오차가 남음을 저장 배열로 확인했다. 실제 합계를 준 오차와 동일 비중에서 모든 비음수 scalar 중 사후 최저 오차는 다르다. PCC의 평균 이득과 16cell의 손해, 정규화 최적화와 원단위 MAE의 다른 방향, 직전 비중×직전 합계가 기존 직전값 기준과 같다는 항등식도 함께 보존했다. 이 검수는 새 독립 검증이나 TabICLv2/RCTL의 새 성능 결과가 아니다.

원문 50의 판단은 다음 조건에 한정된다.

1. 대표만 예측하고 개별 값을 조합하는 발상에는 HTS-Cluster라는 선행 사례가 있다. 이 사실은 단순 발상의 신규성 주장에 반례가 되지만, 가능한 모든 확장에 신규성이 없다는 증명은 아니다.
2. 복원 손실 자체는 실제 과거값으로 계산할 수 있다. 그 값을 다시 추정하는 데 TabICLv2가 어떤 추가 정보를 제공하는지는 이 기록에서 입증되지 않았다.
3. 다른 예측기의 점수로 RCTL 성능을 대변하는 가정을 다시 도입하려면 별도 근거가 필요하다. 모델의 예측 정확도와 그 모델을 이용해 고른 소속의 최종 효용을 구분한다.
4. cell 4개당 scalar 하나라면 N=128/1024/10000의 출력 수는 32/256/2500이다. 원시 입력 읽기·비중 갱신·개별 복원은 여전히 N에 비례한다. 이는 지정 구조의 산술이며 실측 가속률이나 모든 방법의 계산량 하한이 아니다. 전체 PCC 계산도 32cell 진단에서 쓴 비교이며 10,000cell 제안 구현으로 검증하지 않았다.

재검토하려면 기존 대표 예측과 다른 결정, 과거값 직접 계산을 넘어서는 TabICLv2의 정보, 개별 cell 오차와 실제 비용의 절충을 함께 설명해야 한다. 이는 **당시 남겨진 연구 조건**이며 이 정리 작업에 새 실행 권한을 부여하는 명령이 아니다. 당시 새 추천 방향과 최종 Word가 미완료였다는 상태도 유지한다.

## 비용·접근·재사용 범위

49번의 0.08182460000170977초는 저장 산술 타이머다. snapshot 11의 cheap 누적 55.91467169999924초, 기록된 modeling 1947.8085698000016초와 당시 잔여는 [H029의 타이머·원장 대조](../verification/history-029-lineage-check.json)를 재사용한다. 문헌 읽기·다운로드·렌더 시간이나 이번 아카이브 시간을 그 연구 원장에 추가하지 않았다. 모델 fit/forward 0이라는 이 진단의 상태를 전체 과거 연구에 적용하지 않는다.

[보존 근거](../evidence/0050-aggregation-literature/README.md)는 로컬 fetch/render 코드와 접근·렌더·검토 범위 JSON 5개를 원 바이트로 보존하고, 48·50 원문 2개를 재사용한다. 외부 PDF·TXT·HTML·PNG 14개는 해시·원래 위치·읽은 범위를 연결했다. 과거 fetch log는 네 HTTP 200 응답, render log는 7개 exit 0을 기록한다. 당시 OpenReview verification page 보고는 이 성공 로그만으로 독립 확인되지 않는다. 현재 IFIP 웹 요청은 timeout이었지만 저장 PDF는 읽을 수 있었다. 영구 접근 불가나 내용 오류로 판단하지 않았다.

PDF 파생 TXT 세 개는 원래 page header를 재구성해 비교했다. ONDM·HTS는 읽은 decoded text가 같고 HiGP는 제어문자 CR/LF 차이만 있었다. 새로운 연구 문장이 추가된 파생본으로 세지 않되, PDF와 바이트가 같은 중복 파일로 합치지도 않았다. HTML은 보이는 초록·저자·버전·링크 정보를 읽었으며 script/style을 실행하지 않았다.

세 논문의 본문·부록·참고문헌을 읽고 모든 그림·표를 확인한 사실은 세 공식 구현의 재현, 모든 인용 논문의 열람, 모든 정리의 증명 검증을 뜻하지 않는다. HSeq2Seq 등 `review_scope`의 발견 목록 5건은 방법 검토로 승격하지 않았다. 관련 후속 기록·별도 보고서·다른 판본과 전체 원본의 고유 내용, 전체 비용·팀 원자료 접근·최종 변경분·검색 검수는 계속 남아 있다.
