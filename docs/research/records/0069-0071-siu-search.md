## 무엇을 확인했나

[C01] SIU2026의 *Limit Management in Network Traffic Forecasting via Asymmetric Loss Function*은 과소 예측을 더 크게 벌점화하는 용량 계획의 참고 후보다. 이번에 확인한 원자료는 기관의 **서지·초록 HTML**이다. 논문 전체의 방법·수치·코드를 읽거나 이 방법을 TabICL·UPC·RCTL에 적용한 기록으로 분류하지 않는다.

[C02] 당시 저장된 검색 출력은 서로 다른 내용 8개, 디코딩한 텍스트 3,222행·200,430문자, 결과 블록 100개다. 이 전체 내용을 읽었다. 100은 도구가 반환한 검색·열람·오류 블록 수이며 논문 100편, 실험 100회 또는 독립 검증 100건을 뜻하지 않는다.

[C03] 물리적 표현은 JSON 8개와 TXT 2개다. `69a–f.json`은 각각 JSON 문자열이며, 나머지 JSON 2개는 `format`·`raw_text` 객체다. 후자의 `raw_text`를 UTF-8로 인코딩한 바이트가 대응 TXT 원문과 완전히 같다. 당시 복구 스크립트와 해시 원장도 이 관계를 뒷받침한다. 파싱 가능한 JSON이 됐다는 사실은 검색 주장이 검증됐다는 뜻이 아니다.

[C05] 출처는 기존 정확사본 재사용 9그룹과 기관 HTML·검색 표현 11그룹, 합계 20그룹·40개 물리 경로다. 새 원본 사본이나 로컬 본문·전체 JSON 독해 수를 가산하지 않는다. 원69·71·보고서·당시 검토 범위는 H066/H068 검수를 재사용하며, 수집·검색 범위·형식 복구 기록은 추가로 정적 재대조한다.

[C06] 검색 중의 접근 실패와 최종 수집 상태도 분리한다. 로그 `f`에는 UNIBZ PDF 리디렉션 실패와 Project Euclid의 iframe 출력만 있지만, 별도 수집 명세에는 실제 PDF의 성공·크기·해시가 있다. 실제 저장 논문과 후속 H067 검수를 근거로 접근 상태를 판단한다. 오류 한 번을 논문이 없다는 증거로 쓰지 않는다.

## SIU2026에서 확인한 내용과 한계

[C07] 기관 표기의 저자는 Akar N., Satilmis M. M., Gursoy H., TORAMAN Ç. 네 명이다. 두 번째 저자의 HTML tooltip은 **Mustafa Mert Satilmis**, 메타데이터는 **Mustafa**로 표기한다. 이를 다섯 번째 저자로 나누거나 임의로 고쳐 쓰지 않는다. DOI는 [10.1109/SIU71813.2026.11636729](https://doi.org/10.1109/SIU71813.2026.11636729)다.

[C08] 서지는 SIU2026, 이스탄불, 2026년 7월 7–10일 행사를 표시한다. `DC.date`와 `citation_publication_date`에는 값이 없다. 행사 날짜를 확정 출판일로 바꾸지 않는다. 터키어 부제의 `A?g Trafi?gi`는 저장본과 현재 페이지에 있는 표기이며 문자 모양을 추측해 복원하지 않았다.

[C09] `Full Text`와 `Tam Metin Bildiri`는 기관이 붙인 발표 유형이다. 이 문자열이나 일반적인 다운로드 UI 번역문만으로 전체 논문 파일을 확보했다고 볼 수 없다. 실제 저장 페이지에는 DOI·서지 서비스·공유 링크가 있고 논문 PDF 첨부 링크는 확인되지 않았다.

[C10] 초록은 rolling Z-score로 이상치를 처리하고, PELT로 현재 상태를 식별한 뒤, NeuralProphet에 과소 예측 벌점을 강화한 손실을 사용했다고 설명한다. 이 단계들의 세부 구현·선택 기준은 초록에 없다. 현재 연구에서 이 파이프라인을 수행한 것으로 기록하지 않는다.

[C11] 과소 예측 벌점의 계수·단위·수식·대칭 손실 대비 조건은 미확인이다. 이를 특정 quantile loss, DeepCog의 α-OMC, H066의 선형 과소/과대량 비용식과 동일시하지 않는다. 같은 ‘비대칭’이라는 표현만으로 목표 함수가 같아지는 것은 아니다.

[C12] 초록은 실제 네트워크 상황에서 미래 용량을 안전 여유 안에 예측하는 성공률이 높아지고 전반적 오차가 낮게 유지됐다고 보고한다. 데이터의 단위·수량·기간, 비교군, 분할, seed, 성공률 정의와 수치표는 제공하지 않는다. 따라서 이 초록에서 정량 개선율이나 재현 가능한 실험 설정을 추출하지 않는다.

[C13] rolling Z-score·변화점 검출·모델 선택이 어느 시간 구간에서 적합됐는지도 확인할 수 없다. 미래 정보 사용이 없었다고 보증하거나, 반대로 누수가 있었다고 단정하지 않는다. 새 설계를 검토한다면 이 시간 경계를 먼저 확인해야 한다.

[C14] 2026년 10월 10일 일반 HTTPS 조회로 받은 [현재 기관 페이지](https://avesis.metu.edu.tr/publication/details/35df2d7a-e64d-4ab1-b343-82ad5b850e60/limit-management-in-network-traffic-forecasting-via-asymmetric-loss-function-ag-trafigi-tahminlemesinde-asimetrik-kayip-fonksiyonu-ile-limit-yonetimi)는 저장본과 63,000바이트·SHA-256가 같다. DOI는 IEEE 문서 11636729로 이동했으나 HTTP 202·빈 본문이었다. 이 경로에서 논문 본문을 확보하지 못했다는 범위의 확인이며, 논문이 어디에도 공개되지 않았다는 결론은 아니다.

[C15] HTML의 가시 내용·메타 44개·링크 외에 inline script 7개, 외부 script 참조 6개, HTML 주석 2개와 나머지 비공백 markup 426행을 정적으로 읽었다. 스크립트는 기관 UI·검색·저자 표시·분석 도구 설정이고 논문 손실식이나 실험 배열이 아니다. 외부 스크립트와 로고를 실행·렌더링하지 않았으며, HTML 읽기를 논문 그림·표 검수로 세지 않는다.

[C16] 이 묶음의 새 모델 실행·학습·추론·난수 추출과 역사적 스크립트 실행은 모두 0이다. 정리용 작업은 텍스트 디코딩, 형식·해시·별칭 대조, 저장된 수집 기록 확인이다. SIU2026의 모델이나 데이터가 이 저장소에서 재현됐다는 증거는 없다.

## 검색 결과를 재사용할 때 주의할 경계

[C17] 같은 초록이 기관 페이지, 다른 언어 경로, 연구자 목록, 재게시 서비스에서 반복된다. HITS 해설의 ScienceDaily·Phys.org 재게시와 Forecaster의 arXiv·저널 서지도 구분한다. 결과가 여러 번 나왔다는 사실은 독립 실험이 여러 번 있다는 뜻이 아니다. 결과별 원출처·로그·순번은 [100개 결과 색인](../evidence/0069-0071-siu-search/search-result-index.json)에 있다.

[C18] IMDEA의 동일한 페이지 번호 URL도 검색 발췌와 실제 열람 출력이 다르다. `a`의 NDS 목록 발췌에는 DeepCog가 있지만, `b`의 해당 목록 열람에는 *Temporal Connectivity of Vehicular Networks*가 나온다. 동적인 기관 목록의 번호를 논문의 영구 식별자로 쓰지 않고 DOI·고정 기관 항목을 우선한다. JSAC2020, INFOCOM2019 DeepCog 및 α-OMC 워크숍 자료도 각각 구분한다.

[C19] 검색 결과 본문에 다른 연구의 추천·인용 내용이 붙을 수 있다. `c`의 ResearchGate DeepCog 결과에 섞인 JADES·submodularity 설명을 DeepCog 방법으로 채택하지 않는다. `primary_search`의 TSUL 결과 뒤에 붙은 prior-knowledge LSTM 문단의 **76.4%·10%**도 TSUL의 성능 수치로 옮기지 않는다.

[C20] 파일명에 `primary`가 있어도 결과 전체가 일차 출처인 것은 아니다. Eurekamag·ResearchGate·저자 집계 서비스와 공식 기관·학회 자료가 함께 있다. Eurekamag의 `References` 목록에는 도로 교통·고분자·데이터베이스 분야 항목도 섞여 있다. 이를 원논문의 실제 참고문헌 목록으로 확정하지 않는다.

[C21] TSUL 후보의 저장 요약은 흐름 특성에 조건부인 SVAE 분포와 수개월의 링크 용량 계획을 설명한다. 그 요약은 Linear·LSTM 대비 개선과 함께 TFT보다 낮은 예측 정확도·짧은 계산 시간을 보고한다. 본문을 검수하지 않았으므로 이 비교를 재현 결과로 채택하지 않는다. 2025년 조기 서지, 2026년 34권 17–32쪽 서지, 2021년 GLOBECOM 후보도 구별한다.

[C22] Digital Twin 후보는 quantile GRU와 분포 변화 감시를 통한 동기화 문제다. 저장 초록의 통신량 **5.41–7.01%** 감소나 예측 오차·비용 주장을 UPC 소속 수정 또는 RCTL 피크 성능으로 인용하면 연구 대상이 바뀐다. 이 문헌의 원 데이터·코드·수치 검증은 이번 범위에 포함되지 않는다.

[C23] Forecaster의 제3자 PDF 검색 발췌에는 줄이 나뉜 분수와 Table 2가 있다. 이 표의 12개 점수는 [H067](0069-0071-forecaster-dilemma.md)의 저널 표와 같다. 이 부분의 일치만으로 미러 PDF 전체가 동일 판본이라고 확정하지 않는다. 검색 텍스트만으로 수식을 복구하거나 저널 수치를 덮어쓰지 않으며, 실제 저널 PDF·시각·공식 TeX의 판본 차이는 H067 검수가 기준이다. 검색에서 표가 보인다는 사실은 전체 논문이나 별도 독립 실험을 읽었다는 증거가 아니다.

[C24] ECB·ECMWF·ISF의 발표·교육 자료, NFV에서 SFC 이동 비용을 고려한 비대칭 예측, 홍수·기상 평가, 광망·CPU 예측도 탐색 후보로 남긴다. 발표의 예제 숫자, 다른 응용의 성능, 해당 논문이 DeepCog를 인용했다는 사실만으로 TabICL 연구의 비교군 또는 기각 근거를 구성하지 않는다.

[C25] `Rolling-Origin Conformal Prediction under Local Stationarity and Weak Dependence,2026`은 당시 `search_only_not_method_reviewed` 목록에 있다. 이번 8개 저장 로그에서는 대응 원발췌를 확인하지 못했다. 이 문헌의 존재·정확한 서지·방법 검수를 완료 처리하지 않고, 당시 검색 흔적만 남은 미확인 후보로 유지한다.

## 원69–71 및 다음 설계에 연결하는 방식

[C26] 원69와 원71의 ‘선택적으로 읽음’, 코드 미검토, 미실행·후속 방향 표시는 당시 상태다. 이번 후속 독해로 과거 원문을 소급 수정하지 않는다. H067·H068의 실제 본문 검수와 H069의 초록·탐색 기록 검수를 별도 시점으로 연결한다.

[C27] Forecaster는 관측 결과에 조건을 건 평가의 문제를, DeepCog는 용량 결정 비용을, SIU 초록은 과소 예측 벌점을 사용한 용량 계획을 다룬다. 이 셋을 묶어 ‘피크만 평가하면 된다’, ‘분할이 유효하다’, ‘특정 비대칭 목적이면 성능이 개선된다’고 결론 내릴 수 없다. 팀의 예측 대상·행동·평가 표본을 먼저 고정해야 한다.

[C28] 당시 70의 저장 예측 진단과 71의 판단은 [H066](0069-0071-peak-objective.md)에 연결한다. 검색 자료를 읽은 사실만으로 새 SIU 구현·DeepCog 재현·TabICL 재추론을 추가하지 않는다. 동일 예측의 후처리·재집계와 새 모델 실험의 구분도 유지한다.

[C29] 팀은 이 정리문, 기존 정확사본 9개, source_id·해시·40개 사본 경로 및 결과별 접근 링크를 사용할 수 있다. 검색 원문은 외부 문헌 발췌와 만료된 서명 URL을 포함해 이번에 새로 재게시하지 않는다. 서명 URL 대신 안정적인 기관 접근 경로를 안내하되, 그 링크가 원로그 자체의 다운로드 주소라는 뜻은 아니다. 원로그 전체의 팀 공용 보관 위치는 아직 확인되지 않았다.

[C30] 새 실험 설계에 사용하려면 SIU 손실식·단위·시간 분할·모델 선택 경계·실행 가능 코드·데이터 접근을 확보하고, 현재 연구의 행동 및 비교군과 대응시켜야 한다. 그 전까지는 검증된 결과의 재사용 목록과 미확인 후보 목록을 구분한다. 이 문헌 보충으로 69–71 관련 패킷 전체나 전체 과거기록 정리가 완료되는 것은 아니다.
