# Deep Renewal의 간격·크기 공유 학습과 성능 근거 대조

**핵심:** 발생 간격과 양의 크기를 모델링하고 여러 품목의 LSTM을 공유하는 선행 구조는 확인된다. 성능은 자료·지표마다 다르며, 현재 cell 소속 결정의 개선을 입증하지 않는다. 본문·표의 개수와 성능 해석, 부록의 시간 인덱스와 RMSSE 식에는 재사용 전에 확인할 차이가 남는다.

[원기록 82의 판단](0099-intermittence-decision.md)을 잇는 문헌 검수다. 현재 확보한 출판사 보완 자료는 옛 폴더의 저장본과 구별한다. 원문·그림 전체를 재게시하지 않으며 모델을 실행하지 않았다.

**상태:** 36개 주장·6개 묶음의 작성 후 원문·그림 대조 완료.

## 확률모형·공유 학습·수식

<a id="c03"></a>**C03.** 대상은 긴 0구간을 갖는 단변량 비음수 정수 수요다. 균일 시간 n과 양의 수요 발생 index i를 구별하고, Q는 발생 간격, M은 양의 수요 크기다. 사용한 Poisson·기하·음이항 분포는 양의 정수 지지집합으로 이동한 형태다. 품목 수요를 현재 Internet activity의 연속값과 같은 관측량으로 취급하지 않는다.

<a id="c04"></a>**C04.** Eq. 1a/b는 M과 Q의 지수평활을 따로 갱신한다. Eq. 2의 i.i.d. 모형과 시간의존 갱신 사이의 차이, E[1/Q̂]와 1/E[Q̂]의 차이에서 생기는 역수 편향을 논의한다. SBA 보정(1−α/2)M̂/Q̂는 이 맥락의 근사이며 현재 RCTL의 소속 변경식이 아니다.

<a id="c05"></a>**C05.** Table 1의 Static G-Po/G-NB는 기하 간격과 Poisson/음이항 크기를 쓰고, EWMA G-Po/G-NB는 각각의 평균을 과거 관측으로 갱신한다. Static과 EWMA, 간격 분포와 크기 분포를 별도 축으로 비교해야 어느 변경의 효과인지 알 수 있다.

<a id="c06"></a>**C06.** h(k)=P(Q=k|Q≥k)는 직전 발생 뒤 k−1기간 동안 새 수요가 없을 때 다음 발생확률이다. 기하분포의 hazard는 일정하지만 음이항 간격은 aging·시간적 clustering·준주기 패턴을 표현할 수 있다. Fig. 1의 평균 5와 dispersion 1.1/4/20 예시는 확률모형의 형태이며 실측 통신 빈도를 측정한 결과가 아니다.

<a id="c07"></a>**C07.** 부록 A.1은 Y=X+1, μ>1, ν>1로 정의하고 Var(Y)/(E(Y)−1)=ν를 사용한다. 따라서 이 논문의 NB(μ,ν)를 0부터 시작하는 count 분포나 다른 라이브러리의 인자와 같은 값으로 바로 넣으면 안 된다. 표·그림의 ν는 단순히 분산이나 변동계수라고 읽지 않는다.

<a id="c08"></a>**C08.** 간격을 음이항으로 바꾸어도 논문의 positive-support EWMA는 장기적으로 크기와 간격이 1로 수렴하는 문제를 피하지 못한다고 설명한다. 부록 A.3은 해당 구성의 명제·따름정리와 stationary mean 완화 예를 제시하고 Static은 구별한다. 이 설명을 모든 LSTM이 1로 수렴한다는 정리로 확대하지 않으며 증명을 독립 재검증한 것은 아니다.

<a id="c09"></a>**C09.** Eq. 3/4는 hidden state를 LSTM으로 갱신하고 1+softplus 형태의 g로 조건부 평균을 만든다. RNN이 수요 간격·크기의 분포 매개변수를 내고 음의 로그우도로 학습한다는 구성이다. MSE로 단일값만 예측하는 모델이나 활동 여부를 먼저 0/1로 반올림하는 hard gate와 구별한다.

<a id="c10"></a>**C10.** §4.3과 Table 2는 이전 간격과 크기를 함께 입력하고 추가 공변량을 받을 수 있으며, 여러 SKU에서 LSTM의 Θ를 공유하는 global model이라고 명시한다. 공변량을 넣을 수 있다는 설명이 모든 실험에서 특정 공변량을 실제 사용했다는 증거는 아니다. 어느 cell을 함께 학습할지 고르는 UPC 소속 수정 효과도 여기서 검증하지 않았다.

<a id="c11"></a>**C11.** 부록 A.2는 Static 모형의 크기·간격 독립성과 크기의 과거 독립성 아래 다음 수요 평균을 발생확률×양의 수요 평균으로 전개한다. 이는 원기록 82의 확률 곱과 hard gate 구별을 이해하는 근거다. 독립성 없이 같은 단순 분해를 모든 RNN 구현에 적용했다고 주장하지 않는다.

<a id="c12"></a>**C12.** 부록 A.2의 P(Q=n−T_i+1 | Q>n−T_i)를 h_Q(n−T_i)로 적은 부분은 자체 h(k)=P(Q=k|Q≥k) 정의와 1만큼 어긋난다. 그 정의를 대입하면 h_Q(n−T_i+1)에 대응한다는 문서 내부 대조다. PDF와 TeX 모두 같은 표기이며 실제 코드의 인덱스 오류를 확인한 것은 아니다.

<a id="c13"></a>**C13.** §4.4·Table 3은 개별 주문의 정확한 시각을 이용해 Q′를 연속시간 간격으로 바꾸고, 양의 정수 크기는 유지한다. j는 집계된 양수 기간이 아니라 개별 사건 index다. Static E-Po/E-NB와 RNN 확장은 정확한 사건 시각이 있을 때의 대안이며 집계된 Internet activity만으로 그 입력이 확보되지는 않는다.

## 실험 자료와 평가 조건

<a id="c14"></a>**C14.** 완전 주기는 10주 분량의 시간별 수요로 간격 20시간·Poisson 평균 5를 설정한다. 교대 사례는 간격 4/16·크기 10이며 Periodic/Alternating을 100회 시뮬레이션했다. Random은 Static G-Po에서 생성한다. 시각 예시의 LSTM은 1층 5 unit이고 음영은 forward sampling의 1–99%구간, 선은 표본 경로 평균이다.

<a id="c15"></a>**C15.** Fig. 2/3은 유연한 간격과 RNN이 주기·교대 패턴을 표현하는 사례다. Table 4의 Periodic P90은 Static G-Po 0.460→Static NB-NB 0.419→RNN NB-NB 0.412지만 RMSE는 1.219→1.181→1.183이다. RNN이 모든 지표에서 최고라는 결과는 아니며, Alternating의 P50도 1.022→1.021 정도다. 이 수치를 실제 통신 자료의 개선율로 옮기지 않는다.

<a id="c16"></a>**C16.** Car Parts는 2,674개 중 51개월이 완전하고 처음 45개월에 수요가 있는 2,503개, Auto는 3,000개 중 24개월의 intermittent/lumpy 1,227개, RAF는 84개월의 5,000개 품목을 썼다고 보고한다. 모두 현재 cell/beam의 트래픽 실험과 구별되는 재고 수요 자료다.

<a id="c17"></a>**C17.** UCI는 4,070개 품목의 거래 중 마지막 3개월을 일별 집계하고 처음 30일에 수요가 있으며 전체 기간 구매기록이 90개 미만인 1,381개를 유지했다. M5는 Walmart 제품·점포별 30,490개 일별 시계열, 가장 긴 자료 1,913일이라고 보고한다. UCI의 정확한 주문 시각은 연속시간 실험에도 사용했다.

<a id="c18"></a>**C18.** M5 intermittent 개수는 본문 23,401과 Table 5의 23,041이 다르다. lumpy 5,953과 전체 30,490은 같이 보고돼 있다. 저장 HTML 본문과 현재 PDF에서도 같은 차이가 보여 두 값을 보존하며, 어느 값이 실제 전처리 결과인지 임의로 고르지 않는다.

<a id="c19"></a>**C19.** Table 5의 Auto는 1,227시계열×24기간인데 issue point 총수 56,133·평균 18.71을 제시한다. 선택된 자료를 분모로 삼으면 가능한 최대 29,448보다 총수가 크고, 56,133/1,227은 약 45.748이다. /3,000은 18.711로 표시 평균과 가깝지만 실제 통계가 원래 3,000개에서 계산됐다는 확인은 아니다.

<a id="c20"></a>**C20.** 기본 실험은 마지막 6기간을 보류하고 앞 기간으로 학습하는 6-step 예측이다. M5는 마지막 28일과 28일 예측을 사용한다. 품목별 입력 이력과 예측기간을 구별하며, 임의의 시간 섞기나 모든 시점의 관측을 계속 갱신하는 평가로 다시 기술하지 않는다.

<a id="c21"></a>**C21.** 논문은 Apache MXNet·Gluon Adam·Amazon SageMaker, 기본 학습률 0.1과 Croston α=0.1을 보고한다. 처음 4자료에는 HPO를 하지 않았고 RNN은 1층 20 unit·weight decay 0.01이다. 실제 seed·batch·훈련 로그·정규화 구현은 이 기록에서 확인하지 않았다.

<a id="c22"></a>**C22.** M5는 학습 구간의 20%를 검증 자료로 두고 4개 평가 지표의 단순 평균을 목적값으로 Bayesian HPO를 했다고 보고한다. 학습률·층수·unit·epoch를 조정한 선정 설정은 3층×30 unit·750 epoch·학습률 0.01이다. 서로 척도가 다른 지표 평균의 실제 코드와 검증 시점 배치는 미확인이다.

<a id="c23"></a>**C23.** 실험은 3회 반복의 평균·표준편차를 보고하고 확률모형에서 250개 경로를 표본 추출한다. 점 예측 비교에는 경로 평균을 쓴다. 부록의 P50/P90은 ρ=.5/.9의 2배 pinball loss를 품목×예측기간으로 평균하며, 식에는 수요 합으로 나누는 항이 없다. 이 지표값을 비율 오차로 해석하지 않는다.

<a id="c24"></a>**C24.** 부록 A.4에서 RMSSE라 부르는 식은 분모를 학습 구간의 절대 1차 차분 합 × (1/L′)로 정의하고, 바깥 제곱근 없이 제곱오차/분모를 평균한다. PDF 3쪽과 TeX 339–340행이 일치하므로 추출 누락이 아니다. 이름과 식의 차이를 남기고 실제 평가 코드·표 계산이 어느 정의를 썼는지는 미확인으로 둔다. 표 수치를 임의로 수정하거나 현재 RMSSE와 직접 비교하지 않는다.

## 성능과 반례

<a id="c25"></a>**C25.** Table 6에서 Car Parts의 RNN G-Po는 P50/P90/RMSE/RMSSE=0.396/0.447/1.062/0.996이다. Static G-Po는 0.750/0.638/1.410/1.345, TSB의 RMSE/RMSSE는 1.362/1.278이다. 이 자료에서는 보고된 평균값이 개선되지만 같은 RNN 계열 안에서도 P50 최저는 NB-NB 0.385로 지표별 선택이 다르다.

<a id="c26"></a>**C26.** Auto는 학습 18기간에 불과하며 RNN의 일반적 개선을 보이지 않는다고 저자가 설명한다. Table 6에서 Static NB-Po RMSE 7.809·RMSSE 1.452에 비해 RNN NB-Po는 8.634·1.497이다. 짧은 자료에서도 공유 RNN이면 항상 좋아진다는 주장의 근거로 사용할 수 없다.

<a id="c27"></a>**C27.** RAF에서는 all-zero의 RMSSE 1.423이 표의 다른 행보다 낮지만 RMSE 16.786은 Static G-NB 16.541보다 높다. RNN G-Po의 P50은 1.277로 낮고 P90 최저는 Static G-NB 2.354다. 0 예측의 유불리와 모델 선택은 지표에 따라 달라지며, RMSSE 명칭 아래의 구현 공백도 함께 남긴다.

<a id="c28"></a>**C28.** Table 7 UCI의 RNN G-NB는 P50/P90/RMSE=2.039/2.870/7.368로 낮지만 RMSSE 3.566은 TSB 3.409보다 높다. Static G-Po의 2.059/3.043/7.488/3.514를 기준으로 보더라도 모든 지표가 함께 좋아지는 것은 아니다.

<a id="c29"></a>**C29.** 본문은 조정 RNN이 점 예측에서도 약간 낫다고 서술하지만 Table 7에서 TSB의 RMSE/RMSSE는 2.213/1.323, RNN G-Po+HPO는 2.190/1.338이다. 네 HPO 행의 RMSSE는 1.338/1.328/1.354/1.353으로 모두 TSB보다 높다. RMSE도 G-Po/G-NB 두 행만 TSB보다 낮으므로 조정 RNN 전체의 두 지표 우위로 요약하지 않는다.

<a id="c30"></a>**C30.** Table 8은 각 손실을 Static G-Po의 손실로 나눈 비율을 자료·모형 계열에서 요약한다. RNN행의 0.896/0.945/0.973/0.967은 P50/P90/RMSE/RMSSE에서 10.4/5.5/2.7/3.3% 감소에 대응한다. 이는 각 자료·모형의 보장된 개선이나 TSB 대비 수치가 아니다. 괄호는 단측 1표본 t-test의 보고값이며 0.000을 확률이 정확히 0이라고 해석하지 않는다.

<a id="c31"></a>**C31.** UCI의 정확한 구매시각으로 학습한 연속시간 모형은 예측 사건을 마지막 6기간으로 집계해 비교했다. Table 9에서 RNN E-NB의 RMSE 7.359는 RNN G-NB 7.368보다 낮지만 RMSSE 3.738은 3.566보다 높다. 저자도 연속시간 모형을 선호할 실증 근거가 없다고 보고하므로 더 세밀한 시각이 항상 예측을 개선한다고 결론 내리지 않는다.

## 재현 범위와 팀의 재사용

<a id="c32"></a>**C32.** 원문은 SageMaker와 GluonTS 구현 링크를 제시하지만 이 검수에서 해당 코드·데이터·seed·하드웨어·시간·요금의 일치나 실행 성공을 확인하지 않았다. 250경로·3회 반복·HPO 설정은 보고된 실험 조건이며 전체 파이프라인 비용 측정이 아니다. 원연구 스크립트·TeX 컴파일·새 모델 실행은 0이다.

<a id="c33"></a>**C33.** 원기록 82의 “발생 간격·양의 크기·여러 품목의 LSTM 공유 자체만으로 새롭다고 할 수 없다”는 판단은 §4.3과 부록의 구조에 근거가 있다. 다만 품목 수요의 손실 개선은 현재 cell 공유 결정의 성능 증거가 아니며, 이 문헌 한 편의 대조를 전체 문헌의 신규성 심사로 표시하지 않는다.

<a id="c34"></a>**C34.** 원기록 82는 현재 관측 단위에서 실제 무통신이 반복적 예측 손해를 만든다는 근거와 기존 발생/크기 공동 학습보다 유용한 새로운 cell 공유 결정이 함께 있을 때 재진입하도록 했다. 팀은 해당 기록과 이 논문의 support·간격·분할·목적함수·지표 구현부터 비교하고, 가정이나 입력이 달라지는 부분을 새 실험 계획에 명시할 수 있다.

<a id="c35"></a>**C35.** 논문의 결론은 자료별 혼합 결과와 확률 RNN의 가능성이다. 간헐 패턴별 모형 선택, 다른 분포·구조·학습 전략, 계층적 확률예측과의 결합은 후속 연구로 제시된다. 이 후속 아이디어가 이미 실행된 UPC 소속 수정이나 현재 TabICL의 확정된 개선이라고 적지 않는다.

<a id="c36"></a>**C36.** 이번 범위는 원논문 1편의 저장 HTML/TXT 2표현물·4별칭, 별도 시점의 출판사 보완 자료, 원기록 82의 기존 3자료다. 참고문헌 100항목과 부록 6항목을 읽은 일을 해당 논문 106편의 독해로 세지 않는다. 선택했던 원기록 82 문헌 후속 목록은 끝나지만 snapshot24 고유 연혁·누적본문과 전체 연구기록 정리는 남아 있다.
