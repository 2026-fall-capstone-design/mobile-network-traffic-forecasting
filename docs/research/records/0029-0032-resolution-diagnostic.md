같은 세 cell에서 최근 이력을 추가한 단순 모델은 두 해상도 모두 개선됐다. 그러나 공유 학습의 이득은 모델·입력·cell에 따라 달랐다. 이 기록은 “hourly 자료 때문에 앞선 안이 실패했고 10분이면 해결된다”는 설명을 채택하지 않은 경과다. 새 소속 알고리즘이나 TabICL의 필요성을 입증한 실험으로 읽지 않는다. **[C01·C16]**

원문은 2026-09-25의 29(해상도·접근 계획), 30(작은 자료 확보 계획), 31(비교 설계), 32(결과·판단)다. [28의 불확실성 검토](0028-mechanism-uncertainty.md) 이후의 추가 확인이다. [원문 24파일과 기존 비용 원장](../evidence/0029-0032-resolution/README.md), [읽기 범위](../sources/history-021.md), [검수](../verification/history-021.md)를 함께 제공한다. 계획·정적 코드, 저장된 실행 결과, 현재 아카이브의 검산을 구분한다. **[C01]**

## 처음 확인한 해상도 차이

UPC·RCTL 논문 §IV.A는 각 cell 첫 30일을 10분 간격 4,320개로 사용하고, 첫 20일을 학습에 배정한다고 설명한다. Table I과 본문은 입력 길이 q=8, 간격 10분이다. 초기 hourly pilot의 q=8은 서로 다른 시간 범위를 담는다. UPC가 peak 발생 시각을 0–23시로 묶는 단계와 RCTL의 관측 간격은 별개다. 입력·정규화도 다르므로 초기 pilot을 원 논문의 완전 재현으로 부르지 않는다. **[C02]**

STCNet 예제는 UTC 시각에 1시간을 더하고 시간대·cell별 합계를 만든다. 시간 합계만으로 그 안의 여섯 관측 순서를 복원할 수 없다. `[0,0,0,0,0,60]`과 `[10,10,10,10,10,10]`은 같은 합을 갖는 설명용 예시다. 예제 코드의 출력 5채널과 사용한 H5의 3채널 구조도 구별한다. 예제 전체를 실행해 H5를 재생성한 검증은 아니다. **[C02·C06]**

## 자료 접근과 0.6초 표기 정정

파일 ID `2674255`와 metadata 응답의 ID `3044834`는 객체 역할이 다르다. [Dataverse API의 Getting File Metadata 설명](https://guides.dataverse.org/en/6.7/api/native-api.html#getting-file-metadata)은 응답 ID를 file metadata version ID로 명시한다. 서로 다른 숫자만으로 자료가 바뀌었다고 판단하지 않는다. `restricted:false`도 Guestbook 없는 다운로드 성공과 같지 않다. **[C04]**

## 비교 조건과 지표

학습 target은 11월 8–20일, 진단 target은 11월 21–30일이다. 처음 7일은 주간 lag 이력이며, 정규화 척도는 각 해상도별 11월 1–20일의 cell 평균이다. 10분 자료의 학습/진단은 cell당 1,872/1,440행, 시간 자료는 312/240행이다. global의 학습 행은 local 하나의 3배(5,616 또는 936행)이며, cell ID 열은 없다. 동일 학습 행 수를 고정한 비교가 아니다. **[C08]**

- **S, 8열:** 전날·전주 같은 시각, 직전 하루 평균·표준편차(ddof=0, shift 1), 일중·주간 sin/cos 4열. 주간 phase에는 요일과 시각/24가 함께 들어간다.
- **S+L, 16열:** S에 t−8부터 t−1까지 최근 8개 관측을 추가한다. 10분 조건은 target 전 80–10분, 시간 조건은 전 8–1시간이다.
- **Ridge:** StandardScaler와 alpha=1의 pipeline. scaler는 해당 global/local 학습 입력에 적합한다.
- **HGB:** 별도 StandardScaler 없이 사용한다. max_iter=100, max_leaf_nodes=31, min_samples_leaf=20, learning_rate=0.1, l2=1, early_stopping=False, seed=20260925다. 26–27의 두 추정기 공통 scaler 조건과 다르다.

위 입력·모델 설정은 원 코드의 정적 검토다. NPZ의 정답·척도·시각은 CSV 재구성과 일치했으나 실제 fit 입력 X, 학습 객체, 당시 환경 전체는 보존되지 않았다. 저장 예측에서 지표를 다시 계산한 검증이며 독립 적합 재현은 아니다. **[C08·C09]**

normalized MAE는 cell별 정규화 오차를 같은 개수의 시각에 대해 평균한 값이다. 작은 값이 좋다. 아래 두 해상도는 **다른 target 집계·예측 간격·척도**이므로 열 간 값을 예측 우열로 비교하지 않는다. 원 단위 cell별 MAE와 평가 앞/뒤 5일은 [저장값 검산 JSON](../verification/history-021-portable-check.json)에 모두 남겼다. **[C10]**

## 비용과 원 논문 인용 정정

기록된 저비용 fit은 **2해상도 × 2입력 × 2추정기 × (global 1+local 3) = 32개**다. 16개의 fit 기록 행을 16회 fit으로 세지 않는다. 계산 구간은 2.314005800초, 그 안의 fit+predict 합은 2.215385700초다. 두 시간을 더하지 않는다. RSS 최고 기록은 164,704,256 bytes이며 checkpoint에서 채집한 값으로 연속 측정 peak가 아니다. import·Python 시작·전체 도구 대기까지 포함한 총 wall time도 아니다. **[C14]**

접근 실패 0.6770589초, 별도 API 진단 1.3117933초, 공개 CSV 수집 1.1974962초는 각각 저장된 별도 타이머다. 전체 작업 시간을 이 값들의 합으로 확정하지 않는다. 기존 누적 원장의 해당 stage 한 건도 summary와 일치한다. 당시 RCTL fit/forward와 TabICL 호출은 0으로 기록되어 있다. 아카이브에서도 새 연구 모델 실행은 0회다. 원문은 exit 0 완료를 보고한다. 이 묶음에서는 저장 산출물·원장 entry를 대조했으며 당시 종료 콘솔을 별도로 확인하지 않았다.

**32 §4의 “Fig. 7에서 1~4 cluster 비교”는 범위를 좁혀 쓴 표현이다. 실제 그림 축은 1·2·4·6·8·12다.** 논문 본문은 1을 UPC 없는 단일 cluster로, 4를 네 cluster의 예로 설명하고 MLP·LSTM·RCTL이 두 지표에서 2개일 때 가장 좋았다고 보고한다. 본문 해설의 1과 4를 전체 실험 범위로 바꾸지 않는다. 따라서 원 논문에 single global 비교가 없었다는 설명도 맞지 않는다. 그림의 모든 곡선 수치를 새로 추출하거나 원 논문 모델을 재현하지는 않았다. **[C15]**

논문의 첫 30일·큰 cell 집합·RCTL 조건과 이 기록의 선택된 세 cell·단순 모델·평균 정규화 조건은 다르다. 결과 방향만 비교해 모순이나 도시 전체에서 clustering이 불필요하다는 결론을 만들지 않는다.

## 재사용과 다음 설계의 조건

팀은 같은 CSV·설정·보존 예측으로 지표와 반례를 확인할 수 있다. [검산 명령](../evidence/0029-0032-resolution/README.md)은 학습·추론·과거 코드 실행을 포함하지 않는다. 외부 README·notebook은 고정 링크와 해시, H5는 기존 입수 경로와 지정 읽기 범위로 연결했다. **[C16]**

시간 간격만 바꾼 반복 실험을 설계하기 전에 자료량·고정 모델 용량·cell 선정·정규화와 global의 학습 행 수 차이를 확인해야 한다. 원문은 이 원리를 아직 확인하거나 새 후보로 채택하지 않았다. 성공 기준·RCTL 상한의 변경, 새 10분 RCTL/TabICL 실행, 세 cell에 원 UPC 전체 적용도 이 기록의 완료 범위가 아니다.

conditional grouping·regime switching은 당시 검색 발견 단계다. 검색 로그가 있다는 이유로 방법 본문·공식 구현 검토 완료로 올리지 않는다. 외부 notebook 전체 출력·나머지 코드, 실제 fit X와 모델 객체, 원시 CDR 전처리 전체, 이후 33번부터의 판단 연결은 미완료다. 추천 방향·최종 Word 미완료와 옛 Goal·예산은 당시 상태를 적은 자료다.
