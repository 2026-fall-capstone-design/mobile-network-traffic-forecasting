# 21·22: 문헌 근거와 최신 구현의 확인 범위

2026-09-25의 기록21은 진단 결과를 해석하며 문헌의 적용 조건을 제한했고, 기록22는 새로 확인한 구현과 미완료 문헌을 구분했다. 이번 정리는 **당시 읽었다고 기록한 범위와 지금 고정해 확인한 근거**를 연결한다. 새 모델·RCTL 실행은 없다. **H014-C01**

## 문헌이 제한한 판단

MGSTC와 PID는 예측 손실·관측 오차를 이용하고, Joint QoS는 소속과 모델을 함께 갱신한다. 이를 최종 RCTL 결과 없이 정하는 소속 점수와 동일시하지 않는다. Milan의 자료 단위도 현재 진단과 다르다. [기존 세 문헌 검수](0017-adaptation-literature.md)를 재사용하며 이 비교를 새 실험으로 세지 않는다. **H014-C01**

FSA는 전역·국소 특징에서 계수를 만들지만 실제 rollout은 결정적 AR 재귀다. 자체 생성값으로 특징을 다시 계산하는 과정은 이후 실제 관측을 받아 갱신하는 진단과 다르다. 축소한 모델을 같은 source에서 학습한 결과를 공개 대형 checkpoint의 우위로 확대하지 않는다. 그림·본문의 기호 차이와 구현 미확인 범위도 [비교 문서](../references/forecasting-version-boundaries.md)에 남겼다. **H014-C02·H014-C03·H014-C04**

공식 TabICL의 주기 탐색에서 사용하는 detrending은 [20번의 잔차 target 회귀](0020-0021-target-parameterization.md)와 역할이 다르다. 고정 코드에서는 신호를 전처리해 주기를 찾고 sin/cos 특징을 더한다. Encoder와 검출 함수의 기본값 차이도 구분한다. **H014-C05·H014-C06**

## 최신 README가 증명하는 범위

TabPFN-TS의 모델·입력 설명은 문서에 명시된 범위로 기록했다. 당시 main commit이 미기록이라는22의 한계를 유지하고, 이번에 확인한 세 commit을 대체 실행 버전으로 소급 지정하지 않는다. README·CHANGELOG·tag의 날짜는 서로 다르고, README가 같아도 패키지 요구 버전이 바뀌었다. 3.5 checkpoint를 불러오거나 외삽 해결을 검증하지 않았다. **H014-C07·H014-C08**

| 새로 발견한 문헌 | 이번 확인 범위 | 아직 사용할 수 없는 근거 |
|---|---|---|
| CDE benchmark | 초록·서론·관련 연구·배경;39개 데이터·50–20,000표본의 밀도와 calibration 문제 | density 변환의 methods/appendix, 전체 결과·그림·재현; 우리 트래픽 성능으로 직접 환산하지 않음. **H014-C09** |
| TabularMath | 공식 서지와 초록 | 모델 구조·프로토콜·결과표·구현; traffic 증가 구간이나 RCTL 공유 손해의 직접 증거로 쓰지 않음. **H014-C10** |

검색어는 원문22의16행에 보존했다. 검색에서 일치 문헌을 찾지 못했다는 사실은 신규성의 증거가 아니다. **H014-C12**

## 반복 안내 수정은 별도의 운영 기록

[초기 AGENTS 사본](../evidence/0021-0022-literature/originals/SRC-0000455.md.txt)은2026-09-25라는 날짜와 짧은 진행 지침을 담는다. [현재 원본의 보존 사본](../evidence/0642/originals/SRC-0000001.md.txt)은9월27·28일과10월2일 개정을 포함한다. 두 판본을 같은 당시 파일로 취급하지 않는다. 문서 속 명령·예산·Goal은 역사적 자료다. **H014-C11**

22의 “앱 스케줄러나 전역 설정을 변경하지 않았다”와 “현재 실행에서 지침을 적용했다”는 당시 보고다. 파일 존재와 현재 공식 설명만으로 과거 앱 동작을 독립 확인한 것은 아니다. 미래 자동 재개도 원문에서 미시험으로 구분했으며 이번에 실행 시험하지 않았다.

## 재사용과 후속 질문

새 실험에서는 논문 판본, 코드 commit, 패키지와 checkpoint, 입력 가능한 정보와 정답 도착 시점, 평가 지표를 먼저 고정한다. 같은 용어를 쓴다는 이유로 주기 탐색·target 변환·예측 계수 생성·소속 선택을 하나의 방법으로 합치지 않는다. 상세 비교의 미확인 구현과 표기는 실제 적용 전에 확인할 조건이다.

22의 본문은 모두 읽고 접근·발견·운영 보고의 한계를 연결했다. 방법 미검토 문헌을 완료 논문으로 세지 않는다. 기록21의 시간·공간·ID·잔차 진단은 기존 문서에 연결했고, 누적 비용 전체 감사와 이후 연구 통합은 남아 있다. 당시 비용은 새 실행 비용으로 추가하지 않는다. [검수 범위](../verification/history-014.md)·[과거 시도 색인](../prior-attempts.md)으로 이어진다. **H014-C12**
