# 13–15 교차 예측과 cell 식별 정보

2026년 9월 25일의 13·14 계획과 저장 산출물, 15의 수치·방법 판단을 연결했다. [10–12](0010-0012-population-upc-stability.md)에서 확인한 소속 차이가 실제 예측 관계와 연결되는지, 같은 pooled 자료에 cell ID를 더하면 무엇이 달라지는지를 물었다. 13은 기존 예측의 재분석이고, 14는 당시 새 TabICL 3조건과 단순모델 4조건의 실행이다. 이 아카이브에서는 저장값만 검산했다.

15의 §3, 여섯 선행연구의 방법 해석은 다음 묶음에서 일차자료와 대조한다. 원문 전체 62행을 읽고 보존한 것과 전체 주장 검수 완료를 구분한다. [출처·실제 읽은 범위](../sources/history-008.md), [핵심 주장 11개](../verification/history-008-primary-review.json), [검수](../verification/history-008.md)를 함께 본다.

## 13: 다른 cell context의 교차 예측

저장 `median[:,64:]`를 source×target×64시각으로 해석하고, 각 target의 실제 정답과 비교한 MAE 행렬을 target×source 순서로 만들었다. 앞 64열은 이전 anchor 예측이므로 이번 실제 query 계산에서 제외한다. target A에 source B를 쓴 MAE에서 A 자신의 context MAE를 뺀 것이 방향별 excess이며, 두 방향 평균이 아래의 대칭 교차 손해다. 소속 내부 비교에는 대각을 뺀 120개의 비방향 pair를 사용한다.

자기 context 평균 MAE는 0.07261397, 타 cell context 평균은 0.17606688이다. 타 cell 평균의 분모는 16×15개의 방향별 관계다. 대칭 교차 손해의 최소값은 −0.00481877, 중앙값 0.09273679, 최대값 0.28591907이다. 다른 cell의 context가 항상 불리하다는 주장도 하지 않는다.

입력 거리의 원 구현은 504context행×16cell 전체로 StandardScaler를 맞춘 뒤, source마다 같은 날짜를 제외한 context의 8번째 이웃 거리 95%분위수를 참고선으로 썼다. query의 8번째 source 이웃 거리가 참고선 이하인 비율이 저장 `input_support`다. 서로 다른 cell 간 240관계의 분율 중앙값은 56.25%다. pair 상관에는 양방향 분율의 평균을 사용했다.

저장 raw/profile PCC와 rank 상관·분율 집계는 검산했지만, 이웃 거리와 95%참고선 자체는 다시 계산하지 않았다. 이 분율은 진짜 확률분포 support의 경계나 인과 진단이 아니다. 원 분석은 이 기준으로 cell/query를 제외하지 않았다. 다른 cell로 단독 예측을 옮기는 것과 두 cell의 관측을 함께 학습하는 것은 자료 범위가 다르다. 이 교차 손해를 pooled 학습 손해로 사용할 수 없다.

## 14: 같은 pooled 자료에 ID를 더한 결과

기존 16개 입력은 과거 수요·lag·24시간 요약·시간·요일이다. no-ID는 이 입력만, ID는 16열 one-hot을 추가한 32개 입력이다. 세 번째 Tab 조건은 one-hot 열만 저장 순열 `12,5,4,8,2,15,10,11,1,13,0,14,7,9,3,6`로 바꿨다. 같은 식별정보이며 행/정답의 순서를 바꾼 조건이 아니다. 저장 시간 선택과 열 순열의 유효성은 확인했지만 seed 난수를 재생성하지 않았다.

원 코드는 `tabicl-regressor-v2-20260212.ckpt`를 지정하고 조건마다 별도 TabICLRegressor를 생성한다. ensemble1, batch1, CPU, n_jobs1, seed20260925, AMP/FA3/offload=False, 자동 다운로드 False, Torch threads4/interop2, median 출력이다. fit의 의미와 고정 구현은 [05 공식 구현 검토](0005-official-tabicl-audit.md)와 연결한다. 이번 세 실행의 로그에는 개별 checkpoint 해시가 없어, 코드의 파일 지정을 개별 실행 가중치 해시 검증으로 바꾸지 않는다.

Ridge는 StandardScaler와 alpha1, HGB는 absolute_error, max_iter100, learning_rate0.1, max_leaf_nodes15, min_samples_leaf20, l2_regularization1, early_stoppingFalse, 같은 seed다. 각 모델의 no-ID/ID 두 조건을 실행한 기록이며 하이퍼파라미터 탐색은 없다. 아래 전체 평균과 저장된 16cell·7일별 손해를 원 예측에서 다시 계산했다.

## 당시 판단, 재사용과 재검토 조건

당시 관측은 교차 예측 손해가 크면서도 동일 자료의 cell-ID 추가 이득은 작을 수 있다는 것이었다. 기존 대리 점수로 복귀하지 않고, 시간에 따라 자료의 유효성이 달라지는지 후속 질문으로 남겼다. 추천 알고리즘 확정이나 clustering 불필요의 인증 규칙은 아니다. 15의 `TabPFN concept drift clustering`은 검색어 기록이며 이 일곱 조건의 비교모델이 아니다.

같은 조건의 실험을 다시 계획하기 전에 [보존 근거](../evidence/0013-0015/README.md)의 교차 MAE·지원 matrix·24소속·7예측·선택 시간·ID 순열을 재사용한다. 새 연구라면 기간/도시/cell 집합, 같은 자료량의 pooled 비교, 실제 제공 X/Y, seed/표현 반복, 최종 learner와 RCTL 평가 중 무엇이 달라지는지 명시한다. 평균 이득 외에 cell·기간별 손해와 준비/추론 비용도 함께 남긴다.

15 §3의 Effect fusion·Tree-Structured·BanditPAM++·Active Clustering·CURE·NOMADD 해석과 신규성 판단은 [후속 문헌 검수](0015-category-cost-time-literature.md)에서 지정 구간의 방법·가정과 대조했다. 전논문 검토와 이후 시간 유효성 탐색·회귀 TabPFN·전체 후속 연구의 연결은 미완료다. 이 페이지의 수치 정리는 13/14 및 15의 위 지정 부분에 한정한다.
