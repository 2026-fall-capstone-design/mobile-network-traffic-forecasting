기준 예측의 잔차를 다른 모델로 학습해 최종 예측을 보정하는 연결은 이미 선행연구에 있다. 63·65번에서 검토한 Biswas 등의 **One Step Closer to Ground Truth: A Multi-Scale Residual-Aware Representation Learning Pipeline for Predicting Time Series Data**는 그 직접적인 사례다. 따라서 iTransformer를 TabICL로, 잔차 모델을 RCTL로 바꾸는 것만으로 새로운 원리라고 할 수 없다. 반대로 이 논문의 성능표가 우리 통신 cell에서의 학습 이득이나 계산비용 절감을 입증하지도 않는다.

## 어떤 학습 문제를 만들었는가

PDF 3–6쪽의 §3, Figure 2, Algorithm 1에 따르면 기준 모델과 보정 모델은 별도로 학습한 iTransformer다. 기준 모델은 MSE, 보정 모델은 Huber loss를 쓴다. 사전학습 모델의 context만 바꾸는 [Heatload MRRC](0063-0065-heatload-residual.md)와 학습 방식이 다르다.

1. 기준 모델의 여러 예측창이 같은 시각을 예측하면 평균한다. 식 (4)의 겹침 평균으로 잔차 시계열을 구성하고, 처음 lookback 길이만큼의 구간은 잔차 생성에서 빠진다.
2. 학습 잔차는 `기준 예측 − 실제값`이다. 보정 모델은 그 잔차의 시계열을 예측한다.
3. 최종 예측은 `기준 예측 − α × 예측 잔차`다. α는 학습 가중치가 아닌 축소 계수다.
4. 추론 초기 잔차를 만들 때 2L 길이의 과거 구간을 사용하고, 이후에는 예측을 다음 창의 입력으로 넘기는 재귀 구조를 설명한다. 한 번에 H 길이를 출력하는 것과 창 사이의 재귀 전달은 다른 수준의 설명이다.

**초기 잔차의 부호는 원문 안에서 일치하지 않는다.** §3.2.4의 첫 추론 잔차 R1은 `실제값 − 예측값`으로 적혀 있어 학습 정의와 반대다. PDF와 HTML에서 모두 확인했다. Figure 2 설명의 96–191/96–192, 식 (4) 주변의 C×L/C×H 표기도 일치하지 않는 부분이 있다. 실제 코드를 확보해 실행 경로를 확인하지 못했으므로, 이를 실제 구현의 부호 오류로 확정하거나 결과표의 원인으로 연결하지 않는다.

학습 잔차가 out-of-fold 예측으로 만들어졌다는 명시는 찾지 못했다. 학습 내 잔차와 새 시점의 잔차가 같은 분포일지도 미검증이다. 논문은 원자료와 잔차를 각각 표준화하고, 예측을 역변환한 뒤 원척도에서 결합하고 최종 지표를 위해 다시 표준화한다고 설명한다. 각 scaler의 fit 구간과 실제 집계 구현은 확인하지 못했다. 가중치 공유가 없다는 사실만으로 이 모든 시간 경계를 검증한 것은 아니다. (§3.3, C.2, D.2)

## 개선율·비용의 분모

§4.2.3의 MAE 감소율은 3개 비교군×8개 데이터셋의 24개 주장이다. `horizon별 상대 감소율의 평균`과 `평균 MAE의 상대 감소율`은 다르다. 예를 들어 DUET 대비 Electricity의 92.85%는 전자의 산술과 맞고, 후자는 92.73%다. DUET의 8개 수치는 전자로 반올림하면 모두 맞는다.

GPHT의 6개 수치는 전자의 입력 반올림 범위 밖이다. 예를 들어 ETTh2의 인쇄 주장 88.30%와 그 산술 57.36%가 다르다. 다만 논문이 집계 산식을 명시하지 않았고 Traffic/Weather의 차이는 후자의 산식으로 양립할 수 있으므로, 6개 전부를 산식과 무관한 오류로 단정하지 않는다. TimeBridge의 Exchange 81.35%는 기준값이 표에 없어 검산할 수 없다. 각 산식·반올림 구간을 JSON에 분리했다.

## 통계·수식·그림을 인용할 때

**잔차의 예측 가능성.** A.1 식 (11)–(12)는 보정 후 오차 감소 조건을 잔차 예측 오차로 다시 쓴다. 임의의 잔차를 유한 모델이 학습할 수 있다는 보장이 아니다. Table 9의 분포 거리/ADF와 Table 10의 Ljung–Box도 보고된 검정 결과다. p=0.0000은 표시 정밀도의 값이므로 정확한 0이나 본문 p<10⁻⁶ 주장의 독립 검증으로 쓰지 않는다.

A.2는 시간 순서를 섞은 잔차와 평균·분산을 맞춘 Gaussian noise로 잔차 구조를 파괴하는 대조를 보고한다. 섞은 잔차 자체의 예측 지표가 원래 잔차와 비슷해도 최종 예측에 합성하면 성능이 나빠진다고 구분한다. 이 보고는 잔차 예측과 최종 합성을 함께 평가해야 한다는 근거로 읽는다. 원시 잔차·순열·seed·합성 정렬을 확인하지 못했으며, 아래 지표 일관성 문제도 남아 있어 인과적 증명이나 독립 재현으로 승격하지 않는다.

**MSE와 MAE의 조건부 일관성.** 같은 관측·같은 가중치·같은 단위라면 MSE≥MAE²여야 한다. Table 11 Random의 16쌍, Table 12 Random의 12쌍과 Shuffled의 1쌍은 인쇄 반올림을 고려해도 이 조건과 맞지 않는다. 예컨대 Table 11 ETTh1 H=192의 34.42와 11.89²=141.3721, Table 12 Shuffled Exchange H=336의 .481과 .711²=.505521이다. 실제 집계·척도 정의가 다른지 확인하지 못했으므로 원 실행의 오류나 부정행위를 판정하는 근거로 삼지 않는다.

**seed 요약과 ±.** Table 16의 3 seeds로 Table 17의 48개 요약을 대조했다. ETTm1 H=96 MAE .272/.271/.270의 평균은 .271인데 Table 17에는 .272다. 보수적인 닫힌 반올림 구간을 잡으면 경계에서만 접하며, 같은 반올림 규칙으로 양립한다고 자동 판정할 수 없다. 다른 47개 평균의 구간은 내부에서 겹친다. ±가 SD·SE·CI 중 무엇인지 명확하지 않다. 이를 모집단 SD로 해석하면 위 ETTm1의 ±.002가, 표본 SD로 해석하면 ETTh1 H=336 MSE의 ±.000이 인쇄 seed 값과 맞지 않는다. 이 진단은 **조건부 해석**이며, 실제 ±의 정의나 평균과 SD의 공동 실현 가능성을 검증한 것이 아니다.

**confidence 열.** Table 15에서 spread가 0으로 인쇄된 33개 칸은 confidence=99.99다. 나머지 31개는 `100×(1−spread/mean)`을 반올림한 값과 같다. 이는 관찰한 수치 관계일 뿐 논문이 정의한 통계적 신뢰구간이나 99.99% 신뢰성의 근거가 아니다.

**Huber 설명과 판본.** 식 (8)/(13)은 선형항에 ½δ를 포함한다. C.3 설명의 해당 항은 PDF에서 `δ(|a|−δ)`, HTML에서 `δ(|a|−½δ)`로 다르다. 부호가 반대인 ±x 예시도 `2|x| > δ`여야 선형 구간에 들어간다. PDF/HTML 텍스트 대응 검사만으로 모든 수학적 표현이 같다고 처리하지 않았다.

**정성 그림과 평가 입력.** Figure 3의 Sequence Length 축은 H 변화이며 L=96은 고정이다. Figure 4에는 Traffic의 음·양 상관 진동과 Weather의 약 28 lag 이후 음수 구간이 보인다. 모든 lag가 양의 상관이라는 설명으로 합치지 않는다. Figure 5의 선택 사례는 원시 시계열 재계산이나 사례 대표성 검증이 아니다. §4.3은 제안법의 재귀 입력과 기존 방법의 실제값 입력을 구분하지만, 동일 정보·같은 평가 창의 비교인지 확인할 구현은 없다.

## 재사용과 재검토 조건

팀은 잔차 보정 자체를 새 후보로 다시 발명할 필요가 없다. [ECAI](0063-0065-ecai-interface.md)의 global forecast 입력, [Heatload](0063-0065-heatload-residual.md)의 빠른 잔차 context, 이 논문의 별도 잔차 학습은 연결 방식과 비용 조건이 다르다. 새로운 연구를 제안하려면 다음 차이를 먼저 적는다.

- 기준 예측의 생성 시점·잔차 부호·겹침 평균·초기 구간을 고정하고, 각 시점에 실제 사용 가능한 정보로 잔차를 구성한다.
- scaler fit, 잔차 학습 구간, α 선택 구간, 최종 평가 구간을 구별한다. 기록되지 않은 선택 분할을 추정하지 않는다.
- 같은 target·척도·가중치·horizon·갱신 조건의 비교군을 둔다. 잔차 MAE와 최종 통신 cell/RCTL 성과를 분리한다.
- 평균 이득뿐 아니라 손해 조건과 원래 모델의 결과를 남기고, 두 단계와 초기화·탐색을 포함한 비용을 구분한다.
- 방법 이름을 바꾸는 것 외에 달라지는 가설, 남아 있는 예측 정보, 실제 최종 학습기의 이득을 확인할 근거를 명시한다.

재사용 가능한 것은 원문 위치·판본·인쇄표 전사·조건부 검산·기존 판단의 연결이다. 실행 가능한 전체 재현 패키지를 확보했다는 뜻은 아니다. 논문의 표기·수치 공백이 있다고 해서 잔차 보정의 선행 원리가 사라지는 것도 아니다.
