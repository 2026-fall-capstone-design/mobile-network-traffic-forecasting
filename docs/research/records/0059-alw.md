# 59·62 — ALW의 입력 압축, 공동 학습과 실제 비용

ALW는 과거 입력에서 주파수별 중요 구간을 학습하고, 이를 고정된 짧은 표현으로 바꿔 예측기와 함께 학습한다. **입력512→표현256을 곧바로 전체 연산·실행 시간의 절반으로 해석하면 안 된다.** 논문의 비용 표에서는 네 예측기 모두 한 iteration의 시간이 늘었다. 62번이 이 방법을 RCTL과 독립적인 clustering으로 그대로 채택하지 않은 판단의 근거를 확인했다.

[59 계획](../evidence/0059-0062-history-grouping/originals/SRC-0021920.md.txt)과 [62 판단 §1·4·5](../evidence/0059-0062-history-grouping/originals/SRC-0021984.md.txt)를 연결한다. 실제 모바일 cell의 grouping 확인은 [60 기록](0059-0062-history-grouping.md), 정확한 확률 예와 RCTL 구조 비용은 [61 기록](0061-history-logic-cost.md)에 있다. ALW의 결과를 그 두 연구의 추가 실행이나 성능으로 합산하지 않는다.

## 질문과 확인한 자료

당시 질문은 grouping이 필요한 과거 길이를 줄이고 최종 RCTL의 성능·비용에 이득을 주는지였다. ALW는 그 질문과 관련된 입력 선택·압축의 선행 방법이다. cell 소속을 추정하거나 독립적으로 clustering을 만든 논문은 아니다.

논문은 Suxin Tong·Jingling Yuan의 *Efficiently Enhancing Long-term Series Forecasting via Adaptive Lookback with Wavelets*, AAAI40(31),25966–25974, DOI `10.1609/aaai.v40i31.39797`이다. [공식 서지](https://ojs.aaai.org/index.php/AAAI/article/view/39797)의 Published는 2026-03-14다. 저장 HTML의 다른 DC 날짜 필드와 구별한다.

보존한 [공식 PDF](https://ojs.aaai.org/index.php/AAAI/article/download/39797/43758)는 `SRC-0062775`, 2,932,005bytes, SHA-256 `209c86f604086a59dfc96e2c8fe6837facf87ea47d0bcc0c41fe153a7c5ce977`이다. 9쪽 전체, 참고문헌, 그림1–4·식1–5·표1–4를 읽었다. 각 참고문헌의 원문까지 모두 검토한 것은 아니다.

## 방법: 선택한 길이와 실제 연산을 구별한다

입력은 길이 L, 채널 수 N의 다변량 시계열이다. 입력을 정규화하고 DWT로 저주파 성분과 여러 고주파 성분을 만든다. 각 scale에서 시간축의 전체 길이 Lⱼ를 쓰는 선형 Q/K와 tanh를 적용한다. 채널 내적을 `sqrt(N)`으로 나누고 시간축을 평균해 **모든 채널에 공통인 중요도**를 만든다. 특정 cell마다 다른 소속을 고르는 단계가 아니다. (p3–4, 식1–2)

중요도를 최근 시점에서 과거로 누적하고, softmax와 시간 인덱스의 가중합으로 연속적인 경계를 구한다. sigmoid 마스크는 먼 과거의 성분을 작게 만든다. 그 뒤 각 scale 전체를 미리 정한 Hⱼ로 선형 투영하고, PE·채널별 가중치를 적용한 뒤 IDWT로 재구성한다. 최종 표현의 길이 H는 설정값이다. 학습된 경계에 맞춰 실제 tensor를 잘라 계산을 생략한 구현으로 보지 않는다. (식3–5)

고정 코드에서도 Q/K의 Lⱼ→Lⱼ 선형층, Lⱼ×Lⱼ score, 전체 mask와 투영을 계산한다. 마스크가0에 가까워도 앞 단계의 계산이 사라지지 않는다. 주석의 `sqrt(L)`과 달리 실제 score는 `sqrt(C)`로 나누며, C가 논문의 채널 수 N에 해당한다. 그림2–3은 구조와 작동 예시이며, 모든 자료에서 전역 최적 입력 길이를 찾는다는 증명은 아니다.

ALW는 backbone의 submodule로 등록된다. 두 학습 경로는 전체 `self.model.parameters()`를 Adam으로 최적화하고 MSE의 backward/step을 수행한다. validation 손실을 early stopping에 전달하며 test 손실도 매 epoch 출력한다. 출력만으로 test를 기준으로 설정을 선택했다고 확정하지 않는다. 입력 선택기와 최종 예측기의 공동 학습이라는 사실이 당시의 RCTL 독립 clustering 조건과 다르다.

## 자료·분할·입력·지표

논문 표1은 ETTh1·ETTh2·ETTm1·ETTm2·Weather·Exchange·ECL·Traffic의8개 자료, 예측 길이96/192/336/720, TQNet·CycleNet-MLP·iTransformer·DLinear의4개 backbone을 비교한다. 기준선의 입력 길이는 `{96,192,336,512}`에서 탐색하며, ALW는 L512→H256으로 고정한다. db6와 분해 단계 J3을 사용한다. Autoformer 코드도 저장되어 있지만 이 네 모델의 표에 Autoformer 결과를 추가하지 않는다.

Traffic의 의미는 주의가 필요하다. ALW가 인용한 [iTransformer의 공식 논문 p13 Appendix A.1](https://proceedings.iclr.cc/paper_files/paper/2024/file/2ea18fdc667e0ef2ad82b2b4d65147ad-Paper-Conference.pdf)은862개 도로 센서의 시간별 점유율로 정의한다. ALW의 Traffic 설정도 `enc_in=862`, `cycle=168`, `custom` loader를 사용한다. **이동통신 cell 트래픽에 대한 실증 결과로 옮기지 않는다.** 실제 다운로드한 CSV와 그 hash는 이번에 확인하지 않았다.

검토한 loader의 설정은 다음과 같다. 논문 당시 실행 로그에서 확정한 시간 분할과는 구별한다.

| 항목 | 고정 코드에서 확인한 기본 처리 | 남은 한계 |
|---|---|---|
| ETT | 처음12×30일을 train, 다음4×30일씩 validation·test. minute 자료는 시점 수에4를 곱함 | 실제 CSV 날짜·누락·정렬 상태 미확인 |
| 나머지 custom | 행 수 n에서 train=`int(.7n)`, test=`int(.2n)`, 나머지 validation | CSV의 기존 행 순서를 전제로 함 |
| 평가 입력 경계 | validation·test 시작점보다 `seq_len`만큼 앞의 입력을 포함; 예측 target은 입력 끝 이후 | 겹치는 입력과 평가 target을 혼동하지 않음 |
| 전처리 | train 구간에 StandardScaler를 적합하고 나머지에 적용. ALW 내부의 window 정규화는 별도 | 실제 논문 표의 CSV/실행 recipe 일치 미확인 |
| 최종 metric | 예측 window를 합쳐 MSE·MAE를 전체 원소 평균으로 계산 | 겹치는 horizon의 같은 timestamp가 여러 번 들어갈 수 있음 |
| 척도 | 선택한 기본 실행은 scaler 단위로 평가; root의 `inverse` 기본값은 false | 모바일 cell의 원단위 MAE와 직접 비교 불가 |

TQ/Cycle loader에는 같은 이름의 세 dataset class가 앞뒤로 중복 정의되어 있으며 뒤 정의가 최종 binding이다. 해당6개 정의를 모두 읽었다. root loader는 validation을 shuffle하지만 마지막 batch를 유지한다. TQ/Cycle 경로는 train·validation에 shuffle과 `drop_last=True`를 사용한다. 두 경로의 test는 shuffle 없이 마지막 batch도 포함한다. 실제 데이터 행과 호출 로그를 확인한 재현 결과는 아니다.

## 모듈 제거와 긴 입력의 반례

표2는 CycleNet의 네 horizon 평균이다. +ALW의 MSE/MAE는 ETTh1 `.412/.428`, ETTm1 `.347/.379`, Weather `.220/.262`다. 표1의 해당 평균과 반올림 범위에서 맞는다. MSDM·ALWLM·WRM·PE·학습 가중치를 각각 제거한5개 변형의30개 인쇄 지표는 모두 이 기준보다 크다. 이 표의 실제 ablation 코드·실행 설정·원 반복 배열은 미확인이다.

표3에서는 db6가 두 자료의 인쇄 MSE 최소다. 분해 단계 J3은 ETTm1에서 단독 최소지만 Weather의 J3과 J5는 모두 `.220`으로 표시된다. 모든 자료·단계에서 J3의 엄격한 우위를 입증한 결과로 쓰지 않는다.

그림4는 CycleNet, F720, ETT 네 자료에서 L512→4320을 비교한다. ALW도 시간 단위 ETTh1/ETTh2에서는 긴 입력일수록 오차가 증가하는 모습이 남는다. soft-argmax의 분산, 고정 H256의 표현 병목, concept drift라는 설명은 저자의 해석이다. L4320에서29.6%·70.9% 낮다는 본문 비율은 원 곡선 배열 없이 새 정밀 수치로 재현하지 않았다. 긴 입력의 손해를 완전히 없앴다는 근거가 아니다.

## 비용: 고정 L512와 비교해야 하는 표4

표4는 ETTh1/F720에서 기본 L96, `+lookback` L512, ALW L512→H256을 비교한다. **표1의 입력 길이 탐색 기준선과 다른 비교**다. 아래는 고정 L512→ALW의 변화다. 논문이 보고한 parameter·MAC·training time per iteration이며, 현재 장비에서 측정한 값은 아니다.

| 모델 | parameter | MAC | iteration(ms) | 시간 배율 | MSE |
|---|---|---|---|---:|---|
| TQNet | 2.21M→1.54M | 258.74M→284.27M | 5.8→15.2 | 2.62 | .489→.446 |
| CycleNet | 632.18K→749.54K | 141.30M→166.82M | 4.3→13.5 | 3.14 | .473→.448 |
| iTransformer | 357.97K→573.63K | 125.62M→168.97M | 12.1→22.5 | 1.86 | .553→.486 |
| DLinear | 738.72K→618.51K | 165.27M→137.52M | 4.2→15.8 | 3.76 | .472→.465 |

고정 L512보다 MAC이 줄어든 모델은 이 표에서 DLinear 하나다. TQNet은 parameter가 줄어도 MAC과 iteration 시간이 늘어난다. 네 모델 모두 MSE는 낮아지고 시간은 길어진다. 평균 추가 시간은 L512 대비10.15ms, 기본 L96 대비10.875ms다. 논문의 “약10ms 추가”를 속도 향상이나 총 학습 비용 감소로 해석하지 않는다.

원 profiler·반복별 timing·표4의 정확한 batch와 측정 경계·분산, 전체 hyperparameter 탐색 비용은 확보하지 않았다. 입력 길이 탐색을 줄인다는 주장과 전처리·공동 학습까지 포함한 총비용 절감의 실측을 구별한다. RCTL의 구조 MAC에 이 표의 시간 배율을 옮길 수도 없다.

## 코드와 논문 설명의 차이: 재사용 전에 확인할 조건

다음은 **고정 커밋의 정적 경로에서 확인한 차이**다. 실제 논문 실행이 실패했다거나 인쇄된 성능이 틀렸다는 결론은 아니다.

| 항목 | 확인한 사실 | 재사용 시 확인할 점 |
|---|---|---|
| α·β의 양수 조건 | 논문은 양수를 가정. 두 ALW 구현은10으로 초기화한 자유 Parameter이며, 읽은 학습 코드에도 명시적 clamp가 없음 | 실제 학습 중 부호·값은 checkpoint 없이 미확인 |
| PE의 축 | `PE(d_model=Hⱼ)`에 C를 전달해 `[1,C,Hⱼ]`를 더함. PE의 position 인덱스는 channel 축 | 논문의 시간 순서 설명과 동일하다고 가정하지 않음 |
| `use_pe=False` | PE뿐 아니라 channel importance weight의 softmax 곱도 생략 | 이를 표2의 PE 단독 제거 실행과 동일시하지 않음 |
| TQNet 복원식 | `TQNet_ALW`, 기본 `use_norm=1`에서 ALW가 표준편차를 반환. wrapper의 기본 `use_revin=1`은 다시 그 제곱근으로 복원 | 나눌 때의 표준편차와 복원 배율이 다름. 실제 표의 실행 조건·영향 미확인 |
| normalization 비활성화 | iTransformer·Autoformer wrapper는 반환 mean/std를 사용한 복원을 전제 | `use_norm=0`의 지원·정상 실행을 보장하지 않음 |
| wavelet boundary | ALW의 forward 기본은 symmetric, inverse에는 mode를 넘기지 않음. 고정 의존 버전1.3.0의 inverse 기본은 zero | 인자 차이만으로 수치 복원 오류를 단정하지 않음 |
| 환경 | 논문은 PyTorch2.6.0·Tesla T4 16GB 두 개·Linux. requirements는 torch2.1.2, README는 Python3.8.8 안내 | 설치·호환성·실제 출판 환경 재현 미확인 |
| seed·반복 | root run 기본2021, TQ/Cycle 기본2024. 확인한 ETTh1 shell은 seed override 없이 `itr=1` | 논문은 고정 seed라고만 명시. 실제 표의 seed로 확정하지 않음 |

TQ/Cycle ALW layer에는 `model_name=='TQNet'`일 때만 검사하는 미정의 `self.use_revin` 참조도 있다. 실제 확인한 shell의 이름은 `TQNet_ALW`여서 그 앞 조건이 false다. 이를 기본 실행의 확정적인 AttributeError라고 보고하지 않는다. CycleNet의 주기 처리는 축소 길이 `red_len`을 쓰며, 압축된 표현의 위치와 원래 시각의 동일성도 별도 검토 대상이다.

논문의 학습 epoch 탐색 범위는10–100이다. 같은 커밋의 ETTh1 실행 shell에 적힌 F96/192/336/720별 epoch는 DLinear `10/10/1/1`, iTransformer `4/1/1/3`, CycleNet `5/5/5/5`, TQNet `5/3/5/3`이다. 공개 shell이 인쇄 표의 정확한 recipe라는 증거가 없으므로, 이를 그대로 실행하면 표가 재현된다고 안내하지 않는다. README의 장비별 설정 조정 안내도 이 공백을 해소하는 실행 증거는 아니다.

## 당시 판단과 후속 연구의 차이

62번은 이미 공동 학습, 고정 길이 투영, mask 뒤에도 남는 계산, CycleNet과 DLinear의 시간 증가를 구별했다. 이번 검토는 논문 전체·수치·저장 코드와 그 판단을 연결하고, 재사용에 필요한 구현·설정 차이를 추가했다. 이 문헌 하나로 attention·wavelet·window 선택·입력 압축 자체를 새 기여로 주장할 수는 없다. 반대로 모든 grouping이나 RCTL 입력 단축이 불가능하다는 근거도 아니다.

후속 설계에는 기존보다 달라지는 결정, RCTL과 독립인 소속 결정의 의미, 입력을 줄여도 보존되는 정보, 동일 조건의 단순 비교군, cell·기간별 손해, 전처리와 모델 저장·학습·추론을 포함한 비용을 명시해야 한다. ALW의 공동 학습을 도입하려면 당시 연구 조건과 달라지는 부분을 먼저 기록해야 한다. 이는 새 연구의 차이를 설명하기 위한 기준이며 실행 지시가 아니다.

재사용 가능한 것은 고정 논문·코드의 위치와 해시, 실제 읽은 범위, 당시 판단, 인쇄 수치와 산술 검수다. 논문 PDF·외부 구현을 대량 복제하지 않고 원래 위치로 연결했다. 저장 source tree만으로 전체 의존 구현·데이터·실행 로그가 확보됐다고 보지 않는다.

59의 *Optimal Look-back Horizon* v1/v3 검토와 62의 문헌 간 종합은 다음 범위로 남는다. [기존 GPI/CF 검토](0033-0035-process-fit-gap.md)는 재사용하며 새 문헌·실험으로 중복 가산하지 않는다. 새 모델 실행·원 연구 코드 실행·난수 생성은0회이며, 원본 및 기존 연구 원장의 상태를 보존했다.
