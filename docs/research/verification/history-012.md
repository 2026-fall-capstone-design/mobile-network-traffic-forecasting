# 18·21 공간 진단 검수

[기록](../records/0018-0021-spatial-information.md)·[주장별 근거](history-012-primary-review.json)·[저장 결과 검산](history-012-risk-check.json)·[로컬 H5 대조](history-012-local-data-check.json)·[오류 자료 검사](history-012-negative-check.json)·[문서 검사](history-012-document-check.json)를 연결한다.

정리 에이전트가 원문18, 공간 코드, 시작/완료/summary, NPZ와 기록21의 공간 판단을 확인하고 초안을 원문에 다시 대조했다. 같은 에이전트의 검수이며 독립 과학 검토는 아니다. 11개 주장에 출처·범위·한계를 연결했다.

- 저장 결과 검사 444개: 원본 식별, 필수 출처, 5개 배열의 shape·유한값, 시간·ID, 이웃 격자·padding, PCC 최대·동점, 60개 저장 성능 필드, 비용 보고, 이전 시간 진단과의 연결.
- 로컬 H5 검사 367개: 원본 SHA·shape, 자기·이웃 285개 cell의 지정 구간, 정규화·정답, 이웃·PCC, 읽은 입력 구성. PCC 최대 오차는 8.881784197001252e-16이며 선택 이웃 32개가 모두 일치했다.
- 오류 자료 14개: 누락·중복 출처, 잘못된 평균·cell 수치, query 시각·shape·target, 동점 선택·padding·이웃 격자, fit 수·비유한 예측을 모두 검출했다. 임시 사본의 해시를 갱신해 값의 의미를 검사하는 단계까지 도달했으며 원본은 바꾸지 않았다.

전체·주·집합별 수치와 cell·날짜별 이득·손해를 분리했다. 날짜 집계와 대조 차이는 이번 아카이브의 추가 산술이다. 이득인 cell만 고르거나 cell7524를 제외하지 않았다. 첫 주 자기 예측이 이전 expanding과 같아도 두 번째 주부터 학습 조건은 다르다.

확장 입력 X는 공간 NPZ에 없다. H5와 정적 코드로 구성한 입력을 당시 모델이 실제로 소비한 배열의 독립 보존물로 표시하지 않는다. 환경 버전 lock, 상류 CDR 처리, 원 위경도 방향은 이번 범위에서 미확인이다. 원 모델 실행·새 simulation·원 코드 import는 모두 0이며 성능 재현으로 세지 않는다.

기록21 전체 통합, 19/20의 cell ID·target 표현 진단, 22 추가 문헌·최신 구현, 393 공간 후속 및 나머지 전체 기록은 남아 있다. 이 묶음의 PR 병합을 전체 Goal 완료로 판정하지 않는다.
