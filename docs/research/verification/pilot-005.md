# 642 최종판 문서와 연구 완료 범위 검수

642의 최종 보고서·7쪽 Word·완료 자료를 읽고, 인용한 저장 결과와 원장을 대조했다. **방향 제안과 문서 작성 완료, 본실험 미실행**을 구분했다. 이 검수는 새 연구 실험이나 독립 연구자의 재현이 아니다. 같은 아카이브 작성자가 원문과 다시 대조한 결과다. [정리 기록](../records/0642-research-direction.md)

42개 보존 경로 중 이번 묶음에서 본문 전체 16개, Word의 전체 보이는 내용 1개, 이미지 전체 7개, 코드 지정 구간 1개, JSON 지정 필드 2개, 해시만 15개를 확인했다. 이 중 10경로는 기존 묶음에서 보존한 파일을 재사용한다. [출처 표](../sources/pilot-005.md), [manifest](../evidence/0642/manifest.json)

공식 GECOS 코드 한 개는 목록의 원본 ID·해시와 공식 commit 바이트를 확인하고 링크로 연결했다. 목록 밖 UPC PDF와 TabICLv2 웹 판본 두 개는 별도 등록했다. 기존 전체 조사 수에 새로 끼워 넣지 않았다. 자동 `check_archive.py`가 검사하는 외부 메타데이터는 기존 목록과 연결된 항목이며, 이 두 외부 자료의 의미·접근·판본 확인은 이 문서에 적힌 실제 열람 범위다.

## 자동 대조와 사람이 읽는 검토

[문서 검수 도구](../../../scripts/research_archive/verify_recommendation_pilot.py)는 과거 연구 코드를 import하거나 실행하지 않는다. 원본 Windows에서 72개 검사, 보존본 Linux에서 출처·읽기 범위 대조를 더한 147개 검사가 통과했다. 두 모드의 표·비율·cell 집계·비용 결과가 일치했다. [기계 판독 결과](pilot-005-document-check.json)

자동 검사에는 16개 역사적 의존 파일의 해시, 두 문서·PDF·7PNG의 식별, 완료/미실행 필드, 연구 실행 0, 원장 해시, 누적 사용량 복사, cheap 비용 합, 두 문서의 표와 5개 변화율, cell 손해 집계가 포함된다. JSON은 파싱과 실제로 조회한 최상위 값을 구분한다. 최상위 값 안의 하위 트리는 한 단위이며 중첩 키 전체를 추적했다고 주장하지 않는다. 보고서를 구성한 뒤 실제 접근 범위를 manifest의 선언과 대조한다.

Word의 세 번째 표만 코드로 수치를 검사했다. 별도로 최종 7쪽 PNG를 원해상도로 읽고 본문·표·수식을 확인했다. 잘림·겹침·빈 페이지·한글 누락은 관찰되지 않았다. 기존 렌더를 확인한 것이므로 원본 Word를 새 환경에서 다시 렌더링한 성공으로 표현하지 않는다. PDF는 이 묶음에서 해시만 확인했다. [판독·구조·문자열 대조 기록](pilot-005-document-review.json)

## 남아 있는 한계와 후속 검토

- 이 묶음에서는633의 보조 문서를 해시만 확인했다. 이후 [633 부정 결과 검수](pilot-007.md)에서 저장 예측·고정 소속·후속 RCTL 효용을 대조했다. 166의 전체 연구 흐름은 계속 별도 통합·근거 검수 대기다.
- 642의 초기 10쪽 렌더, 보관 전 상태 사본, 이후 개정은 미완료다. 최종판의 확인을 다른 판본의 확인으로 대신하지 않는다.
- 문헌 목록 전체의 최신성·부재·신규성을 검증하지 않았다. UPC와 TabICLv2 지정 구간 및 기존 640의 지정 구간을 넘어서는 주장은 역사적 보고서의 인용으로 남긴다.
- 642의 원문에는 정규화 MAE 표가 중심이다. 정리본은 639에서 확인한 원척도 손해를 추가로 연결하며 원본 바이트는 유지했다.
- 한 개발 조건의 착수 근거다. 원 θ=10·미사용 기간/도시·동일 wall-time·TabPFN·graph 크기 통제·전체 도시 비용·일반화 검증은 실행하지 않았다.

원본 제어 파일 6개는 기준 SHA-256과 같았다. 전체 자료의 최종 변경분 조사와 대표 질문 10개 이상의 전수 아카이브 검색 검수는 이후 완료 단계에 남아 있다.
