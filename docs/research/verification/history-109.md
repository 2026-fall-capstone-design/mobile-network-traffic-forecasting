현재 두 원문457행 전체와 직전 후보표44행·진행기록1–22행을 실제 읽었다. 직전 판본의 동일 본문은 기계 비교 결과와 독해 범위를 구별한다. 기존 수치·원문 검수의 재사용 경로를 연결하며 새 모델 실행·성능 재계산·독립 심사로 표시하지 않는다.

작성 후 후보표45행 전체, 진행기록의 인용 구간164행, 직전 후보표44행·연혁22행을 실제 재독했다. 출력 잘림은 남아 있지 않다. 활동량 비교의 정정 범위를 정확히 고치고 보관 후 보고의 연결을 현재 판본으로 보완했다. 기존 성능 값·논문 결과를 새로 재계산하거나 원 연구 코드를 실행하지 않았다.
