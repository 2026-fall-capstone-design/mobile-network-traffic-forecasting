# H051 검수와 남은 범위

[팀 기록](../records/0059-0062-history-grouping.md) · [28개 주장](history-051-claims.json) · [저장 수치 검수](history-051-numeric-check.json)

예측 6,144개를 읽어 24조건의 MAE 288개, 상호작용 42개, screening 차이36개와 판정12개를 대조했다. 검수기303개 확인이 통과했고 partial/final 공통 배열도 같았다. 같은 검수기는 CI에서 실행하며 모델·원 스크립트는 실행하지 않는다.

원 HDF5와 checkpoint의 전체 SHA를 별도 확인했다. HDF5 지정4열×1488시간·날짜와 scale/actual/query날짜를 대조하고 숫자/문자열 파생물을 보존했다. 실제 fitted X·모델 객체·원 콘솔·전체 환경은 확보하지 않았다. final NPZ의 object 날짜는 NPY header와 직렬화 문자열을 정적으로 읽었고 unpickle은 하지 않았다.

원장 전체 차이는 60번 실행의 한 번 회계 반영과 일치했다. simple 타이머는 fit+predict를 포함하고, stage는 초기 hash·설정 작성과 최종 저장/검사를 포함하지 않는다. call 사이 RSS와 경계 상한을 연속 peak/강제 중단이라고 표시하지 않는다.

검수기가 파일 존재만 확인하는 것을 피하기 위해, 해시까지 새로 맞춘 임시 사본의 MAE·cell값·상호작용·판정·원장·호출·seed·예측·날짜·scale을 각각 바꿨다. 정상 사본1개는 통과했고 오염 사본10개는 의미/수치 검사에서 모두 실패했다. 같은 에이전트의 원문 대조와 자동 검사이며 독립 연구자의 모델 재현은 아니다.

61 논리/MAC 산술은 [후속 H052](history-052.md)에서 별도로 검수했다. ALW 일차문헌은 [후속 H053](history-053.md)에서 대조했다. horizon 저장자료와 62 전체 종합은 [후속 H054](history-054.md)에 연결했다. 원 실행 재현·외부자료 공백과 이후 연구·최종 전체 검수는 미완료다. 새 모델 호출0, 원본과 보호 원장6개 보존을 확인한다.
