# H052 검수와 남은 범위

[팀 기록](../records/0061-history-logic-cost.md) · [주장별 근거](history-052-claims.json) · [수치 검수](history-052-numeric-check.json)

61의 계획·코드·저장 결과와 62의 해당 판단을 원문에 대조했다. 두 Uniform 구간의 중앙값에서 절대 오차를 적분하고 네 관측 상태 쌍의 사후확률을 열거하여 `11/90`, `1/2`, `409/2050`을 확인했다. 초기 잠재 상태가 cell과 독립인 정상분포라는 조건과, known에도 관측이 한 개 이상 필요하다는 경계를 명시했다.

`history_gain_pooled_minus_known`는 실제로 unknown 관측 1개와 2개의 차이 `308/1025`다. 수치를 보존하면서 이름과 비교 대상의 불일치를 드러냈다. RCTL의 층별 행렬 수와 bias·BatchNorm parameter를 구별했고, 전체 parameter에 고정 recurrent bias 896개가 들어 있음을 설명했다.

수치 검수기의 43개 확인이 통과했다. 정상 사본 한 개와, 해시를 다시 맞춘 오류 사본 10개로 분수·소수·차이값·MAC·전체 parameter·비율·원장·완료 표지·모델 호출·잡음 가정의 불일치 검출을 확인했다. 검수기는 CI에 연결했다. 원 연구 코드 실행·모델 생성/forward/학습·난수 추출은 없다.

전후 전체 원장은 cheap 항목 한 개의 추가와 일치한다. 약 96.6µs는 주요 산술 타이머이며 초기 hash·시작 쓰기와 최종 보고·파일 쓰기를 포함하지 않는다. 당시 콘솔·외부 모든 시도 이력과 프로그램 전체 시간은 미확인이다.

같은 에이전트의 원문 대조와 별도 표현의 산술 검산이다. 독립 연구자의 모델 재현은 아니다. 59의 ALW·horizon 일차자료, 62 전체 종합과 이후 연구, 전역 실패/비용·원자료 접근·최종 전체 범위 검수는 미완료다. 탐색 중 읽은 106 직전 원장은 후속 단계가 들어 있어 별도 대기 기록에 남겼고 이 묶음의 새 독해 수에 가산하지 않았다.
