# H073 검수 — 저장 검색의 역할과 읽은 범위

[기록](../records/0072-0075-saved-search-audit.md) · [출처](../sources/history-073.md) · [주장별 대조](history-073-claims.json) · [문서 검사](history-073-document-check.json)

첫 독해 후 작성한32개 주장과 관련 원문을 같은 에이전트가 다시 대조했다. 159개 항목은 전체 첫 독해와 작성 후 분류 목록·주장 관련 구간 재확인으로 검수했다. 모든 원문을 두 번 전구간 읽거나 독립 심사를 받았다는 뜻은 아니다. 실제 후속 위치와 한계는 주장별 대조에 남겼다.

검수 대상은 저장 응답11개와 기존 findings2개다. 159개 응답의 경계·URL·위치를 보존하고, 검색 노출과 본문 확보·그림 확인·코드 실행을 구분한다. 같은 문헌의 반복 URL을 독립 실험으로 세지 않으며 원본 해시가 같은 사본과도 별도로 다룬다.

본문의32개 주장은 출처 구간·검수 방법·한계를 각각 연결한다. 중요한 확인 항목은 다음과 같다.

- arXiv 문제 신고·코드 검색 메뉴를 저자 코드로 오인하지 않는가.
- aggregator의 여러 논문 문장과 표·서지 재인용을 분리했는가.
- spectral forecastability, 조건부 평균 보존, filtration 가측성, 예측 손실을 구별했는가.
- sample/context, 입력 열·표현, cell 소속, 출력 방향·복원, 예측 보정·설명 지표의 역할을 보존했는가.
- `planned`·참고문헌 언급·설정 예시를 구현·실행·재현으로 승격하지 않았는가.
- 접근 실패를 과학적 기각이나 원문 부재의 증거로 쓰지 않았는가.

[원본 보존 검수](../evidence/0072-0075-saved-search/provenance-check.json)는 원본26경로·기존 정확사본2개·보호 상태/예산 파일6개의 바이트를 대조한다. [응답 목록](../evidence/0072-0075-saved-search/response-ledger.json)의 해시는 원문 식별을 위한 것이며 외부 자료의 과학적 타당성을 증명하지 않는다. 원검색 전체를 재배포하지 않았으므로 CI는 저장된 메타데이터와 내부 링크를 검사하고, 원본 대조는 로컬에서 수행한다.

새 학습·추론·역사 코드 실행·패키지 설치는 없다. 문서에서 인용한 설정과 계산 예산은 외부 저자의 설명 또는 과거 기록이며 현재 실행 허가가 아니다. 외부 링크 현재 접근, 미확보 논문 전체·실제 로그·대용량 자료 접근과 전체 Goal 완료는 이 검수의 통과 범위에 포함되지 않는다.
