# H054 검수 — Optimal Look-back 두 버전과 62 종합

[팀 기록](../records/0059-optimal-lookback.md) · [출처별 범위](../sources/history-054.md) · [주장 검수](history-054-claims.json) · [문서 검수](history-054-document-check.json)

저장 v1/v3의 본문·부록·참고문헌13쪽씩과 전체 버전 차이, HTML 본문·MathML, 원 TXT26쪽, 원 미리보기3개를 확인했다. 두 PDF의2·8쪽은 텍스트·렌더 픽셀 동일성을 확인해 시각 독해를 재사용했다. 개정판의 고유11쪽은 각각 직접 읽었다. HTML의 식 분리와 번호 변경, 그림 제목·크기·축 변화도 구분했다. 외부 SVG 원본은 미보유 상태다.

정식 AAAI 서지와 추가 PDF의6·7쪽만 별도로 확인했다. 나머지6쪽은 미독해다. arXiv v2는 원본 폴더에 없고 본문을 읽지 않았다. UCLA 자료는 볼록집합 투영 부등식과 선형 부분공간의 직교 조건에 사용했다. 추가 외부자료3개를 로컬 원본 독해 수로 가산하지 않는다.

부록 A의 결과5개를 v1/v3 × pypdf/pdfplumber/HTML MathML에서 대조한 [30개 전사 비교](history-054-numeric-check.json)를 저장했다. 생성자료·RF의 원출력 재계산이나 독립 모델 재현이 아니다. 자료 설정은 본문·시각 대조이며 설정별 자동 숫자 검사를 했다고 집계하지 않는다.

[논증 검수](../evidence/0059-optimal-lookback/logic-audit.json)는 정리4 증분, 최초 허용치, 증가 상계, 조건부 분산, 볼록 투영, Taylor 잔차, resolution 균형, AR 미래 블록 집계의8사례·18조건이다. 정적 유리수 계산이 논문 모든 SDG 가정을 구현한 실험적 반례라는 뜻은 아니다. Eq83의 숨은 상수를 허용한 느슨한 상계 전체를 단일 예로 반박하지 않는다. 유효한 Bayes 분해와 기대 위험 비증가는 보존한다.

같은 에이전트의 두 번째 원문 대조에서 당시62의 판단과 이번 추가 부록 검수·정식 출판본 확인을 구분한다. ALW·60·61의 기존 검수와62 전체의 문장·비용 시점을 연결한다. 수치가 기존 문서에 다시 등장해도 새 독립 재현이나 원문 본문 수로 더하지 않는다.

현재 묶음의16고유 바이트 그룹·32원본 경로, 재사용 보존본6개, 외부 원본 메타데이터10개 및 보호 상태/예산 원장6개를 확인한다. [문헌 폴더 연결](history-054-packet-scope.json)은 저장 자료의 검토 위치를 전수 대조하며, 미보유 외부 자료나 원격 tree의 다른 코드까지 완료 처리하지 않는다.

원 연구 코드 import/실행·모델 생성/학습/추론·난수 생성은0이다. 남은 전체 범위와 실제 검수 완료 여부는 문서 검수 JSON 및 출처 명세에 보존한다. 이전 H051–H053 검수의 당시 해시를 현재 수정한 문서의 해시인 것처럼 다시 쓰지 않는다.
