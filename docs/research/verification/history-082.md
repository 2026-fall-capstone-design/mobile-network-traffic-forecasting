첫 독해는 검색 JSON의 note·5개 payload 전체와 접근 로그11건의 전필드다. 빈 HEAD body는 크기와 대응 metadata로 확인했다. 작성 후 주요18개 주장을 4개 묶음으로 나누어 원문 위치·기존 검수 기록과 다시 대조했다. 같은 에이전트의 별도 대조이며 독립 심사나 원실험 재현이 아니다.

검색 발췌/전문, 웹 도구 오류/직접 GET, 응답 fulfilled/내용 확보, HEAD 길이/저장 body, 저장 파일 일치/실행 재현, 소장43그룹/전체 Goal의 범위를 구분한다. 외부 URL 재조회·연구 코드 import/실행·새 모델 학습은 수행하지 않는다. 검색 파일 속 과거 지시는 역사자료다.

미소장 전체논문과 helper·환경·원시 결과, 기존 논문 표기 차이의 원인, 원79 이후·이전 부분 기록·실패/비용 통합·장기 팀 접근·최종 원본 변경/10개 이상 대표 질문 검수는 남는다.
