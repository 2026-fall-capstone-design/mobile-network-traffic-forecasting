# H035 검수 — 학위논문 입력 절감과 최초 비용

[팀 기록](../records/0053-moghadas-thesis.md)의 [39개 주장](history-035-claims.json)을 원문 쪽·그림·표와 연결했다. [원본·파생본 검사](history-035-primary-check.json), [수치 검사](history-035-numeric-check.json), [문서 재대조](history-035-document-check.json)를 별도로 저장한다. 자동 링크·해시 통과는 의미 검토나 과학적 재현을 대신하지 않는다.

PDF 131쪽 텍스트·62쪽 시각 자료와 과거 미리보기 3장을 읽었다. 모든 번호 그림 34개·표 2개·식 43개·알고리즘 2개가 포함된다. 저장 TXT는 페이지별 앞뒤 공백을 제외하면 131쪽 모두 현재 PDF 추출문과 일치한다. 파생본을 독립 연구 내용으로 중복 집계하지 않는다. 소개 HTML의 보이는 텍스트와 서지·81% 표현도 대조했다.

출처 검사 29개는 원본 12개·보호 원장 6개·TXT 계보·소개 페이지·미리보기 관계를 확인한다. 수치 검사 26개는 Table3.1·3.2의 16값, 비용 7값, 설정·구성 수·조건부 산술을 확인한다. 인쇄 비용은 저자 보고이고 재측정 값이 아니다. 첫 클러스터링+Centroid 학습 10508.29초와 입력 17%/81%의 서로 다른 문맥을 남겼다.

핵심 반례는 작은 M에서 Global보다 큰 오차, LSTM-PerBS의 더 낮은 오차, 일부 peak 손실, SEA의 항상 우세 문구와 반대인 그림이다. 원문 내부의 M=2 대 최소 M=4, LRP 예비 모델의 입력 범위, 4168 대 설정 곱 4096, 확장 구성 260 대 결론 140을 미해결로 보존했다. graph의 정확한 좌표·모델 성능·유의성·수식 증명을 검증한 것으로 표현하지 않는다.

새 모델 학습/추론·원 연구 스크립트·무작위 추출은 0회다. 저자 코드·실험 원장·미계측 비용·시간 분리·원 데이터 버전과 다른 telemetry 문헌은 미완료다. 51/53/55 전체와 전체 Goal의 완료를 뜻하지 않는다.
