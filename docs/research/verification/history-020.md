# H020 검수 · 28번 기전·불확실성 문헌 판단

[기록 28](../records/0028-mechanism-uncertainty.md)의 15개 핵심 주장을 [원문 locator·판단·한계](history-020-primary-review.json)에 연결했다. 당시 검토 기록의 66행과 manifest 두 개 전체, 외부 코드 세 개 전체를 읽고 지정 논문 구간을 대조한다. [읽기 범위](../sources/history-020.md)는 전체 논문·전체 증명 검토와 구별한다.

[산술 확인](history-020-logic-check.json)은 로그 손실 반례, 504행 context의 prefix 규모, TabMGP 생성 단계 수와 공통 AR(1) 예시의 결정적 계산이다. 학습·추론·무작위 simulation은 0회다. 논문의 200초·700 GPU-hours와 Table 2의 세 악화 행은 보고값 대조이며 독립 성능 재현이 아니다.

[원격 코드 확인](history-020-remote-code-check.json)은 세 고정 commit URL의 실제 바이트가 로컬 manifest와 같은지 확인한다. 논문 URL의 현행 바이트 동등성, 코드 실행 호환성, 정리 가정의 트래픽 충족 여부는 그 검사에 포함하지 않는다.

[문서 검사](history-020-document-check.json)는 원본 13개 identity·보존 사본 3개·기존 연구 상태 6개·출처 목록·표 전사·주장 연결·문서 해시를 기록한다. 원문 두 번째 대조는 같은 정리 에이전트가 수행했다. 자동 검사 통과나 PR 검토를 독립 연구자의 과학적 검증으로 표시하지 않는다.

남은 범위는 세 txt의 고유 내용·주석 여부, 지정 구간 밖 논문과 전체 증명·저자 구현, 이후 연구 판단의 전체 연결이다. 원문 28의 발견 단계 자료와 현재 연구의 추천안·본실험도 완료로 세지 않는다.
