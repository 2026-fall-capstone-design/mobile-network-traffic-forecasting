# H072 검수 — 예측 가능한 출력의 문헌·구현

[팀 기록](../records/0073-forecastable-output-audit.md) · [출처](../sources/history-072.md) · [36개 주장](history-072-claims.json) · [해시 확인](../evidence/0073-forecastable-output/provenance-check.json)

첫 독해 후 작성한 36개 주장을 관련 원문과 다시 대조했다. 동일 에이전트의 별도 재검토이며 독립 연구자 심사나 원실험 재현은 아니다. 초안의 synthetic K 해석을 다섯 종류에서 고정 K=5로, ForeCA의 그림·정리 참조와 mbrdr 가정의 적용 범위를 바로잡았다.

원본 14그룹·28경로와 보호 파일 6개의 동일성을 확인했다. 새 원본 복사는 0개이며 외부 논문·코드는 공식 URL과 해시로 연결한다. ForeCA 9쪽/보충 1쪽, manual 10쪽, 추가 MBRDR2024의 본문 11쪽/백지 1쪽을 읽었다. 원TXT 19쪽을 페이지별로 대조하고 원PNG 3개를 시각 확인했다. 조밀한 그림의 모든 관측 좌표를 전사한 것은 아니다.

작성 후에는 ForeCA 1–8쪽의 시각과 본문(6쪽 추출 인덱스 나열 제외), 보충 1쪽, manual 8쪽의 텍스트·선택 4쪽의 시각, 2024 논문 5쪽의 텍스트·표 2쪽의 시각을 다시 확인했다. GNN 코드 9개와 R 소스 전체, synthetic 생성·로드의 관련 구간을 재대조했다. 정확한 페이지·파일 경계는 주장별 JSON에 있다.

[정량·정적 확인](history-072-static-check.json)은 인쇄 숫자의 전사·표의 자유도/기각 설명·runner 설정과 호출을 확인한다. [문서 검수](history-072-document-check.json)는 원본·별칭·보호 파일·외부 다운로드 해시·주장 앵커·저장 문서를 연결한다. 자동 검사로 의미 검수를 대신하지 않는다.

설치·외부 코드 import·훈련/추론·난수·원자료 역직렬화는 0이다. GNN/2008 원논문 전체, 2018·2019 원정리, 원관측·실제 반복 로그·seed·비용과 저장 검색 11개는 남아 있다. 전체 연구기록의 완료나 최종 모델 채택을 뜻하지 않는다.
