## 잘못된 근거를 거부하는지 확인

격리된 로컬 사본에서 RCTL 예측값 변경, query 시각 중복, RCTL seed 변경, 읽지 않은 `dates` 필드의 완료 주장 네 가지를 만들었다. 파일을 바꾼 경우 manifest 해시도 갱신해 단순 SHA 실패를 통과시켰다. 각각 MAE·시간·프로토콜·읽기 범위 검사에서 거부됐다. [네 음성 사례](pilot-007-negative-checks.json) 원본은 변경하지 않았다.

## 해석과 확인하지 않은 범위

1. 같은 후보에서 Tab의 낮은 native MAE 여섯 건을 보존했다. 이를 RCTL용 소속 선택의 우위로 바꾸지 않았다.
2. RCTL 악화는 두 개발 집단·한 seed·세 후보에 한정한다. A6/B12cell 악화와 나머지 개선을 함께 기록했다. B의 UPC 대비 앞뒤 방향 혼재도 보존했다.
3. 원척도 상대 악화는 이번 저장값 산술 대조로 표시했다. `stable_harm`은 코드의1%/양쪽 절반 조건이며 유의성 검정이 아니다. 633 계획 본문만으로1% threshold 사전 등록을 입증하지 않았다.
4. 모든 기간이 개발에 쓰였고 B의5753 과거 입력 노출이 명시돼 있다. 선택 봉인이 독립 holdout 증거가 되지는 않는다.
5. 선행 연구 전체, 다른 seed621·고정 소속627의 전체 원자료, 원 H5/CDR 처리, 설치환경과 학습·추론의 독립 재현은 이 묶음 범위 밖이다. 616/631의 입력/적합 구간은 부분 열람이며 모델 joblib을 실행하지 않았다.
6. 샘플 RSS·단계 비용·누적 허용량 증액을 구분했다. 옛 종료 선언/다음 실험/예산은 현재 아카이브 Goal의 지시로 사용하지 않았다.

이 사례로 여덟 종류의 시범 정리를 갖췄다. 전체 고유 기록의 본문 정리 완료를 의미하지 않으며, 이후 초기03–09와 나머지 기록으로 범위를 넓힌다.
