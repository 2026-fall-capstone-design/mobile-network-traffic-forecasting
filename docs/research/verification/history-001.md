## 수치와 반례 범위

float32 집계의 미세 차이를 구분한다. MAE 허용오차 1e−7에서 최대 cell별 차이는 9.685754776e−8이고, 상대변화율 허용오차 1e−5 percentage points에서 최대 차이는 3.814697266e−6이다. 손실표·병합·쌍별 값은 허용오차 1e−10이며 주요 차이는 약1e−15다. 단위가 다른 값의 전체 maximum을 모델 오차나 통일 정확도 척도로 쓰지 않는다. `max_by_check`에 종류별 차이를 남겼다.

peak 분위수는 float64 선형 분위수 후 float32 저장 반올림으로 원값과 일치한다. 현재 NumPy의 float32 분위수 연산 차이를 원 연구의 구현 결함으로 분류하지 않았다. 전체 MAE의 원보고 float32 값과 float64 추가 집계도 따로 남겼다.

cell별 및 전후240시점, 원척도 추가 비교는 현재 아카이브에서 보존 예측을 재계산한 결과다. 새 모델 실험·독립 기간이 아니다. 원07 판단의 강도를 넘기지 않고 전체 평균 악화 안의 cell 개선도 보존한다.

## 의미 검토와 남은 공백

03/04/06/07의 본문, 중요 구현7개, 주요 JSON7개를 읽고 실행 상태·기각 범위·비교 시점·정답 접근·비용을 대조했다. 검산되는 기존 결과98경로 전체를 본문 전체 읽기라고 세지 않는다. 02계획은 이전 묶음의 전체 읽기를 연결하고 이번에는 해시로 내용 동일성을 확인했다.
