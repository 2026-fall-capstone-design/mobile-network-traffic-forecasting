# H036 검수 — SRSSS 관측·복원·비용의 조건

[팀 기록](../records/0053-srsss.md)의 핵심 문장을 [주장 명세](history-036-claims.json)에 연결한다. [출처 검사](history-036-primary-check.json), [수치·대수 검사](history-036-numeric-check.json), [문서 재대조](history-036-document-check.json)는 범위가 다르다. 자동 링크·해시 검사를 내용의 정확성이나 독립 재현으로 대체하지 않는다.

PDF 9쪽 텍스트·7쪽 시각 자료, 그림4개·표2개·식16개·알고리즘1개와 과거 미리보기2장을 읽었다. TXT9쪽은 쪽 경계 공백을 제외한 추출문이 모두 같았다. 출처 검사41개는 원본9개·보호원장6개·기존 사본·읽기/파생본·취득 근거를 확인한다. 수치 검사22개는 표36값과 상대 비교, 수량 산술, 제한된 대수 예를 확인한다.

실제 온도 자료의 PMRL 대비 감소23.6/27.8/21.5%는 인쇄값 반올림과 맞는다. 가장 좋은 다른 기준인 JELSR 대비는12.50/1.89/7.46%로 다르다. 원문이 말하는 메모리 O(n²)는 센서 수에 대해 일정하지 않으며, P=10과 합성 전력 c를 실제10개 센서·실측 에너지로 바꾸지 않았다. 주기적 전체 관측과 초기100개 관측도 비용 조건으로 남겼다.

인쇄 식9의 부호, L대L−1 시간표, 부록의 선택 열 설명과 λ=0 경계를 숨기지 않았다. 두 센서의 정적 예에서 원/변환 목적함수의 최소값은 같아도 argmin 집합이 다를 수 있음을 확인했다. 이는 λ>0 결과의 반박·전체 증명 인증·실제 구현의 실패 확정이 아니다. 코드·실행 결과 없이 수식 표기 문제를 과학적 성능 기각으로 옮기지 않는다.

새 모델 학습/추론·원 연구 스크립트·무작위 생성은0회다. 정확한 runtime 범위·전력 측정·원데이터/seed/정규화·저자 구현과 남은 telemetry 문헌은 미완료다. 전체53/55 및 전체 Goal은 계속 진행한다.
