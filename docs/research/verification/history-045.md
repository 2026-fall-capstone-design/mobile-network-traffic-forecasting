57의 고정 세 결과를 원 스크립트와 다른 `E[Z²]−E[Z]²` 방식의 정확 유리수로 검산했다. 손실 평균4/기울기평균1/3, 분산18→0/8/9→121/45, 비율121/40을 저장값과 대조했다. 57 원장 전후는 한 비용 항목만 다르며, 34의 step·처리 행은 저장 epoch와 배치 크기로 계산되는 값임을 확인했다. 독립 계측된 step이나 모델 재현으로 표시하지 않았다.

정적 원문·JSON·사본·receipt·기존 비용·controls 대조215개, 별도 선행57체크27개와 팀용 검산48개를 수행했다. 이 개수에는 파일/해시 확인도 들어 있으며 290개의 독립 연구 결과를 뜻하지 않는다. 주논문 텍스트10쪽·시각3–8쪽과 과거3쪽preview를 읽었으며 파생TXT가 현재추출과같음을 확인했다. 논문부록·저자실행·다른4문헌은 미완료다.

동일 에이전트가 본문·24개 주장과 source범위를 다시 원문에 대조했다. 자동 링크·문구·수치 검사나 CodeRabbit 리뷰는 독립 연구자의 과학적 검증을 대신하지 않는다. 논문 Fig1의 L2거리와57의 분산비를 구별하고, 수집11건/렌더6건의성공과 실제독해를 분리했다.

초기 아카이브 대조 코드가 ZIP 내부 사본을 물리 파일 경로로 열어 중단됐다. inventory의 `kind=zip_member`와 container/member index를 확인해 압축 내부에서 읽도록 고쳤고, 내용은 기존 대표와 같았다. 원자료 누락·연구 실험 실패로 집계하지 않는다. 원 연구 코드·원장 수정, 모델 실행, 난수 생성은 모두0이다.
