숫자 검수는 새로 작성한 작은 결정적 산술로 저장 배열을 대조했다. 실행 당시의 모델 환경·계측·학습을 독립적으로 재현하지 않았다. 같은 에이전트의 원문 2차 대조를 별도 연구자의 과학 검증으로 표현하지 않는다.

이번 대조에서 유지한 해석 경계는 다음과 같다.

- 순위별 상위 평균은 각 방법의 자체 정렬이다. 같은 cell별 지배와 구분하며 앞240의 모든 예외를 보존했다.
- whole/first/last는 같은 개발 자료의 중첩 집계다. 보조 두 seed 조건에는 별도의 global seed가 없다.
- 과거 code의 종료 부근 RSS는 peak RSS가 아니고, numeric wall과 finish elapsed도 계측 경계가 다르다.
- before는 기존 H052와 같은 바이트다. 현재 live 원장의 이후 변화와 당시 snapshot의 정확성을 혼동하지 않는다.
- 원65의 KDD α 선택 분할은 원문에 미기록이다. 나머지 기존 주의점들을 이번 새 발견으로 소급하지 않는다.
- 원68§1의 새 세 논문 수치·정리·식5 논평은 과거 보고이며 후속 일차문헌 검수 대기다. 검색 문자열 독해·해시 일치를 그 검수로 가산하지 않는다.

읽지 않은 PDF/TXT/HTML/PNG와 원실험 공백, 나머지 기록·실패/비용 통합·대용량 팀 접근·최종 변경분·대표질문 검색 검수는 미완료다. 개별 묶음의 PR·CI 통과나 병합은 전체 Goal 완료가 아니다.
