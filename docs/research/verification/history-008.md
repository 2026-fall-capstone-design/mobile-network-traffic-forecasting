# 13/14·15 일부 수치와 방법 검수

[연구 기록](../records/0013-0015-transfer-cell-identity.md)과 [실제 원문 범위](../sources/history-008.md)의 계획·코드·저장 결과를 대조했다. 같은 정리 에이전트의 두 번째 검토이며 독립 연구자의 과학적 검증이 아니다.

- 원문 13개 124,722bytes를 새 보존하고 기존 3사본을 재사용했다. SHA-256·크기·동일 사본과 원문 행 범위를 확인했다.
- [공유 도구](../../../scripts/research_archive/verify_transfer_identity_history.py)의 [520개 확인](history-008-arithmetic.json)은 저장 B1 실제 query에서 16×16 교차 MAE, 정규화 정답, 두 PCC, 세 rank 상관, 24소속의 내/외 손해, 4pair 변경, 7예측의 전체/cell/day MAE와 4ID 차이를 검산한다.
- 시작 설정·세 호출 로그·부분/최종 Tab 3예측·완료 파일이 일치한다. 168시간과 ID 순열의 유효성을 확인했으며 과거 난수를 재생성하지 않았다.
- UPC 24조건을 독립 24실험으로 세지 않는다. 16cell에서는 10개 고유 소속이며 저장 무작위 하한 미만 4행은 2개 고유 소속이다. 이름이 같은 K라도 부분집합의 실제 그룹 수가 다르다.
- Tab 평균 이득과 ID 조건의 5cell 손해·열 순서 변경 조건의 7cell 손해, 두 날 손해를 동시에 보존했다. Ridge/HGB는 평균 악화에도 8cell씩 이득이다. 1,024query의 시간 의존성과 날짜별 표본 수 9/10 차이를 명시했다.
- 교차 MAE와 ID MAE를 바꾸고 파일 해시까지 갱신한 2개 사본, 필수 원문을 하나씩 목록에서 뺀 13개 사본을 검산기가 모두 거부했다. 원본과 게시 근거는 변경하지 않았다.
- [11개 주장과 범위](history-008-primary-review.json)는 연구자료의 출처 대조다. 이번 새 일차문헌 방법 검토는 0이며 15 §3 여섯 문헌은 미완료다.

## 미검산·보고값과 해석의 한계

이웃 거리/95%threshold, 1,000무작위 순열의 개별 표본·분위수, 원 실행시간/RSS는 독립 재현하지 않았다. 지원 matrix의 집계/rank, 보고시간 합과 같은 stage 시간의 중복 기록만 확인했다. 저장 NPZ에 없는 원 순열을 새로 만들지 않았다. 원 도시 UPC와 원 모델·checkpoint 추론을 재실행하지 않았다.

13과 14는 context 자료량이 다르므로 두 MAE의 차이를 pooled 효과로 쓰지 않는다. 관측 full-ID 개선은 모든 clustering 이득의 상한이 아니고 Tab 직접 예측의 우위는 최종 소속/RCTL의 우위가 아니다. 누적 39context/23,424query/RCTL29는 15의 보고로 남기며 이번 증거만으로 재감사 완료라 하지 않는다.

모델·새 clustering·새 난수 실행은 0이다. 원본 상태·예산 6개의 불변은 별도로 확인했다. 같은 저장 산술의 로컬 524개와 portable 520개 검사를 독립 과학적 검증 횟수로 더하지 않는다. 차이는 로컬 원본 control 6개와 portable manifest 계약 2개다.

[문서·출처·표 대조](history-008-document-check.json)와 보존 해시/링크 검사도 게시 전에 확인한다. 수치 검사가 통과해도 인과·유의성·신규성 판단이나 미열람 후속 문헌을 검증한 것은 아니다.
