# H076 검수: TabDistill 상호작용 표

[연구 기록](../records/0076-tabdistill-interaction-audit.md) · [출처](../sources/history-076.md) · [자료](../evidence/0076-tabdistill-interactions/README.md)

20개 핵심 주장의 작성 후 원문 대조를 마쳤다. 27개 CSV의 2,253행과 남은 메타데이터를 읽어 H075에서 남긴 커밋 JSON의 읽기 범위를 완료했다. 외부 저장소 전체나 모든 관련 연구기록의 정리가 끝났다는 뜻은 아니다.

| 구분 | 확인한 범위 |
|---|---|
| 의미 대조 | 항 수·순서·중복, 지표별 비교, 원 생성 표와 후속 소비 코드의 조건, 시간 측정 범위, 실제 실행 연결의 공백 |
| 별도 수치 대조 | 시간·MSE·RMSE·MAE·R2 11,265칸, RMSE 2,253행, 공개 원 필드 2,500개, 데이터별 집계 27개, 반올림 표 162칸, 모델 결과 연결 27쌍 |
| 출처 대조 | CSV 27개 blob SHA-1·SHA-256, 메타데이터 URL 264개, 원본과 동일 사본 2경로, 보호 원본 6개 불변 |
| 미확인 | 원 생성 코드와 실행의 연결, 원 분할·교사·환경 판본, 전체 비용, 외부 원본 전체의 장기 팀 공용 접근 |

검수 중 C11의 Baseline MAE·MSE 끝자리 두 값을 원 CSV 77행에 맞춰 정정했다. 비교 방향은 유지됐다. C03은 수치 집계의 5열을 명시했고, C08은 최대 인덱스의 해석을 0기반 입력 좌표 수의 하한으로 한정했다. 표의 원본 값을 임의로 수정하지 않았다.

[주장별 원문과 두 번째 검토](history-076-claims.json), [수치·출처 대조 결과](../evidence/0076-tabdistill-interactions/interaction-audit.json), [파일·링크 검사](history-076-document-check.json)를 구분해 저장한다. 자동 검사가 문장 의미 검수를 대신하지 않는다. 같은 에이전트의 두 번째 검토이며 독립 연구자의 검증이나 원 모델 재현은 아니다.
