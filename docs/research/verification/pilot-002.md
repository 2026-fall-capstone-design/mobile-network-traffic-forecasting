## 별도 수치 검산

[검수 코드](../../../scripts/research_archive/verify_rctl_pilot.py)는 과거 코드를 실행하거나 import하지 않는다. NPZ는 `allow_pickle=False`로 읽는다. 정답·예측을 float64로 바꿔 각 cell의 MAE, 16cell 평균, 원척도 평균, 비교군별 상대 변화·cell 수·판정 분기를 다시 계산했다.

원본과 [저장소 manifest](../evidence/0639/manifest.json)를 입력한 두 검사가 통과했다. 두 결과의 수치·재사용 경로·epoch가 같았고, 원결과와의 최대 수치 차이는 `1.4210854715202004e-14`였다. 학습·추론 호출은 0이다. [기계가 읽을 수 있는 결과](pilot-002-arithmetic.json)에 모든 계산과 검토 경로를 보존했다.

69개 고정 의존 해시는 원본에서 일치했다. 저장소 사본만 쓰는 검산에서는 포함된 44개를 확인하고, 포함하지 않은 25개를 명시적으로 건너뛴다. 건너뛴 파일의 해시나 모델 checkpoint 내용을 원격에서 다시 검증했다고 주장하지 않는다. 다만 보고한 저장 예측 검산에 필요한 65개 접근 경로는 모두 저장소에서 해결되며 해시가 일치한다.

13개 재사용 규약 비교에서 367 설정의 `loss`는 미기록이다. 있는 필드의 동일성만 확인한다. 325·336·581의 `train` 함수 핵심 부분은 텍스트·해시가 같지만 전처리 wrapper 전체의 등가성은 이번 판정에 포함하지 않는다. 같은 seed여도 UPC 원학습의 thread 4와 새 학습의 thread 1 차이가 있으므로 완전히 동일한 실행 환경으로 표현하지 않는다.

당시 verification 파일의 1,900개 체크는 모두 통과로 저장돼 있다. 이는 당시 코드의 체크 수다. 이번의 별도 수치 검산, 실제 실험 수, 다른 연구자의 검토 수와 구분한다.

## 보존·접근과 남은 검토

76개 출처 경로를 56개 고유 바이트 내용에 연결했다. 새 보존 파일은 55개·1,808,047바이트이며 한 개는 이전 묶음의 638 결과를 참조한다. 보존본과 목록 해시가 일치한다. 읽기용 링크는 저장소 상대경로다. `.pt`를 실행하거나 복사하지 않았다.

160 prepared arrays의 정답·scale 연결은 확인했지만 scale 계산의 원자료 및 첫 672시간 평균의 생성 경로는 후속 검토 대상이다. 달력 날짜, 원래 traffic의 물리 단위, 원논문 RCTL 구현과 로컬 port의 전체 등가성, 다른 seed·cohort·새 기간에서의 성능도 여기서 확정하지 않았다. 640·641·642의 상세 후속 판단은 별도 묶음에서 검수한다.
