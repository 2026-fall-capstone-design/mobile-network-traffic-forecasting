# 초기 01–02 검수

[연구 기록](../records/0001-0002-initial-design.md)과 [원문별 읽기 범위](../sources/pilot-006.md)를 대조했다. 01의 자료 진단/CPU 동작 확인, 02의 사전 계획, 후속 실행 검토 대기를 분리했다. 원문13개(본문7·배열6)를 새로 보존했으며 외부 메타데이터9건은 별도로 연결했다.

## 저장 값의 검산

자체 [검수 코드](../../../scripts/research_archive/verify_initial_pilot.py)를 원본 Windows/보존 Linux 모드에서 실행했다. 원본 371개, 보존 399개 확인이 통과했다. 보존 모드에는 원문13개 해시·크기, 선언한 실제 필드13건, 날짜 발췌2건의 검사가 추가된다. 검사의 개수는 독립 실험 수가 아니다. [보존 모드 결과](pilot-006-initial-check.json)

- 32cell 고정 격자, 시점168–1007, 첫672시간 평균 scale, target, 입력16열.
- 네 smoke의 context256/query64 인덱스, 실제 정답, 유한한 예측, Tab/최근값/하루 전 MAE.
- 별도32cell 진단의 저장 Ridge 오차 MAE, 최근값/하루 전/일주일 전 MAE, target·오차 상관행렬과 분위수.
- 실제 기록된 cell/환경/비용/시간 구간. 원본과 보존 모드의 보고 수치는 동일했다.

배열·지표 대조의 최대 절대차는 원본 0, 보존 8.8817841970012523e-16이며 허용치1e-7 이하다. 후자는 플랫폼의 부동소수점 합산 차이 범위다. 새로운 모델·gradient 학습·예측 생성은 없었고, 과거 연구 코드를 실행하지 않았다.

## H5와 자산 출처

별도 로컬 읽기 전용 검사로 H5의 실제 SHA, `data.shape`, `idx[:]`, `data[:1008,32개 고정 인덱스,2]`를 확인했다. 저장 raw와 정확히 같고 네 calendar 특징 열도 최대차이0이었다. 1,488개 날짜는 유일하고 시간 간격은1시간이다. 후반480시간의 target은 읽지 않았다. [H5 증거](pilot-006-H5-check.json)

7z/checkpoint/소스ZIP의 전체 바이트를 당시 manifest/목록에 대조했다. 공식 commit의 STCNet README·전처리 예시·Git LFS pointer를 저장 사본과 비교했고, 7z 내부 H5의 스트림 해시가 실제 읽은 H5와 같았다. [자산 증거](pilot-006-assets-check.json) 다만 원 CDR부터 전처리를 재생성한 것도, checkpoint를 현재 환경에서 실행한 것도 아니다.

CI는 작은 원본·배열·날짜 발췌를 검산한다. 위 로컬 H5/큰 자산 대조는 저장 증거이며 CI 재실행 범위와 구분한다. 자동 필드 접근 이력은 `array:...` 및 JSON 최상위 값을 기록한다. 큰 JSON 하위 트리는 하나의 값으로 취급하며 재귀 필드 추적이라고 부르지 않는다.

임시 사본 네 가지로 실패 경로도 확인했다. 읽지 않은 `dates`를 읽었다고 선언하거나 실제 조회 JSON 필드를 선언에서 빼면 범위 검사에서 실패했다. 파일 해시 선언까지 바꾼 예측값 변조는 MAE 비교에서, 날짜 중복은 시간 목록 검사에서 실패했다. 원본과 보존 파일은 변경하지 않았다. [네 경우의 결과](pilot-006-negative-checks.json)

## 해석 검수와 근거 공백

1. 초기 상관 진단을 negative transfer의 원인·효과로 해석하지 않았다. 4cell 직접 예측을 clustering/RCTL 성능과 분리했다.
2. 02의 이상적 비용표와 실제 pooled Tab/RCTL 성능을 구분하고, 목적식의 최초성·성능 보장을 주장하지 않았다. grid 반간격 오차를 가중합에 적용할 때 빈도 질량이 필요함을 정리 과정의 수식 검토로 명시했다.
3. 02의 train168–839는672개 target이다. “첫35일”이라는 원문 표현과 lag 준비를 뺀28일 분량을 구분했다. H5의 마지막 날짜는2014-01-01이며 시간대는 미확정이다.
4. 네 smoke Ridge 예측은 없어서 MAE는 보고값이다. 32cell Ridge는 저장 오차 검산이며 적합 재현이 아니다. RSS는0.2초 표본, 4.8401823초는Tab fit/predict 합으로 비용 범위를 한정했다.
5. 초기 계획의 예산·29RCTLfit/2320epoch는 상한이다. 후속03–09의 변경/실행 근거는 아직 본문 검토하지 않았으며 계획을 전체 미실행으로 단정하지 않았다.
6. 원자료 사용 조건은 저장된 Dataverse v1.3 지정 항목을 읽었다. 현재 사이트는 본문 접근이 막혀 최신 확인으로 세지 않았다. [메타데이터 발췌](pilot-006-dataset-metadata.json)

같은 정리 에이전트가 원문·코드·저장값·정리문을 대조했다. 독립 연구자의 과학적 재현이나 전체 과거 기록 검토 완료를 뜻하지 않는다. 이 묶음은 초기 가설·설계 사례 한 종류를 보완하며 이후 부정 결과 등 나머지 사례를 계속 정리한다.
