## 제외와 포함의 근거

로컬 설치 `RECORD`의 SHA-256·크기와 25,186개 파일이 일치했고 불일치는 0개다. 현재 보관된 설치 목록과의 비교이며 원 배포처 진위나 과거 수정의 부재를 독립적으로 증명하지 않는다. 연구가 참조한 TabICL 소스와 환경 메타데이터는 일치하더라도 검토 대상으로 남겼다.

| 처리 상태 | 항목 수 | 이유 |
|---|---:|---|
| 본문 검토를 남긴 고유 파일 내용 | 16,326 | 연구 후보·참조 구현·환경 자료·압축 내부. 연구 기록 수는 아님 |
| 대표로 연결한 동일 사본 | 3,767 | SHA-256 동일. 대표를 아직 읽지 않았으면 검토 미완료 |
| 설치 라이브러리 제외 | 24,470 | RECORD 해시·크기 일치, 연구 참조와 환경 자료는 예외 |

| 외부 runtime 디렉터리 연결 제외 | 3 | 원본 밖 공용 node_modules. 위치만 등록 |

포함 범주의 항목 수는 연구 후보 18,952개, TabICL 구현 참조 93개, 환경 메타데이터 705개, 압축 내부 343개다. 이 합에는 동일 사본이 들어간다. 내용을 임의로 버리지 않도록 일반 미확인 파일은 포함 대기로 남겼다.

snapshot 08의 `tabicl/_model/quantile_dist.py`와 `tabicl/_unsupervised/unsupervised.py`는 현재 설치 파일과 바이트가 같았다. 두 경로의 이력·참조 역할은 남기되 다른 수정본으로 세지 않았다. 로컬 RECORD 대상 중 목록에 없는 97개는 setuptools 내장 의존성 기록의 bytecode 96개와 `bin/wheel` 진입점 1개다. 연구 원문 누락으로 합치지 않고 환경 복원 시 확인할 항목으로 남긴다.

## 목록 검수와 접근

별도 `rg --no-config --files --hidden --no-ignore` 경로 목록과 47,803개가 정확히 일치했다. source_id 중복과 압축 컨테이너 참조 오류는 없다. 해시 계산 시 읽기 전후 크기·수정 시각 및 압축 내부 크기를 대조했다.

첫 시도는 Windows junction 세 개를 통해 외부 runtime 파일 25,584개를 추가 탐색했다. 연결만 등록하도록 고쳐 재수집했고 첫 버전은 집계에서 제외했다. 이전 ID를 재사용하지 않아 번호에 공백이 있다. 가장 큰 ID는 파일 총수가 아니다.

파일별 목록과 처리 이유는 [압축 JSONL](../catalog/inventory.jsonl.gz), [스키마](../catalog/README.md), [집계](../catalog/scope-summary.json)에 보존한다. 도구는 [inventory.py](../../../scripts/research_archive/inventory.py), [catalog.py](../../../scripts/research_archive/catalog.py), [classify.py](../../../scripts/research_archive/classify.py)다.

현재 본문 작업은 [635–638 시범 검수](pilot-001.md)까지 진행했다. 목록·해시·분류와 연구 내용·근거·접근 검수는 별개다. 모든 고유 연구 기록의 수와 전수 검토 완료율은 아직 확정하지 않았다.
