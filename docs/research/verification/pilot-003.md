## 파일·상태·출처 확인

12개 새 연구 원문은 전체 텍스트를 읽고 바이트를 보존했다. 앞서 보존한 635 코드 한 개는 핵심 구간을 다시 대조했다. 따라서 이 묶음의 보존 출처는 13경로, 새 파일은 12개·75,976바이트다. 5개 외부 논문 PDF와 3개 기존 페이지 이미지는 지정 구간을 읽고 메타데이터로 연결했다. Yang HTML 하나는 해시만 확인했으며 내용 검토 수에 더하지 않는다.

640 review manifest가 적은 의존 원문 12개는 현재 원본 SHA-256과 모두 일치했다. 별도로 원본 연구의 AGENTS·state·focus·progress·candidate index·예산 원장 6개를 정리 시작 시 보존 기준과 비교해 변경이 없음을 확인했다. 이 기준은 **정리 작업이 원본을 바꾸지 않았는지**에 관한 것이다. 640 당시 원장의 hash를 후속 연구까지 진행된 현재 원장의 hash와 같다고 요구하지 않는다.

저장소 검사는 보존 사본의 바이트·전체 목록 연결·로컬 Markdown 파일 링크를 확인한다. 외부 논문은 등록된 메타데이터와 전체 목록의 연결만 검사하며 CI에서 원격 PDF를 내려받거나 수식을 검증하지 않는다. 공식 URL의 장기 접근성과 원문 의미는 별도 검토 영역이다. 이번 수식 검수는 위 등식·가정과 원문 구간의 정적 대조이며 과거 학습·추론·traffic 실험 실행은 없다.

## 남아 있는 검토

116·267·473·512·634는 640에 필요한 내용을 연결했을 뿐 각 연구 기록 전체의 관련 코드·결과·문헌까지 정리 완료한 것이 아니다. 640 당시 before 상태 사본은 의존 관계만 파악했고 전체 텍스트 검토가 남아 있다. 이 묶음에서는 641 계획까지 읽었고, 실제 산출물과 결과 재사용은 후속 [pilot-004](pilot-004.md)에서 검수했다.

640의 추정 확률과 평가 분포, 잡음/입력 빈도의 영향, 희소 graph 밖의 관계, 최종 신규성·일반적 성능은 여전히 미확정이다. 639에서 이미 확인된 평균 이득과 기간·원척도 손해를 함께 보존한다. 이 문헌 묶음의 병합은 전체 정리 Goal의 완료가 아니다.
