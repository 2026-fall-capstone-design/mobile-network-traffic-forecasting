# H018 검수 · 기록25의 인접 문헌과 판단 경계

검수일2026-10-09. [14개 주장별 원문 위치·한계](history-018-primary-review.json), [저장 peak 검산](history-018-peak-check.json), [문서·identity 검사](history-018-document-check.json), [읽은 구간](../sources/history-018.md)을 연결한다.

기록25 §3–4의 실제 사용 정보·당시 미추천 판단을 Ma v1/NeST v2/Graph Coloring v3의 지정 방법과 대조했다. NTK는 기관 초록·검색 단계로 남겼다. 세 논문의 PDF에서 고른 총15개 페이지의 지정 내용을 시각 대조했으며 전논문·전체 성능표·저자 코드 검토로 세지 않는다.

Ma의 VAL 집단 평균 fallback과 미래 보장, NeST의 실제 미래값과 예측 guidance, Graph Coloring의 shared 모델 스케줄과 독립 모델 배포를 구별했다. NeST A4의 인쇄된 부등식/가정에 대한 대수 반례, affinity와 sampling 설명 차이, Graph 도식과 수식 차이는 [별도 비교](../references/adjacent-structures.md)에 남겼다. 이 대조는 논문 실증 성능의 재현·반증이 아니다.

저장 test target과 threshold의 strict 비교에서 cell별 peak 개수를 다시 구하고 summary8행의 count/null/평균을 대조했다. 4개cell이0, 나머지12개가1–28이며 합계95cell-time이다. actual peak의 평가 조건을 관측 입력 조건과 혼동하지 않았다. TRAIN threshold/H5 연결은 기존 H001 검수를 재사용했다.

원본3참조와 Ma PDF identity 및 원 연구 상태6개가 기준과 같음을 확인한다. 새 원본 사본0개, 새로운 모델 학습·추론·무작위 실험0회다. 자동 검사는 바이트·저장 산술·로컬 링크를 확인하며, 문헌 의미의 검토는 같은 정리 에이전트가 수행한다. 독립 연구자의 승인이나 전체 아카이브 완료로 표시하지 않는다.

기록25의 문헌/판단 경계를 추가 연결했지만 전체 후속 이력, H016 실패·입력 생성 공백과 H017 중간 입력·checkpoint 팀 공유 공백은 남아 있다. GitHub 반영은 이 검수 범위에 한정한다.
