# TabICL 연구기록 안내

과거에 무엇을 검토했고 어떤 조건에서 판단했는지 찾기 위한 아카이브입니다.
새 실험은 [공통 실험 규약: Milan-900-10min v1.0](../research-protocol.md)을 적용합니다.
과거 기록의 조건과 점수는 당시 근거이며, 새 기준으로 재평가된 결과가 아닙니다.

## 정리된 범위

[PR #157](https://github.com/2026-fall-capstone-design/mobile-network-traffic-forecasting/pull/157)에서
기존 1–642번의 정리와 게시를 마쳤습니다.

| 원래 기록 번호 | 제공하는 내용 | 원번호 수 |
| --- | --- | --- |
| 1–114, 633, 635–642 | 기존 상세 기록과 출처·검수 링크 | 123 |
| 115–632, 634 | 번호와 핵심 주제 한 줄 | 519 |
| 기존 아카이브 합계 | 1–642, 번호 누락·중복 없음 | 642 |

추가로 [643–773번 GECOS 후속 연구 요약](gecos-0643-0773-summary.md)을 제공합니다.
2026-10-17 작성 문서가 다룬 131개 기록에서 핵심 판단·결과·남은 과제를 추렸으며,
개별 원기록의 전체 과정·결과를 게시하거나 독립 검증한 범위는 아닙니다.
이어 [774–829번 핵심 요약](gecos-0774-0829-summary.md)은 2026-10-20 기준 문서가 다룬 56개 기록의
K 확대 완료 결과·후속 개발·미완료 비교를 같은 요약 범위로 제공합니다.
[830–974번 핵심 요약](gecos-0830-0974-summary.md)은 2026-10-23 09:47 기준 문서의 145개 기록에서
정확도 목표 전환과 조건부 전문가 선택의 검증 개선, 아직 미완료인 최종 평가를 정리합니다.

상세 페이지는 155개이며, 원래 기록 번호 수와 다릅니다.
하나의 원번호를 여러 페이지로 나누거나 여러 번호를 한 페이지에서 다룹니다.
H번호는 아카이브 검수 묶음 번호입니다. 파일 이름의 숫자를 원번호로 대신 읽지 않습니다.
주제 표를 작성한 것은 남은 원문의 전체 과정·결과를 검증했다는 뜻이 아닙니다.

## 새 실험을 설계하는 순서

1. 문제별 색인, 519개 주제 표, [643–773번](gecos-0643-0773-summary.md)·[774–829번](gecos-0774-0829-summary.md)·[830–974번](gecos-0830-0974-summary.md) 후속 요약에서 비슷한 질문을 찾습니다.
2. 상세 기록이 있으면 당시 입력·학습·선택·평가 조건, 실패·정정, 재사용 가능한 파일을 읽습니다.
3. 이번 공통 기준과 다른 셀·기간·입력·정규화·분모·시드를 표시합니다.
4. 바뀌는 질문과 조건을 [실험 기록 양식](../progress/README.md)에 적고 [결과 교환 형식](../experiment-results.md)을 맞춥니다.

검색되지 않는다는 이유만으로 과거 시도가 없었다고 판단하지 않습니다.
문헌 검토, 저장 결과 검산, 새 모델 실행, 결과 재인용은 각각 구분합니다.

## 근거와 이전 계획

자료 목록은 원본 경로·사본·해시·실제 읽은 범위를 연결합니다.
48,149개 목록 항목과 16,326개 포함 고유 내용은 파일 조사 수치이며 연구 시도 수가 아닙니다.
자세한 범위는 [조사 기록](verification/inventory-2026-10-08.md)에서 확인합니다.

[이전 정리 계획](../research-archive-plan.md)과 [Goal 프롬프트 이력](../research-archive-goal-prompt.md)은
아카이브가 만들어진 과정을 설명합니다. 과거 문서의 ‘계속 진행’·‘후속 예정’ 표기는 당시 상태입니다.
이번 문서 정비는 남은 519개 기록의 상세 정리를 다시 시작하는 작업이 아닙니다.
