색인은 현재 정리한 범위만 담습니다. 검색 결과가 없다고 과거 시도가 없다고 판단하면 안 됩니다. 파일·기록 번호·실험·재분석을 구분하며, 초기·부정·문헌·캐시 재분석·미실행 사례를 이어서 확인합니다. 이 아카이브는 팀의 최종 모델 선정 결과가 아닙니다.

전체 목록은 48,149항목이고 포함된 고유 파일 내용은 16,326개입니다. 이는 연구 시도 수가 아닙니다. 현재 세 개 시범 사례를 세 페이지로 통합했으며, 전체 고유 연구 내용의 수와 본문 검토율은 아직 확정하지 않았습니다. 검수가 끝난 묶음부터 PR로 반영하고, 원격 반영과 전체 정리 완료를 구분합니다.
