Yu·Yang·Sadeghkhani의 새 렌더는 정리용 중간물이다. 별도 역사적 source_id를 만들거나 독립 문헌으로 세지 않는다. 기존 Zhang/Kallus 이미지 3개는 목록에 원래 있던 자료이므로 PDF와 다른 파일 ID로 연결하지만 다른 논문으로 세지 않는다.

`SRC-0063795`의 당시 Yang HTML은 현재 원본 해시가 640 source manifest와 일치한다. 이번 읽기는 PDF와 공식 웹 HTML의 지정 절을 사용했다. 저장된 HTML 전체의 내용 검토나 현재 웹페이지와의 바이트 동일성을 주장하지 않는다. NSF 링크는 브라우징 도구에서 열리지 않아 제공된 로컬 PDF와 기존 이미지로 본문을 대조했다. 링크의 영구적인 접근 불가를 판정한 것은 아니다.

논문 본문과 그림은 이 PR에 복제하지 않았다. 팀원은 공식 링크에서 본문을 열고 위 판본·쪽수를 확인할 수 있다. 해시는 로컬에서 실제 읽은 파일을 식별하며, 다른 시점에 내려받은 PDF가 같은 바이트라는 보장은 하지 않는다.
