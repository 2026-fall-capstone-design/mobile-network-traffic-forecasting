새 원문 사본 5개·기존 사본 1개·외부 metadata 6개다. 바이트 동일 별칭은 명세의 `exact_alias_source_ids`에 연결한다. PDF/TXT/PNG의 내용상 계보는 별도의 파생 관계이며 해시가 다른 파일을 정확 중복으로 합치지 않는다. 원 논문 p4의 CC BY-NC-ND 표기를 보존하고 원 PDF·전체 추출문·그림을 팀 저장소에 복제하지 않는다. [공식 저장소](https://dspace.networks.imdea.org/handle/20.500.12761/2071)는 입수 경로이며 원본의 정확한 버전은 해시로 구별한다.

PDF 시각 열람은 p4·7·31·37–43·49·58–60·62–72·74–85·88–89·92–103·106–115·118의 총 62쪽이다. 그림 34개·표 2개·번호 식 43개·알고리즘 2개가 모두 포함되며 [범위 명세](../verification/history-035-primary-check.json)에 각각의 페이지가 있다. 페이지 수에는 표지·빈 쪽·서지가 포함되고, 그림의 모든 점을 수치로 복원하거나 식의 정확성을 독립 증명했다는 뜻이 아니다. 122개 참고문헌의 원논문을 각각 읽은 것으로 세지 않는다.

숫자는 Table3.1·3.2의 16개 통계, p115의 7개 비용, 설정·구성 수와 조건부 산술을 대조했다. 저자 원 결과 파일·개별 모델 원장·코드·seed·정규화·적합 구간은 확보하지 않았다. 81% 입력 감소를 전체 에너지 절감으로 전환하지 않았으며 원문 불일치는 팀 기록에 남겼다.

원본 12개와 보호 대상 제어 원장 6개의 해시를 확인했다. 발견 단계의 25개 metadata를 25개 전체 본문 검토로 세지 않는다. SRSSS/Zoom2Net/NETNOMOS PDF·TXT·그림, TabICL imputation HTML과 Ciena 원문 접근 문제는 후속 범위다. H035는 학위논문 범위를 완결하며 51/53/55 전체를 닫지 않는다.
