## Word와 코드의 범위

Word는 기존 최종 PNG 7장을 원해상도로 읽고 본문·표·수식을 확인했다. 구조상 본문 문단 76개·표 5개이며, 주석·변경 추적·각주·미주·텍스트 상자·그림 개체·OMML·숨김 run은 없었다. 바닥글은 문서명과 페이지 필드다. 이 아카이브에서 새 Word를 만들거나 렌더링하지 않았다. 최종 PDF는 해시를 연결했고, 페이지 판독은 PNG를 통해 수행했다.

`build_recommendation_642.py`는 1–70, 228–451행을 읽었다. 직접 출력하지 않은 71–227행은 보고서 문자열에 들어 있다. AST로 추출한 보고서 문자열과 전체 읽은 Markdown의 텍스트가 일치했으며, LF/CRLF 차이가 있어 파일 바이트 중복으로 분류하지 않았다. 과거 생성·보관 코드는 실행하지 않았다.
