[SIU·검색 기록](../records/0069-0071-siu-search.md) · [출처 목록](../catalog/history-069-sources.jsonl) · [보존 명세](../evidence/0069-0071-siu-search/manifest.json) · [형식 검사](../evidence/0069-0071-siu-search/format-audit.json) · [현재판 대조](../evidence/0069-0071-siu-search/external-version-check.json)

검색 a–f의 디코딩 행은 578·256·486·499·372·8, 결과 수는 21·3·15·20·3·2다. 합계 2,199행·64결과이며 위의 두 raw_text 내용을 더하면 **3,222행·100결과**다. 10개 표현을 10개의 서로 다른 검색 내용으로 세지 않는다. 대응 TXT는 JSON 문자열의 UTF-8 바이트와 동일한지 검사했다.

SIU HTML의 script·주석 파생 표현523행과 supporting markup426행을 읽었지만 외부 JS·CSS·로고 픽셀은 연구 본문이 아니므로 실행·다운로드·시각 검수하지 않았다. 기관 페이지에 연구 표·내장 논문 PDF·논문 그림은 확인되지 않았다. 일반적인 파일 다운로드 문구는 기관 UI이며 특정 논문 첨부를 뜻하지 않는다.

[결과별 색인](../evidence/0069-0071-siu-search/search-result-index.json)은 출처 파일·source_id·파일 내 순번·사이트·읽은 수준을 제공한다. 원 검색문 전체나 서명 URL query를 복제하지 않는다. 같은 문헌·재게시·언어별 페이지·참고문헌 결과·열람 오류가 모두 섞여 있으므로 고유 논문 수 또는 독립 실험 수로 사용하지 않는다. `primary`라는 파일명도 일차 출처라는 보증이 아니다.

원 `search_scope`가 명시한 첫 질의 묶음 미보존은 남아 있다. 결과 블록 전체 독해로 연결된 논문 본문, 사라진 검색 원문 또는 실제 모델 실험의 공백이 해소되지 않는다. H067·H068의 본문 검수는 각 묶음의 당시 범위로 유지한다.

script 본문 문자 수는 UTF-8 디코딩 후 CRLF/CR를 LF로 정규화한 기준이다. 원HTML의 CRLF는1,015개이며 파일 크기63,000바이트와 SHA-256는 원바이트 기준으로 보존한다. 파생 script 헤더의 원문 문자 수와 정규화한 감사 수의 차이를 원본 변경으로 해석하지 않는다.
