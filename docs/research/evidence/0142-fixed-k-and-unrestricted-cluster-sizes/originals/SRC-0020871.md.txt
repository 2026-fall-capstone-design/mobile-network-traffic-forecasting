# 113 cluster 크기 제약을 제거한 비교

2026-09-26. 기존 04 pilot은 K4의 각 cluster를 4개 cell로 맞췄다. 원 UPC Algorithm 1의 고정 cluster 수와 같은 크기 조건은 다르다. 원 UPC에는 각 cluster의 cell 수를 같게 만드는 조건이 없다. 이번 확인은 pilot에 추가한 제약의 영향을 구별하는 진단이다.

## 유지한 조건과 변경한 조건

기존 16개 cell, K4, 상태 64개, 후보 수정값 257개, 저장한 TabICL·실제값 risk table을 유지했다. balanced 분할을 다시 실행하지 않고 기존 소속을 읽어 결과를 재현했다. 대안은 현재 합산 위험 증가가 가장 작은 두 cluster를 한 번에 하나씩 합치는 일반적인 병합이며 크기 제한을 두지 않았다. 소속 결정에 RCTL 예측·loss·다음 주 실제값을 쓰지 않았다.

각 소속을 같은 두 수정값 규칙으로 평가하여, 소속의 효과와 수정값을 정한 방법의 효과를 구별했다. 예측기는 기존 `f0(x)+cluster의 상태별 상수`다. **최종 RCTL의 결과가 아니다.** 다음 주 840~1007의 값은 이미 사용된 개발 구간이다.

## 결과

| 소속 결정 | cluster별 cell 수 | Tab 수정값의 MAE | 실제값 수정값의 MAE |
|---|---|---:|---:|
| Tab, 같은 크기 | 4·4·4·4 | 0.085257 | 0.085161 |
| Tab, 크기 제한 없음 | 2·8·2·4 | 0.084498 | 0.084531 |
| 실제값, 같은 크기 | 4·4·4·4 | 0.084429 | 0.086252 |
| 실제값, 크기 제한 없음 | 4·5·3·4 | 0.083985 | 0.085141 |

크기 제한을 없애면 선택되는 소속과 오차가 달라진다. 그러나 같은 Tab 수정값으로 비교하면 단순 실제값 소속이 더 좋고, 같은 실제값 수정값으로 비교하면 Tab 소속이 더 좋다. 소속의 우열이 평가에 사용하는 수정값 규칙에 따라 바뀐다. 이 결과만으로 Tab이 더 좋은 cluster를 찾았다거나 기존 RCTL 실패를 해결했다고 말할 수 없다.

크기 제한을 없앤 것 자체도 UPC 대비 신규성이 아니다. 따라서 새 RCTL 적합으로 자동 진행하지 않는다. 앞으로 고정 K 비교에서 같은 크기 제약을 부여한다면 통제 목적과 원 논문과의 차이를 명시해야 한다.
