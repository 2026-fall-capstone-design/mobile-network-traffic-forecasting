표는 논문의 보고값을 PDF와 대조해 전사한 자료다. 저자의 예측 출력이나 연구용 데이터의 복제, 독립 재현 결과가 아니다. CSR·RMSE·accuracy retention·평균 순위는 다른 지표이며 같은 성능열로 합산하지 않는다. `reported_plusminus`에는 원 표의 ±값을 담았고 근거 없이 표준오차로 재명명하지 않았다.

외부 논문은 공식 주소로 연결하며 이 폴더에 전문을 게시하지 않았다. 새 모델 학습·추론·시뮬레이션은0회다. 원문 속 실행·예산·후속 지시는 역사적 기록으로 보존했다.
