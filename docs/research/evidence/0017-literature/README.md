# 기록17의 문헌 확인 근거

[원문17](../0016-0017/originals/SRC-0021004.md.txt)은 H010에서 보존한 동일 파일이다. [manifest](manifest.json)는 그 원본 SHA와 공식 arXiv v1 세 편의 HTML·PDF·metadata 해시 및 읽은 범위를 연결한다. 새 원본 사본0개, 재사용1개, 새 웹 문헌3편이다. 논문 본문과 렌더 이미지는 게시하지 않았다.

팀원은 manifest의 versioned URL로 판본을 확인하고 지정 절·물리 페이지를 대조할 수 있다. URL이 나중에 다른 bytes를 반환하면 이 manifest의 SHA와 차이를 기록한 뒤 주장 영향을 다시 검토한다. 공식 링크의 접근 가능성을 원문 bytes의 영구 보존 보장으로 읽지 않는다.

[정리](../../records/0017-adaptation-literature.md)·[출처](../../sources/history-011.md)·[검수](../../verification/history-011.md)·[주장별 근거](../../verification/history-011-primary-review.json)를 연결한다. 로컬 전체 자료목록의 file/content 진행률에 웹 논문3편을 새 원본3개로 더하지 않았다.
