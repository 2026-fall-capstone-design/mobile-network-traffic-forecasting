# 초기 누적 비용의 재사용 증거

[정리 기록](../../records/0015-0021-cumulative-costs.md), [출처와 실제 읽기 범위](../../sources/history-015.md), [manifest](manifest.json), [검수](../../verification/history-015.md).

여섯 TabICL 호출군, RCTL29fit 및 시작·종료 기록, 관련 summary·코드·03/04/15/21 비용 문장을 기존28개 원본에 연결한다. `archive_path`는 앞선 묶음의 바이트 보존 사본을 가리킨다. 새 복사본이나 모델 실행은 없다.

호출 합계와 stage시간·단순 모델 시간은 포함 관계가 있으므로 전부 더하지 않는다. 타이머 밖 준비·저장, 실패 시도 전수 비용, 전체 연구시간은 확인되지 않았다. 문서화한 숫자는 당시 저장된 측정값의 재계산이며 현재 환경의 속도 측정이 아니다.
