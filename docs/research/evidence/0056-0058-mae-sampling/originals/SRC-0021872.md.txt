# 57. MAE sample 중요도 산술 확인 계획

2026-09-26. 56 원문 검토에서 나온 논리 확인이다. 실제 네트워크 데이터 성능이나 TabICL 성능 실험이 아니다.

예측식 fθ(x)=θ, θ=0, 입력은 모두 같은 세 sample, 실제 정답은 [-1,-1,10]으로 고정한다. 원 경험 목적은 세 MAE의 단순 평균이다. 비교할 확률은 uniform [1/3,1/3,1/3]과 현재 절대오차 비례 [1/12,1/12,10/12]다. 각 draw에는 1/(3p_i)를 곱한다. Monte Carlo가 아니라 세 결과를 정확히 열거한다.

계산할 값은 (1) 가중 loss의 평균과 분산, (2) 가중 θ-gradient의 평균과 분산, (3) 원래 전체 sample MAE와 gradient다. 기대하는 성질은 두 선택법 모두 평균이 보존되지만 loss 비례 선택의 loss 분산은 0이고 gradient 분산은 uniform보다 커지는 것이다. 실제 값이 다르면 결과를 유지하고 해석을 수정한다.

이는 MAE residual의 크기가 gradient의 크기와 동일하지 않음을 확인한다. 실제 RCTL의 x별 Jacobian이 다르거나 시간 의존성이 있는 조건을 계산한 것은 아니다. RCTL/TabICL 호출 0, 새 fit 0, numeric 상한1초. 실행 한 번, 실패·시간 모두 기록하며 비용을 초기화하지 않는다.
