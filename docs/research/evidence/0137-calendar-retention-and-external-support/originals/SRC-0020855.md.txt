# 107 자료 누락과 외부 입력 근접성의 구별

2026-09-26. 새모델 실행 없이 기존23의 저장된 입력 이웃 비중을 재집계했다.

## 새로 확인한 범위

모든K4 소속은 각cell의 훈련672개를 그대로 포함했다.28일의 시간×요일168개 조합마다 자기cell4개, cluster 전체16개의 sample이 있다. 자기cell 자료가 제거되거나 특정 시간대만 없어져 두 분할의 성능이 달라진 것은 아니다. 이는 **시간·요일 표본 수**가 같다는 뜻이며 트래픽 수준·경로의 분포가 같다는 뜻은 아니다.

각query의 가까운32개 과거 입력 중 같은cluster의 다른cell이 차지하는 평균 비중은 다음과 같다. 숫자가 클수록 이 근접성 정의에서 가까운 다른cell sample이 같은cluster에 많다.

| 기존 소속 | 같은cluster의 다른cell 비중 |
|---|---:|
| Tab-risk | 12.03% |
| empirical-risk | 15.94% |
| KNN-risk | 12.49% |
| PCC balanced | 22.90% |
| random balanced | 11.86% |

Tab-risk는empirical보다3.91%p 작았다. 가까운입력을16개·64개로 잡아도차이는−4.90%p·−3.26%p였고, 두경우모두앞뒤query절반에서같은방향이었다.16cell중10개에서Tab-risk의외부비중이작았다.

따라서 두소속의 실제 자료 구성은 다르다. 다만 가장 큰 외부비중을 가진PCC가 기존RCTL에서 가장 좋은소속은 아니었다. 이웃을많이모으기만하면학습이좋아진다고결론낼수없다. 다른cell의가까운입력은조건부정답의일치나독립적인정보량을보장하지않는다.

입력비중은context168~671,query672~839의64시점/cell을기준으로한기존값이다. 모든query는RCTL전체훈련기간안에있다. 이후20일의지원범위를측정하거나평가정답으로새소속을정한분석이아니다.

## 다음 행동을 바꾸는 판단

다음후보를단순히'자료를더남긴다'또는'가까운sample을더모은다'로정하지않는다. 자기자료는이미보존되고, 입력근접성의순위도RCTL순위를설명하지못한다. 관계충돌·유한표본추정·최적화와평가절차는아직구별되지않았다.

현재RCTLcode에는각block에두개의BatchNorm,전체12개가있다. 훈련중갱신한평균·분산을평가에서사용하므로, 같은가중치여도이통계에따라예측이달라진다. 다음에는기존가중치와소속을고정하고**훈련입력만으로이통계를다시계산하는한요소비교**를수행한다. 이는기존학습정책이남긴평가차이를구별하는진단이며, 새clustering기여나TabICL의신규성으로세지않는다. 성능을보고cell을바꾸거나통계혼합비율을튜닝하지않는다.
