# 107 동일 K에서 보존되는 시간 자료와 추가되는 입력 이웃

2026-09-26.106의 다음 작업을 수행한다. 기존23의 저장된 입력 이웃 비중을 재사용하며 거리·Tab 추론·RCTL을 다시 실행하지 않는다.

## 질문

동일 K4의 Tab-risk와 empirical-risk가 같은 수의 훈련 sample을 사용하면서도 이후 RCTL 성능이 달랐다는 관찰을, 특정 시간대의 자기 자료가 누락되었거나 가까운 외부 입력이 부족했다는 설명으로 좁힐 수 있는가?

## 입력과 계산

1. 기존16cell의 훈련 시점168~839와 각 고정 소속을 확인한다. 각cell의 자기 훈련 sample은 모두 포함되며,4cell cluster당2,688행이다. 시간×요일168개 조합별 행 수와 cell별 기여를 계산한다. 같은 자료가 보존되는지 확인하는 집계이며 모델 실험이 아니다.
2.23에서 저장한 `conditional_pooling_cost/arrays.npz`의 density_k16/32/64만 사용한다. 비중은 context168~671에서 각query의 가까운k개 입력 중 출처cell 빈도다. 정답으로 거리를 정하지 않았다. query는672~839의 고정64시점/cell이며, RCTL의 전체 훈련기간 안에 있다. 이후20일의 입력 지원을 직접 측정하는 결과라고 표현하지 않는다.
3. 각query 소유cell i에 대해 자기 비중 p_i, 같은cluster의 다른cell 비중 합, 해당cluster 전체 비중 합을 계산한다. 주요 k=32,16/64는 기존 민감도 설정 그대로다. 비중이0인 경우도 제외하지 않는다. 앞32·뒤32 query와16cell별 값을 모두 남긴다.
4. 기존 다섯 K4 소속을 모두 보고한다. 이 값을 이용해 새cluster·threshold·특징비중을 선택하지 않는다. 새로운 RCTL 예측은 읽거나 생성하지 않고 기존106의 방향과 해석만 연결한다.

## 판정과 다음 행동

- 각cell의 시간별 기록은 동일하게 남아 있으면 자기 자료 누락이라는 설명을 제외한다. 자기cell의 손실 비중이1/4인 것도 모든K4에서 같다. 단, 가까운 sample의 수는 독립적인 정보량이나 조건부 관계의 일치를 뜻하지 않는다.
- Tab-risk의 외부 이웃 비중이 empirical보다 작지 않다면, 입력 근접성 부족 하나를 고치는 안을 다음 추천 후보로 삼지 않는다. 반대이면 관계 차이·시간 의존과 구별하기 전까지 인과적 설명으로 채택하지 않는다.
- 자료 누락·근접성만으로 설명이 좁혀지지 않으면 현재 RCTL의 학습과 평가 차이 중 한 요소만 고정하여 비교하는 원인 구별 명세를 작성한다. 예컨대 train-mode와eval-mode에서 다른 BatchNorm 통계는 실제 코드·가까운 원문으로 필요성을 확인해야 하며, 바꾸는 것 자체를 TabICL 신규성으로 세지 않는다.

## 비용과 검증

새모델 호출·fit0, 다운로드0, 최대30초. 기존 저장 density의 합이1인지, cell 순서·소속과 전체 행 수가 맞는지 검증한다. 입력 파일은 변경하지 않는다. 측정한 배열 분석 시간만 누적 비용에 한 번 추가한다. 현재 goal은active이며106은 실제 진단과 상태 변경을 수행한progress였다. 차단 반복 횟수는 새로 시작한다.
