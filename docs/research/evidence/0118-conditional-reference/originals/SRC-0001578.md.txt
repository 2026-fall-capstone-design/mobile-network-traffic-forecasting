# 조건부 sample 비교를 연구 기여로 삼을 수 있는가

2026년 9월 26일

**시간 조건에 맞춰 sample을 비교하는 것은 필요한 설계입니다. 다만 이 원리와 사전학습 회귀 모델을 이용한 구현은 이미 선행연구에 있습니다. 따라서 현재 연구의 핵심 기여를 이 부분만으로 정하지 않겠습니다.**

이번에는 네 논문의 방법과 가정, TabPFN+CRT의 공개 코드를 확인했습니다. 실제 모델을 새로 실행한 결과는 아닙니다.

## 선행연구가 이미 해결한 부분

| 연구 | 실제로 하는 일 | 현재 연구에서의 의미 |
|---|---|---|
| TabPFN+CRT, 2026 | 사전학습 회귀 모델로 조건부 분위수를 구하고, 생성한 입력으로 같은 예측기를 다시 평가 | TabICLv2로 바꾸는 것만으로는 새로운 원리가 되지 않음 |
| Conditional Permutation Test, 2020 | 관측값을 조건에 맞는 확률로 교체하고 생성 오차의 영향을 분석 | 실제 값의 범위를 유지하면서 교체하는 방법도 기존에 있음 |
| CCMI, 2019/2020 | 조건부 sample 생성과 분포 비교를 결합하고 생성 편향을 다룸 | 무조건 섞을 때 생기는 문제와 그 보정은 이미 연구됨 |
| CMIknn, 2018 | 조건이 비슷한 sample 안에서 값을 바꿔 관계를 검사 | 최근 상태가 비슷한 sample을 매칭하는 방식은 강한 기본 대안 |

원문: [TabPFN+CRT](https://arxiv.org/abs/2603.06609v1), [Conditional Permutation Test](https://doi.org/10.1111/rssb.12340), [CCMI](https://proceedings.mlr.press/v115/mukherjee20a.html), [CMIknn](https://proceedings.mlr.press/v84/runge18a.html).

## clustering과 연결하려면 구분해야 하는 질문

**첫째는 B의 입력이 A를 예측하는 데 추가 정보를 주는지입니다.** 예를 들어 A의 과거와 시간대를 알고도 B의 현재 트래픽을 보면 예측이 더 쉬워지는 상황입니다. 조건부 검사는 이런 질문에 맞습니다.

**둘째는 A와 B의 sample을 같은 RCTL로 학습하면 좋은지입니다.** 서로 다른 지역이 같은 예측 규칙을 가지고 있다면, 같은 시각의 트래픽끼리 관련이 적어도 학습 자료를 공유할 수 있습니다. 반대로 B의 현재값이 A에 유용하더라도, B의 과거 sample을 context에 섞는 것만으로 그 현재값이 A의 입력에 전달되지는 않습니다.

따라서 조건부 검사의 점수를 곧바로 병합 점수로 사용하려면 두 질문 사이의 연결을 보여야 합니다. 여러 cell의 현재 이력을 RCTL 입력에 함께 넣는 방식은 연결이 더 직접적이지만, 이 경우에는 입력을 묶는 기존 시계열 모델과 비교해야 합니다.

## 시간 조건과 계산 비용에서 확인한 점

‘아침’이라는 입력 열을 남겨 둔 채 밤의 값을 무작위로 가져오면, 아침의 조건에 맞는 비교가 되지 않습니다. 시간·요일·이력을 반영해 교체할 값을 생성해야 합니다. 연속된 시계열의 값을 각각 독립적으로 생성하는 것과 전체 흐름을 유지하는 것도 다릅니다.

또한 사전학습 가중치를 고정해도 계산 비용은 남습니다. TabPFN+CRT의 코드는 조건부 분위수를 미리 계산하지만, 교체한 입력마다 target 예측을 다시 수행합니다. cell 쌍마다 이 검사를 반복하면 비용이 커지므로, cache가 있다는 이유만으로 저렴한 clustering 방법이라고 볼 수 없습니다. [확인한 공식 코드](https://github.com/msalem7777/tabpfn-crt/blob/c495edac3125ba2d0f104fcb7c11d3d9012bab13/tabpfn_crt/crt.py).

이번 검토를 반영하여 **조건부 sample 생성, 근접 상태 매칭, 생성 오차 보정 자체는 신규성 후보에서 제외했습니다.** 연구 방향을 선택하려면 이 도구를 통해 기존 방법의 어떤 잘못된 소속·입력·학습 결정을 바꾸고, 그 결과 실제 예측 또는 비용을 어떻게 개선하는지 보여야 합니다. 현재까지의 긍정적인 Tab 직접 예측 결과와 부족한 clustering 근거를 계속 구분하겠습니다.
