[53 계획](originals/SRC-0021782.md.txt), [취득 로그](originals/SRC-0064355.json), [일반 render 로그](originals/SRC-0064358.json), [당시 검토 범위](originals/SRC-0064359.json), [학위논문 render 로그](originals/SRC-0064363.json)는 원바이트 사본이다. [55 판단](../0052-0054-partial-observation/originals/SRC-0021824.md.txt)은 이미 보존된 사본을 재사용한다. 과거 명령·링크·예산 문구는 역사적 자료다.

학위논문 PDF·TXT·소개 페이지·3개 미리보기는 metadata로 연결한다. [공식 항목](https://dspace.networks.imdea.org/handle/20.500.12761/2071)의 논문을 받았을 때 명세의 SHA-256과 비교하면 검토 버전을 구별할 수 있다. 논문의 전체 복제·새 모델 실행·성능 재현은 이 묶음에 포함되지 않는다.

새 사본 5개·재사용 1개·외부 참조 6개다. 로그의 성공 다운로드와 실제 전체 열람을 구분한다. 학위논문 외의 telemetry 자료와 55의 전체 종합은 남아 있다.
