# 조건부 공유 비용의 보존 근거

[정리 기록](../../records/0023-0025-conditional-pooling.md)과 [출처 안내](../../sources/history-016.md)에서 원문과 주장으로 이동할 수 있다. [manifest](manifest.json)는15개 참조를 연결한다. `originals`의9개 파일은 원본과 바이트가 같고 총651,213bytes다. 기존 B1·설계 자료·RCTL 근거6개는 앞 묶음의 보존물을 재사용한다.

시작 설정·수정 marker·점수·summary와114개 수치 배열을 보존했다. 과거 코드는 정적 열람용이며 실행하지 않는다. 코드의 존재, 저장 결과의 산술 확인, 과거 전체 실행 재현은 서로 다른 증거다. 원float32 실패 코드와 콘솔은 미확인이다.

이번 범위는23과25 §1의 조건부 공유 비용이다.25 원문을 보존한 것이 recursive 예측이나 모든 문헌 주장의 검수 완료를 뜻하지 않는다. [검수 안내](../../verification/history-016.md)에 가능한 재사용과 남은 범위를 적었다.
