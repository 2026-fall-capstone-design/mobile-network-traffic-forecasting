`Patch_Index`는 저장 JSON의 `/files/N/patch`에서 사용하는 **0부터 시작하는** 번호다. `CSV_Line`은 헤더를 1행으로 세는 복원 CSV의 행 번호다. 삭제 patch에는 맨 앞에 hunk 행이 하나 있으므로 patch 자체의 행 번호와 1행 차이가 난다. CSV 안의 인용부호·항 순서·원 수치 문자열은 유지하고, 추가 열만 붙였다.

## 어떤 조건이 확인됐는가

| 항목 | 원 상호작용 CSV | 후속 PMLB 소비 코드에서 확인한 범위 |
|---|---|---|
| 자료 | PMLB 회귀 과제 이름 27개 | 그 이름으로 PMLB를 다시 불러옴 |
| 분할·seed | CSV에는 미기록. 원 생성기의 조건은 미확인 | test 20%, random_state 42의 무작위 분할 |
| 범주 인코딩 | CSV에는 미기록 | 전체 X 인코딩 후 분할 |
| 교사·패키지 판본 | CSV에는 미기록 | 코드의 기본 TabPFN v3와 선택 인자. 과거 결과의 실제 판본 증거는 아님 |
| 최종 EBM | 방법명·상호작용 목록·명목 항 수 | random_state 42, outer_bags 4, max_bins 256으로 새 적합 |
| 시간 | `Train_Time_s` 값만 있고 측정 경계·하드웨어는 미기록 | 일반 모델의 `fit`만 측정. TabPFN은 생성 호출과 `fit`을 함께 측정 |
| 비교 대상 | 7개 SPEX 지수, Baseline, RuleFit | EBM_FBII·선형·트리·XGBoost·TabPFN·PyGAM_FBII |
| 미실행·실패 | 해당 상태 열 없음. 없는 예산 행은 부재로 취급 | 소비 코드에는 예외 기록이 있으나 이를 입력 CSV의 부재 원인으로 소급하지 않음 |
| 우리 트래픽 연구 | cell·기간·UPC·RCTL 해당 없음 | 이 저장 벤치마크도 트래픽 소속 수정 실험은 아님 |

`Baseline-EBM`은 CSV에 적힌 이름을 유지했다. 읽은 CSV와 소비 코드만으로 원 생성기의 FAST 설정을 확인한 것은 아니다. 4월 논문의 방법명·설정을 이 표의 모든 행에 덮어쓰지 않는다.

## 집계의 정의

범위표의 `Feature_Count_Lower_Bound`는 항의 정수 인덱스를 0부터 시작하는 입력 열 번호로 해석해 `최대 인덱스 + 1`로 계산한다. 선택 가능한 좌표 수의 하한이며 전처리 전 원자료의 변수 수를 확정하는 열은 아니다.

방법별 승패는 **같은 데이터셋의 명목 4항**에서 FBII와 해당 baseline을 비교한다. MAE·MSE는 작을수록 유리하며 원 저장값을 실수로 읽어 엄격하게 비교했다. 서로 다른 데이터셋의 원단위 오차를 평균하지 않았다. 반복 seed의 표준오차나 유의성 검정도 계산하지 않았다.

동일 목록 검사는 데이터셋별로 수행한다. 먼저 순서를 그대로 둔 tuple 목록과 4개 오차 지표를 비교하고, 별도로 중복 횟수를 유지하면서 tuple의 순서만 정렬해 비교한다. 시간은 동일 지표 판단에서 제외한다. 이 과정은 독립 실행 여부나 수치 차이의 원인 판정을 대신하지 않는다.

인접 예산 집계는 같은 방법의 n과 n+1행이 모두 존재하고, n+1행의 마지막 항을 제거한 목록이 n행의 목록과 **순서까지 같을 때만** 센다. MSE·MAE의 증감 방향을 각각 비교한다. 중복 항을 하나 더 붙인 행도 원본의 인접 예산으로 포함되므로, 그 수를 새로운 정보 추가 횟수로 해석하지 않는다.

RMSE는 `sqrt(MSE)`와 상대오차 `1e-12`, 절대오차 `1e-9`로 대조했다. 후속 모델 결과 연결표의 `Exactly_Equal`은 허용오차 없는 실수값 일치다. 이 열이 false라고 해서 모두 실질적으로 다른 결과인 것은 아니므로 양쪽 원수치도 함께 제공한다.

## 다시 사용할 순서

1. 범위표에서 과제·방법·예산이 실제로 저장됐는지 확인한다.
2. 명세의 고정 링크와 해시로 원 CSV 판본을 확인하고 항 순서·중복을 유지한다.
3. 4항 비교는 `budget-four.csv`, 그 밖의 예산은 고정 원본을 사용한다.
4. 후속 모델 비교표를 함께 쓰면 연결표의 양쪽 값을 확인한다.
5. 새 실험을 설계할 때 원 생성 코드·실행 판본·분할·시간 범위의 공백을 먼저 기록한다.

고정 링크와 해시는 팀의 추적 경로다. 이 묶음에서 외부 서버의 모든 원본을 다시 다운로드한 것은 아니며, 원본 사본 전체의 장기 팀 보존은 별도 접근 작업으로 남아 있다.
