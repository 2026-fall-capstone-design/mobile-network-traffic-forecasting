# Ciena 검토 근거

[팀 기록](../../records/0053-ciena-telemetry.md) · [manifest](manifest.json) · [원본 목록](../../catalog/history-040-sources.jsonl) · [36개 주장](../../verification/history-040-claims.json) · [출처·표·산술 검수](../../verification/history-040-primary-check.json).

새 원문 파일을 복사하지 않고 기존 정확 사본4개를 연결했다. 세 웹 참조는 H039의 옛 URL 응답·공식 소개·공식 PDF를 같은 ID와 SHA로 재사용한다. 공식 PDF 원문은 [외부 링크](https://nctatechnicalpapers.com/wp-content/uploads/2025/09/2021-reducing-the-cost-of-network-traffic-monitoring-with-ai.pdf)로 읽을 수 있다. CI의 일반 검사는 기존 사본의 bytes와 로컬 링크를 확인한다. 외부 참조3개의 보존 응답 해시·23개 추출본·14개 렌더 및 실제 독해는 H040의 별도 검수 범위다.

작은 산술 예는 실제 원 결과나 새로운 모델 예측이 아니다. 원문·반올림 전 수치·비용 기간이 불명확한 경우 원 표시와 해석 한계를 함께 보존한다. 원본 연구 상태·예산 원장은 수정하지 않았다.
