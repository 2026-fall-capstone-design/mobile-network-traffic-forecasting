# RCTL의 구조를 수식으로 반영하면 clustering 판단이 좋아지는가?

2026-09-26 · 연구 재설계 검토102

**현재 안에는 구조 기반 kernel 점수를 추가하지 않는 것이 적절합니다.** RCTL을 실행하지 않고 구조를 반영하는 방법은 생각할 수 있지만, 지금 확인한 이론과 코드는 실제 RCTL의 공동 학습 효과를 대신 계산해 주지 않습니다. 이 단계에서 추가하면 복잡성이 늘어나면서 핵심 가정이 하나 더 생깁니다.

직전 확인에서는 같은 자료를 사용한 TabICLv2의 직접 예측이 단순 회귀보다 좋았습니다. 그러나 두 가지 K4 clustering을 비교할 때 TabICLv2가 선호한 결과와 RCTL이 선호한 결과가 달랐습니다. 그래서 이번에는 신경망 구조를 반영하는 별도 계산으로 이 차이를 줄일 수 있는지 검토했습니다.

## 무엇을 확인했습니까?

| 확인한 방법 | 할 수 있는 일 | 지금 연구에서 남는 문제 |
|---|---|---|
| 실제 신경망의 gradient 비교 | 현재 모델이 두 sample에서 어떻게 변하는지 계산 | RCTL을 실행해야 하므로 clustering 독립성 조건과 맞지 않습니다. |
| 단순 RNN의 이론적 kernel | 특정 초기화·무한폭 조건에서 RNN의 계산과 학습을 분석 | TCN·LSTM·잔차·BN을 함께 사용하는 현재 RCTL과 구조가 다릅니다. |
| 더 일반적인 구조의 kernel 이론 | LSTM·합성곱·잔차·BN까지 다룰 수 있는 틀 제공 | 초기화 시점의 극한을 안다고 작은 RCTL의 Adam·MAE 학습 결과가 정해지지는 않습니다. |

따라서 **‘LSTM을 이론적으로 다룰 수 없어서 포기한다’는 뜻은 아닙니다.** 현재 RCTL에서 필요한 연결을 확인하지 않은 상태로, 다른 모델의 결과를 대입하지 않겠다는 판단입니다. [RNTK 원문](https://arxiv.org/abs/2006.10246v4), [Tensor Programs II 원문](https://arxiv.org/abs/2006.14548v4), [공식 구현](https://github.com/thegregyang/NTK4A/tree/db79a5bd9e75e5a15548306d4770951f94883fb7).

## TabICLv2의 예측을 결합하면 해결됩니까?

TabICLv2는 각 입력의 이후 값을 추정하는 데 도움을 줄 수 있습니다. 하지만 자료를 합쳐 새 모델을 학습할 때는 sample 수, 같은 시점의 cell 사이 관계, 시간상 의존성, 학습기의 구조도 영향을 줍니다. 개별 입력에 대한 예측 분위수만으로 이 정보가 모두 주어지는 것은 아닙니다.

실제로 단순한 선형 학습기의 제곱오차조차 평균 관계와 학습 자료의 공분산이 함께 결정합니다. 현재 RCTL의 MAE는 이 단순한 식과도 다릅니다. 이 때문에 ‘좋은 Tab 예측 + 구조 점수’라는 조합 자체를 개선 근거로 쓰기 어렵습니다.

계산 비용도 추가됩니다. 직전 진단과 같은 10,752개 학습 행을 dense kernel로 표현하면 double precision 행렬 하나만 약925MB입니다. 이는 산술 저장량이며 실제 peak memory나 실행 시간은 아닙니다. 시점별 중간 계산과 후보 반복 검사도 따로 필요합니다.

## 현재 연구에 반영할 판단

1. 기존 상태별 검사에 kernel 점수를 더하는 방향은 현재 추천하지 않습니다.
2. TabICLv2의 직접 예측 우위는 긍정적 결과로 보존하되, RCTL clustering의 개선 증거와 구별합니다.
3. 다음 설계는 기존 자료에서 확인되는 유용한 결정 또는 비용 절감을 먼저 특정해야 합니다. 대리 점수를 추가하는 것으로 두 모델 사이의 연결 문제를 미루지 않습니다.

이번에는 논문2편의 관련 부분, 렌더링한6쪽, 공식 코드4파일을 확인했습니다. 원문 전체의 증명 검증이나 새 kernel 실험은 하지 않았습니다. 가까운 task-affinity workshop 논문은 공식 PDF 확보에 실패하여 서지·초록과 공개된 일부 내용만 확인한 것으로 기록했습니다. 기존 모델 실행 예산과 Word는 변경하지 않았습니다.

이 문서는 새 추천안이 확정됐다는 보고가 아닙니다. 근거가 부족한 추가 구조를 제외하고, 다음 설계가 해결해야 할 문제를 좁힌 검토입니다.
