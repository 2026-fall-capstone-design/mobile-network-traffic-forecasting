# 과거 자료의 유효성: 개발 진단 결과

2026-09-25. 16의 계획을 먼저 저장하고 `temporal_validity_diagnostic.py`를 실행했다. 원래 16 cell과 활동량 사분위별 무작위 4개씩을 더한 32 cell을 사용했다. 최근값·달력·일주기 및 주간 lag가 포함된 동일한 16개 입력이다. 이전에 관찰한 기간을 포함하므로 독립 최종 검증이 아니다.

| 작은 예측기 | 오래된 2주만 | 최근 2주만 | 누적 자료 |
|---|---:|---:|---:|
| Ridge | 0.132091 | 0.126735 | 0.115344 |
| HGB, absolute loss | 0.180521 | 0.162980 | 0.149347 |

4주 전체 cell 평균의 정규화 MAE다. 오래된 자료를 고정한 것보다 최근 자료가 유리했지만, 과거와 최근 자료를 모두 보존한 누적 방식이 두 예측기에서 더 좋았다. recent와 old는 336행으로 크기가 같고 expanding은 504~1,008행으로 더 크다. 그러므로 새 정보의 가치와 자료량의 가치를 구분한다. 이 결과로 참 조건부 분포 변화가 입증된 것은 아니다.

첫 query 주에서 recent/expanding 중 하나를 cell별로 선택하고 이후 3주에 고정 적용한 값은 Ridge 0.111333, HGB 0.120613이다. 항상 expanding인 값 0.109024, 0.118348보다 불리했다. 새로운 adaptive clustering이 필요하다는 근거로 사용할 수 없다. 모든 cell·주·날짜의 배열과 결과는 `results/temporal_validity/`에 보존했다. 해당 query 정답으로 새로운 선택 규칙을 tuning하지 않았다.

작은 회귀 fit 768회는 30.649초에 종료했고, 그중 fit/predict 측정 합은 29.814초다. 추가 TabICL/RCTL 호출은 0회다. handle 61848은 exit 0이며 재시작하지 않는다.

## 새 문헌이 바꾼 판단

- [MGSTC, arXiv 2508.08281v1](https://arxiv.org/html/2508.08281v1#S4.SS3): §4.3·Algorithm 1은 loss buffer, 짧은 memory와 historical repository로 fine-tuning/aggressive update를 전환한다. §3의 joint-distribution drift 정의에는 달력으로 설명되는 holiday/weekday 차이도 포함한다. 이 정의를 '같은 입력에서 target 관계가 바뀌었다'는 증거로 옮기지 않았다. 실제 학습 손실을 감시에 쓰므로 RCTL 독립 조건에서는 그대로 사용할 수 없다.
- [PID cellular forecasting, arXiv 2608.08332v1](https://arxiv.org/html/2608.08332v1#S3): §3·Algorithm 1은 이전 관측 오차로 다음 예측을 보정하고 §3.C는 cell별 200회 Optuna 탐색을 명시한다. Table IV는 주입한 drift 시나리오다. 고정 모델의 가중치를 바꾸지 않는 것과 최종 모델의 예측/오차에 의존하지 않는 것은 다르므로, 이 방식을 독립 clustering의 근거로 사용하지 않았다.
- [Joint clustering and QoS prediction, arXiv 2604.12903v1](https://arxiv.org/html/2604.12903v1#S3): 식 2는 예측 손실, 분포 일관성, cluster 수 penalty를 함께 최적화하고 §4는 배정과 모델 학습을 번갈아 갱신한다. 이는 QoS 분포와 simulation 자료이며 activity regression과 다르다. '변화에 맞춰 cell을 재배정하고 모델 수를 줄인다'는 발상만으로 신규성을 주장할 수 없음을 확인했다.

위 문헌들은 공식 arXiv HTML에서 해당 본문·식·알고리즘을 확인했다. 이번 파일 작성 시 추가 PDF 보관은 아직 하지 않았다. MGSTC의 drift 검정 식의 정규성 가정과 표기를 우리의 유효한 통계 검정으로 채택하지 않았다. 새 문헌의 수치 성능을 직접 재현하지 않았다.
