# 110–111 하루 주기 위치와 입력 비교 가능성 확인

2026-09-26. 기존 16개 cell의 개발 자료로 한 번씩 수행했다. 새 예측 모델 호출은 없고 RCTL의 결과를 후보 선택에 쓰지 않았다.

## 110: 시각 차이는 다음 주에도 반복되는가

앞 21일에서 24시간 평균 profile의 차이가 가장 작은 정수 이동량을 정했다. 전체 120개 쌍 중 비영 이동은 76개였고, 그중 72개는 앞 14일과 다음 7일에 따로 정한 이동량의 차이가 1시간 이내였다. 선택한 이동량을 뒤의 7일에 고정해 적용했을 때 profile의 평균 절대차는 0.486019에서 0.441194로 약 9.22% 줄었다. 개선 61쌍, 악화 15쌍, 무이동 44쌍이다.

이는 하루 평균 파형 간 차이의 감소다. 다음 트래픽값 예측 오차나 RCTL 오차가 9.22% 줄었다는 뜻이 아니다. 단순 이동량이 반복된다는 첫 조건만 확인했다.

개별 쌍에서 좋은 이동량을 골라도 모든 관계가 하나의 좌표계에 들어맞지는 않았다. 560개 삼각형 중 정확한 일관성은 232개, 오차 1시간 이내는 458개였다. cluster 전체에 각 cell의 고정 좌표를 부여하는 단계가 필요하며, 이 문제 자체는 기존 joint alignment/classification 연구에 있다.

## 111: 실제 예측을 비교할 입력이 있는가

110의 앞 21일 이동별 제곱차를 재사용해 cell마다 donor 2개를 정했다. 각 방향에서 무이동과 좋은 비영 이동 2개를 비교 대상으로 고정했다. 이때 query의 정답은 읽지 않았다.

| 항목 | 결과 |
|---|---:|
| 처음 정한 방향 있는 비교 | 32 |
| 세 이동 조건의 공통 입력을 충분히 확보한 방향 | 14 |
| 비교 가능한 대상 cell | 11 |
| 32개 중 profile의 최선 이동이 0이 아닌 방향 | 13 |
| 14개 중 profile의 최선 이동이 0이 아닌 방향 | 5 |
| 후속 세 이동의 교차 예측 행 | 2,421 |
| 같은 query의 자기 cell 기준 예측 행 | 675 |
| 후속 추론의 최대 합계 | 14 context / 3,096 query 행 |

query는 168개 시간 중 고정한 64개다. 앞뒤 32개씩 나눠 양쪽에 공통 입력이 각각 16개 이상 남는지를 검사했다. 32개 방향 모두의 공통 query는 2,048개 중 1,222개였다. 통과한 14개에 대해 세 이동별로 807개씩 예측하므로 교차 행은 2,421개다. 자기 기준 675개는 대상 cell별 query 합집합이므로 같은 query를 중복 호출하지 않는다.

통과한 방향만 새로운 도시나 전체 cell의 대표라고 보지 않는다. 고정된 입력 반경의 교집합이 부족해 18개 방향을 제외했으며, 결과를 통과시키기 위해 반경을 늘리지 않았다. 남은 14개 중 profile상 비영 이동은 5개이므로 큰 시차를 가진 cell 전반의 유용성도 아직 말할 수 없다.

## 다음에 판단할 것

단순 시각 보정, TabICL이 고른 시각 보정, Ridge/HGB가 고른 시각 보정을 같은 query에서 비교한다. 셋 모두 최근 실제 lag를 그대로 사용한다. 먼저 앞 절반에서 선택한 보정이 뒤 절반 예측에 도움이 되는지, 이어 다른 고정 예측기로 평가해도 같은 선택이 유용한지 살핀다. TabICL의 오차가 작다는 이유만으로 clustering과 RCTL의 개선을 선언하지 않는다.
