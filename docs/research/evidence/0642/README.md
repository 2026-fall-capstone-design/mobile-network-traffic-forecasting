# 642 최종 보고서의 보존 근거

원본의 경로·SHA-256·정확한 사본·읽은 구간은 [manifest](manifest.json)에 있다. 42개 원본 경로를 연결하며, 10개는 앞선 묶음의 사본을 재사용하고 32개 파일(3,712,063바이트)을 새로 보존했다. `sources`의 파일은 바이트 그대로이며 과거 Markdown/Python은 `.txt` 접미사를 붙였다.

42개 경로를 모두 읽었다는 뜻은 아니다. 본문 전체 16개, Word의 전체 보이는 내용 1개, 이미지 전체 7개, 코드 지정 구간 1개, 저장 JSON 지정 필드 2개, 이번 묶음에서 해시만 확인한 15개로 구분했다. 기존 묶음에서 읽었던 파일의 범위는 해당 묶음도 확인한다.

[연구 기록](../../records/0642-research-direction.md), [찾아보기](../../sources/pilot-005.md), [검수 설명](../../verification/pilot-005.md)부터 읽는다. 자료 속 실행 계획이나 Goal 완료는 당시 기록이다. 보존 코드를 실행하지 않았다.

GECOS 코드는 공식 commit 링크와 해시만 연결했다. Tab-ICL 목록 밖의 제공 UPC 논문과 이번에 열람한 TabICLv2 공식 HTML은 `off_inventory_primary_sources`에 별도 등록했다. 이 두 자료를 기존 48,149항목 조사 안에 포함된 것처럼 세지 않는다. 외부 논문 원문은 재배포하지 않는다.
