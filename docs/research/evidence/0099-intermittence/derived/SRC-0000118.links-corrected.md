# 간헐적 트래픽 방향을 현재 연구에 추가할 수 있는가

2026-09-26 추가 검토. 현재의 clustering → RCTL 구조에 **트래픽 발생 여부와 발생량을 나누는 모듈은 추가하지 않는 것이 적절합니다.** 관련 문제가 존재하는 것과, 현재 데이터에서 새 clustering 연구가 필요하다는 것은 구별해야 합니다.

먼저 원문의 희소성 수치를 바로잡았습니다. ISP foundation model 논문의 99.94%는 인용한 데이터 논문에서 ‘빈 구간이 있는 IP 시계열의 비율’입니다. 전체 시점의 99.94%가 0이라는 뜻이 아닙니다. 데이터 논문에는 실제 관측 장비의 장애도 기록되어 있습니다. 따라서 빈 기록을 모두 통신이 없던 시간으로 처리하여 연구 문제를 정할 수는 없습니다. [CESNET 데이터 원문·Table 6](https://pmc.ncbi.nlm.nih.gov/articles/PMC11865510/), [ISP 논문 v2](https://arxiv.org/html/2511.17529v2).

또한 대상이 다릅니다. Milan DenseNet 논문의 0이 많은 자료는 SMS·통화 채널이며, 이를 1시간으로 집계해 예측했습니다. 현재 확인한 Internet activity와 동일한 분포라고 볼 수 없습니다. 기존 진단 파일에서 처음 35일의 1시간 Internet activity, 10,000 grid 전체의 0 비율은 0.01975%입니다. 이는 가공 자료의 관찰이며 원시 네트워크 전체의 특성은 아닙니다. [Citywide 원문 §II·IV.A](https://chuanting.github.io/assets/pdf/ieee_cl_2018.pdf).

| 비교할 선행연구 | 이미 해결하는 부분 | 현재 제안에 필요한 추가 근거 |
|---|---|---|
| 5G beam GRU-MTL, 2025 | GRU가 트래픽량과 활동 여부를 함께 학습하고, 활동 분류 결과를 회귀값에 곱합니다. | cell을 어떤 기준으로 나누면 공동 학습이 개선되는지에 관한 별도 근거가 필요합니다. beam 결과를 cell clustering 효과로 해석할 수 없습니다. |
| Deep Renewal, 2021 | 발생 간격과 양의 수요량을 모델링하고 여러 시계열에서 LSTM을 공유합니다. | 발생 간격·크기·공유 학습의 도입 자체를 신규성으로 제시할 수 없습니다. |

출처: [beam 연구 §3.3·식5–10](https://www.frontiersin.org/journals/communications-and-networks/articles/10.3389/frcmn.2025.1658461/full), [Deep Renewal §4.3](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0259764).

평가 목적도 먼저 정해야 합니다. 같은 입력에서 실제 트래픽이 90% 확률로 0, 10% 확률로 100이라면 MAE에 맞는 예측은 0이고 MSE에 맞는 예측은 10입니다. 이 설명용 예에서 0을 예측했다는 사실만으로 실패라고 말할 수는 없습니다. TabICLv2가 추정한 관계도 최종 RCTL의 예측 목적과 연결되어야 합니다.

현재 확보한 근거로는 간헐성 모듈이 문제와 계산만 늘릴 가능성이 큽니다. **현재 자료에서 실제 손해가 확인되고, 기존 분리형 예측보다 유용한 cell 공유 결정을 만들 수 있을 때만 이 방향을 다시 검토하겠습니다.** 이번에는 새 모델을 실행하지 않았고, 누적 예산과 기존 결과를 유지했습니다. 최종 연구 방향을 확정한 문서는 아닙니다.
