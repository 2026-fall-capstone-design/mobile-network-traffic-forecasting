# 82. 간헐적인 트래픽을 별도 문제로 삼을 근거의 확인

2026-09-26. 새 모델 실행 전 문제의 실재성부터 확인한다. 29–32의 시간 해상도, 51–55의 결측·관측 비용, 66–71의 피크 손실 검토와 구별한다. 기존 covariance·residual clustering을 새 후보로 다시 제시하지 않는다.

## 이번에 확인할 질문

트래픽이 실제로 발생하지 않은 시간과 양의 트래픽이 발생한 시간이 섞이는 현상이 기존 cell의 연속값 예측에 중요한 손해를 남기는가? 원자료의 미관측, 누락된 행, 전처리로 채운 0을 실제 무통신 상태와 구별할 수 있는가? 이 문제가 확인되어야 발생 여부와 발생량을 구별하는 판단을 검토할 수 있다.

기존 ISP foundation model 논문은 재사용한다. 새 원문은 citywide DenseNet 논문, beam-level multi-task 논문, 필요한 원 데이터 논문 또는 간헐 시계열의 가장 가까운 방법 등 최대 네 편으로 제한한다. 초록·검색 결과와 본문을 구분한다. 원문에서 보고한 희소성 비율의 분모, 실제 대상 단위, 전처리, 평가 손실 및 단순 대안과의 비교를 확인한다. 새 PDF 합계 15 MB 이내, 대규모 원자료 다운로드 없음, 외부 코드 실행 없음.

## 새 결정의 진입 조건

1. IP 주소·beam의 실패를 cell의 실패로 그대로 옮기지 않는다. 현재 확보한 Milan 자료의 전처리와 관측 단위를 먼저 대조한다.
2. 발생/양의 크기를 분리하는 hurdle·renewal·Croston 계열은 알려진 방법이다. 이 분리, zero 비율 또는 분위수 사용 자체를 신규성으로 세지 않는다.
3. TabICLv2의 회귀 출력이 0의 확률 질량을 정확히 제공한다고 가정하지 않는다. 단순한 0 빈도·계절 기준과 구별되는 판단이 무엇인지 먼저 명시한다.
4. 새로운 판단이 cell 소속 또는 실제 자료로 학습하는 RCTL에 전달되는 위치가 없으면 후보를 채택하지 않는다. 기존 global RCTL과의 비교를 생략하지 않는다.
5. 직접 근거가 없는 희소 구간을 인위적으로 만들거나 좋은 cell만 골라 성공을 구성하지 않는다.

이번 파일은 원문·전처리·기호적 논리 검토 계획이다. 새 데이터 통계, 단순 모델 fit, TabICL 추론, RCTL fit/forward를 허용하지 않는다. 필요한 수치 확인은 별도 계획을 먼저 고정한다. 남은 예산은 TabICL 11 context·20,640 query행이며 RCTL 새 fit은 0회이다. 누적 비용 원장은 수정하지 않는다.

## 결과별 행동

- 실제 무통신과 관측 누락을 구별할 직접 근거가 없으면 해당 자료로 간헐성 연구를 추천하지 않는다.
- 문제는 있으나 기존 분리형 예측·multi-task 학습과 같은 결정이면 새 구조를 추가하지 않는다.
- 구별되는 결정과 실제 이득 경로가 남을 때만 최소 확인 계획으로 진행한다. 작은 직접 예측 이득을 clustering 성공으로 대체하지 않는다.

최종 연구 방향·Word의 완료로 간주하지 않는다. 반복적인 goal 입력 안내 없이 현재 검토 결과만 진행 기록에 남긴다.
