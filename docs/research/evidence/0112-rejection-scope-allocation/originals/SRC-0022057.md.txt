# 85 기각 범위 재검토와 자료 배분 결정 확인 계획

2026-09-26. 직전84는 수치·완료 조건을 연결한 중간 산출물과 전페이지 검수를 완료한 progress다. 최종 연구 방향은 미확정이다. 이전 후보의 전체 분야 불가능성을 입증한 것으로 확대하지 않는다.

## 먼저 확인할 판단

35·38·40·47·62·76·80의 직접 결과와 논리적 반례를 다시 읽어, 특정 구현 실패, 선행 원리와의 동등성, 현재 범위의 미확인을 구별한다. 16cell/K4/hourly의 부정 결과로 원 UPC의 10000cell/10분/K2 결과를 부정하지 않는다. 반대로 작은 실험의 한계만으로 탈락한 후보를 추천 상태로 복원하지 않는다.

## 제한해서 살필 새 결정

40은 cluster가 작아질 때 외부 자료를 중요도 가중치로 빌리는 방향을 다뤘다. 정확한 joint ratio는 어떤 최종 loss에도 목적을 연결하지만, 이는 기존 IW-MTL의 원리이며 여러 모델이 같은 자료를 처리하면 비용이 늘어난다.

이번에 따로 확인할 것은 **총 실제 sample 처리량을 고정하면서 cluster 사이에 학습 sample을 확률적으로 배분하는 결정**이다. 원래의 cell 예측 소속, 실제 관측 target, RCTL core를 유지한다는 가정 아래, 이 결정이 기존 importance sampling 또는 mixture 책임도의 구현과 정확히 같은지 먼저 확인한다. 회귀 TabICLv2의 예측을 정답으로 바꾸는 안은 다루지 않는다.

1. hard group label과 joint posterior responsibility의 Rao–Blackwell 관계를 기호적으로 확인한다. 모집단의 iid mixture 가정과 실제 시간·cell 의존을 구별한다.
2. 여러 RCTL에 weighted loss를 모두 계산하는 방식과 sample당 하나의 RCTL만 선택하는 방식을 구별한다. 추가 확률 배분이 variance를 다시 늘리는지, 무조건적 효율 우위가 있는지 살핀다.
3. 최근 source selection, multi-task weighting, expert routing 원문을 검색한다. 기존40의 Bickel2008·Kumagai2021·Cherkaoui2026 자료와 겹치면 정확히 동등하다고 기록한다. 새로운 명칭이나 회귀 teacher 사용만으로 신규성을 주장하지 않는다.

## 실행과 중단 규칙

이번 범위는 저장 자료 읽기, 원문 조사, 기호 대수 확인이다. 새 Tab/RCTL/단순모델/숫자 pilot은 시작하지 않는다. 상한과 원장 byte 불변을 유지한다. 후보당 새 대규모 학습을 숨기지 않는다.

- 기존 가중 자료 공유와 같은 기대 목적이고, 총 처리량 제약이 알려진 중요도 sampling으로만 구현되면 새 후보로 채택하지 않는다.
- 학습 표본의 정보 이득이나 TabICLv2의 역할이 없는 단순 routing이면 중단한다.
- 현재 자료의 직접 손해와 연결되는 별도의 결정 이득이 확인되어야 다음 최소 확인 계획을 만들 수 있다. 기호적 variance 감소만으로 RCTL 성능을 확인했다고 하지 않는다.

사용자에게 보낸 실제 운영 제약 질문은 미응답이다. 임의의 privacy/latency 제약을 가정하지 않으며, 이 응답이 없다는 사실만으로 goal을 blocked로 표시하지 않는다.
