# 86 소속 고정 이후 학습 공유의 범위 검토

2026-09-26. 직전85는 고정 처리량 재추출의 실행 가능성과 기각 범위를 바로잡은 progress다. 최종 추천은 미확정이다. 이번에는 새 점수나 sample 배분을 만들기 전에, 확인된 자료 분할 손해를 최종 학습 방식으로 줄이는 선택을 살핀다.

## 비교할 서로 다른 결정

1. 각 cluster의 RCTL을 독립 초기화하고 해당 자료만 학습한다.
2. 소속을 고정한 뒤 전체 자료로 RCTL을 학습하고, 이를 복사하여 각 cluster에서 미세조정한다. 이후 파라미터는 독립이다.
3. 소속을 고정한 뒤 RCTL의 일부 파라미터를 실제로 공유하여 함께 학습하고, 나머지는 cluster별로 유지한다.

2와3은 다르다. 처음 가중치만 같다고 학습 과정의 자료 공유가 계속되는 것은 아니다. 최종 예측 경로에 TCN·LSTM·이중 잔차를 유지하는지, 학습·메모리·추론 비용이 실제로 줄어드는지 따로 살핀다. 새로운 RCTL을 실제로 학습하거나 head·BN만 추가 적합하지 않는다.

## 먼저 읽을 기존 근거와 추가 조사

- 28의 ECAI2025 Type-II global 가중치 복사·고정·추가층, 38의 finite-learning 판단, 78의 task representation 및 shared backbone을 먼저 대조한다.
- global–local forecasting, multi-task regularization, 최근 grouped parameter sharing의 원문에서 공유 단위와 소속 결정의 학습기 의존성을 확인한다. 기존 원문을 우선 사용한다.
- TabICLv2가 필요한 새 결정을 분명히 적지 못하면 모델 공유만을 새 후보로 추천하지 않는다. 완전한 성능 보장이 없다는 사실만으로 불가능하다고 판단하지도 않는다.

## 실행 경계

이번 단계는 원문·코드 읽기와 기호적 비용·연결 검토다. 새 모델·수치 pilot은 0회로 제한한다. RCTL 새 fit0, Tab 잔여11context/20640행, 원장 hash를 유지한다. 기존83의 운영 제약 질문에 답이 없다는 이유로 제약을 발명하지 않는다. 웹 검색 인증 오류를 우회하기 위한 자격 증명 변경은 하지 않으며 공개 원문 직접 접근이 가능하면 그것을 사용한다.

최종 산출물은 새로운 추천안이 성립하는지의 결정과 정확한 이유다. 알려진 transfer learning·parameter tying에 Tab 명칭만 더하면 이번 후보는 채택하지 않는다. 그 경우에도 학습 방식 변경이 현재 범위에 가능한지와 어떤 증거가 부족한지를 분리하여 남긴다.
