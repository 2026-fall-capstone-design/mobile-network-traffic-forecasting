# RCTL 학습 공유와 비용에 관한 검토

2026년 9월 26일. cell을 clustering한 뒤에도 학습 정보를 공유하면 자료 분할의 손해를 줄일 수 있는지 검토했습니다. **가능한 학습 대안이지만, 공유 구조를 추가하는 것만으로 신규성이 생기지는 않습니다.**

## 무엇이 달라지는가

지금까지의 작은 RCTL 비교에서는 cluster마다 모델을 따로 초기화하고 해당 cluster의 자료로 학습했습니다. 다른 cluster가 관측한 정보는 학습 과정에서 전달되지 않습니다. 이 조건에서 cluster별 모델은 global 모델보다 훈련 오차가 작고 validation 오차는 컸습니다.

이를 바꾸는 방법은 여러 가지이며, 서로 구별해야 합니다.

| 학습 방식 | 실제로 공유되는 것 |
|---|---|
| global 모델을 학습한 뒤 복사하여 각각 미세조정 | 출발점이 되는 가중치. 이후 모델들은 각자 달라집니다. |
| global 모델의 일부 층을 고정하고 cluster별 부분만 학습 | 고정된 공통 표현. cluster별로 조정할 수 있는 범위는 줄어듭니다. |
| 일부 가중치를 함께 갱신하고 나머지는 cluster별로 학습 | 여러 cluster의 자료가 공통 부분을 계속 바꿉니다. |

clustering 소속을 먼저 확정한다면, 후단에서 이런 학습을 하는 것이 자동으로 독립성 위반이 되지는 않습니다. RCTL의 학습 결과를 다시 소속 결정에 사용하는 경우와 구분해야 합니다.

## 선행연구가 이미 다룬 부분

ECAI 2025의 *Boosting Global Time Series Forecasting Models*는 global 모델의 일부 층을 복사·고정하고 cluster별 보완 층을 학습합니다. 다만 이 연구의 clustering은 최종 예측기의 residual과 validation 결과를 이용합니다. 우리의 독립성 조건과 다른 부분은 소속을 결정하는 과정입니다. 공통 표현과 cluster별 학습을 결합하는 것 자체는 이미 제시되어 있습니다. [원문 §3.2·Algorithm 1](https://kar.kent.ac.uk/111229/1/FAIA-413-FAIA251157.pdf)

*Clustered Multi-Task Learning: A Convex Formulation*도 전체 task의 공통 부분, cluster 사이 차이, cluster 내부 차이에 서로 다른 규제를 줍니다. 완전한 공유와 완전한 분리 사이의 수준을 조절한다는 원리도 새로운 발상은 아닙니다. 이 연구의 선형 모델에 관한 결과를 RCTL의 비선형 구조에 그대로 적용하지는 않았습니다. [버전 고정 원문](https://arxiv.org/abs/0809.2085v1)

## 저장량과 연산량은 다르게 줄어든다

공통 가중치를 하나만 저장하면 모델 저장량은 줄어듭니다. 그러나 A와 B의 입력이 다르면 공통 층도 각각의 입력을 계산해야 합니다. 따라서 가중치를 공유한다는 이유만으로 예측 연산이 한 번으로 줄어들지는 않습니다.

학습도 마찬가지입니다. 기존 cluster별 RCTL이 각자 자기 sample을 처리하여 전체 처리량이 N개였다면, 공동 학습의 처리량도 N개일 수 있습니다. 모델 수가 줄었다는 이유만으로 학습량이 같은 비율로 줄었다고 해석하면 안 됩니다. global 모델을 먼저 준비한다면 그 학습 비용도 포함해야 합니다.

## TabICLv2에 필요한 역할

학습 공유는 자료 분할의 손해를 줄일 수 있는 방법입니다. 하지만 단순 clustering이나 cell ID를 사용하는 global 모델도 이런 방법을 이용할 수 있습니다. **같은 학습 공유 조건에서, TabICLv2가 다른 방법보다 더 유용한 cell 소속을 정해야 연구의 기여가 됩니다.**

현재 확인된 TabICLv2의 직접 예측 우위만으로는 어떤 RCTL 층을 공유해야 하는지, 어떤 cell을 같은 모델에 넣어야 하는지가 결정되지 않습니다. 따라서 이번 검토에서는 학습 공유를 새 추천안으로 채택하지 않았습니다. 독립 초기화로 확인한 기존 결과의 적용 범위를 명확히 하고, 후단 학습 방식을 비교할 때 지켜야 할 조건을 정리했습니다.

새 모델 학습·추론은 실행하지 않았습니다. 기존 누적 실행 상한과 검수된 중간 Word 문서는 유지했으며, 최종 추천 방향은 아직 미확정입니다.
