# 86 소속 고정 이후 RCTL 학습 공유의 판단

2026-09-26. 86계획에 따라 원문과 현재 RCTL 구현을 읽었다. 새 모델 학습·추론·수치 pilot은 없다. 기존 partition의 실패를 전체 연구의 불가능성으로 확대하지 않되, 학습 공유라는 알려진 변경만으로 추천안을 복원하지 않는다.

## 1. 같은 것으로 취급하면 안 되는 네 방법

| 방법 | 다른 cluster의 자료가 영향을 주는 경로 | 원래 cluster별 독립 RCTL과의 차이 |
|---|---|---|
| 독립 초기화·독립 학습 | 없음 | 기존 비교의 기준 |
| global 학습 후 복사·미세조정 | 초기 파라미터를 통해 전달됨 | 이후에는 각 cluster가 독립적으로 변함. global 준비 비용도 필요 |
| global 층을 복사·고정하고 cluster별 층 학습 | 고정된 공통 표현을 통해 전달됨 | 학습 가능한 함수군·파라미터 수가 달라짐 |
| 일부 파라미터를 실제로 공유하며 공동 학습 | 공유 파라미터에 여러 cluster의 gradient가 반영됨 | 어느 부분을 공유할지와 cluster별 부분을 명시해야 함 |

처음 가중치가 같은 것은 학습 중 계속 공유한다는 뜻이 아니다. 복사한 가중치를 단순 평균하는 것, 같은 파라미터 객체를 함께 갱신하는 것, 고정하는 것도 각각 다르다. 소속을 미리 고정하고 이런 학습을 하는 것 자체는 ‘RCTL 결과를 clustering에 사용하지 않는다’는 조건을 자동으로 위반하지 않는다.

## 2. 원문으로 확인한 가장 가까운 원리

### 2.1 ECAI 2025: global 표현과 cluster별 보완

Ren·Wu의 *Boosting Global Time Series Forecasting Models: A Two-Stage Modelling Framework* §3.2, Figure1, Algorithm1을 다시 읽었다. global 모델의 처음 L−1개 층을 복사·고정하고, cluster별 층과 입력을 결합한 보완 모듈을 붙인다. cluster 수·구성은 최종 예측기의 residual과 validation 손실을 이용한다. 단순히 global 초기값에서 전층을 다시 미세조정하는 방법으로 설명하면 부정확하다.

이 원문은 공통 표현을 유지하면서 cluster별 학습을 추가하는 방향의 직접 선행연구다. 우리의 독립성 조건에서는 학습된 RCTL residual로 소속을 정하는 부분을 그대로 사용할 수 없다. 그러나 이것은 **후단 학습 공유까지 금지한다는 뜻이 아니다.** 소속을 먼저 확정하는 다른 절차와 결합하는 것은 가능하며, 그 다른 절차의 실익이 별도로 필요하다. [기관 공개 출판본](https://kar.kent.ac.uk/111229/1/FAIA-413-FAIA251157.pdf)

### 2.2 Jacob·Bach·Vert: global·cluster·task의 공유 강도

*Clustered Multi-Task Learning: A Convex Formulation*, arXiv:0809.2085v1, §2 식1–11과 §3 식12–16·3.2를 읽었다. 선형 task의 평균 가중치 크기, cluster 사이 차이, cluster 내부 차이에 서로 다른 규제를 주며, 모르는 소속은 joint 최적화의 convex relaxation으로 다룬다. 모든 task를 완전히 같게 하거나 완전히 분리하는 선택 사이의 공유 수준이 이미 명시되어 있다.

따라서 ‘전체의 공통 부분을 남기고 cluster별 차이를 학습한다’는 원리는 새롭지 않다. 다만 이 선형 규제의 성질을 RCTL의 비선형 hidden 층에 그대로 옮기는 것도 맞지 않는다. 논문의 모집단·실험 결과가 우리 traffic/RCTL 효과를 검증한 것은 아니다. [버전 고정 원문](https://arxiv.org/abs/0809.2085v1)

기록: arXiv 메타데이터와 버전은2008-09-11/v1이다. 제공 PDF 첫쪽의 조판 날짜는2018-10-22로 표시된다. 이를 새2018연구나2026후속연구로 해석하지 않는다. 이번에 원문 전체의 모든 증명·실험을 재현하지 않았다.

## 3. 현재 RCTL에서 공유란 정확히 무엇인가

`rctl_torch.py`의 각 block은 causal convolution, BatchNorm, convolution, 잔차, LSTM, 추가 잔차 순서다. 여섯 block과 중간 skip, 입력에서 마지막으로 가는 shortcut, 최종 dense를 사용한다. TCN과 LSTM을 서로 독립인 두 예측기처럼 떼어 ‘공통 장기 모델·개별 단기 모델’이라고 설명해서는 안 된다.

각 cluster의 예측 경로에 같은 block 구성을 남기면서 일부 파라미터를 묶는 설계는 가능하다. 그러나 다음이 구체적으로 정해져야 한다.

- 공유 범위: 앞 몇 block, 모든 core, 또는 특정 층의 파라미터인가.
- BatchNorm: 학습 가능한 affine 계수와 running 통계가 각각 공통인가, cluster별인가.
- final shortcut과 dense: cluster별로 다른가.
- 공동 학습: cluster 크기가 다를 때 sample 비중과 loss 가중은 무엇인가.

이는 구현 항목이지 이번에 채택한 새 설계가 아니다. 임의로 층 하나를 고르거나 TabICLv2의 출력 차이만으로 필요한 RCTL 공유 층을 알았다고 하지 않는다. 같은 입력–출력 함수를 표현하는 신경망도 hidden 표현·파라미터는 다를 수 있다. 반대로 RCTL의 층별 학습 결과로 소속을 조정하면 원래의 clustering 독립성 조건이 달라진다.

## 4. 비용을 분리해서 판단한다

아래는 실행 시간이 아닌 기호적 작업량이다. 각 cell의 서로 다른 입력을 하나의 담당 모델에 넣는 현재 scalar 예측을 가정한다. 모든 모델은 같은 구조·입력 길이를 사용한다.

- 독립 모델 K개의 파라미터가 각각 P이면 저장량은 KP다.
- 공통 파라미터 P_s와 cluster별 파라미터 P_c이면 P_s+K P_c다. private BatchNorm buffer와 optimizer 상태는 별도다.
- N개의 서로 다른 입력을 예측하는 연산은 대략 N(C_s+C_c)다. 가중치를 공유해도 서로 다른 입력에 대한 feature 계산이 자동으로 한 번이 되지는 않는다.
- 한 번의 전체 학습 순회에서 독립 cluster들이 각각 자기 sample만 처리해 합계 N개를 처리했다면, 공동 학습도 N개를 처리할 수 있다. 따라서 독립 모델 K개였다는 이유만으로 학습 forward/backward가 KN에서 N으로 줄었다고 주장하면 안 된다.
- global 모델을 먼저 학습한 뒤 복사하여 미세조정하면 global 준비 비용이 추가된다. 더 적은 미세조정 epoch로 보상하는지, 여러 후속 학습에 재사용하는지는 실제 측정이 필요하다.

모델들이 **동일 입력의 같은 공통 표현**을 여러 head에 쓰는 경우에는 공유 계산의 이점이 따로 생길 수 있다. 그러나 이는 현재의 서로 다른 cell별 입력을 하나씩 담당 모델에 보내는 조건과 다르며, 81의 공동 입력·다중 출력 문제와 구분한다.

## 5. TabICLv2를 붙인 뒤에도 남는 질문

공통 학습은 이미 관찰한 자료 분할 손해를 줄일 가능성이 있다. 그렇다고 TabICLv2가 정한 소속이 필요한 이유가 자동으로 생기지는 않는다. 전체 shared core와 cell ID·단순 group·cluster별 head를 사용하는 대안도 같은 혜택을 받을 수 있다.

현재 확인된 Tab의 직접 예측 우위는 ‘다음 트래픽을 더 잘 추정했다’는 증거다. 어느 RCTL 층을 함께 학습해야 하는지, 어떤 cell 조합이 같은 파라미터를 공유해야 하는지, 공유 강도가 어느 정도여야 하는지에 대한 증거가 아니다. 출력 예측 거리를 층 공유 점수라고 이름을 바꿔 이 간극을 없앨 수 없다.

최소한 다음 차이가 필요하다. **같은 공통 학습 조건에서 단순한 소속 결정이 놓치는 손해가 있고, TabICLv2의 정보가 이를 줄이는 다른 소속을 선택해야 한다.** 이전 독립 RCTL 결과만으로 이 조건이 성립하거나 성립하지 않는다고 확정할 수 없다. 하지만 현재 이 직접 근거가 없으므로 새 모델 학습을 시작할 후보로 올리지 않는다.

## 6. 결정과 근거 범위

공통 초기화·고정 표현·부분 파라미터 공유는 범위 안에서 검토할 수 있는 학습 대안이다. 비용 때문에 불가능하거나 독립성 위반이라는 이유로 일괄 기각하지 않는다. **이번 형태를 새로운 연구 방향으로 추천하지는 않는다.** 알려진 학습 공유 원리와 Tab을 사용하는 새로운 결정의 차이가 아직 없다.

기존 비교의 independent-from-scratch라는 조건은 명시할 필요가 있다. 원 UPC의 이득을 검토할 때와 새 알고리즘을 제안할 때는 이 학습 조건을 맞추어야 한다. 그렇다고 이전29회 결과를 취소하거나, 비교가 불완전하다는 이유로 실패 후보를 성공으로 바꾸지는 않는다.

이번 공개자료 수집은 arXiv 원문1편14쪽/184,537bytes와 Crossref 메타데이터·공식 페이지다. CVPR2020의 추정한 개별 URL은404였고, day=all index는 HTTP200이지만 내부적으로 DATE 오류를 반환했다. 이를 논문 전문 확보로 세지 않는다. ‘Regularized multi-task learning’ 등의 Crossref 결과는 metadata까지만 확인했으므로 원리 검증 근거로 쓰지 않는다. BeautifulSoup은 설치되어 있지 않아 해당 추출 명령은 실패했고, 기존 텍스트와 표준적인 파일 읽기를 사용했다. 환경을 변경하지 않았다.
