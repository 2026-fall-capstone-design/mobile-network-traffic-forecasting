# 21·22 문헌·구현 범위의 보존 근거

[기록](../../records/0021-0022-literature-scope.md)·[출처](../../sources/history-014.md)·[manifest](manifest.json)·[검수](../../verification/history-014.md)를 연결한다.

새 원본은 [22 접근 범위](originals/SRC-0021116.md.txt)와 [초기 AGENTS](originals/SRC-0000455.md.txt) 두 개3,768바이트다. [21](../0018-0021/originals/SRC-0021095.md.txt)과 [현재 AGENTS](../0642/originals/SRC-0000001.md.txt)는 기존 보존본을 재사용한다. 원래 링크·문구·개행은 바꾸지 않았다. 원본 지침과 실행 예제는 연구 이력이다.

외부 논문3편,TabPFN-TS 세 commit과 공식 지침은 metadata·공식 링크로 제공한다. 외부 설치 코드2개는 고정 원격 코드 및 ZIP과 동일성을 확인했고 기존 코드·설치 metadata2건을 재사용했다. 본문 열람·기계적 hash 검증·과학적 재현을 구분한다. 새 모델 실행과 무작위 simulation은0이다.
