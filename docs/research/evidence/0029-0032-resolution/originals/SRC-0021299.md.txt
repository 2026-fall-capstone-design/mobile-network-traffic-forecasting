# 10분 자료 접근 경로의 제한된 확인

2026-09-25. 29에서 남긴 HTTPError의 실제 상태 코드를 확인하고, 10분 자료의 작은 공개 부분집합을 확보할 수 있는지 조사한다. 원본 해상도 자체를 연구 신규성으로 내세우지 않는다.

## 범위와 예산

- 기존 Harvard 첫날 파일 API의 HEAD 응답과 파일 metadata를 각각 한 번 확인한다. HEAD는 데이터 본문을 읽지 않으며, metadata는 최대 256 KiB만 읽는다.
- 오류가 나면 상태 코드·응답 host·Content-Type만 저장한다. 임시 서명 URL, 쿠키, 인증 정보는 기록하지 않는다. 서버가 인증·사용 제한을 요구하면 우회하지 않는다.
- 모델 실행과 새 RCTL 학습은 없다. 원본 일별 파일 전체를 내려받지 않는다.
- 공개 대체본은 저자·배포자 README, 변환 코드, 자료 크기, 시간 간격, cell 식별자 보존 여부를 먼저 확인한다. 10분 자료를 hourly 자료로 오인하지 않으며, 시뮬레이션이나 보간 자료를 원본으로 표시하지 않는다.
- 데이터 내용 확인이 필요하면 별도로 범위와 읽기 상한을 고정한다. 현재 단계는 연구 가설을 통과시키는 성능 실험이 아니다.

## 결과별 행동

1. 정상 metadata와 부분 접근이 확인되면, 선택 cell의 완전한 시계열을 작게 얻을 경로를 구체화한다.
2. 접근이 제한되면 공개 대체본의 출처와 전처리를 확인한다. 동일한 실패 요청을 반복하지 않는다.
3. 작은 10분 자료를 확보하지 못하면 현재 hourly 근거의 적용 범위를 유지한다. 자료 부재로 10분 예측에서의 효용을 단정하지 않는다.

## 접근 결과와 대체 자료 확인 범위

Harvard 오류 메시지는 guestbookID 96에 대한 응답이 있어야 다운로드할 수 있다는 내용이다. 이를 우회하거나 사용자 정보를 대신 제출하지 않는다. 파일 metadata는 unrestricted로 표시되어 있으나 다운로드 절차는 별개다.

공개 GitHub 프로젝트 `Yunis-konda001/Milan-mobile-traffic-forecasting`의 commit `6042fb01b0ae6c4ec2e2942d171186d5d6517349`에서 cell 4159, 4556, 5161의 CSV를 찾았다. README와 notebook 코드의 다운로드 hash를 확인하고 자료 생성 부분을 읽었다. 원본의 internet 열을 cell·timestamp별로 합산하여 저장하며, 모델 입력용 결측 보완은 CSV 저장 후 수행한다. 원 데이터 배포자의 공식 부분집합은 아니다. cell 5161은 두 달 전체에서 활동량이 최대인 cell을 고른 것이므로 모집단 대표성이나 순수한 사전 선정 표본으로 취급하지 않는다.

다음 확인은 세 CSV 총 1.5 MB 이내 다운로드, Git blob hash 일치, timestamp·cell·중복·결측 검사로 제한한다. 외부 notebook은 실행하지 않는다. 원본의 10분 관측 간격인지 확인하고, 현지 시각으로 변환한 첫 30일의 6개 관측 합을 기존 STCNet hourly 자료와 대조한다. 시간 변환은 STCNet 코드에 명시된 UTC+1을 적용하며 오차를 줄이기 위해 시각을 임의 이동하지 않는다. 모든 원래 국가별 행이 남아 있지는 않아 원시 기록과 완전히 동일하다고 주장하지 않는다.

모델 실행 없이, 10분 자료에 남은 시간 내 변동을 기술하는 용도로만 사용한다. 성능 결과가 좋아서 cell을 택한 것처럼 재해석하거나 세 cell로 10,000 cell의 결론을 내리지 않는다. 추가 진단의 기준은 실제 값을 보기 전에 따로 고정한다.
