# 100. 사전학습 clustering과 시간 조건 정규화의 적용 범위

2026-09-26. 99 이후 읽기 검토다. 기존 후보 인덱스와 28·74·78·80·84·99의 결과를 확인했다. Tab의 직접 예측 우위와 RCTL의 유용한 소속 결정은 아직 연결되지 않았다. 이를 새 분포 거리 또는 task embedding으로 덮지 않는다.

## 질문과 범위

최근 TabClustPFN과 APT가 기존 후보에 없던 직접적인 해결 경로를 제공하는지 확인한다. 검색으로 확인한 초록·본문의 일부는 탐색 정보이고, 아래 방법·공식 코드 검토 뒤 채택 여부를 기록한다. 이번에 두 연구를 처음 발견했다고 주장하지 않는다. TabClustPFN PDF는 기존 저장본을 우선 재사용한다.

1. TabClustPFN의 실제 묶는 단위, 사전학습 정답, PIN/CIN 실행 순서, K=1 허용 여부, TabICL encoder 초기화와 회귀 TabICLv2의 차이를 확인한다. 공식 코드에서 K 선택·반복 횟수와 inference 제한을 읽는다.
2. APT의 timestamp 구성, prototype 선택, affine 변환, 사전학습과 최종 공동 학습, 실제 데이터 단위를 확인한다. 공식 코드에서 기본 prototype 수·top-k·학습 분리 경로를 읽되 외부 코드는 실행하지 않는다.
3. 기존 cell별 scalar pooling과 대응하여 어떤 정보를 추가로 제공하는지, 무엇을 묶는지, 최종 RCTL과의 독립성이 유지되는지 표로 비교한다. 모델 이름에 clustering이 있다는 사실을 예측 목적의 소속 결정 근거로 쓰지 않는다.
4. GMM/표 행의 잠재 집단을 복원하는 목적과 다음 시점 조건부 평균·중앙값을 공유하는 목적을 직접 기호 예시로 구별한다. 변환이 예측값에 미치는 효과는 affine 예시로 확인한다. 새 수치 traffic 실험이나 선행연구 재현으로 세지 않는다.
5. 실용적인 새 결정이 없으면 두 모듈을 현재안에 추가하지 않는다. 최신 방법을 사용하지 않는다는 이유만으로 연구가 오래되었다고 판단하지 않으며, 기존 63–65·77의 변환/동적 소속 후보를 이름만 바꾸어 재개하지 않는다.

## 예산과 기록

모델 fit/predict/gradient/BN 갱신, 실제 traffic 통계 재계산은 모두 0이다. 사전학습 가중치를 받거나 학습하지 않는다. 공개 원문 최대 2편(추가 총 15MB 이내), 관련 공식 코드 파일만 수집하고 commit/hash·열람 범위를 기록한다. 선택한 방법/알고리즘 페이지를 렌더링하여 대조한다. 원장 SHA-256 `807600a7666a6d6912c8db3014a033b5c3c7643527a02fc726da14cb8664d34f`, 잔여 Tab 11 context/20,640 query 행, 추가 RCTL fit 0을 유지한다. 정수·기호 확인은 실행 성능으로 부르지 않는다.
