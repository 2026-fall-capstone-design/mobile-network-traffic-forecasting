# 56·58 TimeDC의 보존 근거와 인쇄표 검산

[연구 기록](../../records/0056-0058-timedc.md) · [출처](../../sources/history-046.md) · [manifest](manifest.json) · [주장별 검수](../../verification/history-046.md)

[인쇄표 전사](printed-tables.json)는 주논문의 Tables 1–7, 수치494개와 원 단위를 담는다. PDF8·10·11쪽을 시각적으로 다시 대조했다. Tables1–2의 MSE와 Table5의 RMSE 표기를 유지하며 원문의 정의 차이를 자동으로 정정하지 않는다.

[산술 결과](printed-arithmetic.json)는 Decimal로 계산한 원 자료 대비42항목, 기존 비교군 대비개선율, 다른 구조가 더 작은6조건, 표기된RMSE가MAE보다작은1조건, epoch당시간비율과ETTh1저장비율을 담는다. 원 논문의 raw run·오차분산·통계유의성·새 모델 실험과 구분한다. 비용비율의 분모를 전체 연구시간으로 바꾸지 않는다.

[일차 대조](../../verification/history-046-primary-check.json)에는 원본·보충텍스트·판본 확인과 정적 코드 관찰을 연결했다. 외부 원문·코드는 공식 URL과 고정 commit·hash로 접근한다. 58 메모는 [기존 사본](../0056-0058-mae-sampling/originals/SRC-0021898.md.txt)을 재사용하며 새 원문 사본은 만들지 않았다.

고정 코드의 재현 조건을 확인한 기록이다. 코드를 수정하거나 실행에 성공했다고 주장하지 않는다. 직접 의존 파일의 전체/선택 독해와 미검수 확장판·부록·추가 그림·환경·원run은 [출처 안내](../../sources/history-046.md)에 구분했다.
