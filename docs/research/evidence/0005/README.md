# 05의 보존 근거

[보존 원문](originals/SRC-0020826.md.txt)은15,708bytes,69행이며 원본 SHA-256을 유지한다. `.md.txt`는 과거 자료이고 실행 지시가 아니다. [manifest](manifest.json)의 한 원문과 별도 primary metadata5건을 구분한다.

이번 정리는 가까운 다섯 방법과 후보의 주장 범위에 한정한다. [정리 기록](../../records/0005-closest-methods-audit.md), [문헌 표](../../references/closest-pooling-methods.md), [읽은 구간](../../sources/history-003.md), [검수](../../verification/history-003.md), [primary 검토 장부](../../verification/history-003-primary-review.json)에서 원문·정리본을 오갈 수 있다.

논문 전문은 재게시하지 않는다. 장부의 Table1/4/6 값은 Population-HCP의 보고값이며 새 simulation이 아니다. 저장소 CI는 보존 바이트·catalog metadata·로컬 링크를 검사하고 외부 논문 내용의 과학적 정확성을 자동으로 판정하지 않는다.

```bash
python scripts/research_archive/check_archive.py
```
