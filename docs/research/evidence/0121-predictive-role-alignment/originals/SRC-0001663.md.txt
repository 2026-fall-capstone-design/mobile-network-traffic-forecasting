# 91. 공간 입력의 역할 정렬을 통한 함수 공유 검토

2026-09-26. 직전90은 원문3편의 적용 조건과 실제 제약 필요성을 구분한 progress다. 최신 진행 기록·후보 인덱스·원장 hash·snapshot32 보존 결과를 확인했다. 최종 추천안은 미완료다.

## 기존 후보와 다른 결정

47·75·81의 입력 선택/공동 입력 후보를 그대로 반복하지 않는다. 검토할 후보는 **같은 공간 입력을 유지하면서, 각 cell의 이웃 열을 예측에서 맡는 역할에 맞게 정렬한 뒤 함수 공유 소속을 정하는 것**이다. 시간축의 순서를 바꾸거나 미래 target을 입력에 넣는 안은 아니다.

기존 동서남북 열은 위치는 같아도 예측 역할은 다를 수 있다. 예를 들어 A의 북쪽 관측과 B의 동쪽 관측이 각각 자기 cell의 다음 변화에 같은 관계를 가진다면, 위치 열 그대로의 함수 차이는 역할을 맞춘 뒤 달라질 수 있다. 그러나 이는 아직 논리 예시이며 실제 traffic의 손해나 신규성 근거가 아니다.

TabICLv2의 검토할 역할은 실제 관측한 공간 입력과 target에서 조건부 예측 관계를 추정하여 **열의 대응과 함수 공유의 단위**를 바꾸는 것이다. 실제 RCTL에는 대응이 고정된 과거 이웃 입력이 전달된다. Tab 예측을 RCTL target으로 대체하지 않으며 RCTL 결과를 정렬/소속 선택에 사용하지 않는다.

## 원문·논리 선행 검사

1. spatial alignment, role-based spatiotemporal forecasting, permutation-equivariant forecasting, network transfer forecasting의 가장 가까운 원문 최대3편을 읽는다. 이미 알려진 입력 정렬/역할 graph를 추정기만 바꾸는 안이면 추천하지 않는다.
2. 단일 global+cell ID, 이웃 평균, PCC로 고른 이웃, attention/GNN의 기존 역할 대응으로 해결되는지 구별한다. 고정 열을 유지하는 전역 모델이 표현할 수 없다고 단정하지 않는다.
3. arbitrary permutation이 시간축·자기 cell 위치·달력 정보·예측 시점의 정보 가용성을 보존하는지 확인한다. 관측되지 않은 입력 조합에서 비교한 함수 유사성을 근거로 쓰지 않는다.
4. 46의 일부 공간 입력 이득과 약한 전체 효과를 그대로 유지한다. 유리한 cell만 골라 독립 성공으로 세지 않는다. 선행연구에 실제 예측 역할 불일치의 근거가 없으면 새로운 추론에 진입하지 않는다.
5. 단순 거리/Procrustes/OT/graph matching, permutation search와 동등한지 확인하고, 비교 수가 factorial로 늘어나는 방식은 기본안으로 두지 않는다. 공통 입력 순서만의 임의 차이를 연구 문제로 만들지 않는다.
