# 다른 cell의 정보를 활용하는 것과 같은 RCTL을 공유하는 것

2026년9월26일 · 연구 재설계 추가 검토

**이번 검토에서는 공통 모델의 내부 표현이나 전이 점수로 cell을 묶는 방식을 새 구조로 추가하지 않습니다.** 관련 선행연구가 판단하는 대상과 현재 clustering이 판단해야 하는 대상이 다르기 때문입니다. 현재 연구가 불가능하다는 결론이 아니라, 그 차이를 해결하지 않은 점수 교체만으로 연구를 진행하지 않겠다는 판단입니다.

## 무엇이 다른가

전이학습에서는 A에서 유용했던 특징을 가져온 뒤 B에 맞는 예측층을 다시 학습할 수 있습니다. 반면 현재 연구는 선택한 cell의 실제 sample을 모아 cluster별 RCTL을 학습합니다. **다른 cell의 특징을 활용할 수 있는지와 같은 입력에서 같은 출력 관계를 함께 학습할 수 있는지는 서로 다른 질문입니다.**

예를 들어 같은 최근 입력 x에 대해 A의 이후 트래픽은 `c+x`, B는 `c−x`라고 하겠습니다. c는 트래픽이 양수가 되게 하는 공통 기준값입니다. A의 예측을 뒤집고 기준값을 맞추면 B를 정확히 예측할 수 있으므로, 추가 변환을 허용하는 전이 점수는 좋을 수 있습니다.

그렇지만 입력에 cell을 구별할 정보가 없고 하나의 출력만 사용한다면, 같은 x에서 두 정답을 동시에 맞출 수 없습니다. 반대로 cell을 구별하는 입력이나 cell별 출력층이 있다면 하나의 모델도 두 관계를 표현할 수 있습니다. 따라서 “관계가 다르므로 무조건 분리해야 한다”는 결론도 성립하지 않습니다. 이 예시는 논리를 설명하기 위한 것이며 실제 트래픽 실험 결과는 아닙니다.

## 선행연구에서 확인한 내용

| 연구 | 실제로 판단하거나 바꾸는 것 | 현재 연구에 반영할 점 |
|---|---|---|
| Task2Vec, ICCV2019 | 공통 사전학습 모델에서 task별 출력층을 적합한 뒤, 필요한 특징을 나타내는 표현을 계산합니다. | 고정된 backbone을 사용해도 task별 추가 학습이 있습니다. 표현 유사도를 동일한 출력 모델의 공유 가능성과 같게 취급하지 않습니다. |
| Simple Transferability Estimation for Regression Tasks, UAI2023 | source 특징이나 예측값으로 target을 다시 회귀할 때의 적합도를 계산합니다. | 점수에 포함된 출력 변환을 실제 최종 학습에서도 허용하는지 확인해야 합니다. 전이 성능의 순위와 cell pooling 성능을 구별합니다. |
| NTKMTL, NeurIPS2025 | 학습 중인 모델의 미분 정보를 이용해 task별 학습 비중을 조절합니다. | 학습 전의 독립적인 clustering 기준이 아닙니다. RCTL의 학습 정보를 병합 결정에 넣으면 현재 독립성 조건이 바뀝니다. |

Task2Vec의 회귀 관련 보충 실험까지 확인했습니다. 따라서 단순히 분류 분야 연구라는 이유로 제외한 것은 아닙니다. UAI2023의 이론은 고정된 source 특징과 target 출력층의 추가 학습을 대상으로 합니다. NTKMTL의 빠른 변형도 미분 계산과 학습이 없어지는 방식은 아닙니다. [Task2Vec 원문](https://openaccess.thecvf.com/content_ICCV_2019/html/Achille_Task2Vec_Task_Embedding_for_Meta-Learning_ICCV_2019_paper.html), [회귀 전이 점수 원문](https://proceedings.mlr.press/v216/nguyen23a.html), [NTKMTL 원문](https://proceedings.neurips.cc/paper_files/paper/2025/file/4522de4178bddb36b49aa26efad537cf-Paper-Conference.pdf)

## 연구 방향에 반영한 판단

앞으로의 후보는 다음 연결을 구체적으로 설명해야 합니다.

1. TabICLv2가 어떤 정보를 제공하는가.
2. 그 정보로 cell 소속, 입력, target 또는 공유하는 부분 중 무엇을 바꾸는가.
3. 바뀐 사항이 실제 관측 sample로 학습하는 RCTL에 어떻게 전달되는가.
4. 같은 정보를 준 단일 global 모델보다 clustering이 필요한 이유가 무엇인가.

cell별 출력층이나 변환을 추가하면 일부 충돌을 해결할 수 있습니다. 다만 그 구조 자체는 기존 전이학습·다중 task 학습에 존재합니다. 같은 구조를 적용한 global 모델과 비교하지 않고 clustering의 이득이라고 주장하지 않겠습니다. 기존의 조건부 변환 및 출력 압축 검토와도 중복을 확인했습니다.

현재까지 확인한 TabICLv2의 장점은 일부 작은 실제 데이터 비교에서의 직접 예측 성능입니다. 그 긍정적 결과는 유지합니다. 동시에 그것만으로 TabICLv2가 정한 cluster에서 RCTL도 더 잘 학습한다고 결론 내리지는 않습니다. 이번 검토는 이 연결을 흐리게 만드는 추가 구조를 제외한 것이며, 최종 추천안의 확정은 아닙니다.
