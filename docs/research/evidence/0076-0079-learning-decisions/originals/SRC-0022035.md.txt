# 78. 최종 학습 없이 공유 효과를 추정하는 방법의 검토 계획

2026-09-26. 직전77은 새 원문·공식 코드로 동적 소속 후보의 판단을 바꾼 progress였다. 활성 goal과 기존 실행 상한을 유지한다. 이번 계획은 원문·공식 코드·기존 결과 읽기이며 새 수치 진단이나 모델 실행을 허용하지 않는다.

## 이번에 확인할 연결

현재의 핵심 실패는 cell의 참 예측 관계와 유한한 RCTL의 공동학습 결과를 같은 것으로 취급한 데 있다. 35·38은 capacity/panel 이론을,76은 최종 학습 loss로 관계를 전달하는 방법을 읽었다. 28에는 NTK task-affinity 검색 기록이 있지만 원문 전체 방법은 미검토라고 쓰여 있다. 이번에는 task embedding·transferability estimation이 **후속 모델을 학습하지 않고도 공유 상대를 판단하는 근거**를 실제로 제공하는지 확인한다.

검토할 후보 행동은 TabICLv2가 추정한 예측 함수의 거리 자체 대신, 공통 probe에서 얻은 task 표현으로 공유 가능한 cell을 정하는 것이다. 이때 단순 embedding clustering을 신규성으로 세지 않는다. probe의 학습 결과가 그 probe의 성능만 설명하는지, 다른 최종 학습기의 결과까지 설명할 수 있는지 구별한다. RCTL의 학습 결과·예측·loss를 clustering에 넣는 방식은 사용하지 않는다.

## 검토 범위와 재진입 제한

1. 가장 가까운 primary 원문 최대3편/새PDF총15MB 이내. Task2Vec, task-affinity/NTK, regression transferability 중 실제 질문에 맞는 원문을 선택한다. 서로 다른 task의 관계를 추정하는 것과, 고정 source 표현을 특정 target에 전이하는 점수를 혼동하지 않는다.
2. 필요한 정보가 labels, pretrained probe, candidate model features, random architecture, learned weights, adaptation gradients 중 무엇인지 확인한다. 논문의 task-specific head 학습을 ‘학습 없음’으로 축약하지 않는다.
3. 알려진 이론의 linearization, wide-network, common initialization, squared loss 조건을 MAE/BatchNorm/LSTM RCTL에 자동 대입하지 않는다. 단순히 정리가 없다는 이유로 실증 근거를 기각하지도 않는다.
4. 실제 pooling/clustering 성능 실험이 있는지, 단일 source model 순위 평가인지 구별한다. classification 결과를 회귀 traffic의 직접 검증으로 부르지 않는다.
5. TabICLv2를 넣었을 때 제공되는 값·바뀌는 결정·후속 실제 target 학습과의 연결을 특정하지 못하면 새 실행을 하지 않는다. 기존 conditional function clustering/증류와 같으면 해당 기록으로 연결하고 중복 후보로 세지 않는다.

## 이번 턴에 이미 읽어 확인한 범위

기존 raw-unit 지표의 누락 가능성을 점검했으나 `results/rctl_pilot/summary.json`에 raw_activity_mae가 이미 있었다. global84.1003, Tab100.6125/104.0103이다. 새 계산·새 성능 발견이 아니며, 단위 변경으로 기존 실패를 해결했다고 주장하지 않는다. UPC 원문은 MAPE와 MAE를 모두 제시하며 상대오차의 중요성을 언급한다. 이 내용을 근거로 결과를 본 뒤 유리한 지표를 새 주목표로 정하지 않는다.

`train_rctl_pilot.py:79–87`에서 같은 seed의 모든 cluster가 같은 초기화를 사용함을 확인했다. 이는 model merging의 충분조건이 아니다. 기존 학습 모델을 평균내는 방향은 clustering 후 실제 자료로 RCTL을 학습하는 현재 목표를 대체할 수 있으므로 이번 후보로 실행하지 않는다.

누적 Tab69contexts/39360query,잔여11/20640;RCTL29fits/잔여0. 상한 변경·이전 실행 재시작 없음.

## 원문 선택 — 다운로드 전 고정

Task2Vec ICCV2019, Simple Transferability Estimation for Regression Tasks UAI2023, NTKMTL NeurIPS2025의 세 논문으로 좁힌다. 앞의 두 논문은 필요한 경우 공식/저자 보충자료도 읽으며, main/supplement를 별도 PDF로 저장하더라도 논문 수는3편, 총 새PDF15MB 상한은 유지한다. NTK affinity M3L2024 workshop은 검색에 본문 일부가 노출되지만 직접 OpenReview 접근은 verification 화면으로 실패했다. 우회하지 않고 같은 계열의 정식 공개 NTKMTL을 본문 검토 대상으로 삼는다. ETAP2026과 RMB-CLE는 기존 검토를 재사용하고 새 발견으로 세지 않는다.

## 해석의 범위를 확인하는 기호 예시

출력층을 바꾸는 전이와 하나의 출력을 공유하는 pooling의 차이는 두 개의 선형 관계를 이용하여 문서에서 기호로 확인한다. 새로운 자료·난수·수치 프로그램·모델을 생성하거나 실행하지 않는다. 이 예시는 원문의 실험 결과나 새로운 정리가 아니며, 실제 RCTL 입력에 cell 구별 정보가 있는 경우까지 일반화하지 않는다.
