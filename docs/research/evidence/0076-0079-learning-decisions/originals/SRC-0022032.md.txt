# 77. 시간에 따라 바뀌는 소속을 clustering에 도입할 수 있는가

2026-09-26. 문헌·공식 코드·논리 검토. 새 모델 학습·추론·수치 pilot은 실행하지 않았다. 최종 추천안은 아직 정하지 않았다.

## 이번에 바꾸려던 결정

지금까지는 한 cell의 전체 학습 구간에 하나의 cluster 소속을 부여했다. 이번에는 같은 cell이라도 예측 시점의 시간대와 관측 상태에 따라 함께 학습할 cell이 달라지는 구성을 검토했다. 달력 특징을 입력에 추가하는 것과는 다르다. 실제로 달라지는 것은 각 RCTL에 전달할 학습 sample과 예측 시점의 모델 배정이다.

출발 가설은 “A와 B가 오전에는 같은 예측 관계를 보이지만 오후에는 다르다면, 하나의 고정 소속이 유용한 공유를 놓칠 수 있다”이다. 이 상황은 논리적으로 가능하다. 그러나 시간별 트래픽 높이·PCC 변화만으로 그러한 학습 손해가 실제로 발생한다고 판단할 수는 없다. 시간대를 입력으로 받는 하나의 global 모델이 차이를 학습할 수도 있기 때문이다.

## 가까운 원문에서 확인한 내용

### 1. Dynamic clustering of time series data

Sartório·Fonseca의 arXiv:2002.01890v1, 2020-01-28, 27쪽을 확보했다. §2의 DLM mixture와 §3–3.3의 시간별 소속·추정 절차를 읽었다. p10–11을 시각 대조했다. 2025년 출판 논문은 별도의 제목·초록만 확인했으며 2020년 PDF와 동일한 버전으로 처리하지 않았다.

소속 확률을 시간별로 두고 Evolutional Dirichlet Process로 이어, 잡음 때문에 소속이 매 시점 크게 바뀌는 것을 억제한다. §3.1의 소속 확률은 해당 시점의 관측값과 각 cluster DLM의 likelihood를 사용한다. Theorem 1은 forward filtering, Theorem 2는 전체 관측 구간에 조건을 건 backward sampling이다. §3.2에서는 소속과 cluster DLM을 반복해서 함께 추정한다.

공식 README가 이 논문을 직접 연결하는 `victhorio/dynmix`의 commit `bf866cefcd1f2754ee4b2ede31ff14aed79d0a7e`를 고정했다. `dynamic.py:60–94`는 Monte Carlo 소속 추정→backward estimator→가중 DLM 적합이고, `dynamic.py:207–261`은 관측 likelihood→소속 sampling→smoothing이다. `dirichlet.py:18–67`에서 forward와 backward 계산을 구별했다. 코드는 정적으로 읽었으며 설치·import·실행하지 않았다. PyPI 1.1.2 배포 시점과 GitHub commit도 같다고 가정하지 않았다.

**현재 설계에 주는 판단:** 동적 소속과 시간적 안정화 자체는 이미 제안되었다. 전체 과거 학습 구간을 이용한 소속 추정 자체가 잘못은 아니다. 다만 평가 시점 뒤의 관측까지 이용한 smoothed 소속을 그 시점에서 사용 가능했던 예측 배정으로 처리하면 안 된다. 미래 배정에는 별도의 origin-available 규칙이 필요하다. DLM 결과를 사용하는 것은 RCTL 독립성 위반이 아니지만, DLM의 소속이 RCTL 학습에도 유리한지는 별도 연결 문제다.

출처: https://arxiv.org/abs/2002.01890 ; https://github.com/victhorio/dynmix/tree/bf866cefcd1f2754ee4b2ede31ff14aed79d0a7e

### 2. DynaSTar, IJCAI 2026

정식 제목은 *Tracking Topological Shifts: How Can Dynamic Graph Invariant Learning Enable Reliable Out-of-Time Spatio-Temporal Prediction?*이다. 공식 proceedings PDF 9쪽의 §3–5, Eq1–20, Table1–2 및 Fig3을 읽고 p3·7을 시각 확인했다. 도로 센서 연구이며 통신 cell 결과가 아니다.

최근 입력을 encoder와 memory module로 표현하고, Eq4에서 node 쌍 관계를 계산한다. Eq5는 이전 graph와 현재 graph의 momentum 갱신이다. 확률 edge를 sparse graph로 만들어 node별 modulation과 invariant loss를 함께 학습한다. Graph 생성에도 예측 loss가 전달된다. 추론 중 graph 상태를 바꾸는 것은 신경망 전체를 매번 재학습하는 것과 다르다.

Table2에서 momentum graph를 제외한 장기 SD MAE는 28.49, 전체 방법은 26.87이며, SGBA는 31.27과 29.23이다. 이는 해당 graph forecaster 내부의 ablation이다. RCTL과 독립적인 cell 소속의 효과로 옮겨 해석하지 않는다. Fig3의 상대 runtime·throughput 비교도 graph 생성 비용이 없어졌다는 뜻은 아니다. Eq4는 전체 node 쌍을 형성하므로 sparse aggregation과 전체 관계 계산을 구분해야 한다.

논문에 적힌 공식 GitHub `ShaunHao/dynastar`를 확인했으나 이번 접근에서는 API 404였다. 따라서 구현 검증·재현 실행으로 표시하지 않는다.

**현재 설계에 주는 판단:** “시간에 따라 관계를 바꾸고 잡음을 완화한다”는 설명만으로 새 기여가 되지 않는다. 이 논문은 입력 이웃을 바꾸는 방법이며, 함께 학습할 cell을 정해 별도 RCTL을 만드는 방법과 결정 단위가 다르다.

출처: https://www.ijcai.org/proceedings/2026/296 ; https://www.ijcai.org/proceedings/2026/0296.pdf

### 3. 통신망의 dynamic clustering은 어떤 목적이었는가

Liu et al., *Spatial–temporal graph neural network traffic prediction based load balancing with reinforcement learning in cellular networks*, Information Fusion 103 (2024), 102079. BIMSA 공개 PDF 16쪽을 확보했다. Fig3, §3.1, §4.2–4.3, §5.1.1–5.1.2를 읽었고 p4·9를 시각 확인했다.

Fig3은 트래픽 예측→부하 분산에 참여할 cell의 clustering→강화학습으로 자원 조정 순서다. §4.2와 Algorithm1은 이전 구간 평균 부하로 초기 중심을 정한 뒤, 부하·거리·이동 사용자 수의 세 변수로 K=2 k-means를 수행한다. 통신 traffic의 시간 변화와 clustering을 다루지만, 예측모델에 전달할 학습 자료를 나누는 방법은 아니다.

예측 자료는 Trentino 289개 격자·62일·10분 간격의 Internet 활동량이며, 이후 무선망 자원 조정은 별도 simulation이다. 공개 격자 기록을 실제 handover·capacity label과 동일하게 취급하지 않는다. p15의 data availability에는 confidential로 기재되어 있으므로 논문의 전체 통합 데이터를 확보했다고 주장하지 않는다. 모델·RL 실험을 재현하지 않았다.

**현재 설계에 주는 판단:** 이 논문의 이득은 예측 결과로 자원 배분을 바꾸는 데 연결된다. 이것을 clustering→RCTL의 성능 향상 근거로 사용하면 알고리즘 순서와 목적이 바뀐다.

출처: https://bimsa.net/doc/publication/3963.pdf ; https://doi.org/10.1016/j.inffus.2023.102079

## RCTL에 연결하면 서로 다른 세 설계가 된다

| 선택 | 학습 자료와 배정 | 기존 연구 범위와의 관계 | 비용·연결에서 필요한 조건 |
|---|---|---|---|
| 시간대마다 별도 cell partition | S개 상태별 partition, 각 partition의 K개 RCTL | 상태별 clustering→RCTL은 구현 가능 | 최대 SK개 모델을 보관한다. 각 학습 sample을 한 상태에만 배정하면 전체 행 수가 S배가 되는 것은 아니지만, 모델 수와 상태별 자료 부족은 증가한다. |
| 고정된 K개 RCTL bank에 매 시점 배정 | cell이 아닌 (cell, 시점) sample의 expert 선택 | mixture-of-experts 또는 sample routing과 가깝다 | 배정 규칙을 학습 전에 고정하고 각 expert가 받을 입력을 학습 자료로 포함해야 한다. 시간 순서만 바꿔 이름을 cell clustering으로 부르지 않는다. |
| 새로운 자료마다 cell partition 갱신 | 바뀐 소속으로 cluster별 RCTL 갱신 | 동적 clustering→재학습 | 입력 규격이 같으면 이전 모델로 수치 예측은 가능하다. 그러나 새 cluster 자료를 반영한 학습 상태가 되는 것은 아니며, 입력 channel 수·순서까지 바뀌면 별도 호환 처리도 필요하다. |

한 시점에 한 RCTL만 호출하는 bank라도 준비한 모델의 수·학습 비용이 하나가 되는 것은 아니다. 반대로 소속을 바꾼다고 매번 반드시 모든 모델을 재학습해야 하는 것도 아니다. 사전에 학습시킨 범위 안에서 배정하는 방법과 새 partition을 실제로 다시 학습하는 방법을 분리해야 한다.

TabICLv2 context를 cell당 한 번 준비하고 상태별 query를 묶어서 계산한다면 준비 횟수는 N, 예측 행 수는 N×S×Q가 될 수 있다. 상태마다 별도 context를 만드는 설계는 준비도 N×S가 된다. 동일 context의 cache를 다른 context에 무조건 재사용할 수 없다. 모든 cell 쌍을 상태별로 비교하면 비교 비용은 O(SN²)이며, 사전에 cell당 k개 후보만 찾으면 O(SNk)의 후보 평가로 제한할 수 있다. 이는 작업량 식이지 이번에 측정한 실행 시간은 아니다.

## 기존 실제 기록과 대조한 판단

17의 이전·최근·누적 자료 비교에서 최근 자료만 사용하는 전략의 일관된 이득이 없었다. 27의 관측 상태 분석에서는 일부 빠른 증가 상태에서 empirical grouping의 이득이 있었지만 전체 손해를 상쇄하지 못했고 Tab grouping의 안정된 이득은 아니었다. 32의 10분 원자료에서도 global 단순 모델이 강했다. 이 결과가 모든 동적 모델을 반박하는 것은 아니다. 다만 “시간에 따라 traffic이 변하므로 소속도 바꿔야 한다”는 현재 후보의 필요성을 직접 지지하지 않는다.

60·74의 TabICLv2 직접 예측 우위는 그대로 유지한다. 그러나 그 값만으로 상태별 expert 선택이나 RCTL의 공유 이득을 추론할 수 없다. 같은 달력·최근 입력을 사용하는 global 모델, 단순 달력별 분할, 기존 동적 mixture가 강한 대안이다.

**이번 판단은 ‘동적 소속을 새 핵심 구조로 추가하지 않는다’이다.** 동적 소속·시간적 안정화는 기존 연구와 겹친다. 새로 필요한 배정 규칙과 학습 자료의 연결까지 해결하지 않으면, 이전 proxy 문제에 모델 bank와 갱신 비용을 더하는 형태가 된다. 이는 dynamic clustering 분야 전체의 부정이나 현재 연구 목표의 완료를 의미하지 않는다.

재진입하려면 ①예측 시점에 관측 가능한 조건, ②조건에 따라 공유 상대가 실제로 바뀌는 근거, ③같은 정보를 받는 global 모델과 단순 분할이 남기는 손해, ④Tab이 다른 결정을 만드는 정보, ⑤이미 학습한 RCTL의 유효 범위 안에서 그 결정을 실행하는 규칙을 함께 제시해야 한다. 현재 ②–④를 충족하는 직접 근거는 확보하지 못했다.
