## 확인할 후보와 재진입 사유

76의 teacher반응 증류와65의 residual/조건부 정규화는 다시 실행하지 않는다. 검토할 질문은 **clustering 점수가 임의 RCTL의 손해를 대신한다고 가정하는 대신, 최종 학습 함수가 지켜야 하는 성질을 사전에 명시하면 분리 필요성을 직접 연결할 수 있는가**이다.

구체적인 후보는 입력 변화에 따른 출력 변화의 제한(예: Lipschitz 제약) 아래 함께 표현할 수 없는 cell 관계를 찾는 것이다. 일반 거리/증류와 동일한 후보로 이름만 바뀌지 않도록 다음을 먼저 확인한다.

1. 가장 가까운 Lipschitz regression, mixture/piecewise regression, supervised clustering 원문의 실제 결정과 동일한가? 이론·알고리즘을 최대3편으로 좁혀 읽는다.
2. 이 제약이 원래 traffic 문제에서 필요한 이유가 있는가? 공유가 불리하도록 인위적인 제한을 만든 것이라면 채택하지 않는다.
3. Tab의 조건부 평균/중앙값 차이를 사용하되 예측 분위수를 평균함수의 신뢰구간이라고 부르지 않는다. 실제 target을 쓰는 단순 회귀·empirical 차이보다 Tab의 역할이 무엇인지 따진다.
4. TCN·LSTM·dual residual을 유지하면서 해당 성질을 실제 강제할 수 있는가? norm제약의 느슨한 상한, BatchNorm/dropout/train-inference 차이, 입력 정규화·cell ID가 제한을 바꾸는지를 확인한다.
5. 이 연결이 성립해도 실제 cell에서의 손해·개선 근거가 남아야 한다. 알려진 방법의 추정기만 바꾸거나 RCTL norm을 억지로 제한하는 후보는 새 실행 없이 제외한다.

이번 범위는 원문·현재 모델 코드 읽기와 기호 반례 검토다. 모델학습/Tab추론/데이터 수치진단0, RCTL호출0이다. 새로운 구현이나 진단이 필요하면 별도 계획을 먼저 저장한다. 목표를 단순 규칙의 수학적 일관성 확인으로 줄이지 않는다.
