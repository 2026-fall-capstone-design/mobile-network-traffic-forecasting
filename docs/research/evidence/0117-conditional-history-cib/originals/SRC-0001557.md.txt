# 88 조건부 sample 생성의 선행연구와 새 결정 여부 검토 계획

2026-09-26. 87의 코드 검토에서 원문이 의도한 조건부 독립 기준과 공개 구현의 무조건 batch shuffle을 구분했다. 이 차이만으로 새 방법을 추천하지 않는다.

## 한정된 질문

시간·요일·자기 이력을 고정해 다른 cell의 추가 예측 정보를 판단할 때, 조건부 생성 기준을 바로잡는 것 이상의 미해결 문제가 있는가? Tab 회귀 모델이 기존의 조건부 randomization/permutation 또는 예측 손실 비교보다 유용한 clustering 결정을 제공할 수 있는가?

## 수행 순서

1. arXiv2603.06609v1의 본문·알고리즘·가정을 읽어 TabPFN을 예측 통계량으로 사용하는지 조건부 생성기로 사용하는지 구분한다.
2. 가장 가까운 conditional permutation/randomization 원문과 조건부 MI의 negative sample 구성 방법을 최대 세 편 추가로 확인한다. 정확한 조건부 분포·추정한 분포·iid·시계열 블록 가정을 구별한다.
3. 기존47·81의 입력 공유·집합 의존성 후보 및 28의 미검토 목록과 대조한다. 조건부 정보 자체 또는 Tab으로 기존 추정기 교체만 남으면 신규 후보로 실행하지 않는다.
4. sample의 예측 관계가 같음, 서로의 입력이 추가 정보를 제공함, 공동 RCTL 학습이 이득임을 구별한다. 이 중 실제로 바꾸는 결정과 RCTL 입력으로 전달되는 정보가 없다면 미채택으로 정리한다.
5. 실제 데이터·새 모델 실행에 들어갈 경우 별도 계획이 필요하다. 이번 범위는 원문·공식 코드의 읽기와 기호 비교다. 수치 진단·Tab·RCTL 호출 0회, 비용 원장 불변.

## 채택·중단 기준

기존 conditional test를 Tab으로 구현하는 것만으로 충분하면 새 알고리즘으로 추천하지 않는다. 새로운 partition 결정과 강한 단순 대안보다 유리할 원리가 있어야 다음 최소 확인 계획을 만든다. 논문 구현의 문제를 고치는 것과 현재 cell clustering 연구의 중요성·신규성을 입증하는 것은 별개다. 연구 전체의 완료·중단을 뜻하지 않는다.
