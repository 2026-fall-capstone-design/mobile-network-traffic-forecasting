[서지·조건](paper-info.json), [읽은 범위](read-scopes.json), [Table 1 표시값](displayed-table-1.json), [재계산](table-1-audit.json), [표 2–5](tables-2-5.json), [그림 대조](figure-review.json)를 제공한다. 원문의 표시값·강조와 이번 정리에서 계산한 최저값 수를 구분한다. 실험 원시값이나 논문 전체를 재게시한 자료는 아니다.

저장소 루트에서 `python scripts/research_archive/check_dgcformer_display.py --check`로 공개 표시값의 64개 비교를 재계산할 수 있다. 연구 모델·학습 자료·네트워크 접속은 사용하지 않는다. 이 검사는 전사된 값의 산술을 확인하며 논문 실험의 재현이나 모든 주장의 의미 검수를 대신하지 않는다.
