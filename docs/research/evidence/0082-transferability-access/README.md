- [manifest](manifest.json): 새3그룹과 기존 판단1개, 읽은 범위와 가산 단위.
- [접근 시도](access-attempts.json): 11건의 당시 status·시각·요청 방법·크기·SHA와 저장 파일 대조. 전필드 첫 독해 후 필요한 응답 정보만 발췌했다.
- [검색 범위](search-record-scopes.json): 중첩5개 payload의 실제 읽은 범위와 원문 미확보·부분 저장 한계.

원 JSON 전체나 외부 논문·검색 발췌 전체를 재게시하지 않는다. source_id·원본 루트 상대경로·SHA·핵심 관찰로 추적하고, 문헌 전체 검수는 기존 H079–H081에 연결했다. 0바이트 HEAD body는 본문이 없는 응답이며 손상 PDF나 독립 본문이 아니다. 검색 스니펫·동일 서지 반복·기존 추출 출력을 새 논문 독해나 실험으로 세지 않는다.
