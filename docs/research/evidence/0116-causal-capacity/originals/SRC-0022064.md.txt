# 87 공동 출력의 표현 용량과 조건부 관계 구현 검토

2026-09-26. 원문·코드 읽기와 기호적 확인만 수행하였다. 새 Tab 추론, RCTL 학습·forward·gradient, 데이터 수치 진단은 모두 0회다. 기존 예산과 29-fit 상한은 그대로다.

## 1. 확인한 용량 제약과 적용 범위

81에서 검토한 변형은 여러 cell의 이력을 한 번에 입력하고, 기존 causal core의 출력을 flatten한 뒤 여러 cell을 동시에 출력한다. 원래의 cell별 scalar RCTL과 다른 학습 단위다. 동일 폭에서 global 다중 출력의 산술 연산량이 작다는 81의 계산은 유지되지만, 이것이 충분한 표현 용량을 보장하지는 않는다.

`rctl_torch.py`의 모든 convolution은 왼쪽 padding이며, LSTM은 정방향이고, 잔차 경로는 시간별 1×1 projection이다. 마지막 폭은 16이다. 평가 모드에서는 BatchNorm의 저장 통계가 상수이고 dropout이 꺼져 있다. 최근값이 이전 입력 위치에 복제되지 않고, 최근값을 이용하는 window 정규화도 없다고 가정한다.

이 조건에서 이전 입력 O를 고정하고 마지막 시점의 cell 벡터 Z만 바꾸면, 앞선 hidden 시점은 변하지 않는다. 마지막 16차원 hidden만 변한다. 선형 다중 출력 head를 붙인 예측은 다음 꼴이다.

`f(O,Z) = a(O) + B h(O,Z)`, `B: d×16`.

따라서 미분 가능한 지점에서 `rank(∂f/∂Z) ≤ 16`이다. 전체 flatten 차원 `16L`과 최신 입력의 영향이 통과하는 차원 16은 다르다. ReLU 경계에서는 통상적인 Jacobian이 존재하지 않을 수 있으나, 고정 O에서 출력 차이가 B의 열공간에 속한다는 진술은 그대로다.

이는 새 변형의 구조적 성질이지 실제 트래픽에서 확인한 손해가 아니다. cell마다 scalar global RCTL을 따로 호출하면 각 호출에 자신의 hidden이 생기므로, N개 cell을 함께 보았을 때 위의 공동 rank-16 상한을 적용할 수 없다. training 모드 BatchNorm이 시간·batch를 섞는 경우, 입력별 RevIN처럼 최근값으로 이전 위치를 바꾸는 경우, 최신값을 여러 위치에 복제하는 경우도 위 전제와 다르다.

## 2. MSE와 연결할 수 있는 한정된 성질

제곱 적분 가능한 실제 target Y에 대해 `m=E[Y|O,Z]`, `m_O=E[Y|O]`, `U=m−m_O`라 하자. 위 형태의 f에서는 `f−E[f|O]`가 고정된 최대 16차원 공간에 속한다. 조건부 평균의 직교 분해와 최소 rank 근사 성질로 다음 하한을 얻는다.

`E||Y−f||² − E||Y−m||² ≥ Σ_{j>16} λ_j(E[UUᵀ])`.

증명은 `m−f`를 O에 대한 조건부 평균 성분과 평균 0인 성분으로 분해한 뒤, U를 B의 열공간에 투영하는 최선의 경우보다 실제 오차가 작을 수 없음을 이용한다. 이는 출력별 평균이 아닌 합 MSE이며, 출력 평균 MSE에는 d로 나눈다. MAE에 같은 수식을 적용하지 않는다.

하한에는 알려지지 않은 참 조건부 평균이 들어간다. target의 단순 공분산에는 예측할 수 없는 잡음이 포함되며, Tab 예측의 공분산에는 추정 오차가 포함된다. 둘 중 하나를 바로 대입하여 실제 RCTL 손해가 입증되었다고 판단할 수 없다. 74의 4-cell 결과도 d>16의 제약을 확인한 결과가 아니다.

## 3. 단순 해결책부터 고려해야 하는 이유

최신 cell 값을 출력에 직접 더하는 `f(O,Z)=Z+core(O,Z)`는 전체 출력 Jacobian의 rank-16 상한을 없앤다. cell별 선형 AR 항도 각 cell의 독립적인 선형 반응을 직접 전달한다. 출력 차분 후 최신값 복원은 이에 해당한다. 이것이 모든 비선형 관계를 해결한다는 뜻은 아니지만, 단순히 출력 cell 수가 16보다 많다는 이유만으로 clustering이 필요하다는 주장은 성립하지 않는다.

cluster당 cell 수를 줄여 폭 제약을 완화할 수는 있다. 그러나 이 사실만으로 어떤 cell을 함께 묶어야 하는지, Tab이 단순 균등 분할보다 어떤 결정을 개선하는지는 정해지지 않는다. 표현 병목만을 근거로 새 연구 방향을 채택하지 않는다. 81의 비용표에 용량 관련 해석 범위를 덧붙이는 것으로 판단을 제한한다.

## 4. 추가로 발견한 조건부 관계 추정의 구체적 문제

IJCAI 2025의 *Conditional Information Bottleneck-Based Multivariate Time Series Forecasting*은 patch 사이 관계를 앞선 patch들에 조건화한다. 원문 §4.3 식24–25의 기준 분포는 `P(C)P(A|C)P(B|C)`다. §4.4 알고리즘1은 이 항과 예측 손실을 함께 학습한다. 이는 clustering 또는 사전학습 Tab 모델을 제시한 논문은 아니다.

공식 저장소 commit `ac09a66245f9eaa7371065ec3f7d3673df125c94`의 실제 경로를 확인했다.

- `layers/CMI.py`, `generate_samples`: 이전 patch들을 평균한 벡터를 condition으로 사용한다. patch1과 condition을 유지하고 patch2의 batch 순서를 무조건 무작위로 섞는다.
- `layers/CIBMTSF_backbone.py` 203–216행: 이 함수를 인접 patch에 호출하고 평균한 값을 clipping하여 보조 손실에 넣는다.
- `exp/exp_main.py` 172–204행: 실제 예측 MSE와 보조 손실을 합하여 backward한다. 사용되지 않는 예제 코드로 판단하지 않는다.

고정된 표현의 독립 sample 모집단에서 무조건 patch2를 섞는 이상화를 하면 기준 분포는 `P(A,C)P(B)`가 된다. 이에 대한 KL은 `I(B;A,C)=I(B;C)+I(B;A|C)`다. 원문 식24의 CMI와 같지 않다. condition을 함수 입력에 그대로 남긴 것과 condition에 맞는 분포에서 B를 추출하는 것은 서로 다른 연산이다.

기호 반례로 균등한 이진 C와 `A=C`, `B=C`를 생각하면, `I(A;B|C)=0`이지만 무조건 shuffle 기준의 KL은 `log 2`다. 이미 C에 들어 있는 정보만으로도 구별이 가능하다. 이는 실제 데이터 실험이나 해당 논문의 성능 재현이 아니다.

공개 구현의 유한 batch·동일 행으로 돌아오는 permutation·겹친 시간 window·학습 중 변하는 표현·유한 critic·clipping까지 고려하면, 실제 출력이 위 모집단 KL과 같다고 주장할 수 없다. 확인한 것은 기준 sample 생성 방식이 조건부 독립 분포를 일반적으로 만들지 않는다는 점이다. mean으로 요약한 과거와 원문의 전체 과거도 정보가 다르다. 이것만으로 논문의 모든 이론이나 예측 결과를 부정하지 않는다.

## 5. 현재 연구에 적용하는 판단

네트워크 트래픽의 달력·일주기 이력을 조건으로 남겨 둔 채 sample을 무작위로 섞어도, 달력과 sample 사이의 관계는 깨질 수 있다. 따라서 앞으로 조건부 정보·교체 검사를 설계한다면, 유지하는 열 이름뿐 아니라 실제 생성되는 결합분포를 확인해야 한다. 이는 선행 구현에서 배운 설계 점검이지 신규 알고리즘의 증거가 아니다.

Tab 회귀 분포로 조건부 sample을 만들 수 있는지 검토할 가치는 있으나, conditional randomization/permutation과 조건부 MI 추정은 기존 분야다. arXiv2603.06609v1의 TabPFN+CRT는 이번에 공식 초록·버전까지 확인했으며, 본문을 읽기 전에는 신규성이 있다고 판단하지 않는다. scalar 회귀 분위수를 다변량 시계열의 공동 생성기로 간주하지도 않는다.

다음 검토는 ‘Tab을 조건부 sampler로 쓰면 새롭다’는 제안을 만드는 것이 아니라, 가장 가까운 기존 방법과 그 가정을 먼저 확인하는 것이다. 이미 검토한 입력 graph/Granger 후보로 돌아갈 경우 47·81의 기각 이유를 실제로 바꾸는 결정이 있어야 한다. 이번 단계에서 새 추천 방향과 최종 Word를 완성한 것은 아니다.
