# 표현 용량과 조건부 비교에서 확인한 사항

2026년 9월 26일. 이번 검토는 기존의 clustering → RCTL 구조에서 어떤 문제를 실제로 해결해야 하는지 좁히기 위한 원문·코드 분석입니다. 새로운 모델 학습이나 성능 실험은 하지 않았습니다.

**두 가지를 확인했습니다. 여러 cell을 한꺼번에 출력하도록 RCTL을 바꾸면 표현 용량에 제약이 생길 수 있습니다. 또한 과거 이력을 고정해 두었다는 설명만으로 비교 sample의 시간 조건이 보존되지는 않습니다. 두 사실 모두 연구 설계에 중요하지만, 그 자체가 새 clustering 방법의 개선 근거는 아닙니다.**

## 여러 cell을 동시에 출력할 때의 제약

기존 RCTL의 마지막 hidden 폭은 16입니다. 여러 cell의 값을 한 번에 입력하고 마지막 출력층만 여러 cell용으로 바꾸면, 최신 시점의 변화는 이 16차원 표현을 거쳐 출력됩니다. 과거 시점의 표현까지 합친 전체 크기와 최신값의 영향을 전달하는 크기는 다릅니다.

이 성질은 새로 검토한 다중 출력 변형에 해당합니다. 원래처럼 각 cell의 입력을 scalar RCTL에 따로 넣으면, 모든 cell이 하나의 16차원 표현을 함께 거치는 것은 아닙니다. 따라서 원래 UPC·RCTL의 결함으로 설명할 수 없습니다.

최근값을 출력에 직접 더하고 RCTL이 변화량을 예측하게 하는 간단한 구성은 이 제약의 일부를 없앱니다. cell별 선형 예측항을 함께 쓰는 방법도 있습니다. 먼저 이런 단순 대안과 비교해야 하며, 폭이 좁다는 이유만으로 복잡한 clustering을 추가하는 것은 타당하지 않습니다. 실제 트래픽에서 손해가 발생하는지와 Tab이 더 좋은 소속을 선택하는지는 아직 별도의 질문입니다.

## ‘같은 조건’이 실제로 유지되는지 확인해야 합니다

IJCAI 2025의 조건부 정보 병목 논문은 앞선 이력을 알고 있을 때 인접 구간 사이에 얼마나 새로운 관계가 남는지 계산합니다. 원문과 공개 코드를 대조한 결과, 코드에서는 앞선 이력의 요약값을 그대로 두고 비교할 다음 patch를 다른 sample에서 무작위로 가져옵니다. 이 방식은 같은 이력 아래에서 다음 patch를 다시 추출하는 것과 일반적으로 다릅니다. [원문 §4.3](https://www.ijcai.org/proceedings/2025/0627.pdf), [공식 구현](https://github.com/Xinhui-Lee/CIB-MTSF/blob/ac09a66245f9eaa7371065ec3f7d3673df125c94/CIB-MTSF/CIB-MTSF/layers/CMI.py).

네트워크 트래픽으로 비유하면, 입력에 ‘아침’이라는 시간 정보를 남겨 두면서 밤의 sample을 무작위로 가져오는 상황입니다. 모델은 cell 사이의 새로운 예측 관계보다 아침과 밤의 불일치를 구별할 수 있습니다. 시간 열을 고정했다는 사실만으로 시간 조건에 맞는 비교가 되는 것은 아닙니다. 이 비유는 해당 논문의 실제 데이터에서 관측한 결과가 아니라, 구현 방식의 차이를 설명하기 위한 것입니다.

이 점은 사용자가 제기했던 전체 트래픽 흐름의 보존 문제와 연결됩니다. 앞으로 sample을 교체하거나 공간 관계를 평가할 때는 최근 모양뿐 아니라 시간·요일·계절 이력과 결합된 분포가 유지되는지 확인해야 합니다. 다만 조건을 맞춘 재추출은 이미 conditional randomization과 conditional permutation에서 연구한 원리입니다. TabICLv2를 사용한다는 이유만으로 신규성이 생기지는 않습니다.

## 이번 결과가 바꾸는 연구 판단

| 검토한 방향 | 현재 판단 | 다음에 필요한 근거 |
|---|---|---|
| RCTL의 공동 출력 폭 제약을 clustering으로 완화 | 단순 잔차·선형 항과 비교가 먼저 필요 | 실제 예측 가능한 변동이 제약을 넘고, Tab이 유용한 소속을 선택한다는 근거 |
| 시간 조건을 보존하는 sample 비교 | 조건 유지 여부를 생성 과정에서 확인할 필요가 있음 | 기존 조건부 검사와 다른 결정 또는 실제 계산·추정 이득 |
| Tab 회귀 분포를 조건부 sample 생성에 사용 | 선행연구 검토 대상으로 남김 | 시계열 의존성과 조건부 생성 정확성, 단순 대안 대비 이점 |

공식 자료에서 [TabPFN과 conditional randomization을 결합한 논문](https://arxiv.org/abs/2603.06609v1)도 확인했습니다. 이 논문의 본문과 기존 조건부 검사 원리를 먼저 대조하여, 이미 해결된 문제에 이름만 바꿔 접근하는 것을 피하겠습니다. 이번 코드 분석을 실제 성능 개선이나 최종 연구 방향 확정으로 제시하지 않습니다.
