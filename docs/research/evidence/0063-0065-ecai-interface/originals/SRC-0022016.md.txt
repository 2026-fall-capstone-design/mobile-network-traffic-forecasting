# 65. 실제 학습과 연결되는 잔차·분포 변환의 검토

2026-09-26. 63–64 계획에 따른 원문·공식 구현·논리 검토다. 새 모델 실행이나 새 추천안의 채택은 없다. 기존 목표와 누적 상한을 유지한다.

## 바뀐 판단

Tab의 점수만 clustering에 사용하는 방식과, Tab이 정한 입력·target 표현을 RCTL도 사용하는 방식은 구별된다. 후자는 실제 학습 문제가 달라져 대리 점수와 최종 학습의 간극을 일부 줄일 수 있다. 그러나 이 연결 자체는 이미 발표돼 있다. 다음 세 후보를 그대로 새 알고리즘으로 추천하지 않는다.

| 후보 | 실제로 달라지는 것 | 가장 가까운 기존 원리 | 현재 판정 |
|---|---|---|---|
| Tab 예측을 RCTL 입력에 추가 | 실제값을 예측하는 RCTL의 입력 열 | ECAI2025 Fig.3(d)의 global forecast + cluster-specific model | 모델 교체만으로 신규성 없음 |
| 실제값−Tab 예측을 RCTL로 예측 | 실제 관측 target의 잔차 표현, 최종 합산 | KDD2026 residual pipeline; Heatload2026 MRRC | 보정할 정보가 실제로 남는지와 전체 비용의 근거 필요 |
| cell·달력별 분포를 맞춘 후 clustering/RCTL | 입력과 실제 target의 좌표 및 역변환 | PLOS2018 copula clustering; GP-Copula2019; TACTiS-2; conditional normalization2023 | 단순 결합은 기존 원리와 중복. 제거할 정보와 남길 정보를 먼저 지정해야 함 |

이 판정은 Tab의 예측력이 없다는 뜻이 아니다. 60의 4cell 개발 확인에서 global_L2 Tab MAE0.06732739는 Ridge0.09019911/HGB0.10247648보다 낮았다. 이번에는 그 결과를 재실행하거나 RCTL 개선 결과로 바꾸지 않았다.

## 연결의 논리: 무엇을 제거하고 무엇을 배울 것인가

1. **잔차 표현:** 기준값 b와 보정값 r에 대해 `|y−(b+r)|=|(y−b)−r|`이다. residual 학습은 원 단위 MAE와 정확히 연결되지만, 유한 RCTL이 residual을 더 쉽게 배운다는 것은 별개다. RCTL 내부의 residual connection과 외부 target 잔차도 다르다.
2. **전체 이력을 조건으로 한 정확한 CDF:** H가 RCTL에 주는 전체 정보일 때 `U=F(Y|H)`는 조건부 uniform이다(연속 분포). U의 조건부 중앙값은.5이므로 이를 역변환한 단일 미래값 중앙값은 원래 F의 중앙값이다. RCTL이 추가 예측할 역할을 남긴 설계가 아니다. 추정된 F의 오차를 RCTL이 보정할 수는 있지만, 이때는 calibration/오차 보정 문제로 정의해야 한다.
3. **달력 Z만 조건으로 한 CDF:** `U=F(Y|Z)`는 Z에 대해서는 uniform이지만 추가 최근 이력 H까지 조건화했을 때 uniform이라고 할 수 없다. 따라서 단기 예측 정보는 남을 수 있다. 다만 F의 추정 오차와 cell별 남은 역학 차이는 별도로 존재한다. 이 원리 자체는 위 선행연구와 중복된다.
4. **비선형 변환의 손실:** 엄격 단조 변환은 이상적인 조건부 중앙값의 역변환을 허용하지만 유한 후보들의 MAE 순위를 보존하지 않는다. 설명용 한 정답100에 두 예측90/102라면 원 오차10/2다. F(90)=.48/F(100)=.50/F(102)=.90인 증가 CDF에서는 변환 오차.02/.40으로 순서가 바뀐다. 실제 데이터 결과가 아니다. 원 단위 목표를 유지하려면 역변환 후 loss를 계산해야 하며, 이것만으로 신규성이 생기지는 않는다.

## 다음 설계로 넘길 내용

단순 residual 보정, 경험 CDF를 Tab CDF로 바꾸는 방법, 조건부 정규화+기존 clustering을 새 후보로 반복하지 않는다. 다른 결정이 남으려면 최소한 (a) 실제 데이터에서 분리해야 하는 변동, (b) 단순 계절 정규화 후에도 남는 손해, (c) Tab이 더 정확하거나 싸게 추정하는 정보가 연결되어야 한다. 없는 근거를 추가 모듈로 메우지 않는다. 다음 후보는 이 세 항목을 원문과 이미 확보한 자료로 먼저 좁힌 후, 새로운 알고리즘 결정이 있을 때만 잔여 추론을 사용한다.
