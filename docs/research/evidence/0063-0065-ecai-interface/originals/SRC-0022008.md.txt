# 63: Tab 예측을 실제 RCTL 입력·target에 전달하는 방향 검토

2026-09-26. 기존 goal과 누적 예산을 유지한다. 아직 추천 방향이 아니다. 이 계획 전에는 원문 검색·열람만 했으며 새 파일 다운로드·모델 계산은 하지 않았다.

## 확인할 결정

앞선 risk 좌표 검사는 Tab 예측을 최종 RCTL에 전달하지 않았다. 이번에는 다음을 구별한다.

1. Tab의 예측을 입력 열로 추가하고 실제 관측값을 RCTL target으로 유지한다.
2. 실제값에서 Tab의 기준 예측을 뺀 잔차를 RCTL target으로 쓰고, 최종 출력에 기준 예측을 더한다.
3. 서로 다른 시간 해상도의 기준 예측과 잔차 예측을 연결한다.

세 방법 모두 기존 residual learning·stacking에 해당할 수 있다. Tab 이름, clustering 추가, 두 모듈의 결합만으로 신규성이 있다고 판단하지 않는다. 실제 RCTL의 학습 자료를 Tab이 생성한 정답으로 대체하지 않는다. 두 번째 방법은 실제 target의 가역적 표현 변경이지만, 최종 예측의 Tab 의존성과 온라인 추론 비용도 생긴다.

## 원문과 구현

- 이미 확보한 Ren·Wu, ECAI2025의 §5/Figure3/Table5–6를 추가로 읽는다. 이전28은 §3–4 중심이었다. 잔차 clustering 뒤 global 예측을 입력에 넣는 비교가 이미 있는지 확인한다. 원 PDF를 재사용한다.
- Spoek et al., arXiv2608.20024v1(2026-08-20): §3–4, §5.5–5.6, Figure2/Table7, 공식 code를 확인한다. 예측 시점에 이용 가능한 값과 잔차 target 생성, 갱신 빈도·horizon·비용 비교를 구분한다. 본 논문은 난방 수요이며 통신 traffic 실험으로 인용하지 않는다.
- 직접 참조한 multi-scale residual-aware TSFM 연구가 실제로 더 가까우면 원문을 읽는다. 초록만 확인한 자료는 방법 검토 완료 목록에 넣지 않는다.

공개 PDF는 파일당20MB, metadata/개별 정적코드는5MB 이내로 보관한다. URL·version·commit·hash·검토 절을 기록한다. 외부 코드를 실행하지 않는다.

## 기각·진행 기준

- 기존 연구와 같은 입력/target/행동이면 모델 대체안을 새 알고리즘으로 추천하지 않는다.
- MAE의 잔차 변환 등가성과 유한 RCTL 함수 집합의 차이를 분리한다. 잔차 variance 감소만으로 MAE·학습 비용 개선을 보장하지 않는다.
- 과거 잔차를 전체 기간에 fit한 predictor로 만드는 방식과 실제 예측 시점 이전 자료만 쓰는 방식을 구분한다. 시간 순서에 맞춘 target 생성 비용을 빠뜨리지 않는다.
- 실제로 새로운 문제와 다른 결정이 남을 때만 별도 최소 확인 계획을 작성한다. 이미 기각한 surrogate 거리 변형으로 되돌아가지 않는다.
