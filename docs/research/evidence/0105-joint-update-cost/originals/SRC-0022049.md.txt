# 83 정적 cluster의 재학습 단위 검토 계획

2026-09-26. 기존 goal과 누적 실행 상한을 유지한다. 이번 단계는 문헌·기존 코드·논리 검토다. 새 수치 진단, TabICLv2 추론, RCTL 학습을 실행하지 않는다.

## 확인할 주장

예측 관계가 변하는 시점이 비슷한 기존 cell을 고정된 cluster로 묶으면, 관계가 바뀌지 않은 cell까지 반복 재학습하는 비용을 줄일 수 있는가? TabICLv2가 관측 분포 변화와 예측 관계 변화를 구별하여 실제로 다른 유용한 partition을 정할 수 있는가?

정확도 향상을 자동으로 가정하지 않는다. 업데이트 필요성을 TabICLv2 오차로 정하는 것이 RCTL의 업데이트 필요성을 대신한다는 문제도 별도로 검사한다. 데이터에 변화가 있다는 사실만으로 재학습의 필요성이 증명되지 않는다.

## 기존 검토와 구별할 결정

- 17은 과거/최근/누적 학습 구간 선택의 예측 성능을 비교했다. 이번에는 고정된 cell partition을 재학습 비용의 단위로 쓰는 결정만 검토한다.
- 77은 시간에 따른 cell 소속 변경·모델 routing을 검토했다. 이번에는 소속을 고정하고 어느 모델을 언제 다시 학습하는지의 비용을 살핀다.
- 유지 비용을 새 목적이라고 부르는 것만으로 신규성이 생기지는 않는다. 유사한 drift를 묶는 선행 방법을 먼저 대조한다.
- 직전의 용량 방향은 실제 RCTL 코드에서 진입 여부를 먼저 확인한다. 모든 시점의 16차원 출력을 flatten하므로 최종 특징 폭은 16이 아니라 입력 길이 L에 대해 16L이다. 이를 임의 rank 제한으로 축소하여 문제를 만들지 않는다.

## 출처와 검토 범위

최대 세 편의 새로운 원문을 지정된 방법 절 중심으로 확인한다. 첫 우선순위는 Adaptive federated learning framework for predicting EV charging stations occupancy의 Fed-PPBC다. 두 번째는 Multi-stream regression model based on fuzzy drift variance matrix의 원문이다. 세 번째는 실제 통신 트래픽에서의 drift와 재학습 판단을 직접 다룬 공개 원문으로, 앞선 두 편을 확인한 뒤 필요할 때만 정한다.

검색 날짜·검색어·버전·원문 접근 여부·읽은 위치를 기록한다. 초록/검색 결과만 확인한 논문은 방법 검토로 세지 않는다. PDF는 최대 세 개, 합계 12MB 이내에서 정상 공개 경로로 확보한다. 공식 코드 정적 열람은 필요한 경우에만 하며 실행하지 않는다.

## 판단 기준

1. 이미 유사 drift를 기준으로 공유 대상을 정하는 방법이 있으면, 정확히 어떤 계산/행동이 달라지는지 먼저 제시한다.
2. 재학습 시점을 바꿀 때 예측 성능과 비용을 함께 계산한다. group 크기가 커져도 update 비용이 일정하다는 가정을 숨기지 않는다.
3. TabICLv2가 더 정확한 예측을 했다는 기존 결과를 drift 검출 정확성이나 RCTL 갱신 필요성으로 바꾸지 않는다.
4. 기존 자료에서 이 문제의 존재와 핵심 연결을 판단할 수 없다면 후보 미채택으로 남긴다. 임의 drift·업무 SLA·정답을 가진 갱신 시점을 만들어 실제 효용으로 주장하지 않는다.
5. 차별성과 직접 근거가 남을 때만 별도의 최소 확인 계획을 만든다. 이번 계획은 추가 모델 실행을 허가하지 않는다.
