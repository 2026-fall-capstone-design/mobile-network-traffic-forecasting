# 28 · 보존 원문과 공식 근거

| 보존 자료 | 역할 |
|---|---|
| [원문 28](originals/SRC-0021257.md.txt) | 당시 질문·네 문헌 판단·논리 반례·미완료 상태, 66행 |
| [method_audit_28 manifest](originals/SRC-0063064.json) | 세 PDF와 TabMGP 코드의 당시 URL·해시·크기 |
| [method_audit_28_clt manifest](originals/SRC-0063067.json) | CLT HTML·코드 두 개의 당시 URL·해시·크기 |

세 파일 12,092 bytes를 원본 그대로 보존했다. 원문 안의 과거 경로·Goal·명령·예산은 역사 자료다. 현재 안내는 [연구 기록](../../records/0028-mechanism-uncertainty.md)과 [출처 지도](../../sources/history-020.md)를 사용한다.

[manifest](manifest.json)의 `sources`는 위 세 사본, `primary_sources`는 논문 네 건·코드 세 건의 공식 링크와 실제 읽기 범위, `hash_only_sources`는 미검토 추출 txt 세 건이다. 외부 자료 전체를 사본으로 게시하지 않았다. 각 원본의 path·size·SHA256·alias와 기록 번호 0028을 연결한다.

새 모델 실행·원코드 import·무작위 실험은 없다. [결정적 산술](../../verification/history-020-logic-check.json), [코드 URL 바이트 확인](../../verification/history-020-remote-code-check.json), [주장별 대조](../../verification/history-020-primary-review.json)는 서로 다른 검수다.
