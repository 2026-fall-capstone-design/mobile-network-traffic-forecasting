# UPC 소속과 교차 예측 관계의 연결 — 실행 전 계획

2026-09-25. 12까지의 결과는 UPC 해석 아래의 소속 변동을 보였지만 예측 손해를 보이지 않았다. 기존 B1에서 저장한 실제 query의 교차 예측만 재사용하여 연결 가능한 범위를 확인한다. 새 모델 실행이나 RCTL 소속 조정은 없다.

## 고정한 질문과 계산

- 16개 고정 cell, context target 168~671, query target 672~839 안의 이미 고정된 64시점을 사용한다. anchor 근사 예측은 사용하지 않는다.
- A의 같은 query에 대한 B context의 MAE에서 A context의 MAE를 뺀 값을 방향별 교차 손해로 계산한다. 양방향 평균을 pair 요약으로 둔다. 이 값은 cell 간 교차 예측 차이이며 pooled context의 성능, RCTL 공동 학습 손해, 참 조건부 관계 차이가 아니다.
- 첫 28일 raw PCC와 24시간 weekday 평균 profile PCC가 이 교차 손해와 어느 정도 함께 움직이는지 Spearman 상관을 기록한다. 학습 기간과 확인 기간은 분리한다.
- 입력 지원을 따로 진단한다. 모든 context 입력으로 고정한 StandardScaler를 사용한다. source cell context에서 같은 날을 제외한 8번째 이웃 거리의 95% 분위수를 참고선으로 삼는다. target query와 source context의 8번째 이웃 거리가 이 참고선 이하인 비율을 기록한다. 이는 입력 근접성 진단이며 참 관측 지원 판정이나 보장된 통계 임계값이 아니다. 결과로 cell을 제외하지 않는다.
- 11의 모든 UPC 해석별 소속을 16 cell에 제한하여 실제 포함 cell 수와 cluster 크기를 적는다. cluster 내부와 외부의 교차 손해 평균, 크기를 보존한 1,000회 무작위 소속에서의 내부 평균 분포를 기록한다. 새 clustering 성능 검증이나 독립적인 유의성 검정으로 부르지 않는다.
- 주 해석 daily_profile/K3/ascending의 앞뒤 소속에서 pair 관계가 유지/변경된 네 경우의 교차 손해를 모두 보고한다. 소속 변동만으로 피해를 선언하지 않는다.
- seed 20260925. 저비용 계산 60초, RSS 2 GiB 이내. 기존 prediction 파일과 계획의 SHA-256을 결과에 기록한다.

## 결과별 판단

PCC나 입력 지원으로 교차 손해가 잘 설명되거나 UPC 내부 손해가 작으면 ‘UPC가 놓치는 큰 예측 관계 충돌’을 이 자료로 주장하지 않는다. 반대 결과도 TabICL 기준에서 관찰한 불일치일 뿐 공동 학습 개선의 증명이 아니다. 어느 경우에도 이 진단만으로 새 연구 방향을 추천하지 않는다. 목표는 실재 문제가 어느 수준까지 확인되었는지 결정하는 것이다.
