# 같은 pooled 자료에서 cell 식별 정보의 추가 가치 — 실행 전 계획

2026-09-25. 13에서 교차 예측 오차와 입력 거리 초과 비율의 pair 순위 상관이 0.748이었다. 교차 오차를 공동 학습 손해로 해석하지 않고, 같은 pooled context에서 cell 식별 정보를 알려 줄 때 예측이 실제로 달라지는지 확인한다. 이 검사는 후보 clustering 알고리즘이나 조건부 독립성 검정의 신규성을 주장하지 않는다.

## 핵심 질문

시간·요일·lag 입력과 실제 학습 행을 모두 동일하게 유지할 때 cell ID가 TabICLv2의 확인 구간 MAE를 줄이는가? 이는 별도의 cell 구분에 사용할 예측 정보가 남아 있는지 확인하는 진단이다. ID 효과가 있다고 해서 특정 partition, model 수 또는 RCTL의 이득이 확인되는 것은 아니다. 이미 관찰한 RCTL 출력으로 규칙을 조정하지 않는다.

## 고정된 구성

- 기존 16개 cell을 모두 사용한다. source 배열은 design_data.npz와 risk_table_predictions.npz이다.
- context target 구간은 168~671이며 3주다. 한 주의 168개 시간 위치 각각에 대해 세 주 중 한 주를 seed 20260925로 선택한다. 이 168개 target 시각을 전 cell에 동일하게 적용한다. context는 16×168=2,688행이다. 각 행은 실제 input/target이며 가상 target을 만들지 않는다.
- query는 B1에 이미 고정된 672~839의 64시점, 16×64=1,024행이다. 이후 test 자료를 추가로 읽지 않는다. 같은 query와 실제 target으로 모든 조건을 비교한다.
- 조건 1: 기존 16개 시간·lag 입력만 사용한다. 조건 2: 16차원 one-hot cell ID를 추가한다. 조건 3: ID 열의 순서를 seed 20260926으로 바꾼다. 조건 2와 3의 제공 정보는 같으며 feature grouping/단일 ensemble의 표현 민감도를 확인한다.
- 회귀 TabICLv2는 pinned checkpoint, ensemble 1, CPU 4 threads, amp/fA3/offload 없음, random_state 20260925. 출력은 MAE에 맞는 median이다. 조건별로 별도 context를 준비한다. 다른 context의 cache를 섞지 않는다.
- 단순 비교는 같은 context/query의 Ridge(alpha=1), HistGradientBoostingRegressor(loss=absolute_error, max_iter=100, learning_rate=.1, max_leaf_nodes=15, min_samples_leaf=20, l2_regularization=1, early_stopping=False)이다. 각 no-ID/ID 두 조건을 실행한다. 파라미터 튜닝은 하지 않는다.
- 전체·cell별·날짜별 MAE와 ID-noID 차이를 기록한다. query 64개는 7일에 걸쳐 있으므로 서로 독립인 1,024개 표본의 유의성 검정으로 처리하지 않는다. 열 순서 변경 효과와 날짜별 변동을 그대로 보고한다.

## 예산과 결과별 행동

새 TabICL 3 contexts, query 3,072행. 누적 39 contexts/23,424행으로 기존 80/60,000 상한 이내다. 이 단계 모델 계산 8분, RSS 8 GiB 상한. 기존 RCTL 29-fit 상한은 유지하며 새 fit은 없다. cheap numeric 전체 600초 안에서 단순 비교를 수행한다. 실제 시간·hash를 보존한다.

두 ID 표현에서 일관되게 이득이 없으면 이 자료에서 'cell ID 정보를 보존하는 clustering'을 연구의 핵심 문제로 채택하지 않는다. 이득이 있으면 effect fusion 및 conditional-information clustering과 다른 결정·계산 원리가 있는지 먼저 확인한다. HGB도 비슷한 정보를 얻으면 TabICL 고유의 이득을 주장하지 않는다. 이득 크기에 업무상 합격선을 임의로 붙이지 않는다. 본 확인은 연구 필요성과 관측 정보의 진단이지 RCTL 성능 검증의 대체물이 아니다.
