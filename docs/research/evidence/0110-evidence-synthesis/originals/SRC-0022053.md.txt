2026-09-26. `84_evidence_synthesis_plan.md` 범위에서 진행했다. 이 단계는 새 연구 후보나 추가 모델 실험이 아니다. 최종 추천 방향은 미확정이며 원래 goal의 완료 조건은 유지한다.

## 구분한 판단

- 직접 예측 74: 같은 4cell·28열·context256·뒤168시간에서 Tab mean MSE0.0095798159, HGB0.0119248073, Ridge0.0143598472. 원 JSON과 대조했다. 다른 입력·cell·기간의 RCTL 숫자와 직접 비교하지 않는다.
- 소속 결정 80: input-only/raw joint/Tab/Ridge/HGB의 K4 소속이 같았다. PCC·random·untrained probe까지 같다는 뜻은 아니다. 증거 추출 코드의 최초 assert가 이 범위를 너무 넓게 잡아 중단했으며, 해당 다섯 방법을 명시하여 수정했다. 모델 호출·데이터 진단은 없었다.
- RCTL 07: 같은 K4 비교에서 Tab risk의 MAE가 실제 관측값 risk보다 두 seed에서7.02%·5.08% 컸다. globalK1의0.0710677654는 보조 기준이며 K4와 같은 모델 수 비교가 아니다. PCCbalanced를 원본UPC재현으로 표시하지 않았다.
- 사용한 기간은 현재 개발 자료다. 새로운 추천안을 검증하는 독립 최종 평가로 재사용하지 않는다.

## 새로 구체화한 비용 표

설명용 M256/Q64/k16을 고정하여 N128/1024/10000의 query 행 수를 정수 산술로 계산했다. 원자료 hash와 결과는 `84_evidence_and_workload.json`에 있다.

| N | 전체 교차 query | 방향별 후보 제한 | 선택 쌍의 양방향 평가 상한 |
|---:|---:|---:|---:|
|128|1,040,384|131,072|262,144|
|1,024|67,043,328|1,048,576|2,097,152|
|10,000|6,399,360,000|10,240,000|20,480,000|

own-query NQ는 별도다. 무방향 후보 수는 실제 중복 제거 결과로 세며, 최대 min(Nk,N(N−1)/2)다. 한쪽에서 찾은 후보가 상대 쪽에서도 선택되었다고 보고 무조건 Nk/2로 줄이지 않는다. 같은 context의 준비 결과 재사용과 context 교체·병합 후 새 준비 비용을 구분했다. 위 표는 실행 시간도, 최종 알고리즘의 검증 결과도 아니다. 후보 검색 자체가 전체 쌍이면 전체 비용을 선형이라고 부를 수 없다.

## 남은 판단

실제 네트워크의 데이터 분리·메모리·지연·갱신 주기 제약이 있는지 사용자에게 선택적 질문을 보냈다. 아직 답변이 없어 제약의 존재나 부재를 확정하지 않았다. 연구를 성립시키려 임의의 제약을 추가하지 않는다. 이 질문에 대한 답변이 없다는 이유만으로 목표가 blocked라고 표시하지 않는다.

추가 RCTL fit은0회 허용, Tab 잔여11contexts/20640행을 유지한다. 이번에 비용 원장을 변경하지 않았다. 문서 수치 검증·정수 작업량 산술·문서 생성 외 새 실행이 없다. 실제 유용한 clustering 결정, 그 결정에서 TabICLv2의 실익, RCTL과의 연결이 남아 있다. 이번 중간 문서가 이 미완료 조건을 대신하지 않는다.

다음 자동 재개에서 이 문서를 다시 만들거나 이전 탈락 후보를 재실행하지 않는다. 실제 운영 조건에 대한 새 답변이 있으면 기존 결정 인덱스와 대조하여 문제 정의가 달라지는지 먼저 판단한다. 답변이 없으면 조건을 발명하지 말고 기존 근거로 판단할 수 있는 별도의 원리가 남는지를 검토한다. 어떤 후보도 새 근거 없이 추천 상태로 바꾸지 않는다.
