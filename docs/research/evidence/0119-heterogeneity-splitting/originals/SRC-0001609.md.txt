# 89 관측 이질성과 global/local 학습 결정의 연결 검토

2026-09-26. 직전88은 네 원문·공식 구현·호출 비용을 확인하고 조건부 생성 방식만의 신규성을 배제한 progress였다. 기존 fit 상한과 전체 연구 목표를 유지한다.

## 확인할 질문

35에서 확인한 global 대비 K4의 일반화 손해는 모든 분할이 무의미하다는 뜻이 아니다. 과거 자료에서 측정하는 이질성이 어떤 종류이며, 실제 global/local 선택의 이득과 어떻게 연결되는지 더 가까운 원문을 확인한다. 38에 초록만 확인한 것으로 남아 있는 forecasting heterogeneity 연구를 우선한다.

1. 서로 다른 시간 분포, 다른 조건부 예측 규칙, 다른 예측 가능성, 유한 자료·최적화 손해를 구분한다.
2. 이질성 측정에 최종 예측모델의 재학습·오차가 필요한지, 특징/입력만으로 구하는지 확인한다. RCTL 독립성에 대한 적용 범위를 명시한다.
3. global/local 우열에 실제로 쓰는 결정과 비용을 읽고 기존 conditional prediction/OT/variance 보정 후보와 동등한지 확인한다.
4. TabICLv2의 역할이 새로운 유용한 결정을 만드는지 또는 기존 이질성 추정기의 단순 교체인지 판정한다.

이번 단계는 원문·공식 코드와 기존35·38 실행 기록의 읽기 및 기호 검토다. 새 데이터 수치 진단, Tab/RCTL 호출은0이다. 새 원문은 가장 가까운 최대3편을 상세 검토하며, 실행이 필요하면 별도 계획을 고정한다. 실제 성능 재현을 한 것으로 표시하지 않는다. 기존 원문의 한계를 찾았다는 사실만으로 새 clustering 방법을 추천하지 않는다.
