# 89 이질성 측정과 RCTL 분할 필요성의 구분

2026-09-26. `89_heterogeneity_decision_scope_plan.md` 이후의 읽기·기호 검토다. 원문 2편을 확보했고, 다른 1편은 초록 확인에 한정한다. 새 수치 진단·TabICLv2 추론·RCTL 학습은 실행하지 않았다. 최종 추천안은 아니다.

## 1. 이번에 달라진 판단

특징이 비슷한 cell을 모으는 것과 분리 학습이 유리한 cell을 찾는 것을 같은 문제로 취급하지 않는다. 반대로 다양성을 크게 만들면 항상 공유 이득이 생긴다고 바꾸어 주장하지도 않는다. 이번 원문들은 이질성의 효과가 사용하는 정보, 모델의 표현 능력, 자료량과 함께 바뀐다는 근거를 제공한다. 특징 분산을 줄이거나 늘리는 새 항을 clustering 점수에 추가할 근거는 얻지 못했다.

구체적으로 다음 비교를 구별해야 한다.

| 바꾸는 것 | 판단할 수 있는 것 | 그 비교만으로 판단할 수 없는 것 |
|---|---|---|
| global 모델의 입력에 cell 또는 group 정보를 추가 | 입력에서 구분하지 못하던 차이를 알려주는 효과 | 모델을 여러 개로 나누는 추가 이득 |
| 같은 정보로 global 모델과 cluster별 모델 비교 | 유한 자료·표현 능력·학습 방식이 합쳐진 분할 효과 | 파형 차이 하나가 원인이라는 설명 |
| 주어진 context를 다른 cell의 context로 교체 | 해당 추론기에서 참고 자료를 바꾸는 효과 | 전체 관측 자료로 학습한 RCTL의 추정 오차 |
| 특징 공간의 분산이나 거리를 비교 | 정의한 특징에서의 이질성 | 최종 예측 손실과 병합 가능성 |

## 2. 원문 확인과 적용 범위

### A. Global Models for Time Series Forecasting: A Simulation Study

Hewamalage·Bergmeir·Bandara, [arXiv 2012.12485v3](https://arxiv.org/abs/2012.12485v3), 2021-03-22, 35쪽. 이번에 읽은 버전은 이 preprint이며 출판본의 모든 수정 사항을 확인한 것은 아니다.

- §2.3–2.5: 생성 규칙/계수, 시계열 길이·개수와 예측기의 복잡성을 구분한다. `GFM.GroupFeature`는 알려진 그룹을 입력으로 추가한 단일 global 모델이다.
- §4.2–4.3: 정규화·로그·window 변환을 사용하고, 신경망은 10개 초기화의 중앙값으로 평가한다. 현재 RCTL pilot과 동일 조건은 아니다.
- §5.1/Table 5–6: 자료량 실험의 범위가 DGP마다 다르며 group-feature 실험은 logistic-map에 제한된다. §6.1.6/Table 8은 group 정보를 준 RNN의 SMAPE 38.27→36.68을 보고한다.
- §7 마지막: 별도 cluster 모델을 학습하는 `GFM.Cluster`는 후속 실험으로 남긴다. 따라서 이 버전의 group-feature 결과를 clustering→여러 RCTL의 직접 검증으로 인용하지 않는다.

적용: 그룹이 유용한 정보를 담는지와 분리 학습이 유리한지를 나누어 비교한다. 알려진 생성 규칙을 사용하는 synthetic 결과는 실제 traffic에서 좋은 그룹을 찾았다는 증거를 대신하지 않는다. Table 6의 길이600과 §6.1.6의 길이240은 일치하지 않으므로 재현 설정으로 임의 확정하지 않는다. Online Appendix와 외부 코드는 이번에 실행·검증하지 않았다.

### B. The impact of data set similarity and diversity on transfer learning success in time series forecasting

Ehrig 등, [arXiv 2404.06198v2](https://arxiv.org/abs/2404.06198v2), 2024-07-05, 34쪽.

- §3/Table 1–3: 주 단위 단변량, horizon15의 DeepAR 사전학습·zero-shot·fine-tuning 비교다. `Traffic`은 도로 점유율이며 통신 cell 트래픽이 아니다.
- §5.2: source와 target 집합을 별도로 표준화한 특징의 pair 거리 중앙값을 계산한다. §5.4: 특징별 분산을 source 집합 사이에서 min–max 변환한 뒤 합한다. 절대적인 병합 임계값이 아니다.
- §6/Table 11–12: 관계의 방향뿐 아니라 불확실성이 크다. 정확도와 다양성의 기울기는 다섯 target 중 한 곳만 유의하고, 유사성–bias의 기울기는 모두 유의하지 않다. §7.2도 보장 가능한 절대 기준을 제시하지 않는다고 밝힌다.

적용: 이 결과를 근거로 무조건 동질적/다양한 cluster를 선택하지 않는다. 특징의 산포와 입력→target 관계의 차이는 별도 정보다. 이 연구의 zero-shot은 학습된 DeepAR의 전이이며 Tab의 context 교체와 동일 연산이 아니다. 본문 방법을 확인했지만 공식 재현 코드의 실행 가능성이나 같은 조건의 성능은 검증하지 않았다.

### C. Measuring time series heterogeneity for global learning

Sonnleitner, ESWA270:125666, [DOI](https://doi.org/10.1016/j.eswa.2024.125666), [SSRN 4897928](https://ssrn.com/abstract=4897928). 초록에는 LightGBM에서 13개 특징의 분산과 pooling 크기를 조사한다고 적혀 있다. publisher·SSRN 본문 요청은403, Fraunhofer 페이지 읽기는 실패했다. 따라서 특징별 부호, 통제·표본추출·튜닝·구현을 확인한 논문으로 세지 않는다. 이전38의 초록 수준 표시는 유지한다. 8–13% 등의 검색 요약 수치를 이번 연구의 근거로 추가하지 않는다.

## 3. 정보를 더 주는 효과와 모델을 나누는 효과: 자체 기호 검토

아래는 원문 정리의 인용이 아닌 자체 분해다. 실제 수치를 계산하지 않았으며 신규 알고리즘이나 RCTL 성능 보장이 아니다.

제곱손실을 사용하는 고정 모집단을 생각한다. `C`는 cell, `X`는 실제 예측 시점에 사용할 입력, `G=π(C)`는 고정한 소속이다. 참 평균 `μ_C(X)=E[Y|X,C]`와 `μ_G(X)=E[Y|X,G]`를 둔다. 실제 학습한 함수 `f̂π(X,G)`의 모집단 MSE는 다음 세 항으로 정확히 나뉜다.

`E[(Y−μ_C(X))²] + E[(μ_C(X)−μ_G(X))²] + E[(μ_G(X)−f̂π(X,G))²]`

조건부 평균의 직교성으로 교차항이0이 된다. 유한 제곱적률과 해당 정보 집합을 전제로 하며, 학습 자료/소속을 고정하고 독립적인 미래 모집단에 대해 해석한다. 마지막 항은 선택한 함수군의 최선과 실제 학습 결과 사이로 더 나눌 수 있으나 둘 다 Tab의 예측 분산과 같은 양은 아니다.

이 분해가 알려주는 것은 다음과 같다.

1. **두 번째 항은 cell 정보를 합쳐서 잃는 예측 정보다.** 파형/PCC 차이가 커도 입력X가 cell의 차이를 충분히 구별하면 이 항은0일 수 있다. 다른 cell에 단독 전이할 때의 외삽 실패도 이 항과 같지 않다.
2. **세 번째 항에는 표현·유한학습 손해가 있다.** 그룹을 잘게 나누어 두 번째 항을 줄여도, 자료를 적게 받은 RCTL의 학습 손해가 커질 수 있다.
3. **Tab 출력으로 참 평균을 대체하면 추정 문제로 바뀐다.** 그 추정기가 정확한지와 RCTL의 마지막 항이 작아지는지를 별도로 확인해야 한다.
4. **현재 pilot의 MAE에는 이 제곱 분해를 그대로 사용하지 않는다.** MAE는 조건부 중앙값 및 절대손실의 위험 차이로 비교해야 한다. 분위수 폭이나 MSE 차이를 MAE의 학습 손해로 대입하지 않는다.

같은 입력을 받는 global 함수가 각 cluster 함수군에 포함된다면, 무한 자료에서 각 cluster별 최선의 모집단 위험의 합은 global 최선보다 나쁠 수 없다. 이것은 함수의 존재에 관한 주장이다. 유한 자료로 학습한 여러 RCTL의 위험이 작다는 결론은 따라오지 않는다. 공통 학습·분할 학습의 비용도 따로 계산해야 한다.

## 4. 기존 관측과 연결되는 부분

35의 저장 checkpoint 확인에서 K4의 일곱 조건 모두 train MAE는 global보다 작고 validation MAE는 컸다. 이는 ‘기존 RCTL이 이질적 자료를 전혀 표현하지 못한다’는 설명보다 학습·일반화 조건을 먼저 살펴야 한다는 근거다. global seed가 하나이고 optimizer step, hourly 자료/입력 구성도 달라 단순 과적합의 인과 증명은 아니다.

15에서는 Tab의 cell ID 추가 이득이 평균 약0.78–1.01%였지만, 이것을 모든 가능한 clustering 이득의 상한으로 사용할 수 없다고 이미 정리했다. 이 원칙은 유지한다. 이번 A의 group-feature 실험도 입력 정보와 분리 학습을 구분해야 하는 근거이며, ID 추가를 새 후보로 재실행하지 않는다.

80에서는 input-only/raw/Tab/Ridge/HGB 기반 K4 소속이 같았다. 이질성 점수의 이름만 바꾸어 이 결과를 회피하지 않는다. 새 후보라면 **기존보다 다른 소속이 나오는 이유와 그 차이가 실제 학습의 어느 항을 줄이는지**가 함께 필요하다.

## 5. 실제 설계에 반영할 결정

- 특징 이질성 최소화/다양성 최대화를 새로운 병합 규칙으로 채택하지 않는다.
- ‘Tab이 cell 차이를 더 잘 찾는다’라는 문장으로 RCTL 분할을 정당화하지 않는다.
- 향후 분할 후보의 비교표에는 같은 소속을 group 입력으로만 쓰는 global 대안을 포함할 필요를 명시한다. 이번에는 추가 RCTL fit을 허용하거나 실행하지 않는다.
- 다음 후보가 정보 손실을 줄이는지, 학습 자료·용량·정규화·갱신 비용을 바꾸는지 먼저 하나로 특정한다. 모든 손해를 모호한 ‘이질성’으로 합치지 않는다.

이번 판단은 기존 후보를 확인된 사실에 맞게 좁힌 것이다. 목표가 요구하는 개선 방향 하나의 선택, 구현, 직접 근거 연결과 최종 Word는 아직 미완료다. 실제 외부 blocker는 없다.
