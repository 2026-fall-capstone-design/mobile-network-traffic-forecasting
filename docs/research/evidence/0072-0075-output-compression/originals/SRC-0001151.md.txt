## 새로 확인한 근접 연구와 설계상의 판단

- RMB-CLE (arXiv 2602.14231, 2026): task별 예측 교차 오차를 inverse-similarity profile로 바꾸어 cosine/average-linkage clustering, cluster별 최종 boosting. 교차 예측 오차로 task를 묶고 별도 최종 모델을 학습한다는 구조 자체는 신규성이 아니다.
- ETAP (arXiv 2602.18591, ICLR 2026): 공동 모델의 gradient affinity와 실제 subset MTL gain을 학습한 보정기를 결합한다. affinity와 실제 gain의 차이를 명시적으로 다룬다. RCTL 결과를 clustering에 넣을 수 없는 현재 조건에서는 그대로 채택할 수 없다.
- Entangled by Design (arXiv 2607.25532): tabular ICL의 spurious feature routing과 environment-stratified context를 다룬다. context 조건을 나누는 발상만으로 신규성을 주장하지 않는다.
- On the Role of Time Series Clustering in Traffic Matrix Prediction (arXiv 2604.26081): Abilene/GÉANT의 histogram/ACF/PSD 및 random clustering을 비교한다. grouping 의미보다 분할 자체가 이득일 수 있다는 직접 반론. 최종 비교에는 같은 K의 random/balanced partition이 필요하다. OD flow와 Milan grid 활동량은 구분한다.
- TabClustPFN (arXiv 2601.21656): TabICL encoder 기반의 별도 사전학습 unsupervised sample clustering 모델이다. 회귀 TabICLv2 context를 이용한 cell grouping과 같은 모델·문제가 아니다.
- Montero-Manso & Hyndman 2021 §3.3의 global 일반화 논의는 series 간 독립성과 effective sample size를 가정한다. 잔차 상관을 추가한 것만으로 그 정리를 RCTL 성능 보장으로 바꿀 수 없다.

## 아직 채택하지 않은 다음 원리 검토

함께 발생한 여러 cell의 변동이 공유 학습에서 독립적인 자료 증가를 의미하지 않을 수 있다는 문제를 살펴본다. 단, 높은 잔차 상관 자체는 곧 negative transfer가 아니며, 단순 모델의 미설명 구조·전처리 보충의 영향일 수 있다. 동시 의존성, 조건부 관계 차이, 실제 공유 이득을 구분해야 한다.

주의: TabICL에 넣는 모든 행을 유지한 채 cell별 행의 순서나 대응 시각만 바꾸면 같은 표의 순열일 뿐이다. 이를 독립성 개입 실험으로 제안하지 않는다. covariance를 이용한 단순 평균 추정의 이득이나 평균제곱오차 분해를 MAE 기반 RCTL의 이득으로 바꾸어 설명하지 않는다.

현재 추천 후보는 아직 확정하지 않았다. 추가 모델 실행 전에 가장 강한 기존 방법과 같아지는지, 데이터 의존성에 대한 새로운 결정이 실제 최종 학습에 영향을 주는지 좁혀야 한다. 자료·환경 접근성은 해결되었으며 외부 blocker는 없다.

## 16 cell의 실제 추론과 후보 수정

- 공통 64개 anchor의 예측으로 실제 query를 대신하는 첫 risk-table 후보를 실행했다. 실제 입력을 직접 예측한 MAE 0.072614에 비해 anchor 사용 MAE가 0.140444로 악화되었다. 최근값을 복원해도 0.125104여서 이 후보를 기각했다. 이 후보로 RCTL을 학습하지 않았다.
- 다음 후보는 cell의 실제 query 입력 각각에 TabICL을 적용하고, 공통 기준 예측에서 벗어나는 정도에 대한 absolute-loss 곡선을 상태별로 합산한다. 직접 입력은 보존되지만 공유 규칙의 함수군은 `f0(x)+delta_cluster,state(x)`로 제한된다. RCTL risk의 정확한 대리물이 아니다.
- 04 계획의 새 추론은 16 context × 504 sample, cell당 query 168개, 총 2688행이며 약 34.13초에 완료했다. 누적 TabICL 36 context, query 20352행. RCTL 학습은 이 기록 작성 시 0회.
- 다음 주 설계 구간의 단순 surrogate MAE: full-risk 0.085257, 실제 target 기반 risk 0.086252, KNN-risk 0.090493, median-only 0.084888, median+IQR 0.084712, global Ridge 0.089022. 이는 새 후보가 input 양자화 때문에 붕괴하는 문제는 피했지만, full distribution이나 새 partition의 우위를 보인 결과는 아니다.
- 같은 TabICL risk 추정으로 수정값을 정했을 때 PCC partition의 MAE가 0.084242로 full-risk partition보다 작았다. 따라서 현재 자료에서 clustering 개선이 입증되었다고 판단하지 않는다.
- RCTL과 surrogate의 관계가 미확인인 상태를 더 이상 문장으로 넘기지 않고, 04 계획에서 이미 정한 5 partition 및 2 seed 비교를 소속/설정 hash 고정 뒤 실행한다. 이는 후보의 사후 확인이며 결과로 clustering을 조정하지 않는다. 작은 차이와 학습 seed 변동은 구분한다.
- 공식 Keras RCTL과 Torch port의 복사된 가중치에서 forward 차이는 입력 1채널 최대 5.96e-7, 확장 9채널 최대 1.91e-6이었다. 학습 경로까지 동일하다는 뜻은 아니다. `rctl_port_check.json`.
- 직전 goal turn은 완료된 실제 추론 handle의 결과를 회수하여 다음 행동을 바꾸었으므로 progress로 분류한다. 외부 blocker는 없다.

## RCTL 완료와 B2 기각

- 29/29 fits 완료, 1,565 epochs, wall time 1,658.14초. `summarize_rctl_pilot.py`로 hash, 예측의 유한성, 전 cell·query의 누락·중복 여부를 확인했다. 최종 20일은 이제 읽은 상태다.
- TabICL risk clustering의 primary MAE는 두 seed에서 0.08732813, 0.08776006. empirical risk clustering은 0.08160040, 0.08351629. 각각 7.02%, 5.08% 불리했다. 첫 seed의 PCC 대비 2.84% 개선만으로 후보를 채택하지 않는다.
- B2는 추천안에서 기각했다. `07_rctl_candidate_decision.md`에 범위·비교·해석을 정리했다. peak 보조 지표의 일부 이득을 primary 성공으로 바꾸지 않는다.
- RCTL 29-fit 상한을 모두 사용했다. 추가 RCTL 학습은 시작하지 않는다. TabICL 누적 사용은 36 contexts, 20,352 query rows로 변하지 않았다. 기존 test를 새 설계에 참조하면 이후 개발 자료로 취급한다.

## 후속 원리 확인과 전체 자료 진단

- `08_finite_sample_information_plan.md`를 먼저 고정하고, MAE sample-median learner의 동일 조건부 분포/다른 공동 의존성 반례를 실제 계산했다. 독립 sample pooling은 MAE를 0.012957 줄였고 완전 중복 조건은 이득 0이었다. RCTL 확인으로 대체하지 않는다.
- 한 주의 실제 TabICL residual/median indicator pair 순위는 앞뒤 기간에 불안정했다. 공분산 항을 추가하는 안은 추천하지 않았다. 기존 GLS pooling·quantile score inference, PPCI의 label 조건을 원문과 비교하여 `09_additional_path_audit.md`에 기록했다.
- `10_population_scope_plan.md` 후 10,000 grid의 처음 35일만 학습 없이 진단했다. pilot은 비교적 높은 활동량 영역이며, 전체 자료의 일·주 기준 성능과 차이가 있다. B2 실패를 모든 도시 영역의 결론으로 확대하지 않는다.
- 평균 weekday profile은 앞뒤 2주에서 PCC 중앙값 0.9841로 안정적이나 peak mode 일치율은 38.23%였다. 원문 UPC의 PCC 단계가 보완할 수 있으므로 peak 값만으로 실패를 선언하지 않았다.
- `11_upc_core_stability_plan.md`의 공개된 해석을 고정한 뒤 큰 peak group의 단계 전체를 계산했다. 99.86% cell이 두 기간에 배정되었으며 주 해석 K=3에서 소속 일치율 56.64%, ARI 0.2158이었다. 배정 순서·파형 해석별 차이를 모두 보존했다. public clustering 코드와 원문 Algorithm 1이 다르고 작은 group 처리도 불명확하므로 원본 UPC 재현으로 부르지 않는다.
- 세 신규 진단의 계산 시간은 총 0.839초이며 모델 호출은 없다. `12_population_and_upc_findings.md`에 해석을 정리했다. 소속 불안정이 예측 손해인지 확인하기 전에는 새로운 연구 주제로 추천하지 않는다.
- 현재 goal은 미완료·active다. 외부 blocker는 없으며 이번 turn은 실제 RCTL 결과 회수·검증, 반례 확인, 새로운 자료 진단과 후속 판단을 만든 progress turn이다. 추천 후보가 없다는 이유만으로 완료 또는 blocked로 표시하지 않는다.
