# 73. 예측할 출력의 압축을 결정하는 clustering 후보 검토

2026-09-26. 아래는 추천 전 문헌·논리 검토 계획이다. 새 모델 실행 또는 데이터 수치 계산을 허용하지 않는다.

## 변경하려는 실제 결정

기존 UPC처럼 같은 RCTL 파라미터를 공유해도 cell마다 별도 입력을 통과시키면 예측 실행 수는 cell 수만큼 남는다. cell 묶음의 미래값을 몇 개의 공통 출력으로 표현하고, 그 출력만 RCTL로 예측한 뒤 cell별 값을 복원하는 대안을 검토한다. 단순 합계 1개로 복원했던 48–50과 달리 필요한 출력 차원과 묶음을 함께 결정할 수 있는지 본다. 원래 TCN·LSTM·이중 잔차 core는 유지하되 입력/출력 head와 실제 관측 target의 선형 변환은 명시해야 한다.

TabICLv2의 후보 역할은 과거 원시 파형의 분산이 아니라, 예측 시점에 알려진 입력으로 설명되는 미래 평균의 구조를 추정하는 것이다. 추정된 예측값의 공분산만 쓰면 teacher의 추정 오류·평활화도 압축 기준에 섞인다. 확인 구간의 실제 target으로 그 영향을 보정하는 모멘트와, 손실·계산량의 연결을 먼저 검토한다.

## 가장 가까운 연구와 확인 범위

1. ForeCA (Goerg, ICML 2013): 목적·정상성·스펙트럼 entropy·whitening·알고리즘·한계. 예측 가능한 성분 추출 자체의 선행연구다.
2. OpenReview MHQXfiXsr3, TMLR 2025: 정확한 제목/저자를 원문에서 확인한다. 검색 결과의 pooling→latent forecast→lift 및 MAE 공동학습 구조를 §3/실험에서 읽는다. 예측 공간 압축·cluster의 공동 최적화가 이미 제공하는 부분을 확인한다.
3. Yoo/Cook response dimension reduction (2008)와 공개 CSAM 2024 MBRDR 설명: 2008 원문 확보를 시도하되 미확보를 숨기지 않는다. 확인 가능한 2024 원문의 조건부 평균 보존·오차 공분산·추정 가정·학습 절차로 범위를 제한한다.

기존 HiGP/HTS-Cluster/48–50, NOMADD, conditional transform 검토를 재사용한다. 새 PDF 최대 3개, 합계 15 MB 이내. 관련 식·방법 페이지를 시각 검수한다. 검색 결과만으로 methods-reviewed라고 쓰지 않는다.

## 반드시 해결할 논리

- 선형 projection과 조건부 평균의 낮은 차원 자체는 새 기여가 아니다. 기존 predictive DR·reduced-rank regression과 동등한지 확인한다.
- 일반 MAE에는 MSE의 직교 분해를 적용할 수 없다. MSE 변경이 필요하면 원래 MAE RCTL과 다른 설정으로 명시하고 공정한 비교를 제안한다.
- 예측 가능한 출력 성분을 찾았어도 줄인 입력으로 그 성분을 예측할 수 있다는 뜻이 아니다. 출력 압축과 입력 축소를 분리한다.
- TabICLv2 mean과 median을 구별한다. 기존 median 저장값으로 conditional-mean 정리를 검증했다고 하지 않는다.
- 오차 보정 모멘트의 기대값, 추정 bias와 양의 준정부호 여부, 시간 의존성과 data split 조건을 유도한다. 단순 first-order 보정 자체를 신규 정리로 주장하지 않는다.
- RCTL의 학습 결과·예측·loss는 cluster나 출력 차원 선택에 쓰지 않는다. Tab 예측을 RCTL 정답으로 대체하지 않고 실제 관측 벡터의 변환을 학습한다.
- 계산 절감에는 입력 채널 증가·출력 복원·teacher 준비 비용도 포함한다. 모델 수 감소를 시간별 forward 수 감소와 혼동하지 않는다.

## 진행/폐기 조건

자료에서 다룰 출력 압축 문제, 기존보다 달라지는 결정, 회귀 TabICLv2의 추가 가치가 모두 남으면 작은 데이터 확인을 별도 계획한다. PCA·선형 reduced-rank·ForeCA와 같거나, teacher의 잘못된 예측을 정답처럼 압축하여 유리해지는 구조라면 해당 주장을 폐기한다. 막연한 모듈 결합이나 최종 RCTL 성능 보장으로 추천하지 않는다.

이번 원문 검토는 model 0회, numeric diagnostic 0회다. Tab 잔여15contexts/21,984query행, RCTL잔여0fit, 기존 누적 비용 상한을 그대로 유지한다.
