# 72. 예측모델의 작동 방식과 clustering의 연결 검토

2026-09-26. 새 모델·수치 진단 전에 저장한다. 이전 69–71 및 기존 기각안을 재실행하지 않는다.

## 확인할 질문

TabICLv2의 조건부 예측 차이를 최종 RCTL의 공유 이득으로 바꾸어 설명했던 문제를 피하면서, clustering이 바꿀 수 있는 실제 학습 결정을 찾는다. 단순 성능 지표 변경·context 선택·기존 손실 기반 clustering의 명칭 변경을 후보로 채택하지 않는다.

1. Ahmadi et al., Globalization for Scalable Short-term Load Forecasting, arXiv:2507.11729v1 (2025-07-15). 검색으로 처음 확인했다. §3–4, §5.2–5.5, Table 1–2와 데이터/코드 접근성을 읽는다. 전력 부하의 근거를 통신 cell의 직접 결과로 쓰지 않는다.

## 판단 기준

- 대상 모델의 학습 결과를 clustering에 넣는 방법은 RCTL 독립성 조건과 양립하는지 구분한다.
- feature-transforming/target-transforming이라는 분류 자체가 통계적 성능 보장은 아니다. TabICLv2와 RCTL을 그 명칭만으로 같은 군에 놓지 않는다.
- coefficient similarity와 예측함수 similarity, 입력 겹침, 유한 sample 수 증가의 효과를 구별한다.
- 논문에서 관측한 이득이 clustering 때문인지, 특징·정규화·모델 수·개별 최적화 차이 때문인지 확인한다.
- 신규 후보가 나오면 기존 근접 연구와 달라지는 결정, TabICLv2가 추가하는 정보, 단순 대안, 최소 확인을 별도로 구체화한다. 원문 검토만으로 성능 향상을 선언하지 않는다.
