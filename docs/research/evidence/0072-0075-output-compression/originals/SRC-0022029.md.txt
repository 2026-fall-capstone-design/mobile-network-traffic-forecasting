# 75. 입력 공유 경로의 중복 검토 중단

2026-09-26. 새 모델·자료 수치 계산 0회다. 추천안 확정이 아니다.

74에서 TabICLv2의 직접 예측력이 확인되어, 다른 cell의 과거를 추가 입력으로 쓰는 경로를 다시 살폈다. 하지만 기존 `47_input_sharing_findings.md`를 대조한 결과, 이 행동의 구분·DIC-ST·Markov boundary·양방향 의존성과 공동 함수 충돌·비용은 이미 검토했다. 75를 별도의 새로운 알고리즘이나 해결한 문제로 계산하지 않는다.

추가 검색은 다음 선행 구조도 확인했다. 이 항목은 검색/공식 초록 범위이며 전체 방법을 읽었다고 쓰지 않는다.

- Hmamouche 등의 Granger graph clustering 기반 feature selection(2017). 추가 입력의 중복을 graph clustering으로 조절하는 발상도 기존에 있다.
- Huang/Qin, Computers & Chemical Engineering2025, DOI10.1016/j.compchemeng.2025.109214: Granger coupling→graph/community→LSTM이라는 출판사 초록·방법 개요. 현재 통신 결과로 이전하지 않는다.
- Ohmori 등2025, DOI10.5954/icarob.2025.gs6-2: pairwise 검사 대신 조합 검사를 제안하는 공식 metadata 초록. 모든조합의 계산량을 해결했다고 추정하지 않는다.
- PriorLabs의 공식 awesome-tabpfn 목록은 feature relevance testing/conditional Shapley 등의 별도 연구를 연결한다. Tab을 입력 중요도 추정에 썼다는 사실만으로 신규성을 주장할 수 없다. 링크된 연구는 이번에 본문까지 읽지 않았다.

이 방향을 지금 새로 실행하면 동일한 미확인 연결에 다시 비용을 쓸 가능성이 크다. 같은 조건의 자기cell-only Tab 비교는 유용할 수 있으나, 구체적인 신규 결정이 없는 상태에서 수행하지 않는다. stage74와46의 원자료·결과를 그대로 보존하고 Tab잔여11contexts를 아낀다.

다음 후보를 제안하기 전 `candidate_decision_index.md`에서 이미 기각한 원리와 다시 열 수 있는 조건을 대조한다. 단순 모델·데이터·이름 변경만으로 새 후보라고 기록하지 않는다. 이 조치는 탐색의 반복을 줄이기 위한 것으로, 전체 연구가 불가능하거나 목표가 완료됐다는 판단이 아니다.
