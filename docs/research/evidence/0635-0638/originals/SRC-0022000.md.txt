# 636. 동일 관계 비교의 파일 저장 오류 복구

635는 입력 분류기 첫 적합·128확률 예측 뒤 `save(path, p=...)` 호출에서 종료됐습니다. helper의 위치 인자도 p라는 이름을 사용하여 생긴 TypeError입니다. 정산된3.919026899995515초·HGB1fit을 보존합니다. Tab0·RCTL0이며 과학적 성능 기각이 아닙니다. 메모리의 확률128개는 저장되지 않았고 종료 process에서 복구할 수 없습니다. meter의 query count가 저장되기 전에 실패한 점은 별도 기록합니다.

원635 source·설정·부분profile graph·실패trace·정산은 수정하지 않습니다. 별도636 wrapper가 저장 helper의 첫 인자를 `path`로 바꾸며 worker·자료·graph·threshold·quantile·배정·종료 조건은 그대로 가져옵니다. 첫 분류기 결과1fit/128행만 저장 실패 때문에 재생성됩니다. 성공한Tab나분위수실험의반복은없습니다.
