# 640. 관계 clustering의 기존 범위와 지금 확인할 기여

집중 문제는 `independent_UPC_membership_decision_information`입니다. 639의 실제 RCTL 평균 이득과 강한 HGB 대비 전반 손해를 모두 보존합니다. 이번에는 모델을 실행하지 않고, 기존267·473·116·512·634의 상세 근거와 새로운 직접 선행연구의 결정식을 비교했습니다.

## 1. 기존 연구가 이미 해결한 부분

| 가장 가까운 방법 | 무엇을 같다고 보는가 | 소속을 정하는 연산 | 현재 규칙과의 실제 차이 |
|---|---|---|---|
| Zhang·Wang·Zhu(2019), 473 재사용 | 개체별 절편을 허용한 조건부 분위수의 group 기울기 | 개체별 초기 회귀 → group quantile loss가 작은 곳에 배정 → group 회귀 재적합 | 중앙값 관계로 묶는 발상, 이질적 잡음의 허용은 기존 내용. 현재는 선형 기울기나 공동 예측 손실 대신 입력별 관계 score를 사용 |
| Yu·Gu·Volgushev(2024), 116 재사용 | 추정 오차를 고려한 개체별 회귀 파라미터 | 개별 추정치 차이를 추정 공분산으로 표준화 → spectral clustering | 개체별 한 번 추정·그룹 재적합 없는 소속 결정도 기존 내용. 현재 CDF 밀도는 예측 잡음의 밀도이며, 이 논문의 파라미터 추정 분산이 아님 |
| Yang·Chen·Li·Li(2024; 공개 원고2023), 이번 추가 확인 | 상태변수에 따라 변하는 조건부 분위수 계수 함수 | 개체별 local quantile 회귀 → 공통 상태에서 계수 함수 거리 → complete-linkage clustering → 소속 확정 후 공동 추정 | 비선형 관계·시간 의존·clustering과 최종 공동 추정의 분리도 기존 내용. 현재는 계수 함수 거리 대신 별도 구간의 실제 Y가 들어간 충돌 score를 사용 |
| Sadeghkhani(2026), 267 재사용 | 함께 예측할 때 줄어드는 실제 검증 위험 | 후보 group을 실제로 합쳐 적합하고 가장 큰 위험 감소를 주는 병합 선택 | 현재는 pooled 모델을 반복 적합하지 않지만, 그만큼 실제 공동 학습 위험을 직접 평가하지 않음 |

원문 연결: [Zhang 등 공개 원문](https://par.nsf.gov/servlets/purl/10101135), [Yu 등 v2](https://arxiv.org/html/2201.01793v2), [Yang 등 v1](https://arxiv.org/html/2303.13218v1), [Sadeghkhani](https://doi.org/10.1007/s41060-026-01197-4).

Yang 등의 §2는 `Qτ(Y|X,Z,α)=Xᵀβτ,i(Z)+ατ,i`를 사용합니다. §3.1의 거리는 공통 Z에서 두 계수 함수의 유클리드 거리 평균이며, 병합 거리는 complete linkage입니다. §3.3에서 소속을 고정한 뒤 실제 자료를 모아 다시 추정합니다. §4.1의 정상성·mixing·양의 밀도·매끄러움·group 분리 조건까지 읽었습니다. 16개 입력의 임의 비선형 회귀를 모두 해결한 논문은 아니지만, 이를 선형 방법으로 축소하거나 시간 의존을 무시한 논문으로 설명할 수 없습니다. 출판 정보는 JBES42(3),1026–1040(2024), DOI10.1080/07350015.2023.2277172이며 이번 방법 검토 판본은 arXiv v1입니다.

116의 공분산 거리,473의 quantile loss,267의 병합 위험을 다시 읽었으며, 전체 증명을 새로 검증했다고 표시하지 않습니다. 새로운 원문 전체 HTML의 확보와 지정 절의 내용 검토도 구분합니다.

## 2. 현재 규칙에서 남는 차이와 아직 주장할 수 없는 것

현재 규칙은 하루 profile로 찾은 이웃 중 입력이 겹치는 pair에만 점수를 만듭니다. Tab이 각 cell의 분위수 함수를 추정하고, 별도 query의 실제 정답을 이용해 `w(D−a){0.5−1[Y≤q]}`를 계산합니다. 두 시간 절반에서 cluster 내부 충돌 합이 모두 줄어들 때만 UPC의 cell 소속을 이동합니다. 639의 이득은 이 전체 규칙의 한 조건 결과입니다.

기존 함수 거리와 구별해 확인할 질문은 **같은 예측 함수를 확보했을 때, 실제 확인 정답을 이용하는 이 score가 단순한 함수 거리보다 유용한 소속을 정하는가**입니다. 가중치 재사용, 비선형 추정, 분위수, sparse graph, RCTL과의 분리 각각은 신규성이 아닙니다. 512·634의 정확한 재가중 관계도 유지하므로 새로운 직교 score를 발명했다고 주장하지 않습니다.

다른 입력 빈도나 잡음 폭을 자동 제거한다는 주장도 채택하지 않습니다. 참 조건에서 중앙값이 같으면 score의 기대값은0이지만, 다른 중앙값의 score 크기는 입력 겹침과 잡음 밀도에 따라 달라집니다. 단위는 MAE가 아니라 확률 방향입니다. 또한 실제 구현은 지원 mask 뒤 cell별 평균을 같은 비중으로 합칩니다. 학습 구간의 출처확률 p가 이 재가중된 확인 분포의 확률과 일치한다는 보장은 없습니다. 정상성·정확한 보조 추정과 올바른 평가 분포 아래의 일차 민감도 소거를 실제 유한 traffic의 검정 보장으로 옮기지 않습니다. 이는 현재 알고리즘을 폐기할 사유를 미리 정한 것이 아니라 이론적 해석의 범위를 명시한 것입니다.

22개 지원 edge 밖의 관계는 미확인입니다. 같은 cluster의 모든 pair가 적합하다는 인증이 아니며, 양의 edge 합을 줄이는 목적은 group 크기·연결 수의 영향을 받습니다. 목적값 감소만으로 이 문제가 해소됐다고 보지 않습니다. 후속 보정이나 새 threshold는 붙이지 않습니다.

## 3. 비용에서 실제 확보한 범위

후보79pair를 먼저 입력 지원으로 좁혀22pair를 평가했고14개 cell의 조건부분포를 재사용했습니다. 완료 예측은3,712개의 고유 query 행이며,635–638의 실패·복구를 포함한 실제 준비와 계산은197.0864183초입니다. 새 group마다 Tab을 다시 적합하지 않았다는 장점이 있습니다.

그러나 Yu/Yang도 개체별 추정 결과를 clustering에 재사용합니다. 공동 적합을 하는267보다 특정 비용을 줄일 가능성과, 모든 선행보다 빠르다는 주장은 다릅니다. 일반적으로 제한된 edge 수 E≤Nk에서 cell별 준비N회, query 계산 Q(N+2E) 상한으로 정리할 수 있지만, tree 검색의 최악 비용·지원 분류·분위수 출력·잘못 제외한 후보의 대가는 남습니다. 16개 cell의 실측을1만 개 전체 도시의 실행 가능성으로 확대하지 않습니다.

## 4. 판단과 필요한 최소 확인

현재 후보를 단순히 ‘TabICL을 이용한 비선형 관계 clustering’이라는 최종 주제로 채택하지 않습니다. 그렇다고 이미 얻은 소속 변경과 실제 RCTL 이득을 지우거나 원인 완전 규명을 다시 시작하지 않습니다. 남은 한 기여 주장은 실제 정답을 사용하는 관계 score의 **추가 소속 판단**입니다.

[641 고정 비교](641_cached_relation_score_ablation_plan.md)에서는 저장된 Tab/HGB 출력·동일22edge·동일 mask·동일 배정 규칙을 사용하여, 직접 중앙값 거리와 정답을 사용하지 않는 plug-in 충돌의 소속을 계산합니다. 새 모델·예측·자료 수집 없이 끝냅니다. 직접 거리는 가까운 함수 clustering의 단순 대안이며 원 논문 전체 재현으로 부르지 않습니다. plug-in은 같은 충돌 대상에서 확인 정답을 제거한 분석용 대조이며 새 후보로 채택하지 않습니다.

같은 소속이면 현재 연산의 추가 판단 기여를 주장하지 않습니다. 다르면 그 소속을 먼저 봉인하며, 차이만으로 우수하다고 하지 않습니다. 실제 효용을 확인할 필요가 남을 때만 정확한 RCTL 완료 group을 재사용하고 빠진 group의 최소 계획으로 연결합니다. 두 대조 중 좋은 결과만 선택하거나 새 seed·기간으로 구제하지 않습니다.

640의 새 모델·traffic 수치·예약·원장 변경은0입니다. 초기280/445 통합과633의 인계 적용은 재사용했으며, 기존 문서 전체 재작성과 완료 실험 반복은 없습니다. 최종 신규성·전체 연구 산출물은 미완료입니다.
