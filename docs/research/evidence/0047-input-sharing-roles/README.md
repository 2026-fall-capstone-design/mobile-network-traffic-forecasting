# 47 입력 역할·문헌·논리·작업량 근거

[팀용 기록](../../records/0047-input-sharing-roles.md), [출처별 열람 범위](../../sources/history-028.md), [검수](../../verification/history-028.md)를 먼저 읽는다. [manifest](manifest.json)에 원본23개와 별도 UPC 참조의 버전·해시·접근 방법을 남겼다.

- `originals/`의 새7개는 로컬 입수·렌더 코드3개와 기록 JSON4개다. 9,102 bytes와 원래 줄바꿈을 그대로 보존했다. 코드 사본은 `.py.txt`이며 실행하지 않았다.
- 45 계획·47 원문·snapshot10 manifest는 [H027의 정확 사본](../0045-0046-input-stability/README.md)을 재사용했다. 46 저장 예측·비용 근거도 그 묶음에 있다.
- 논문2개·GECOS·지정 PNG6개는 metadata9개로, 미독해 TXT/HTML4개는 해시만의 metadata로 구분했다. 공식 링크에서 같은 버전을 확인하고 manifest 해시로 저장본을 식별한다. 원자료·모델·전체 실행 환경은 여기서 재배포하거나 재현하지 않았다.
- [원논문 대조](../../verification/history-028-primary-check.json)는 표5행·34수치와 선택 수식의 위치를 기록한다. [논리/작업량 확인](../../verification/history-028-logic-check.json)은 정확한 유리수 대수와 지정 비교 방식의 산술이며 새 성능 실험이 아니다.

미확인 접근 보고·나머지 논문 구간·변환 TXT/HTML 고유 내용·후속 기록은 출처 페이지에 남았다. 문헌 선택 검수 완료가 전체 패킷이나 전체 연구 아카이브 완료를 뜻하지 않는다.
