# 114 입력 반응을 이용한 cell 관계의 문헌상 중복 확인

2026-09-26. 새 모델 실행에 앞서 문헌과 적용 조건만 확인한다. 112 시각 보정의 기각과 113 크기 제약 진단은 별도 결과로 유지한다.

## 확인할 결정

값이 비슷한 두 예측기가 입력 변화에는 반대로 반응할 수 있다는 문제를 입력 미분으로 다루는 방향은, 기존 76의 Jacobian/관계 증류 및 78의 task embedding 검토와 겹칠 수 있다. 이번에는 검색에서 확인된 Bai·Zhao의 *Saliency-Regularized Deep Multi-Task Learning*을 원문과 공식 코드로 대조하여, '예측 함수의 입력 반응으로 task 관계를 정한다'는 주장 자체가 이미 알려져 있는지 확인한다.

## 읽을 범위와 질문

- 저자·출판 연도·DOI·원문 버전을 일차 출처로 확인한다. 검색 엔진의 게시 날짜를 출판 연도로 쓰지 않는다.
- 목적식, 입력 gradient를 계산하는 좌표, task별 head와 공유 표현의 관계, task 관계 행렬의 갱신을 확인한다.
- 같은 gradient에서 같은 함수로 가는 정리의 기준값·정의역 조건을 확인한다. 유한 관측점에서의 근접성과 전체 정의역에서의 등식을 구별한다.
- 여러 task의 입력이 동일한지와 다를 때의 처리, 실제 실험 대상·비교 방법·추가 비용을 확인한다.
- 논문의 gradient가 예측값의 미분인지 loss의 미분인지, 미분의 부호가 유지되는지 공식 구현에서 대조한다. 코드는 실행하지 않는다.

## 현재 연구의 채택 기준

TabICLv2를 고정 probe로 쓴다는 이유만으로 새 구조라고 하지 않는다. 최종 RCTL 학습과 분리할 수 있다는 점과 새로운 소속 결정 원리가 있다는 점은 별개다. 기존 76·78에서 확인한 입력 좌표 일관성, 공통 입력 지원, 예측값 정확도와 미분 정확도의 구별도 유지한다.

새로운 구체적 결정과 개선 근거가 없으면 이 계열에는 남은 모델 예산을 쓰지 않는다. 새 검색 결과를 읽은 사실만으로 추천 방향을 만들지 않는다. 이번 산출물은 출처·수식·코드 위치가 있는 적용 범위 검토와 다음 행동 하나다.

모델 호출·RCTL 학습·수치 실험 0. 원문과 공식 코드의 제한된 다운로드·정적 열람만 수행하며 누적 실행 상한을 바꾸지 않는다.
