## 원문과 구현에서 확인한 범위

Guangji Bai·Liang Zhao의 *Saliency-Regularized Deep Multi-Task Learning*은 KDD 2022 논문이다. arXiv 2207.01117은 2022-07-03 제출된 v1이며 DOI는 10.1145/3534678.3539442다. 날짜와 DOI는 [arXiv 원문 페이지](https://arxiv.org/abs/2207.01117)와 공식 코드의 서지 정보를 대조했다. 검색 엔진에 나온 최근 게시 날짜를 출판 연도로 사용하지 않았다.

저자 서버의 11쪽 PDF를 확보하여 §3–5와 Appendix A·D를 읽었다. 식 (1)–(4)와 증명의 기준값 조건은 3·4·10쪽을 렌더링하여 대조했다. 저자본 첫 페이지의 DOI는 placeholder이므로 공식 서지의 DOI와 구별했다. [저자 공개 원문](https://cs.emory.edu/~lzhao41/materials/papers/Saliency_Regularized_Deep_Multi_Task_Learning__KDD_22_.pdf)

SRDML은 공유 표현 위에 task별 head를 두고, head 출력의 표현에 대한 미분 차이를 관계 가중치로 규제한다. 식 (4)는 예측 loss와 정규화한 task 쌍별 항을 함께 최적화한다. 소속을 먼저 고정하는 clustering과는 다르다. 원문 §3.1은 같은 입력에 여러 task 정답이 있는 구성을 사용한다. 합성 회귀와 CIFAR-MTL·CelebA·COCO 결과를 네트워크 트래픽의 독립 clustering 성능으로 옮길 수 없다.

정리 1은 모든 입력에서의 미분 일치와 같은 기준값을 다룬다. Appendix A.2의 정리 2 전체 증명 위치에는 placeholder가 남아 있으므로 이 저자본에서 완전한 증명을 확인했다고 쓰지 않는다. 이 한계가 논문의 실제 실험을 반박한다는 뜻은 아니다.

공식 코드 commit `b65d6da39a2f92491f0982790a9bd3a3e2d5b9bf`를 고정했다. 다음은 정적 열람이며 실행·재현 결과가 아니다.

- `synthetic_train.py:114–126`은 같은 입력에서 task별 출력 gradient를 구하고 두 **부호 있는 gradient의 차이**에 L1 norm을 적용한다. 먼저 절댓값으로 특징 중요도를 만든 후 비교하는 코드가 아니다. 128–143행은 회귀 loss와 규제항으로 모델·관계 가중치를 갱신한다. 선형 task에서는 입력 gradient가 기울기 계수이므로 기존 계수 관계 학습과도 연결된다.
- `train.py:76–93`은 shared feature map에 대한 head 출력 gradient를 공간 차원으로 합친 뒤 L1 차이를 구한다. 95–123행은 모델과 관계 가중치를 각각 갱신한다. raw 입력의 모든 좌표 미분을 그대로 비교하는 연산과 구별한다.
- 공개 합성 코드의 기본값은 10 sample이며 양·음의 상수 계수 벡터를 사용한다. 원문 §5.1의 100 sample·다른 base 벡터 설정과 같지 않다. 코드를 실행하는 것만으로 논문 표를 재현했다고 할 수 없다.

## 현재 연구에 적용할 때 남는 문제

아래는 원문 결과와 구별한 이번 검토의 해석이다.

첫째, 미분이 같다는 것은 함수의 높이까지 같다는 뜻이 아니다. 예를 들어 `fA(x)=x+1`, `fB(x)=x+100`의 미분은 같지만 같은 입력에 내놓는 값은 다르다. 전체 연결된 정의역에서 미분이 같고 한 기준점의 값까지 같아야 동일한 함수를 얻는다. 정의역이 끊어져 있으면 연결 성분마다 기준이 필요하다. 유한 query에서 비슷한 미분을 관찰한 것을 이 조건과 같게 취급할 수 없다. 이 설명은 기본 미적분의 적용 조건이며 새 정리가 아니다.

둘째, 현재 cell들은 같은 시각이라도 최근 lag 입력이 다르다. 실제 관측 입력들을 연결한 차분에는 여러 특징 변화가 함께 들어 있다. 시간 sin/cos·평균 등 파생 열을 독립적으로 움직이는 미분은 실제 이력의 변화와도 다를 수 있다. 기존 76에서 확인한 입력 생성 조건이 그대로 적용된다.

셋째, TabICLv2의 예측값이 더 정확하다는 결과는 미분도 더 정확하다는 근거가 아니다. 서로 다른 context의 내부 표현 좌표를 직접 비교하는 경우에는 좌표의 비교 가능성까지 별도로 필요하다. 부호를 살렸다는 이유만으로 이 문제가 사라지지 않는다.

넷째, SRDML의 관계는 그 관계를 규제항으로 받는 학습기와 함께 정해진다. 현재 요구대로 RCTL 학습 전에 관계를 고정하려면 다른 계산기로 관계를 추정할 수는 있지만, 그 소속에서 RCTL을 실제 학습했을 때의 이점은 남는 확인 대상이다. 같은 gradient 함수끼리 모았다는 사실만으로 학습 이득을 증명했다고 할 수 없다.

따라서 76의 관계 증류, 78의 Task2Vec·전이 점수에 이어, **입력 미분의 부호를 이용하는 것 자체도 차별점으로 세지 않는다.** 새로운 자료 공유 결정을 설명하지 못한 상태에서 미분 추론·보조 loss·attention 모듈을 더하지 않는다.

## 후속 방향의 중복 점검

114 검토 중 잔차의 동시 상관으로 자료 중복을 구별하는 방향도 다시 떠올랐으나, 상세 08·09 대조에서 이미 분석한 경로임을 확인했다. 기존 한 주의 Tab 잔차 상관 순위는 앞뒤 기간에서 안정적이지 않았고, Maharaj·Inder 1999는 이미 disturbance covariance를 이용한 pooling을 다룬다. 새 계산을 하지 않았으며 새로운 발견이나 후보로 집계하지 않는다. 인덱스에 이 경로를 명시하여 재진입을 막는다.

새로 검색한 *Towards Principled Task Grouping for Multi-Task Learning*의 TMLR 2026 원문은 아직 상세 검토 전이다. 다음 행동은 그 논문의 transfer gain이 정확히 어떤 학습기·입력·정답·추가 적합을 요구하는지 확인하는 것이다. 원문의 정리가 지원하는 결정과 현재 독립 clustering이 필요한 결정을 대조한 뒤, 남는 차이가 있을 때만 새 후보 명세를 작성한다. 제목의 'principled'라는 표현을 타당성의 증거로 쓰지 않는다.
