# 53·55 SRSSS 근거 묶음

[팀 기록](../../records/0053-srsss.md) · [읽은 범위](../../sources/history-036.md) · [검수](../../verification/history-036.md) · [명세](manifest.json).

[53 계획](../0053-moghadas-thesis/originals/SRC-0021782.md.txt), [55 판단](../0052-0054-partial-observation/originals/SRC-0021824.md.txt), [취득 로그](../0053-moghadas-thesis/originals/SRC-0064355.json), [render 로그](../0053-moghadas-thesis/originals/SRC-0064358.json), [당시 열람 범위](../0053-moghadas-thesis/originals/SRC-0064359.json)는 기존 정확 사본을 재사용한다. 원문의 과거 실행·예산·후속 지시는 역사 자료다.

SRSSS PDF·추출 TXT·당시 미리보기 2장은 metadata와 [정식 논문](https://ojs.aaai.org/index.php/AAAI/article/view/9895)으로 연결한다. 기존 사본 5개·외부 참조 4개·새 복사 0개다. 자료를 받으면 명세의 SHA-256으로 검토한 버전인지 확인할 수 있다.

수치 검수는 인쇄된 표와 제한된 대수 계산이다. 원 논문 전체 복제, 실제 센서 전력 측정, 저자 모델 재현, TabICL·RCTL 새 실험은 포함하지 않는다.
