# GECOS 후속 연구 핵심 요약 975–1439

[연구기록 안내](README.md) · [이전 830–974번 요약](gecos-0830-0974-summary.md) · [공통 실험 규약](../research-protocol.md)

830–974번에서 진행 중이던 전문가 선택 실험을 마친 뒤, 여러 군집 구성에서 얻은 RCTL 예측을 결합하고 TabICLv2로 보정하는 방향을 발전시켰습니다.
**R30 평가에서 재학습 기준선의 micro MAPE 11.0544%를 8.9497%로 낮춰, 상대 19.04% 감소와 당시 두 수치 목표 충족을 확인했습니다.**

## 핵심 흐름

| 주요 기록 | 핵심 흐름 |
| --- | --- |
| 975 | **전문가 선택의 최종 평가.** Tab 분위수로 RCTL 전문가를 고른 후보의 최종 평가를 마쳤습니다. 기존 UPC 기준 대비 macro MAPE가 22.9913%에서 20.0679%로 낮아졌지만, 당시 절대 목표는 충족하지 못했습니다. |
| 997–1037 | **R30 기준선과 RCTL 예측 결합.** R30 평가로 전환하고, 기존 두 군집의 RCTL을 세 시드로 재학습해 11.0544%를 새 기준선으로 정했습니다. 네 가지 군집 구성의 RCTL 예측을 결합한 후보는 10.5438%를 기록했습니다. |
| 1137–1183 | **TabICLv2 보정과 과거 사례 확대.** TabICLv2로 RCTL 예측을 보정해 10.0159%를 얻었습니다. 같은 셀의 과거 보정 사례를 856개에서 2,864개로 늘리고 기존 보정과 결합해 9.8335%까지 낮췄습니다. |
| 1356–1428 | **TabICLv2 추가 학습, 예측 혼합과 공통 보정.** 보정값을 고르는 방식을 개선하고, 사전학습 상태와 추가 학습을 거친 TabICLv2의 예측을 혼합했습니다. 검증에서 정한 공통값을 모든 예측에서 차감하자 micro MAPE가 9.6346%에서 8.9497%로 낮아졌고, 1428번에서 두 수치 목표의 충족을 검산했습니다. |
| 1429–1439 | **목표 달성 후 군집과 입력 축소 비교.** RCTL 축소 비교에서는 전체 셀을 함께 학습하고 달력 정보를 넣은 N12의 두 시드 평균 MAPE가 가장 낮았습니다. 최종 모델의 RCTL 구성을 고정한 별도 단일 시드 비교에서 Tab 입력 17개, 12개, 8개의 MAPE는 각각 8.9497%, 8.9643%, 9.4261%였습니다. |

## 평가 조건과 한계

975번은 20/5/5 분할의 macro MAPE, R30은 전체 30일 정규화를 적용한 micro MAPE이므로 각 실험의 기준선 안에서 비교합니다.
공통값 차감으로 얻은 MAPE 개선은 일부 저활동 셀에 집중됐고, 차감 직전보다 MAE는 소폭 증가했습니다.
R30은 검증과 평가 구간이 겹치므로 별도 기간에서의 성능 확인이 남아 있습니다. 새 실험은 [공통 실험 규약](../research-protocol.md)을 따릅니다.

공식 연구 원장과 주요 결과 및 검산 기록을 바탕으로, 2026년 11월 5일 기준 975–1439번 465건의 핵심 흐름을 정리했습니다.
