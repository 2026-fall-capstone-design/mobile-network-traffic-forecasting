# 미해결 질문과 재검토 조건

현재는 59–62의 연결과 63–65의 ECAI 검토부터 작성한 부분 문서입니다. 전체 과거기록의 종합 완료를 뜻하지 않습니다. 다른 검수 기록은 [안내](README.md)와 [과거 시도 색인](prior-attempts.md)에서 찾을 수 있습니다.

## 최적 입력 길이를 실제 소속 결정과 연결할 조건

[59–62 검토](records/0059-optimal-lookback.md) 이후에도 실제 cell의 정보집합·공유량·손실 척도에서 clustering이 필요한지는 별도 질문입니다. 최초 평탄구간이나 증가 상계만으로 전체 오차의 최적 길이를 확정할 수 없습니다. 문헌의 미보유 SVG·원실행 설정/자료, 이후63번부터의 판단 연결도 남아 있습니다. 새 설계는 기존4cell·두길이·일/주lag·pooling조건과 달라진 부분 및 선택/준비 비용을 명시해야 합니다.

## 예측값·잔차가 최종 학습을 바꾸는 조건

[ECAI와65의 해당 판단](records/0063-0065-ecai-interface.md) 이후에도 실제값 target/잔차 target/최종 합성, 예측 발행 시점,군집 효과와예측기 변경 효과를어떻게구분할지가남습니다. 공개예제의in-sample잔차·전후검정잔차정의·validation/시간계측공백을먼저확인해야합니다. Fig.3(d)전체구현/실행자료와다른여섯문헌은미완료이며,모델이름을바꾼것만으로새기여가확인되지는않습니다.

## 빠른 잔차 보정이 무엇을 개선해야 하는가

[Heatload 선행 검수](records/0063-0065-heatload-residual.md) 이후에도 실제로 사용 가능한 Base·날씨의 시각, 과거 시점에 고정한 잔차와 현재 origin에서 다시 보간한 잔차의 차이, 동일 갱신 빈도의 비교군과 전체 비용이 남습니다. 단기·에너지 목표의 손익을 분리하고, 잔차 MAE 항등식만으로 유한 RCTL의 학습 이득을 확정하지 않아야 합니다. 비공개 15분 자료와 공개 hourly 자료의 재현 범위도 구분합니다.

## 잔차 학습의 선택 구간과 성능표를 어떻게 연결할 것인가

[KDD 선행 검수](records/0063-0065-kdd-residual.md)에서 초기 잔차 부호, α의 선택 분할, 실제 target·가중치, 모델 열의 정체성, ±/confidence 정의와 전체 비용을 원 구현·예측까지 연결하지 못했습니다. 우리 설계의 가설과 검증은 이러한 미확인 수치를 그대로 채택하지 않고 독립적으로 명시해야 합니다. 논문의 공백이 잔차 보정 자체의 신규성을 만들어 주지는 않습니다.

## 주변 분포를 제거한 뒤 어떤 예측 정보가 남는가

[PLOS 선행 검수](records/0064-0065-plos-copula.md)는고정증가주변변환과달력·이력별조건부변환을구분합니다. 동일lagcopula가전체조건부법칙이나최종RCTL이득을보장하지않습니다. 실제설계를계속할때는남길정보·동률/결측·시간분할·K/linkage/거리규약과전체비용을먼저명시해야합니다. 원논문을재현하려면STMA식·Figure8의WA·구현/원자료판본도확인대상입니다.

## 원논문과 공개 재구현 중 어느 조건을 비교할 것인가

[GP-Copula 검수](records/0064-0065-gp-copula.md)는원표와GluonTS재구현표를구분합니다. CDF적합창/결측·반복채움,실제factory설정,평가구간·정규화·분위수·표본수부터고정해야합니다. SD/SE표기의모순과원배열·전체비용공백이남아있으므로인쇄±값을자동수정하거나새유의성을주장하지않습니다.

## 변환 뒤 배울 정보와 실제 구현 조건은 무엇인가

[TACTiS-2 검수](records/0064-0065-tactis2.md)에서full-history PIT의단일중앙값과다변량의존을구분했습니다. 학습된근사CDF의오차보정인지공동copula학습인지먼저정해야합니다. 공개CLI의단계LR·샘플범위·정규화NLL·solar분할·보간시각은논문조건과바로동일시할수없습니다. 원실행판/config/raw배열과전체비용확인이남아있습니다.

## 조건부 정규화에서 제거할 변동과 유지할 정보

[조건부 정규화 검수](records/0064-0065-conditional-normalization.md) 뒤에도 변환의 조건집합, 미래 공변량 가용성, 시간순 분할, 잔존 의존, 원척도 손실과 비용을 정의해야 합니다. 평균·분산 정규화에 full-history PIT 중앙값 논리를 그대로 적용할 수 없으며, 척도가 달라지면 정규화 MAE 순위도 보존되지 않습니다. 공개 패키지의 재귀 bootstrap·ACF·행lag·선택 lognormal 경로는 원논문 실행판 확인과 분리해 검증해야 합니다.

## H062 이후: 표현과 보호 목적의 연결

63–65 일곱 문헌의 [종합 판단](records/0063-0065-synthesis.md)은 연결했지만, 실제 원실험·비공개 데이터·실행판·전체비용 공백은 개별 기록에 남는다. 66–68의 [저장24프로파일과기준risk반례](records/0066-0068-group-risk.md)는 확인했다. 새 보호loss로 학습한 성능이나 독립 평가를 확인한 것은 아니다.

MMR2405.01709v2(35쪽), MRI2602.04155v2(32쪽), 통신 q-FFL2502.06743v2(7쪽)의 본문 검수는 후속 기록에 연결했다. q-FFL의 표·수식은 arXiv 원문/TeX와 대조했지만 IEEE 최종 본문과 통신 구현은 미확인이다. 세 목적의 본문 비교는 [H066](records/0066-0068-objectives.md)에 통합했다. 각 문헌의 실행 근거 공백은 남는다. snapshot16의45파일 해시와 과거 complete=true도 전체내용 검토나 전체Goal 완료를 대신하지 않는다.
