# GECOS 후속 연구 핵심 요약

[연구기록 안내](README.md) · [기존 상세 기록](record-index.md) · [문제별 과거 시도](prior-attempts.md) · [공통 실험 규약](../research-protocol.md)

기록 643~773번을 다룬 2026년 10월 17일 작성 요약 문서에서 핵심 결과와 다음 과제를 정리했습니다.
아래 수치와 완료 상태는 해당 문서의 보고 내용이며, 이번 게시에서 원기록 131개나 실험 결과를 독립적으로 재검증한 것은 아닙니다.

900셀 공통 실험 기반을 마련하고, TabICL을 이용한 군집 소속 수정과 여러 후속 방법을 비교했습니다.
작은 표본에서는 개선이 있었지만, **900셀에서 강한 비교군보다 실질적으로 우수한 신규 방법은 아직 확보하지 못했습니다.**
최신 기록인 773번에서는 군집 수 확장 실험을 준비하고 실제 학습에 연결했으며, 문서 작성 시점의 최종 성능 결과는 미완료 상태입니다.

UPC는 시간 패턴으로 초기 군집 소속을 정하는 절차이고, RCTL은 군집 구성원의 자료를 모아 학습하는 예측기입니다.
U20·U14는 각각 처음 20일·14일로 만든 UPC 소속이며, T1·T2는 U14를 Tab 관계로 수정한 소속입니다. K는 군집 수입니다.

MAPE는 원시 양수 목표의 셀별 백분율 오차를 셀마다 같은 비중으로 평균한 값입니다.
708은 세 시드 53·54·55의 26~30일 평가이고, C9는 seed53의 21~25일 개발 검증입니다.
**평가 기간과 시드 수가 다른 두 결과의 수치를 직접 비교하지 않습니다.**
과거 노출 감사에서 Milan 자료와 기존 학습·예측의 중첩이 확인되어, 21~30일을 미노출 최종 확인 자료로 선언할 수 없습니다.

## 다음 확인 과제

후속 연구의 핵심 질문은 **군집 수를 늘렸을 때 예측이 좋아지는지, 같은 군집 수와 크기에서도 Tab이 단순한 대조보다 좋은 소속을 선택하는지**입니다.

- K 확장 실험을 완료하고, 같은 K·크기의 대조군 대비 추가 효과를 확인합니다.
- 과거에 노출된 Milan 평가 구간과 별도로 확인 자료를 확정합니다. Abilene은 후보지만 최종 확인 설정의 검증은 남아 있습니다.
- 자료의 시간·셀 간 의존성을 반영하는 통계 절차를 검증합니다. 문서상 최종 채택에는 U20과 강한 비교군 대비 상대 MAPE 3% 이상 개선뿐 아니라, 다중 시드·별도 자료 재확인·MAE·비용 조건도 요구됩니다.

위 과제와 채택 조건은 출처 문서에 기록된 후속 연구의 상태입니다. 팀의 새 실험은 [공통 실험 규약](../research-protocol.md)과 [실험 기록 양식](../progress/README.md)에 조건을 명시합니다.
