## 변경 기록

### 2026-10-23 — 재현 비교 기준 v1.2 적용

[개정 PDF](standards/milan-900-10min-v1.2.pdf)와 [공통 실험 규약](research-protocol.md)을 기준으로 현재 안내·결과 형식·실험 양식을 갱신했습니다.

- 전체 30일의 유한 관측으로 셀별 정규화 계수를 고정하고 원 배열·계수·역변환·최종 지표는 float64로 처리합니다.
- 제공 코드의 타깃 경계와 검증·평가 중복을 보존하며 `independent_test=false`인 재현 비교로 설명합니다.
- raw micro MAPE·micro MAE를 우선 보고하고 macro MAPE·macro MAE도 함께 저장합니다. 선택은 모델별 유효 검증표본 전체의 정규화 MAE입니다.
- 시드 점수 평균과 예측평균 앙상블을 구분하고, 앙상블 구성·가중치와 동일 예측 집합의 단순 평균 기준을 기록합니다.
- v1.0 PDF와 과거 결과의 당시 조건을 보존합니다. 문서 갱신은 연구 코드 구현이나 기존 결과의 v1.2 재평가 완료를 뜻하지 않습니다.

### 2026-10-16 — 공통 기준 v1.0 반영과 문서 탐색 정리

[문서 검토 기록](progress/2026-10-16-documentation-review.md)에서 기준 PDF와의 대응·검토 범위를 확인합니다.

- 2026-10-14 기준 PDF의 900셀·10분·입력 8개·학습/검증/평가·정규화·결측·지표·시드 규칙을 문서에 반영합니다.
- 합성 데모의 1시간·RMSE 규약과 연구용 결과 교환 형식을 구분합니다. 실행 코드·모델·저장 결과의 재평가 완료를 주장하지 않습니다.
- 과거 연구는 당시 조건을 보존하고 공통 기준과 연결합니다. 상세 123개 원번호와 나머지 519개 주제 표의 범위를 유지합니다.
- 연구 안내·색인·용어·계획의 제목 단계와 표 형식을 정돈하고 [문서 작성 기준](document-style.md)을 추가합니다.

### 2026-10-08 — 연구 주제를 기준으로 명칭과 문서 정리

- 연구 주제는 모바일 네트워크 트래픽 예측으로 유지하고, 사용할 모델과 구조는 비교 실험으로 선정합니다.
- 저장소 이름을 `tabicl-traffic-forecasting`에서 `mobile-network-traffic-forecasting`으로 변경합니다.
- 프로젝트 소개, 팀 작업 보드, 웹 표기와 관련 링크를 같은 주제로 통일합니다.
- 특정 모델을 전제로 한 연구 방향과 실험 예시를 수정하고, 모델 선정 기준을 공통 실험 규약에 기록합니다.
- 기존 기준 모델, 평가 지표, 합성 예제와 정적 웹은 비교·검증을 위한 공통 구성으로 사용합니다.
