## 변경 기록

### 2026-10-08 — 연구 주제를 기준으로 명칭과 문서 정리

- 연구 주제는 모바일 네트워크 트래픽 예측으로 유지하고, 사용할 모델과 구조는 비교 실험으로 선정합니다.
- 저장소 이름을 `tabicl-traffic-forecasting`에서 `mobile-network-traffic-forecasting`으로 변경합니다.
- 프로젝트 소개, 팀 작업 보드, 웹 표기와 관련 링크를 같은 주제로 통일합니다.
- 특정 모델을 전제로 한 연구 방향과 실험 예시를 수정하고, 모델 선정 기준을 공통 실험 규약에 기록합니다.
- 기존 기준 모델, 평가 지표, 합성 예제와 정적 웹은 비교·검증을 위한 공통 구성으로 사용합니다.
