# 데이터 준비

`sample/`에는 기본 동작을 확인할 작은 합성 데이터를 둡니다.
실제 모바일 트래픽이나 TabICLv2의 성능을 나타내는 데이터가 아닙니다.

원본은 `data/raw/`, 중간 데이터는 `data/processed/`에 보관합니다. 두 위치는 Git에서 제외됩니다.
웹에서 공개할 결과만 별도 검토하여 `web/data/`에 내보냅니다.

실제 데이터 도입 시 출처·다운로드 주소, 버전·파일 해시, 사용·재배포 조건,
대상 지역·셀·기간, 원본 단위·시간대, 집계·결측·0 처리 기준을 기록합니다.
연구 데이터 선택과 대상 기간은 아직 미정입니다.

연구 전체 결과는 Git에서 제외되는 `artifacts/<run_id>/`에 저장할 수 있습니다.
팀 저장 공간을 사용할 때는 결과 메타데이터에 위치와 접근 방법을 남깁니다.
